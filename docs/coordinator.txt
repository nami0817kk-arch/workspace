# ■ 連絡方法
#
# 現在の調整役はクラウド側（Claude Code on the web）で動いていて、PC のセッションとは
# 別のマシンにいる。**SendMessage は届かない。**PC 側の ListAgents に出ないため、
# 宛先として指定できない。セッション名も巡回ごとに変わるので、名前を宛先にしない。
#
#   1. docs/session-faq.md を読む（大半はここで解ける）
#   2. それでも解けなければ workspace に Issue を立てる。
#      タイトルの先頭に [調整役] を付ける（テンプレートあり）。2時間おきの巡回が拾う
#   3. 急ぐもの・ユーザーにしか決められない事項は、ユーザーに直接聞く
#
# PC 上のセッション同士は同一マシンなので、従来どおり ListAgents + SendMessage で
# 直接やり取りできる。速いので、PC 内で完結する相談はそちらを使ってよい。
#
# ■ 調整役にできること・できないこと
#
# できる: GitHub（PR・CI・Issue・master）の把握と判断、横断ドキュメントの整備、
#         誰の担当でもない領域の修正
# できない: PC 上の worktree 操作、ローカルのタスクスケジューラ（kabu-daily-fetch 等）
#           の生存確認、ポート9222 の Chrome 操作、PC セッションへの直接の声かけ
#
# ■ 関連ファイル
#
#   docs/sessions.md    誰が何を持っているか・異常の閾値・PC 依存の範囲
#   docs/patrol-log.md  巡回が見たものの記録（1行追記）
#
# PC 側で調整役を立て直す場合は、このファイルをそのセッション名に書き換えて push する。
# その場合は SendMessage が使えるようになるが、PC が落ちると調整役ごと止まる。
