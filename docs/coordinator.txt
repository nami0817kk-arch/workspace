# 注意: 現在の調整役は**クラウド側**（Claude Code on the web）で動いていて、PC の
# セッションとは別のマシンにいる。そのため PC 側の ListAgents に出ないことがあり、
# その場合 SendMessage は届かない。届かないときは:
#
#   1. docs/session-faq.md を読む（大半はここで解ける）
#   2. それでも解けなければ workspace に Issue を立てる。
#      タイトルの先頭に [調整役] と付けること（クラウド側から GitHub 経由で拾う）
#   3. 急ぐもの・ユーザーにしか決められない事項は、ユーザーに直接聞く
#
# クラウド側の調整役にできること: GitHub（PR・CI・Issue・master）の把握と判断、
# 横断ドキュメントの整備。できないこと: PC 上の worktree 操作、ローカルのタスク
# スケジューラ（kabu-daily-fetch 等）の生存確認、ポート9222 の Chrome 操作。
#
# PC 側で調整役を立て直したら、このファイルをそのセッション名に書き換えて push する。
