# audiogen 設計メモ

BGM と効果音をその場で合成するツールキット (`src/audiogen/`) の設計記録。

## 方針

**手続き的合成(procedural synthesis)を選び、生成 AI モデルは使わない。**

BGM / SFX を「生成する」手段は大きく2つある。

| 方式 | 長所 | 短所 |
|---|---|---|
| 生成 AI モデル (text-to-audio) | 表現の幅が広い、指示が自然言語 | API キー/課金/ネットワークが必要、生成が遅い、同じ結果を再現しにくい、ライセンス確認が要る |
| 手続き的合成(採用) | 依存ゼロ・即座に生成・完全に再現可能・パラメータで細かく制御 | 音色は合成音に限られる、生楽器やボーカルは作れない |

ラボでの試作・ゲームのプロトタイプ用途では「すぐ動く」「同じ設定なら同じ音が出る」ことの
価値が大きいため、後者を採用した。将来 text-to-audio を試す場合も、
`sfx.generate()` / `bgm.generate()` と同じ形の関数を別バックエンドとして足せばよい。

依存ライブラリは**ゼロ**。numpy も使わず、`math` / `random` / `wave` だけで完結させている。
音声は「-1.0〜1.0 の float を並べた `list`」で扱う。

## レイヤ構成

下から積み上げる形になっていて、上のレイヤは下のレイヤだけに依存する。

```
core        バッファ操作・ミックス・正規化・WAV 書き出し
  ├ oscillators   波形生成(位相積算式)
  ├ envelope      ADSR / 指数減衰
  ├ effects       フィルタ・ディレイ・リバーブ・歪み
  └ notes         音名・音階・和音・コード進行
       ├ drums    ドラム音源 + 16分グリッドのパターン
       ├ sfx      効果音プリセット
       └ bgm      曲の構成と生成
            └ cli コマンドライン
```

## 実装上のポイント

### 位相積算式のオシレータ

`oscillators.render()` は周波数を毎サンプル位相に足し込む。おかげで周波数に
`f(t) -> Hz` の関数を渡せる。レーザー音の急降下も、ジャンプ音の上昇も、
ビブラートも、すべて同じ仕組みで書ける。周波数を切り替えても波形が途切れない。

### 直流成分(DC オフセット)を出さない

デューティ比を変えた矩形波は、素朴に ±1 で作ると平均値がゼロにならない。
duty=0.125 なら DC は -0.75 にもなり、ヘッドルームを食いつぶすうえ再生時に
プチッというノイズの原因になる。`square_shape()` は上下の振幅を面積が
釣り合うように取り、duty=0.5 では通常の矩形波と一致させている。
仕上げでは `core.remove_dc()` を通して残りの偏りも取り除く。

初期実装では実測で最大 -0.22 の DC が乗っていたが、この対策後は 0.0003 以下になった。

### 継ぎ目のないループ

BGM はリバーブ/ディレイの残響が小節の終わりを越える。単純に切ると
ループ時に不自然に途切れるので、`core.wrap_tail()` ではみ出した残響を
先頭に折り返して加算している。出力長はちょうど「小節数 × 1小節」になるため、
そのまま繰り返し再生してよい。

### 再現性

`seed` を渡すと、メロディの生成もノイズ系の音色も完全に決定的になる。
気に入った素材の設定を控えておけば、いつでも同じ WAV を作り直せる。

## メロディ生成のしかた

音階上の「度数」の整数空間でランダムウォークする。

1. 小節ごとにコード進行から和音(度数)を決める
2. スタイルごとの音価リストから、1小節が埋まるまで音の長さを引く
3. 一定確率で休符にする
4. 音高は前の音から ±1〜3 度動かす。強拍ではコードトーン(和音の構成音)に
   最も近い度数へ寄せる

「常にコードトーン」では機械的すぎ、「完全にランダム」では調子外れになる。
強拍だけ和声に寄せることで、それらしい旋律になった。

## 検証結果

- テスト 226 件がパス(`pytest`)
- 全プリセットの実測: ピーク 0.6〜0.92、DC オフセット 0.0003 以下、ループ継ぎ目の段差 0.009 以下
- `bgm_calm`(キー C メジャー)の周波数解析では、C/E/G/A/B に強いエネルギーが出て、
  スケール外の C#/D#/F#/G#/A# はほぼゼロ。狙ったキーの音が鳴っていることを確認した
- 8小節の BGM 1曲(44.1kHz)の生成に数秒。全プリセット(SFX 15 + BGM 7)で約35秒
