# 情報源として使えるサイト（実測）

WebSearch 経由でのアクセス可否を実際に試した結果。
**記事の本文はどのサイトも読めない**（見出しとスニペットのみ）ので、
本文が必要なときは人が読んで貼るしかない。

## ✅ 使える

| サイト | 言語 | 備考 |
|---|---|---|
| Sky Sports | 英 | 移籍情報が厚い。Transfer Centre が使いやすい |
| ESPN | 英 | 記者名つきの記事が多く、確度の判断がしやすい |
| goal.com | 英/日 | 日本語版もある |
| kicker.de | 独 | ドイツの老舗サッカー誌。ブンデス系はここ |
| 90min.com / football365.com / tribalfootball.com | 英 | 二次的な扱いに |
| football-italia.net | 英 | セリエA |
| x.com（旧Twitter） | 各国 | ページは開けないが、**検索結果に投稿本文が出る**。投稿日はURLから分かる |

## ❌ 使えない（クローラーを恒久的にブロックしている）

BBC / The Guardian / The Athletic / New York Times / Marca / AS /
Mundo Deportivo / L'Équipe / Gazzetta dello Sport / Bild /
Telegraph / Independent / Mirror / Standard / talkSPORT / Transfermarkt

これらを使いたい場合は、人が本文をコピーして渡すしかない。

## 検索ツールの要約は信用しない

検索結果には「AIが生成した要約」が付くが、**見出しに存在しない内容を混ぜてくる**。
実際に踏んだ例:

- 移籍先が検索ごとに食い違った（同じ選手に別クラブが割り当てられた）
- 何年も前から在籍している選手を「今夏の新加入」として挙げた
- 2025年の投稿と2026年の投稿を混ぜて「今月の移籍」として並べた
- 返ってきた見出しのどこにも無い移籍（選手名・クラブ名ごと）を要約だけで断言した

**採用してよいのは、実際の記事見出し・投稿本文に書かれていることだけ。**
要約にしか出てこない情報は、別の検索で見出しレベルの裏が取れるまで使わない。

## X（旧Twitter）の集め方

x.com のページは開けない（egress で塞がれている）。取れるのは**検索結果のタイトル**だけで、
そこに投稿本文がそのまま入っている。

```
Fabrizio Romano on X: "🚨🔵🔴 Understand Alejandro Balde has informed
Barcelona about his desire to STAY at the club..." / X
→ https://x.com/FabrizioRomano/status/2092546263447146991
```

### 投稿日はURLから分かる

検索結果に投稿日は出ないが、**投稿URLの数字に時刻が埋まっている**（Snowflake ID）。
ページを開かずに投稿時刻を出せる。

```bash
python -m src.cli x https://x.com/FabrizioRomano/status/2092546263447146991
```

```
@FabrizioRomano　Fabrizio Romano（未確認）
    投稿: 2026-08-26 09:34 UTC　（79時間前）
    ! @FabrizioRomano の投稿は 79時間前のものです（24時間を超過）
```

これで「2025年の投稿が最新として混ざる」問題が消える。候補ファイルの `hours_ago` も
この数字を使う。`draft` のときにも自動で見て、古い投稿を出典にしていれば警告が出る。

### 追うアカウント

`config/sources.yaml` の `accounts` に登録する。検索リストは `python -m src.cli x` で出る。
**ここに無いアカウントの投稿は `未確認` より上に上げない。**

| アカウント | 置ける最大の確度 | 何に強いか |
|---|---|---|
| @FabrizioRomano | `未確認` | 移籍全般。完了案件は here we go |
| @David_Ornstein | `未確認` | プレミア・The Athletic |
| @MatteMoretto | `未確認` | スペイン・イタリア |
| @DiMarzio | `未確認` | セリエA |
| @TheAthleticFC | `報道` | 媒体の公式アカウント |

記者個人の投稿は、どれだけ実績があっても**それ単独では `未確認`**。
主要紙が同じ内容を報じて初めて `報道` に上がる。
クラブ・リーグ・選手の公式アカウントは `確定`。
ファンアカウントとアグリゲーターは使わない。

### 切れた投稿は補わない

検索結果のタイトルは途中で切れることがある。

```
"...So far, Julian only wanted Barcel..."
```

**切れたまま引用するか、使わないかのどちらか。** 続きを推測で補わない。
`from_search_result()` は末尾が `…` `...` のものに印を付ける。

金額はアカウントごとに数字が違うことが多い。断定せず幅で伝える。

## 翻訳して使うときの線引き

- **事実そのもの**（誰がどこへ、いつ、いくら、誰が何と発言したか）に著作権はない。
  自分の言葉で書き直して伝えるぶんには問題ない
- **記事の文章をそのまま訳して流すのは避ける**。全訳は複製にあたる
- 発言やSNS投稿を引用するときは、出典を明示し、必要な長さに留め、
  引用が本編の主役にならないようにする
- 出典URLは `sources:` に入れれば概要欄に自動で載る
