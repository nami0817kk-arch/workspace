# タイトルとサムネイルの型

参考チャンネル（まとめ系のサッカーニュース）の様式に寄せてある。
狙いは一覧で目を引くこと。ただし**煽っても、書いてあることは本当**にする。

## タイトル

```
【速報】アルバレスがバルサに行けない本当の理由
【朗報】鈴木彩艶さん、まさかの移籍先が決定ｷﾀｰ！
チェルシーが今夏だけで得た金額がこちらです…
```

取材メモの `theme.prefix` と `theme.title` から組み立てる。

### 頭の札（prefix）

| 札 | 使うとき |
|---|---|
| `速報` | いま入った確定・報道。**未確認だけの回には付けない** |
| `朗報` | 良いニュース |
| `悲報` | 悪いニュース |
| （なし） | 事実の提示、数字もの、まとめ |

`draft` は【速報】が付いているのに確定・報道の節が1つも無いと注意を出す。
噂だけの回に速報と書くと、内容と釣り合わない。

### 続きが気になる書き方

| 型 | 例 |
|---|---|
| 「〜がこちらです…」 | チェルシーが今夏だけで得た金額がこちらです… |
| 「〜が話題に…」 | ヤマルの身体に起きている異変が話題に… |
| 「〜さん、」 | 鈴木彩艶さん、早くもお墨付きを貰う |
| 「まさかの〜」 | まさかの移籍先が決定 |
| 「本当の理由」 | バルサに行けない本当の理由 |
| 反応の記号 | ｷﾀｰ！！！！ / www |

**線引き**: 中身にあることだけを煽る。動画で答えない問いをタイトルに書かない。
「衝撃の事実」と書いて事実が出てこないのは釣り。この形式の信用は
「タイトルの答えが必ず中にある」ことで持っている。

## サムネイル

**報道テロップ風**（既定）。`config/project.yaml` の `video.thumbnail_style: news`。

```
┌───────────────────────────────────┐
│ ■速報 │ 2026.08.30                        │  ← 赤フラグ＋日付
│                                           │
│           写真（選手・試合）                 │
│                                           │
│ ▌主見出し（事実を言い切る）                  │  ← 14文字くらいまで
│ ▌副見出し（誰が何と言ったか）                │  ← 18文字くらいまで
├───────────────────────────────────┤
│ ■ 海外サッカーニュース      キーワード  キーワード │  ← ティッカー
└───────────────────────────────────┘
```

取材メモに書く。

```yaml
theme:
  prefix: 速報                              # 左上の赤フラグになる
thumbnail:
  line1: アルバレスに決断の期限              # 主見出し
  line2: アトレティコ「バルサには売らない」    # 副見出し
  tags: [移籍期限まで2日, アーセナル]         # ティッカーのキーワード
```

### 書き方

- **主見出しは事実を言い切る。** 「〜か？」「〜が話題に」で逃げない。
  何が起きたのかが一目で分かることを優先する
- **副見出しは引用か具体。** 誰が何と言ったか、数字はいくつか。
  主見出しの言い換えにしない
- **タグはキーワード。** 反応の一言ではなく、選手名・クラブ名・論点を置く。
  ティッカーは煽る場所ではない

### 仕組み

- 見出しは**入る中でいちばん大きい字が自動で選ばれる**。幅は実測して確かめるので
  帯からはみ出さない。2行に折り返しても下敷きは1枚にまとまる
- 帯で画面を割らないので、**写真がそのまま残る**。素材が良いほど効く
- 写真は `assets/backgrounds/` に置いて frontmatter の `bg` で指定する。
  素材が無いときは生成したスタジアム画像が使われる

### 他のスタイル

`thumbnail_style` を変えると切り替わる。

| 値 | 見た目 | 使いどころ |
|---|---|---|
| `news` | 報道テロップ風（既定） | ニュースとして信用してもらいたいとき |
| `band` | 黄色帯＋赤帯＋反応タグ | 煽って再生数を取りにいくとき |
| `clean` | 文字組みだけ | 写真素材が無いとき |

## 尺

**2〜3分**。参考チャンネルの実測は 1:23〜2:22 だった。

`check` で想定尺が出るので、長すぎたら節を減らすか、各節の `say` を短くする。
1本1テーマなので、話を足すより削るほうが効く。
