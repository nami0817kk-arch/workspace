# 背景の作り方・差し替え方

## 同梱の背景（自前生成・権利フリー）

`python -m src.cli init-assets` で `assets/backgrounds/` に3種類が生成される。
自分で描き起こしているので、そのまま使ってよい。

| ファイル | 見た目 | 向いている場面 |
|---|---|---|
| `stadium.png` | ナイターのスタジアム（観客席＋芝） | 標準。ニュース全般 |
| `pitch.png` | 芝を大きく寄せた画 | 話題が変わったときの切り替え |
| `tactics.png` | 戦術ボード風 | 解説・図解を差し込むシーン |

下側は自動で暗く落としてあるので、白いテロップが読める。

## 指定のしかた

```markdown
---
bg: assets/backgrounds/stadium.mp4     # 動画ぜんたいの既定
---

## 章1
@bg: assets/backgrounds/pitch.png      # この章だけ差し替え
```

**静止画と動画を混ぜてよい。** 章ごとに `@bg` を変えれば画が単調にならない。
サイズ比が違う素材でも、画面いっぱいに拡大して中央を切り出すので混在できる。

## 動画を背景にする

`.mp4` `.mov` `.webm` `.mkv` `.m4v` を指定すると背景動画になる。

- 尺が足りなければ自動でループする
- 立ち絵とテロップは透過して重ねられる
- 実写の上でも文字が読めるよう、下側に暗い幕が入る

書き出しは静止画背景より時間がかかる（背景を1本につないでから重ねるため）。
構成を確認したいだけなら、静止画背景で作ってから最後に動画へ差し替えるのが速い。

## 静止画からクリップを作る

写真1枚あれば、ゆっくり寄っていく背景クリップにできる。止まった絵より動画らしくなる。

```bash
python -m src.cli make-clip assets/backgrounds/stadium.png --seconds 12
python -m src.cli make-clip pitch_photo.jpg --seconds 15 --zoom 1.25
```

## フリー素材を使うとき

この環境からは素材サイトにアクセスできないので、**素材のダウンロードは手元で**行い、
`assets/backgrounds/` に置く。よく使われる無料素材サイト:

- Pexels / Pixabay / Mixkit / Coverr … 動画・写真ともに商用利用可のものが多い
- Unsplash … 写真

サイトごとにライセンスが違う。とくに次を確認すること:

- **商用利用・収益化の可否**（YouTubeの広告収入は商用利用にあたる）
- **クレジット表記の要否**（必要なら概要欄へ。`sources:` に併記すると楽）
- **スポーツ中継の映像そのものは使えない**。試合映像・選手の写真には
  リーグやクラブ、通信社の権利がある。素材サイトにある「サッカーをする人」の
  映像と、放送の切り抜きは別物なので混同しない
