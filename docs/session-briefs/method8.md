# 方式8 — Apify の道具

最初に読むもの: `docs/monetization-plans.md`、`docs/public-identity.md`、`CLAUDE.md`、`docs/session-faq.md`、このフォルダの `_common.md`。

## 中身

Apify は「ウェブからデータを集める道具（Actor）」を売り買いする場所。道具を作って登録し、他の人や AI エージェントが使うと、
使った量に応じて取り分が入る。集客・課金・税処理は Apify が持つ。

企画書（https://claude.ai/artifact/XjtQMUycprQ7PY9Ecnvwru の方式8の節）には「当たっているのは一部」という留保がある。

## 最初にやること（順番どおりに）

1. **使う人への対応が義務かを確かめる。** 有料の道具に、不具合報告（issue）への対応や保守を求める規約・品質基準がないか。
   あるなら受託の線に当たりうる（`_common.md`）。**ユーザーに出して、続けるか決めてもらう**
2. **ストアで当たりの分布を数字で出す。** 公開されている利用数・課金形態を見て、どういう種類の道具が実際に使われているか。
   「良さそう」で作り始めない
3. 当たりが特定の種類に偏っているなら、そこに寄せるか畳むかを数字を添えてユーザーに出す

## 気をつけること

- **データを取ってくる先の規約を必ず先に確認する。** 他人の規約違反を製品にしない
- 無料枠を超えると課金が発生する。課金の可能性がある操作は実行前にユーザーへ聞く
- 流用できる資産: `platform/ai-lab` のブラウザ操作の基盤、`libs/kabutan` の取得系

Apify のアカウント・本人確認・税務情報（W-8BEN）・支払い受け取りはユーザーの担当。畳むなら理由を1行残す。
