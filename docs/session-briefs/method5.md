## 中身

パズルを**プログラムで生成**し（生成AIには作らせない。解が一意であることを保証できないため）、Amazon の自費出版（KDP）で紙の本として出す。
注文ごとに Amazon が印刷・発送する。収益は1冊ごとの印税。

**解が一意であることを機械で検証し、通らない盤面は本に入れない。** 誤った問題を1問でも載せるとレビューで致命傷になる。

## 商標は確認済み（ユーザーに頼まなくてよい）

- **「数独」は使えない。** ニコリが第16類（本）で登録（第3327502号）。第9・28・30・41類も
- **スリザーリンク・カックロ・ナンバーリンク・ましゅ等もニコリの商標。** ニコリのパズル名は使わない
- **「ナンプレ」は語としては各社が使っている**が、「実力検定ナンプレ」「はじめての、ナンプレ」など
  ナンプレを含む題名が第16類で多数登録済み。**題名を決めたら1つずつ J-PlatPat で称呼検索して重ならないことを確かめる**
- 英語圏の Amazon に出す場合の "Sudoku" の扱いは未確認

## 方式7 との関係

**同じ生成器が方式7（Reddit の日替わり）でも使える。** 生成器の出力の形（盤面・解答・難易度の受け渡し方）を決めて台帳に書く。
方式7が先に作っていたら、それを使う。同じものを2つ作らない。

KDP の登録・本人確認・税務情報（W-8BEN で米国の源泉徴収を0%に）・銀行口座はユーザーの担当。原稿と入稿データの作成はセッション。
