## 1. 社会保険（最優先）

企画書: https://claude.ai/artifact/JvCm7MmGbxE1y7gz9jEgcH（先に全部読む）

パートやアルバイトの人が「月◯万円・週◯時間」と入れると、社会保険の加入対象になるか・手取りがどう変わるかを返す計算機。
**2026年10月から対象が広がり、2035年まで5回山が来る。1回目がもう来る。** ページは数十で済む。

- 協会けんぽの料率は出所を明示すれば使える（確認済み）。数字をそのまま使って計算するのは改変に当たらない
- **料率は毎年3月に改定される。** 率の表は1箇所にまとめ、範囲外の年は黙って計算せず例外にする
  （`projects/kabu-agari-ranking/src/market_calendar.py` と `price_limit.py` が同じ考え方の先例）
- **加入の可否を断定しない。** 出すのは公表基準に照らした計算結果。最終確認は年金事務所・社労士へ、と必ず添える
- ドメインは `shaho.dailyquarry.com` を想定

## 2. 案8 IPA 過去問（ユーザーの返事待ち）

`projects/ipa-kakomon/README.md` を読む。問題文・選択肢・正解の取り出しと、1問1ページの組み立てまでできている（テスト39本）。

**ユーザーに見本を見せてあり、次の3点の判断を待っている。** 返事が来るまでは社会保険を進める。

1. 正解を最初は隠し、「正解と解説を見る」を押すと開く形でよいか
2. 解説の長さと書き方（4つの選択肢それぞれが何の説明になっているかを潰す形）
3. 出典の出し方（ページ末尾にまとめている）

見本は `python tools/build_sample.py <PDFのディレクトリ>` で作り直せる。PDF は年度ページから拾う（README の「PDF の取り方」。URL を組み立てると 404 の HTML が返る）。

図や表は線で描かれていてテキストに出ない。ルビと下付き文字（CO₂ の 2）で一度壊している。
**`needs_review` が立った問はページにしない作り**なので、そこを緩めないこと。
