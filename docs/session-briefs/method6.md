# 方式6 — Notion テンプレート

最初に読むもの: `docs/monetization-plans.md`、`docs/public-identity.md`、`CLAUDE.md`、`docs/session-faq.md`、このフォルダの `_common.md`。

## 中身

Notion（メモ・管理アプリ）で使うひな形（家計簿・タスク管理など）を作り、Notion の売り場で売る。手数料は売上の10%（企画書の値）。
**弱点は作り込みと作り手の知名度で売れ方が決まること。数で押せない。**

## 最初にやること（順番どおりに）

1. **買った人への対応が義務かを確かめる。** 売り場の規約で、作り手に問い合わせ対応・返金対応・更新を求めていないか。
   求めているなら受託の線に当たりうる（`_common.md`）。**ユーザーに出して、続けるか決めてもらう**
2. 売れているテンプレートの価格帯と、何で差がついているか（作り込みの深さ・見せ方・特定の職種向け）を実測する
3. 上位が個人の知名度で売れているなら、屋号を出したばかりのこちらは不利。その不利を埋める答えが無ければ畳んでよい

ユーザーは株・楽天の価格追跡・サッカーゲーム・YouTube の運用をしている。**自分が実際に使っている型のほうが借り物より強い。**

畳むなら理由を1行残す。
