# 方式2 — AI 画像の素材とグッズ

最初に読むもの: `docs/monetization-plans.md`、`docs/public-identity.md`、`CLAUDE.md`、`docs/session-faq.md`、このフォルダの `_common.md`。

## 中身

AI で作った画像を、素材を売るサイト（ブログや広告用の写真・イラスト）や、T シャツ・スマホケースを作って売るサイトに登録する。
集客・決済・製造・発送はサイト側が持つ。収益は1枚売れるごとの取り分。**弱点は1枚あたりの額が小さいこと。**

## 最初にやること

**何枚で採算が合うかを数字で出す。** 作り始めてから「1枚1円だった」と分かるのが一番もったいない。

- 各サイトの取り分・単価・審査・支払いの下限を一次情報で調べる
- **AI 生成画像を受け付けるかどうかがサイトごとに違う。** 断っているところ・申告が要るところ・制限なしを先に確定させる
- 「月◯円を得るには何枚要るか」を出し、現実的かどうかをユーザーに判断してもらう
- グッズの購入者対応をサイトが持つか（`_common.md` の受託の線）も確かめる

## 使える資産

画像生成は `platform/ai-lab` の imagegen。**Gemini の画像モデルは無料枠が無い**（課金を有効にしないと 429 で `limit: 0`）。
**従量課金になるものは使わない。**

採算が合わないと出たら、そう書いて畳んでよい。
