## 確認済みのこと（調べ直さなくてよい）

- **日本は受取対象国。** 支払いは Stripe 経由、最低 $10、手数料 $2.25 + 0.25%（円で受け取ると為替1%）
- **「週300人」はアプリの利用者数ではない。** 300 Weekly Active Users は**アプリが入るコミュニティ側の規模**の条件
- 今の期は **2026-08-01 〜 2026-12-31**。次の期は条件が変わりうる。1人3アプリまで

| 種類 | 条件 | 支払い |
|---|---|---|
| インストール | 300WAU 以上のコミュニティに **50件** 導入（7日維持） | $500 |
| 同 | 250件 / 1,000件 | 累計 $1,500 / $3,500 |
| 利用者 | 1日 **5,000人**（7日移動平均） | $4,000（1回限り） |
| 利用者（継続） | 5,000人超で申請 | 月次（1万人で月 $555） |

## 最初にやるのは実装ではない

**勝負どころは「面白いものを作る」ではなく「コミュニティの管理人に入れてもらえるか」。**

1. **300WAU 以上のパズル・ゲーム系コミュニティを50件、名前を挙げて一覧にする。** 50件に届かないなら最初の $500 に届かない
2. そのコミュニティの管理人が何を入れていて、何を断っているかを見る。同種のアプリが入っているなら置き換えてもらう理由が要る
3. どう持ち込むか（r/devvit での露出か、個別の mod mail か）を決める

1 が「50件も無い」なら、インストール型は諦めて利用者型（1日5,000人）に賭けることになる。別のゲームなので、方針をユーザーに出す。
