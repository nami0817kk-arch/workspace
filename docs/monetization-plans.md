## どのセッションでも守ること

- **公開名義は屋号「つるはし社」だけ。** 個人名・ユーザー名・生年を公開物に出さない
- **課金の可能性があるものは実行前にユーザーへ聞く。** 従量課金は不採用、年数千円の
  一度きりの支出は可（2026-09-24 変更）
- **アカウント作成・本人確認・支払い・各社ダッシュボードへのログインはユーザーの担当。**
  それ以外（調査・実装・文面・申請書類の下書き）は担当セッションが行う
- ドメインは `dailyquarry.com` の**サブドメインを足す**。新しく買わない
- **price-tracker に AdSense は載せられない**（楽天ウェブサービス第8条4項）。
  ほかのサイトの都合で緩めない
- 当たらなければ0円が最も確率の高い結果。**やめる基準を先に決めてから作る**

## 状態の書き方

担当セッションは、着手したら自分の行の「状態」を次のどれかにする。

`未着手` → `調査中` → `実装中` → `公開` → `様子見` → `畳んだ`

畳んだときは理由を1行で残す。**同じ案が半年後に「良さそう」と再提案されるのを防ぐ。**
