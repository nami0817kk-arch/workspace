これで毎月続けて入る保証のある方式は無くなった。どれも当たれば残るが、翌月も入る保証は無い。
いちばん近いのは方式7（Reddit）の継続支払いで、1日5,000人を超えたあとに申請すれば月次で入る。

### Reddit の条件（2026-09-25 に一次情報で確認）

出典: [Earning money on Reddit](https://support.reddithelp.com/hc/en-us/articles/37760672112660-Earning-money-on-Reddit) ／
[Developer Funds H2 2026 Terms](https://support.reddithelp.com/hc/en-us/articles/50860336905108-Reddit-Developer-Funds-H2-2026-Terms)

- **日本は対象国**。支払いは Stripe Connect 経由。最低支払額 $10、手数料 $2.25 + 0.25%、
  ドル以外で受け取ると為替に 1%
- **「週300人」は読み違いだった。** 300 Weekly Active Users は**アプリの利用者数ではなく、
  アプリが入っているコミュニティ側の規模**の条件。自分のアプリが週300人に使われる必要はない
- 現実的な最初の目標は**インストール数のほう**

| 種類 | 条件 | 支払い |
|---|---|---|
| インストール | 300WAU 以上のコミュニティに **50件** 導入（7日間維持） | $500 |
| インストール | 同 **250件** | $1,000（累計 $1,500） |
| インストール | 同 **1,000件** | $2,000（累計 $3,500） |
| 利用者 | 1日あたり **5,000人**（7日移動平均） | $4,000（1回限り） |
| 利用者（継続） | 5,000人超で申請すると月次 | 例: 1万人で月 $555 |

- **今の期は 2026-08-01 〜 2026-12-31**。次期の条件は変わりうる
- 1人あたり**3アプリまで**
- つまりこの方式の勝負どころは「面白いものを作る」ではなく、**モデレーターに入れてもらえるか**。
  作る前に、どのコミュニティに、どう持ち込むかを決めること

## どのセッションでも守ること

- **客と直接向き合い続ける形は採らない**（受託・直販・月額課金。ユーザーの言葉で「受託とかは無理」）。
  プラットフォーム経由でも、**開発者に問い合わせ対応・保守・返金対応を義務づける規約**になっていたら
  同じ線に当たりうる。見つけたら着手前にユーザーへ出すこと（方式6 Notion・方式8 Apify は特に確認）
- **公開名義は屋号「つるはし社」だけ。** 個人名・ユーザー名・生年を公開物に出さない
- **課金の可能性があるものは実行前にユーザーへ聞く。** 従量課金は不採用、年数千円の
  一度きりの支出は可（2026-09-24 変更）
- **アカウント作成・本人確認・支払い・各社ダッシュボードへのログインはユーザーの担当。**
  それ以外（調査・実装・文面・申請書類の下書き）は担当セッションが行う
- ドメインは `dailyquarry.com` の**サブドメインを足す**。新しく買わない
- **price-tracker に AdSense は載せられない**（楽天ウェブサービス規約 第10条1項(4)）。
  ほかのサイトの都合で緩めない。**楽天の API を使う新しいサイトにも同じ制約がかかる**
  （リンクだけなら、かからない。`docs/public-identity.md` 参照）
- 当たらなければ0円が最も確率の高い結果。**やめる基準を先に決めてから作る**

## 状態の書き方

担当セッションは、着手したら自分の行の「状態」を次のどれかにする。

`未着手` → `調査中` → `実装中` → `公開` → `様子見` → `畳んだ`

畳んだときは理由を1行で残す。**同じ案が半年後に「良さそう」と再提案されるのを防ぐ。**
