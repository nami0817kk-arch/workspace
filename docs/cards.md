# カードと画像

画面の上半分は、カード（引用・移籍・スコア・箇条書きなど）と写真を置くスペースになっている。
どちらも「行の下に1行足すだけ」で出せる。

## カード

frontmatter の `cards:` で定義して、行から `card:` で呼び出す。
**指定した行以降そのまま残り**、`card: none` で消える（見出しと同じ挙動）。

```markdown
---
cards:
  sky_zero:
    type: quote
    source: Sky Sports
    color: "#e2495a"
    text: "Atletico Madrid say there's 'zero per cent chance' of him joining Barcelona"
    translation: アトレティコは「バルサ移籍の可能性はゼロパーセント」だと語った
---

## 章1
キャスター: スカイスポーツは、こう報じています。
  telop: 「可能性はゼロパーセント」とアトレティコ
  source: 報道
  card: sky_zero
解説: つまり交渉のテーブルにすら着かない、ということです。
  card: none      ← ここでカードを引っ込める
```

存在しないカード名を書くと、ビルド前に行番号つきで弾かれる。

### type: quote — 引用カード

海外紙の見出しやSNSの投稿を**原文のまま**出し、下に訳を添える。
情報源が画面で分かるので、ニュース動画では効果が大きい。

| 項目 | 内容 |
|---|---|
| `source` | 媒体名。左上のチップに出る（例: Sky Sports / ESPN / Fabrizio Romano (X)） |
| `text` | 原文。英数字だけなら欧文フォントで組まれる |
| `translation` | 訳（省略可） |
| `color` | チップとアクセント帯の色 |

**原文は必ず実際に確認できた範囲だけを載せる。** 見えていない部分を補完しない。
検索結果で末尾が切れている投稿は、切れたまま `...` で止める。

### type: transfer — 移籍カード

```yaml
  move:
    type: transfer
    player: フリアン・アルバレス（26）
    from: アトレティコ・マドリード
    to: アーセナル？ / 残留？
    fee: 移籍金は1.5億ユーロ規模と報道（未確定）
```

### type: points — 箇条書きカード

```yaml
  summary:
    type: points
    title: 現時点の整理
    items:
      - バルセロナ行きはアトレティコが拒否
      - 残された道はアーセナルか残留
      - 決めるのは本人。期限まで数日
```

まとめの章に置くと、話した内容が整理されて残る。項目は5つまで。

### type: bars — 数量を比べるカード

```yaml
  compare:
    type: bars
    title: 今季の得点数
    unit: 点
    items:
      - {label: 選手A, value: 14, highlight: true}
      - {label: 選手B, value: 11}
    note: ※数値の出典をここに書く
```

同じ指標どうしの比較なので**棒は1色**で通し、注目させたい1本だけ明るくする
（色を項目ごとに変えると、色に意味があるように見えてしまう）。
数値は棒の右端に直接置く。動画なのでホバーで見せられないため。
項目は6つまで。

**数字は必ず出典を確認したものだけを載せる。** 概算や幅がある数字は `note` に明記する。

### type: reactions — 反応を並べるカード

ニュースに対する反応を吹き出しで並べる。1件ずつ出どころのラベルを付けられる。

```yaml
  reactions:
    type: reactions
    title: この移籍への反応
    items:
      - {text: 金額の問題じゃないってのがアトレティコらしい, label: X}
      - {text: 本人が納得しないと動かないだろうな, label: X}
    note: ※公開されている投稿から引用
```

項目は5件まで。`label` を省略すると出どころ表示なしになる。

**出どころの分からない発言は載せない。** 反応を集めるときの注意:

- 引用は**公開されている投稿**に限る。鍵アカウントや非公開のやりとりは使わない
- **個人が特定できる情報**（アカウント名、アイコン、プロフィール）は載せない
- 掲示板（5ch など）の書き込みは、**運営元の使用許諾が別途必要**。
  許諾なく転載すると著作権侵害になる（[5chまとめサイト運営者向けの案内](https://5ch.io/matome.html)）
- 反応そのものを動画の主役にすると、YouTube の「再利用されたコンテンツ」の
  判断に関わることがある。自分の解説を主、反応を従にしておくのが無難

### type: table — 表

```yaml
  standings:
    type: table
    title: 順位表
    columns: [順位, クラブ, 勝点]
    rows:
      - ["1", クラブA, "12"]
      - ["2", クラブB, "10"]
    highlight_row: 0     # 0始まり。省略可
```

行は6つまで。列数が合わないとビルド前に弾かれる。

## 画像

行に `image:` を書くと、同じスペースに写真が出る。白フチが付く。

```markdown
キャスター: エミレーツ・スタジアムです。
  telop: アーセナルの本拠地
  image: assets/images/emirates.jpg
```

カードと画像を両方指定すると、**画像が上・カードが下**に積まれる。
入りきらないときは全体が自動で縮む。

フリー素材の入手先とライセンスの注意は [背景](backgrounds.md) と同じ。
`assets/images/` に置く運用にしておくと管理しやすい。

**試合写真・選手の写真は素材サイトにはほぼ無い。** あるのは通信社の管理下にあるもので、
勝手には使えない。使えるのは「スタジアム」「ボール」「芝」「観客」といった
一般的な被写体だと考えておくとよい。


## サムネイル

`build` のたびに `thumbnail.png` が出る。中身は frontmatter で決める。

```markdown
thumbnail_badge: 移籍                    # 左上の小さなチップ
thumbnail_title: アルバレス\n「バルサ移籍はゼロ」   # \n で改行
thumbnail_subtitle: デッドラインデー直前   # 下の帯
date: 2026年8月29日                      # 左下
```

タイトルは**入る中でいちばん大きい字が自動で選ばれる**（3行以内、かつ他の要素と
ぶつからない高さ）。最後の行が1〜2文字だけになるときは1段階小さくして行を揃える。

サムネだけ作り直すときは `python -m src.cli thumbnail <台本>`。

## score（試合結果）

スコアを大きく置き、得点者を左右に分ける。試合結果の動画では画面の主役になる。

```yaml
  result:
    type: score
    competition: プレミアリーグ 第3節
    home: アーセナル
    away: リバプール
    score: "2 - 1"
    home_scorers: ["45' サカ", "78' ハヴァーツ"]
    away_scorers: ["67' サラー"]
    note: エミレーツ・スタジアム
```

- `home` / `away` / `score` は必須。ほかは省略できる
- チーム名は**収まる大きさが自動で選ばれる**。「浦和」から
  「ボルシア・メンヒェングラートバッハ」まで幅があるため。
  いちばん小さい字でも入らないときは末尾を `…` で詰める
- 数字は欧文フォントで組む
