# 理の書の題材を型で選ぶ

正は `C:/Users/なみ/dev/workspace/projects/naze/docs/topic-types.md`（型）と `docs/topic-demand.md`（題材の強さ）。
ここは選ぶ手順と要点。数字・当たりと外れの例は docs を読む。**自分のチャンネルの再生数からは決めない。題名・文・見た目はまねない。型だけ使う。**

2026-11-05、113 チャンネルを集め、80 チャンネル 2,666 本を「そのチャンネルの真ん中の再生数の何倍か」で比べて決めた。
基準: 10 倍以上が 7%、10 万回以上が 26%。

## 手順（題材を出す前に、この順で）

1. **問いの型を 1 つ、主の道具を 1 つ選ぶ。** A・B・C・D を先に考える
2. **型の条件を満たす**（下の表）。外れの形（7 つ並べる・歴史の順・教科書の答え・制度や会社が理由・経済の「だけ」）にしない
3. **題材そのものの強さを見る**（下の「題材の強さ」）。当たっていない題材なら、型を変えるか題材を変える
4. **同じ題材を YouTube で検索する。** 先行があれば、道具が違うときだけ出す。同じ題名の写しは外れる（120万 → 1.6万）
5. **同じ国・同じ場所を続けない**（247万のあと 11万）
6. **題名の確かめ方は「計算」と書かず、見せ方で書く**（海を抜く・同じ縮尺で並べる・断面で見る）。題名に「計算・検証」を出して 10 倍以上になった回は 23 本中 0 本
7. **一行の引きで番号を振ってユーザーに出し、○× をもらう。** ○× はユーザーが付ける

ユーザーが「調べて」と言ったときは、候補を足さずに調べた結果だけを出す（2026-11-05 に 2 回、候補を出して「違う」「候補出しではなく」と言われた）。

## 問いの型 10 個（強い順）

| 型 | 問いの形 | 条件 | 道具 |
|---|---|---|---|
| **A 水の行方** | ここの水は、どこから来て、どこへ消えるのか。なぜ埋まらない・蒸発しない・あふれないのか | 誰でも知る場所（湖・川・山・島・温泉・国）の水。家や乗り物の中の水、宇宙の水は外れ | 抜く＋計算する |
| **B いる** | こんな所に、なぜ人・町・魚がいるのか。何で暮らしているのか | 「水・電気・食べ物はどうしているか」まで問う。続けても落ちにくい | 測る＋抜く |
| **C 同じなのに違う** | 同じ言葉・形・場所なのに、なぜ別の国・別の姿なのか | 名指しの 2 つ。地図や見た目で双子に見える。7 か所を回らない | 並べる＋測る |
| **D できない** | それ以上の大きさ・そういう物は、なぜ無いのか | 上限や不在を、誰でも知る物（エベレスト・ゾウ・穴・飛行機）で言える。「条件 6 つ」の数え上げにしない | 計算する |
| **E いない** | 広い・近い土地に、なぜ誰も住んでいないのか | 大陸の一部・国・地方まるごとの大きさ。同じ国を続けない | 測る＋並べる |
| **F あるのに使わない** | たくさんある物を、なぜ使わない・食べない・捨てられないのか | 量を数字で言える。答えは物の性質（粒・塩・熱・毒）。好みや値段にしない | 計算する |
| **G つながらない** | 近い 2 つのあいだに、なぜ橋・道・船がないのか。なぜ行けないのか | 両岸が県・国の大きさ。距離の短さが驚き（14km）。答えは海の底・流れ・地盤 | 抜く＋測る |
| **H こわれない** | 巨大な物は、なぜ沈まない・倒れない・ぶつからないのか | いま立っている・動いている物の仕組み。作った順の歴史にしない | 計算する＋抜く |
| **I 見かけない・なのに** | 毎日見ている物は A なのに、なぜ B なのか | 町で毎日見ているのに説明できない物。「見かけない」「電気なしで動く」が特に当たる。教科書に答えがある題材は外れ | 計算する＋抜く |
| **J かたち・かたより** | 誰でも知る場所は、なぜその形なのか。なぜそこだけなのか | 地形の「だけ・真ん中・溝」。経済・文化の「だけ」と、物の形は外れ。型だけでは頼れない | 抜く＋測る |

- A・B・C は外れにくい。D・F は大当たりが出やすい。E は底が堅い
- 2 回の調べの両方で強かったのは C・D・I。B・E・G は地理のチャンネルの中でだけ確かめられた
- **もしもは型にしない。** 単独の本編にせず、章の中で「仮に 1 つ変える」見せ方として使う
- まだ作っていない型（2026-11-05）: A・B・C・E・F・G・H。これまでの回は J（チリ・富士山・地震）・D（エレベーター・ロケット・深海・作品の計算）・I（空の色）

## 測り直すとき（「型を測り直して」「他チャンネルを調べて」）

道具は `projects/naze/tools/`。YouTube のページを読むだけで、API キーは要らない。作業は scratchpad でやり、JSON は git に入れない。

```
python tools/ytpeer.py 語の一覧.txt peer.json            # 検索（今年・再生数順・4分以上）。公開3か月以内を集める
python tools/ytch.py tools/ytch_channels.txt ch.json 3   # チャンネルごとの新しい順（約90本）と人気順
python tools/ytfeat.py                                   # 題名の特徴ごとの当たりの割合（ch_all.json を読む）
python tools/yttype.py                                   # 型ごとの本数・倍率・当たりの割合
python tools/yttopic.py                                  # 題材ごとに、何チャンネルが当てたか
python tools/ytbundle.py                                 # 広い分野ごと
```

測るときの決まり（2026-11-05 に踏んだ穴）:

- **「そのチャンネルの真ん中の何倍か」で比べる。** 再生数そのままだと、大きいチャンネルの回ばかり上に来る
- **小さい集まりで決まりにしない。** 16 チャンネルで出た決まり 3 つが 35 チャンネルで消え、35 チャンネルで出た 1 つが 80 チャンネルで消えた。広げて、別のチャンネルでも出るかを確かめてから書く
- **言葉で機械的に振った数字は、外れの中身を目で読んでから書く。** 「つながる」が家系図の回を拾い、「水はどこ」がトイレの回を拾った
- **再生数の表示は「3.1万」のように小数がある。** 数字だけ抜くと 10 倍ずれる
- 公開 3 日以内の回はまだ伸びる途中なので比べない
- 型分けを直したら docs/topic-types.md とこのスキルの両方を直す（スキルは `claude-skills/` へ写してコミット）
