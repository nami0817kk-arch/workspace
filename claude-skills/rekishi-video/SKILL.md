# 歴史の地層の動画をつくる

コードと決まり: `C:/Users/なみ/dev/workspace/projects/rekishi-chiso`（**worktree を切ってから触る**）
素材（立ち絵・表情・絵画・地図）: `C:/Users/なみ/dev/output/rekishi-chiso/assets`（リポジトリに入れない）

**決まりの本体は `projects/rekishi-chiso/CLAUDE.md`。** ここは手順と関門だけ。

## コンセプト（2026-10-04 にユーザーと固めた。変えるときは聞く）

- **通説を掘る**：地表（誰もが知る通説）→ 生涯を掘る → 最後の節「見立て」で本当の姿と通説が生まれた理由
- 剣崎雌雄（掘る案内人）× 春日部つむぎ（驚く聞き手）の掛け合い。2人とも黄色いヘルメット。抑揚は2人とも抑えめ
- 画面：動く絵画・字幕・掘り出したメモ・地層の年表・**図（地図／グラフ／相関図／人物の比較）**・絵画の吹き出し（bubble）・1文の挿絵（icon）・表情と口パク・集中線・地層のワイプ
- BGM なし。強調語の飛び出しは使わない。最後に次回予告。サムネイルは決まった形（thumb）
- 1本30〜40分・**1日1本**（10-04 ユーザー決定）。ショートは本編から何本も。シリーズ「悪女と呼ばれた女たち」

## 手順

```
題材 → 台本 → kana → check → voice（抑揚の確認） → draft（確認用） → ユーザーの OK → approve → build → shorts → thumb → describe
```

1. **題材**：シリーズの次の人物。いちばん強い「通説」を1つ決める（それが冒頭とサムネイルになる）
2. **台本**：`scripts/_template.yaml` を写して書く。事実は出典を控え、数字は確かめたものだけ。
   言い伝えは「伝えられています」と言う。図は3つ以上（地名は `places.yaml`、無ければ座標を確かめて足す）。
   絵は Commons のパブリックドメインだけ（撮影者の CC 付きは使わない）。取ったら**1枚ずつ目で見る**（別人の絵が混じる）
3. `python -m chiso.cli kana scripts/x.yaml` で**全行の読みを見る**。読み違いは `readings.yaml` に足す
4. `python -m chiso.cli check scripts/x.yaml`：素材・見立て・次回・サムネ・図・長さ。× があれば直す
5. `python -m chiso.cli draft scripts/x.yaml --lines 40` で冒頭だけの確認用（約5分で作れる）→ コマを抜いて重なりを見る
6. `python -m chiso.cli draft scripts/x.yaml` で全体の確認用（約30分）。**見せる前にコマを抜いて確かめる**
7. 台本はページかファイルで見せる。**approve を打つのは、ユーザーがその台本にはっきり「OK」と言ったときだけ**
   （「見せて」「出す」「声はOK」は台本の承認ではない）
8. `build` → `shorts` → `thumb` → `describe`（概要欄）。`screen`（本番の動画をユーザーが見て OK と言ったときだけ）→ `upload --at "YYYY-MM-DD 19:00"`（予約投稿。字幕・サムネイル・概要欄つき）

## つまずき所

- 「作り直しは後で」「待って」と言われたら、走っている処理を**すぐ止める**（TaskStop と、残った python・ffmpeg）
- 大きい動画（200MB 超）はスマホに届かない。ユーザーは**スマホ版は要らない**と言っている
- VOICEVOX の「〜んですか」が途中で切れる癖は自動で直る。読み違いは kana で見つける
- Commons の API は回数制限がある。curl で間隔をあけて取る（Python の通信は証明書で落ちる）
- 描き方を変えたら控えの画像は自動で作り直される（描き方の指紋）。背景の動画は `work/<台本>/bg` に控え
