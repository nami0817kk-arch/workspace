## 参考から決めた型（数は調べの値）

| 項目 | 決まり | 根拠 |
|---|---|---|
| 絵 | 全面。常設のパネル（肖像の額・メモ欄・年表帯）なし。主役は表情のあるAI絵、古画・古写真は額や部分で | 参考15本で常設パネル0本、AI絵が主役12本 |
| 動き | **一定の速さのパン（上→下・右→左など）を、カットの最初から最後まで**。画面幅の毎秒約1.4〜2.5%。絵を1.08〜1.2倍に置いて余白を流す。縦の構図は上下、横の構図は左右。隣のカットと向きを替える。寄り（拡大）は顔の感情の場面だけ | 歴史横丁は約7割がこれ、止まった絵0% |
| 動きの意味 | **向きと止まる所を話で決める**（その行で語る物・人がカットの終わりに主役）。2人目の名前の行は、1人目から2人目へ流して入れる（明かしのパン）。**語った瞬間だけ寄る・話に関係ない寄りはしない** | ユーザー「ただ寄るとかは話に関係ないのは意味ない」、9/28 にも「写真に寄るのは不要」 |
| カット | 次の文の頭の0.1〜0.3秒前にハードカット。同じ人物の別構図だけ0.5秒の溶け合い。1カット平均10〜15秒、同じ絵は続けて20秒まで | 歴史横丁のカットは7か所全部が文の頭の直前 |
| 図 | 語りに合わせて**書き込む**（表の行・系図の札と線・地図の印と矢印）。キンブラ型：点線0.2秒→札0.25秒→小札。図の間は背景を止める | キンブラの関係図、サッカーのチャンネルの表の行の出し方 |
| 絵の中の動き | 話に合う絵だけ控えめに（炎のゆらぎと火の粉・灯のちらつき・煙/霧の流れ・水面）。`fx:` | 眠れない夜は炎や血だけ動かす。Gemini の動画（Veo）は無料版では作れない（10-25 確認） |
| 見出し | 本編＝左上の小さな札「年月日｜章題」（字は画面の高さの約2.8%）。ショート＝案Bの黒い太帯（札＋題2行、下に「いま」札と年表） | 参考で全幅の帯0本・左上の小札10本。ショートは honto 型をユーザーが選んだ（10-24） |
| 字幕 | 語りそのまま・ブロックで一度に出す（増える方式はやらない）。本編は下中央1行約24字・2行まで・話し手名なし（想像の台詞だけ「想像」札）。記録の言葉は明朝＋読んでいる所まで赤ペンの下線 | 焼き付け14/15・話し手名0/15 |
| 部品 | ①紺の「史料」「要点」の引用札 ②くい違いを3つの箱で並べ最後を赤 ③「覚えてほしい名前」3枚 ④地図の矢印・陣の印 ⑤史料の頁＋該当行の赤枠＋出典。`parts:` | 幕末裏ばなし・歴史の裏窓・AI Historia |
| 章 | 章題カード4秒（暗くした絵に「第N章」小＋章題を大きな明朝）。最後に約20秒の終了画面の空き | 7/15 |
| 音 | 声は剣崎、本編は既定の速さ、ショートは約1.3倍（1.4倍を超えない）。BGM は numpy 合成で声より約23dB 下、効果音なし | BGM 無しは0/15、中央値の差23dB |

## 作る順（本編）

1. 台本 `scripts/<題>-story.yaml`（`_template_story.yaml` を写す。冒頭は場面→ずれ→40〜80秒で1つの「なぜ」→かけら→約束→橋渡し。最後の章は「その後」）
2. 絵の割り当てと動きを `scripts/story/<題>_main_look.yaml` に（`ai:` の切り出し・`pan:`・`focus:`・`fx:`・`parts:`・`figure_extend:`・章ごとの `now`/`dates`）
3. **静止画でイメージ合わせ**：`python -m chiso.cli story-main scripts/story/<題>_main_look.yaml`（`--frames` で時点を指定）。ユーザーに見せる
4. 足りないAI絵を作る（下の「AI絵」）
5. 書き出し：`story-main … --build`（冒頭だけ試すなら `--limit 60`）。2本同時に書き出さない。空きが30GB未満なら止まる
6. 確かめ：全編のデコード検査（壊れ0）、2分ごとのコマ一覧、`scratchpad/mainana` の物差し（`changes.py`・`analyze.py`・`audio.py`）で参考と比べる。確認用は480p・20MB前後（スマホに届く大きさ）

## AI絵（Gemini を Chrome で操作）

- API の Gemini は画像に無料枠が無い。Cloudflare FLUX は質が弱く、1日の枠も切れやすい。Pollinations は透かしが入る。**gemini.google.com を Claude in Chrome で操作するのが既定**（ユーザーのログイン済み・無料版）。
- 同じ会話の中で作ると人物がそろう。別の会話・アカウントでは、前の人物の絵2枚を `file_upload` で添付する（画像の file input は「アップロードとツール」メニューを開いている間だけ DOM にある。JS で表示させて ref を取る）。
- 「添付の女性と同じ顔で」と書くと断られることがある → 顔立ちを言葉で書く（細面・切れ長の目・髪型・着物の色）。
- 1日の無料枠が切れると「対応できません」「テキストベースのAIなので」と返る、またはフルサイズのダウンロードが止まる → **ユーザーの指示どおり別のアカウントに切り替える**（左下のアカウントのメニュー。パスワード入力が要るならそこで止めて聞く）。
- 保存はフルサイズのダウンロード（最後の `button[aria-label*=ダウンロード]` を JS で押す）→ `~/Downloads` に `.jfif`。取り違えないよう、作るたびに保存して名前を付け、最後に一覧画像で全部を目で見る。ユーザーの他のファイルには触らない。
- 実在の人物の顔写真・肖像の加工はしない。実在の俳優に似た顔が出たら作り直す。顔が別人に見えたら作り直す。
- 文字・署名・家紋・額の字が入った絵は、作り直すか、切り出しで外す。

## してはいけないこと

- 話に関係ない寄り・パン（向きと終点を話で決めないパン）。
- 効果音・派手な効果（参考のどちらも粒子・光の筋・画面の揺れは使っていない）。
- 冒頭のあいさつ・章の予定の説明・断り書き・掛け合い。
- 動画を見せる前の投稿（screen の関門は変わらず）。
