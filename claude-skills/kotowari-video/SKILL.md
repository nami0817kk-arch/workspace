# 理の書の動画をつくる

チャンネル: [@kotowari_no_sho](https://www.youtube.com/@kotowari_no_sho)（運営：のこぎり社。2026-10-26 に旧 棒人間ストーリーを作り替えた）
コード: `C:/Users/なみ/dev/workspace/projects/naze`（**worktree を切ってから触る**。2026-10-26 時点はブランチ `claude/naze`、worktree `dev/wt-naze`）
出力: `projects/naze/out/<題材>/`（gitignore）。鍵はリポジトリの外（`dev/output/yononaka-danmen/secrets/token.json`）

**決まりは `projects/naze/CLAUDE.md`、台本の書き方は `projects/naze/docs/writing.md`。** ここは手順と関門だけ。
コマンドは `python -m naze <手順> episodes/<題材>`（VOICEVOX を先に起動。Blender は既定のパス）。

## 基本形（2026-10-26 ユーザー決定）

- **題材 1 つ → 本編 1 本（横 1920×1080・15 分前後・5 章）＋ショート 5 本（縦 1080×1920・3 分以内、目安 60〜75 秒）**
- ショートは本編の切り抜きではない。章と同じ事実・同じ地点で「問い→答え」が 1 本で完結する台本にする
- **投稿は 1 日 2 本**。1 セット 6 本 = 3 日ぶん。1 日目 12:00 ショート1・19:00 本編、2・3 日目は 12:00 と 19:00 にショート
- 題材は「答えの先に次のなぜが 5 段続くもの」。答えが 1 つで終わる題材はショート単発にする
- 扱わないもの: 数学の題材、創作の物語、他チャンネルの題材の並び・題名の型・見た目のまね

## 手順（この順に）

```
題材 → 下調べ → 台本6本 → 見せる(台本) → kana → voice → prep/stills(地形) → render → compose → qc → 見せる(動画) → upload(予約)
```

1. **題材**: 候補は Google/YouTube の検索候補で「なぜ ○○」が実際に打たれているものから。番号を振ってユーザーに出し、○×はユーザーが付ける。
   `posted.json` が無い代わりに、チャンネルの投稿一覧と `episodes/` を見て、同じ題材を二度作らない
2. **下調べ**: 数字は一次資料（官公庁・学会・公式）か自分の計算だけ。出どころは `episodes/<題材>/ep.py` の冒頭 docstring に書く。
   地形の回は国土地理院の標高タイル（`naze.dem`）、地点は国土地理院の地名検索（`msearch.gsi.go.jp`）。
   見つからない地点は地図から読んで「読み」と書く。標高は `Dem.height_at` で自分で測る
3. **台本 6 本**: `docs/writing.md` の型で。冒頭 10 秒＝意外な事実を数字つきで言い切る → 問い → 答えを一言 → 使う道具を言う。
   数字は 1 分に 4 個以上、身近なものに換える（倍・個分・歩いて○分）。「普通は〜のはず、ところが」を 1 本に 1 回。
   結びは答えを 1 行 → 冒頭の絵に戻る → 暮らしに渡す（次に〜したら〜を見てください）。本編だけ伏線を張って回収する。
   一文 25 字以内。わかりやすさ優先（答えを先に・難しい語は言い換え・身近な比べ）。
   **登録と高評価のお願いは仕組みが自動で足す**（本編は最後の章だけ）。台本に書かない
4. **見せる（台本）**: 本編 5 章＋ショート 5 本を番号つきで。直したい行は番号で聞く。未決は 1 つまで
5. **kana → voice**: `kana` で全行の読みを見て、違えば `say` で直す（名越＝なごえ、仮粧坂＝けわいざか など）。
   声は剣崎雌雄（id 21）。概要欄に「音声：VOICEVOX:剣崎雌雄」
6. **地形の回**: 実在の場所は `tex_opts=dict(photo=True, photo_sat=1.35, photo_gain=1.12)`（空中写真）、高さが主役なら色分け。
   谷や台地を言う行には `profile=dict(a=…, b=…, names=[…])` で断面図を 1 つ入れる。
   `prep` → `stills 1,60,…`（行ごとに 1 コマ）を**目で見る**（札の重なり・海の暗さ・カメラの向き）→ `render`（本編の章は 1 章 40 分前後、夜に回す。途中から再開できる）
   計算の回: `ep.py` に `draw()` と `sfx_events(L)`。`stills` で目で見る
7. **compose → qc**: `qc` が台本（速さ・字幕と語りの差・文の長さ・数字の数・冒頭と結びの型）・画面（重なり・はみ出し・黒・止まり）・音（音量・無音）を見る。
   ✖ が 1 つでもあれば直す。△ は `qc_sheet.png` を目で見て判断。**qc に通らないと upload が止まる**
8. **本編**: `episodes/<題材>/long.py` に章を並べ `python -m naze long episodes/<題材>`。`chapters.txt` の目次を概要欄に貼る。
   サムネは `python -m naze.thumb <字の無い stills のコマ> out.jpg "1行目" "【強調】2行目" --sub "添え書き"`
9. **見せる（動画）**: 投稿の前に必ず動画を送る（ショートは mp4 をそのまま。本編は 30MB を超えるので qc_sheet.png とサムネを先に、mp4 は求められたら）
10. **upload**: `python -m naze.upload 動画.mp4 --title … --desc-file episodes/<題材>/desc.txt --publish-at 2026-10-27T12:00:00+09:00`。
    カテゴリは教育。予約は 9〜24 時。概要欄は 出典 → 音声のクレジット → 運営：のこぎり社 → タグ。本名・nami・0817 を出さない

## 関門（飛ばさない）

- 台本を見せてから作る。動画を見せてから投稿する（「見せて」は承認ではない）
- `qc` に通っていない動画・点検のあとで作り直した動画は `upload` が止める
- 課金の可能性があるものはユーザーに聞く（Gemini の絵は無料枠で作っている。地球の絵は `episodes/satellite/assets/`）

## つまずき所

- `@kotowari` は curl で 404 でも Studio で取れなかった。ハンドルの空きは Studio でしか確かめられない
- 文字列の中の改行を書き換えスクリプトで触ると `\n` が本物の改行になる。`sub=` は Edit で直す
- 地形の座標の原点は範囲の真ん中（km、x 東・y 北）。カメラ yaw は 0 で南から北
- 引きの画面が止まると qc の「止まったまま」で落ちる。計算の回はゆっくり寄り引きを入れてある
- 読みの点検の詳しい手順は**スキル `voice-reading-check`**
