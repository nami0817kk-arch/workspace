# 告知用の文案

投稿は本人が行うこと。以下は下書きで、そのまま使っても、削って使ってもよい。

各コミュニティには固有の空気があるので、**貼り付ける前に一度その場を読むこと**。
宣伝を嫌う場所に定型文を落とすと逆効果になる。

ブラウザですぐ遊べます（無料）

## サッカーゲーム系コミュニティ・掲示板 (やや長め)

```
個人でサッカークラブ経営シミュレーションを作りました。無料で、広告も課金も
ありません。ブラウザ版があるのでインストールなしで試せます。

■ どんなゲームか
5部リーグの弱小クラブを引き受けて、育成・移籍・戦術・経営をやりくりしながら
上を目指します。1部までの昇降格、国内カップ、大陸カップがあります。

■ 力を入れたところ
・試合をライブで観戦できて、決定機のたびに判断を求められます。シュートか
  パスか、守備なら積極的に行くかカバーに徹するか。成功率は実際に対峙する
  2人の能力値から出しているので、画面に「誰と誰の勝負か」が出ます。
・選手は42の能力値、54種類の特性、20種類の性格を持ちます。性格は成長効率や
  移籍希望の出やすさに、特性は試合中の挙動に実際に効きます。
・得点数やシュート本数、退場率は実際のサッカーの統計に寄せて調整しました。
  20シーズン以上回して、リーグ全体の戦力が際限なく上下しないことも確認して
  います。

■ 正直なところ
・実在のクラブ・選手は登場しません（ライセンスの都合です）
・日本語のみです
・個人開発なので、粗いところは残っていると思います。感想や不具合報告を
  もらえると助かります。

<Web版のURL>
```

## 投稿するときの注意

- **URLだけ貼らない。** 何のゲームかを1行で言ってから貼る
- **スクリーンショットを必ず添える。** 文字だけの告知はほぼ読まれない
- 反応が付いたら返信する。告知そのものより、その後のやり取りが次の人を連れてくる
- 「宣伝禁止」のルールがある場所には投稿しない
