# AdSense の申請と有効化

広告収入を取りにいくと決めた（2026-09-26）。そのための手順と、いまの状態。

**前提として、審査に通っても収入は出ない。** 出るのは流入があってからで、
2026-09-26 時点の Google のインデックスは1ページ。審査は「広告を出せる状態」に
するだけで、そこから先は別の問題（`README.md` の「収益化の現状」を見る）。

## いまの状態（2026-09-26 時点）

| 要件 | 状態 |
|---|---|
| 独自ドメイン | ✅ `kabu.dailyquarry.com`（`pages.dev` は審査に通りにくい） |
| 運営者が分かる | ✅ `/about` に屋号（つるはし社） |
| 連絡先がある | ✅ `/contact`（`info[at]dailyquarry.com`。迷惑メール対策で [at] 表記） |
| プライバシーポリシー | ✅ `/privacy`（Cookie と第三者配信広告について明記） |
| 中身がある | ✅ 約200ページ。毎営業日16時に更新 |
| 運用の実績 | ⏳ 2026-08-24 から。20営業日に届くのは10月上旬 |
| `ads.txt` | ✅ pub-ID を入れたときだけ出る（コメントだけのファイルは「有効なレコードが無い」と報告される） |
| 広告のコード | ⏳ `ADSENSE_CLIENT` が空なので何も出していない |

「20営業日」は**こちらで決めた目安**で、AdSense が公表している条件ではない。
公表されているのは「十分なコンテンツ」「独自性」「ポリシー順守」といった言葉だけ。

## 申請の手順

1. **AdSense に登録し、サイト `kabu.dailyquarry.com` を追加する**（利用者の作業）。
2. **pub-ID（`ca-pub-...`）を `src/site_config.py` の `ADSENSE_CLIENT` に入れる**。
   これだけで `<head>` に AdSense のスクリプトが出る（自動広告が動く形）。
   **枠（`<ins>`）は置かない。** `ADSENSE_SLOT` は空のままでよい。
   審査に必要なのはスクリプトの設置であって、枠の有無ではない。
3. push してデプロイし、本番の `<head>` にスクリプトが出ていることを確認する。
4. AdSense の画面で審査を申し込む。
5. 通ったら:
   - `ads.txt` は自動で出る（`ADSENSE_CLIENT` から組み立てる）。内容を AdSense の
     画面の指示と突き合わせる
   - `/privacy` の「利用する**予定**です」を「利用しています」に直す
   - 広告の位置を自動広告に任せるか、手で置くかを決める。手で置くなら
     `ADSENSE_SLOT` に本物の枠IDを入れる

## 広告の置き方で決めていること

- **本文の先頭には置かない。** ランキングの表の位置は実測して 849px → 469px まで
  詰めてある（スマホ）。先頭に広告を入れると、そこが元に戻る。
- 枠は各ページの**本文の後ろ**だけ。
- **枠IDが無いまま `<ins>` を出さない。** `data-ad-slot="0000000000"` のような
  作り物の枠は、審査でも配信でも通らない。

この3つはテストで固定してある（`tests/test_site_pages.py`）。

## 落ちたときに見るところ

- **コンテンツが薄い**と言われた場合: ページ数ではなく、1ページの中身を見られている。
  月まとめのように営業日が少ない月のページは、閾値を入れて作らないようにする。
- **サイトが使用できない**と言われた場合: 独自ドメインの DNS と、Cloudflare Pages の
  カスタムドメイン設定を確認する。
- 落ちても再申請はできる。指摘された点だけを直す。
