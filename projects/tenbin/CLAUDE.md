# ひらがなてんびん（tenbin）

ばね付きのてんびんの上に、**ひらがなを1字ずつ積んでいく** iOS アプリ（予定）。
手本は `projects/goso-boat`（ブラウザの試作 → Flutter の流れも同じ）。

## 決まったこと（ユーザー決定 2026-10-03）

- 出す先は **iOS だけ**。収益は **無料＋報酬広告＋広告を消す買い切り**。名義は **つるはし社**
- **エンドレス積み**: 1字ずつ来て、何字積めるかを競う（面クリア型はやめた）
- **形で勝負・回転あり**: 字の形がそのまま当たり判定。回してから落とす。くせは無し
- **置く場所は自由**（目盛り吸着はやめた）
- **積むのはひらがな**。動物はやめた
- **てんびんは台の種類の1つ**（2026-10-03「てんびんはだいの要素のひとつにしよう」）。
  台は `core.js` の `PLATFORMS`: ふつう・てんびん・ゆらゆら（左右に往復）・さか・せまい・ふたつ（すき間あり）。
  2026-10-04「だいをもう少し大きく」で幅を約2割広げた（ふつう340・てんびん370・ゆらゆら290・せまい210・ふたつ160×2）。
  遊ぶ前に選ぶ。さいこう記録は台ごと。名前（「ひらがなてんびん」）は仮。下の「名前」

## 名前（2026-10-04「名前は検索されやすいものに」。**案。決めるのはユーザー**）

goso-boat と同じ「ストアの正式名は検索語を並べた長い名前、ホーム画面は短い名前」の形にする。
検索されるのは作品名ではなく「ことばパズル」「積み上げ」「脳トレ」のような**一般の語**なので、それを正式名と副題に入れる。
短い名前は他と被らない造語にして、覚えた人が打てば1位に出るようにする。

- 推し: 正式名「もじつみ：ひらがな積み上げ ことばパズル」／ホーム「もじつみ」
  副題「くっつけて言葉を作る脳トレ バランスゲーム」
  英語「Moji Stack: Hiragana Word Tower」
- キーワード欄（100字、名前に入れた語は重ねない）例: 積み木,タワー,物理,文字,単語,言葉遊び,脳トレ,暇つぶし,てんびん,バランス
- 避けたもの: 「ひらがなつみき」（同名の既存アプリあり）、「てんびん」を頭に置く（てんびんは台の1つにすぎず、検索もされない）
- 2026-10-04 に検索したかぎり「もじつみ」という名のアプリは見当たらない（申請前に App Store Connect で名前を押さえて確かめる）

## 面白さの柱（2026-10-03「コンセプトはいいけど、面白みはない」→ 全体の品質改善）

- **くっついた字でことばを作る**（2026-10-03「くっついてる奴にしよう！順番だと面白くない」）。
  字はばらばらに来る（いくつかのことばの字を混ぜた袋から出すので、ことばに使う字が多め）。
  積んだ字が**触れ合っていれば、向きは問わず**、つながった順に読めたらことばができる（`core.js` の `findWords`）。
  2026-10-04「くっついていれば文字判定にしたい」で、たて（上→下）・よこ（左→右）の決まりをやめた（戻さない）。
  間に別の字が挟まったつながりは、そのまま読む（ね・ら・こ は ねこ にならない）。
  触れ合いは「物理で当たっている」か「輪郭どうしが 10px 以内」（横に並べた字は重力ですき間が空き、字の縁取りで
  画面ではくっついて見える。4px では取りこぼしが多かった: 2026-10-04「言葉として反応しない時がある」）。
  判定は字が落ち着いた時と、そのあとも落ち着いている間15コマごと（あとからずれてくっついた字も拾う）。
  **同じことばも別の字で作れば何度でも数える**（ことば帳には1度）。
  `node test/findwords.test.js` が縦・横・右から左・下から上・挟まった字・離れた字・すき間・2度目を確かめる。
  向きをやめたことで、自動でばらばらに落とすだけでも1回あたり約2語→約8語できるようになった（点が出やすい）。できたことばは**ことば帳**に集まる。「ことばの順に来る」案はやめた（戻さない）
- ことばは `words.js`（約2100語）。**`tool/mkwords.py` が作る**（手で直さない）。土台は手で選んだ `words_manual.js`（332語）、
  それに頻度表 wordfreq の上位から UniDic で品詞と読みを見て、清音46字で読める名詞・形容詞・動詞（言い切り）・副詞を足す。
  カタカナ語・感動詞・文法の語・子どもに向かない語（性・犯罪・薬物・死）・漢字1字の音読みの2字（かん・せん…）・切れ端は除く。
  2026-10-04「まるとかが反応しない」で、手の332語では普通の言葉が足りなかったため。濁点を外すと綴りが変わる言葉は入れない。
  `node test/words.test.js` が字と字数を確かめる。2000語にしてから、ばらばらに落とすだけで1回あたり約14語できる
- **点数で競う**（2026-10-03「文字をくっつけて言葉にするとポイントアップ」）。字1つ10点、ことばは (字数-1)²×100点
  （2字100・3字400・4字900・5字1600）。1字で同時にいくつもできたら、その数だけ倍。
  長いことばの一部（あさひ の中の あさ）は、その時もあとからも数えない。字を分け合う十字のことばは数える。
  さいこう記録は台ごとの点（保存キー `bests2`。字数で記録していた `bests` は使わない）
- つぎの字は3字先まで見せる（どの字でことばを作るか考えられるように）
- **持っている字とことばになる字が光る**（`core.js` の `partners`）。2字のことばになる字は濃く、長いことばの一部は薄く。
  はじめの画面に「上と下でも（ねこ）・右から左でも（うみ）」の見本の絵
- **手ごたえ**: 着地の音・粒・つぶれ、ことばができた光と音、崩れたときのスロー・揺れ。音は Web Audio でその場で作る（素材なし）
- **目標**: 自分のさいこうの高さに点線。こえたら知らせる。台ごとに字数と高さを記録
- **テンポ**: 次を落とせるまでの待ちを短く（最短20コマ、遅くても3秒）
- 台えらびは遊ぶ前の画面へ（遊んでいる最中に押し間違えない）
- **報酬広告で「つづける」**（2026-10-04 ユーザー指示「1.2の実施」）: 崩れたあと1回だけ。落ちた字・落ちかけの字
  （台の下・床・画面外・速く動いている・台の上に重心がない）を取り除き、点はそのまま。てんびんは片側に偏ったままだと
  すぐまた傾くので、偏りが450をこえる分だけ**重い側の字を**新しいものから取り除く（軽い側を取ると偏りが増えて
  台が空になるまで続いた: 2026-10-04 の見直しで発見）。そのあと90コマは失敗を数えず、落とせない（`core.js` の `revive`）。
  `node test/revive.test.js`（台が空にならない・待ちのあと落とした字が数えられる も確かめる）。
  自動試験で、字を残したまま つづけて4秒もつのは 120回中109回
  広告の決まりは下の「広告と課金」
- **アイテム**（2026-10-04「積み上げるのが難しいから何かアイテムとかどうかな？アイテムは有無選べる」）。
  はじめの画面で あり／なし を選ぶ（既定は あり）。**記録は あり／なし で分ける**（保存キーは台の名前＋`+i`）。
  のり＝つぎの字が最初に触れた字・台にくっつく / いた＝つぎに平らな板（130×12、字でも点でもない）/
  とりけし＝最後の字を取り除く / こおり＝いま触れ合っている字どうしと台を全部くっつける。
  くっつけるのは 2点のかたい拘束（`core.js` の `weld`、stiffness 1）。2026-10-04「アイテム使用時の運動力学がおかしい」で直したこと:
  (1) のりは触れた瞬間ではなく、勢いが落ちてから（遅くても0.5秒）その時触れている字・台にくっつける（`settleGlue`。
  ぶつかった勢いのままつなぐと引き合って はじけた: ゆらゆらで速さ127）。つなぐ前に両方を止める。
  (2) つないだ字どうしは同じ「かたまり」（負の collisionFilter.group）にして互いにぶつからない（拘束と押し合いがけんかして震えた）。
  (3) 字を取り除くときは `removeBody` で拘束も一緒に外す（つづける で消えた字の拘束が残り、ほかの字が空中で止まった）。3字以上のことば か 字8つごとに1つもらえる（各2つまで）。
  はじめは のり・とりけし を1つずつ。`node test/items.test.js`。
  実測: せまい台で端からはみ出した字は のり で落ちない。てんびんで14字まで崩れないのが こおりなし 6/15 → 5字ごとに使うと 15/15
- **ことば帳のごほうび**（同上）: 集めた数で台と字の色がひらく。台: ふつう0・てんびん10・さか25・ふたつ50・ゆらゆら90・せまい140。
  字の色: いつもの0・さくら30・うみ70・もり150・すみ250・きんいろ400（ことばを約2100語にしたとき引き上げた）。ちょうど届いたときに遊んでいる画面と結果で知らせる。
  はじめの画面・ことば帳に「あと○語で…がひらく」

## 広告と課金（2026-10-04「広告の仕組みを作って」。`prototype/monetization.js`、`node test/money.test.js`）

goso-boat の lib/monetization と同じ形。画面から切り離した決まり（`Money`）＋広告（`FakeAds`）＋ストア（`FakeStore`）。
**アプリにするときは `Money` を Dart に移し、FakeAds / FakeStore を AdMob・StoreKit の実装に差し替える。**
- 動画（報酬）: 「つづける」（崩れたあと1回の遊びで1回）・「▶ もらう」（アイテムありのとき1回の遊びで1回、アイテム1つ）。
  **最後まで見たときだけ渡す。** 読み込めない（6秒待つ）・途中で閉じた・表示に失敗した は渡さず、理由を出す（タダでは渡さない）
- 全画面: 結果から次を始めるとき（もう一度／台をかえる）、3回に1回。入れてすぐの3回は出さない（4・5・6回目と数えて6回目のあとが最初）。
  在庫が無ければ数えはそのまま次にもう一度。出す前に数え直す。結果を見ている間に読み込んでおく
- 広告を消す（買い切り、**値段は仮に 370円** = goso-boat と同じ。決めるのはユーザー）: 全画面なし・動画なしで つづける／もらう。
  はじめの画面に「広告を消す」「購入を復元」（審査で要る）
- docs/app-pitfalls.md への備え: ごほうびは画面の状態を見ずに渡す（2）・広告は55分で読み直す（3）・裏に回っている間は出さない
- 試作: 動画は5秒（とじるとごほうびなし）、全画面は3秒で閉じられる待ち画面。はじめの画面の「試作用: 広告のふるまい」で
  ふつう／読み込めない／途中で閉じる／表示に失敗 を切り替えて流れを試せる。購入も試作では本当にはしない
- 本物の動画広告の長さはこちらで決められない（広告ごとに違う）

## どうぶつタワーに寄せない（2026-10-03 の経緯）

一度「どうぶつタワーを真似して」で、写真の動物・青空・太陽・雲・緑のギザギザの台まで寄せたが、
ユーザーが「さすがに似すぎてて著作権」と止めた。**動物はやめて、ひらがなにした。**
遊びの仕組み（積む・回す・落ちたら終わり）は独占されないが、**見た目の組み合わせまで似せると、
App Store の審査 4.1（Copycats）と評判で危ない。** 次のものは戻さない:
写真の動物、青空＋太陽＋白い雲、緑のギザギザの台。
いまの見た目は、木の板・石の支点・色分けしたひらがなと、**和の景色**（2026-10-04「品質を上げて！背景とかをー」）:
地面のそばは 生け垣と石灯籠の庭・縁側の板張りの床・うすい山並み。積むほど空が 昼の生成り → 夕焼け（赤い夕日・
たなびく細い雲・鳥の影）→ 紫の夕暮れ → 星と三日月の夜空 と変わる。桜の花びらが画面に舞う。遠くのものほど
ゆっくり動く（index.html の `drawScenery`・`farY`）。夜でも読めるよう点数の下に紙を敷く。
**景色は台ごと**（2026-10-04「背景はステージごとに変える」。index.html の `SCENES`・`NEAR`）:
ふつう＝にわ（春・桜）／てんびん＝じんじゃ（秋・赤い鳥居・もみじ・玉砂利）／さか＝ちゃばたけ（初夏・若葉）／
ふたつ＝かわ（夏の夜・柳・太鼓橋・ほたる）／ゆらゆら＝うみ（水平線・松・小舟・桟橋）／せまい＝ゆきやま（冬・雪の杉・小屋・雪）。
空の色の移り方・山並み・床・舞うものを台ごとに持つ。どれも積むほど夕方を経て夜空になる
動物版の道具（写真の切り抜き・輪郭取り）は git の履歴にある（コミット「Gemini の写真5匹…」）。

## 試作（prototype/）

- `core.js` 物理（matter.js + poly-decomp）。ブラウザと node で共用
- `index.html` 画面
- `glyphs.js` ひらがな46字の当たり判定の輪郭。**`tool/glyphs.js` が生成**（手で直さない）。
  字形は `fonts/` の M PLUS Rounded 1c Black（SIL OFL 1.1、`fonts/OFL.txt`。アプリに入れて販売してよい）。
  フォントは字ごとに分割ファイルなので、**全部の字を読み込んでから**描く・輪郭を取る
  （「む」だけ別ファイルで、読み込み前に描くと見た目と当たり判定がずれた）
- `node tool/sim.js [回数] [center|rand|smart]` 自動で積ませ、何字で崩れるかと物理の破綻を見る
  （先に projects/tenbin で `npm install`）
- 輪郭を取り直す: `PLAYWRIGHT=<playwright の場所> CHROMIUM=<chromium> node tool/glyphs.js`
- 失敗: 字が床に着く／画面外へ落ちる、または板の端が床に着く
- **matter.js は部品をまとめた体の慣性に、重心からの距離の分を足さない。** `build()` で平行軸の分を足して
  `setInertia` している。外すと字が回りやすすぎて、動かない台に当たった瞬間に回って飛ぶ（2026-10-03 に踏んだ）
- 自動試験は台ごとに `PLAT=flat node tool/sim.js 20 smart` のように回す
- 重さは面積に比例（画の多い字ほど重い）。ばねの強さ `K_SPRING`、ころがりにくさ `ADAMP` が難しさの主なつまみ
