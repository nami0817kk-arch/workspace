# ひらがなてんびん（tenbin）

ばね付きのてんびんの上に、**ひらがなを1字ずつ積んでいく** iOS アプリ（予定）。
手本は `projects/goso-boat`（ブラウザの試作 → Flutter の流れも同じ）。

## 決まったこと（ユーザー決定 2026-10-03）

- 出す先は **iOS だけ**。収益は **無料＋報酬広告＋広告を消す買い切り**。名義は **つるはし社**
- **エンドレス積み**: 1字ずつ来て、何字積めるかを競う（面クリア型はやめた）
- **形で勝負・回転あり**: 字の形がそのまま当たり判定。回してから落とす。くせは無し
- **置く場所は自由**（目盛り吸着はやめた）
- **積むのはひらがな**。動物はやめた
- **てんびんは台の種類の1つ**（2026-10-03「てんびんはだいの要素のひとつにしよう」）。
  台は `core.js` の `PLATFORMS`: ふつう・てんびん・ゆらゆら（左右に往復）・さか・せまい・ふたつ（すき間あり）。
  遊ぶ前に選ぶ。さいこう記録は台ごと。名前（「ひらがなてんびん」）は仮

## 面白さの柱（2026-10-03「コンセプトはいいけど、面白みはない」→ 全体の品質改善）

- **くっついた字でことばを作る**（2026-10-03「くっついてる奴にしよう！順番だと面白くない」）。
  字はばらばらに来る（いくつかのことばの字を混ぜた袋から出すので、ことばに使う字が多め）。
  積んだ字が**たて（上→下）かよこ（左→右）に触れ合って**読めたら、ことばができる（`core.js` の `findWords`）。
  触れ合いは「物理で当たっている」か「輪郭どうしが 4px 以内」（横に並べた字は重力ですき間が空くため）。
  `node test/findwords.test.js` が縦・横・逆向き・離れた字を確かめる。1回の中で同じことばは1度だけ。できたことばは**ことば帳**に集まる。「ことばの順に来る」案はやめた（戻さない）
- ことばは `words.js`（清音46字だけで正しく書ける144語）。濁点を外すと綴りが変わる言葉（とんぼ→とんほ）は入れない。
  `node test/words.test.js` が字と字数を確かめる
- つぎの字は3字先まで見せる（どの字でことばを作るか考えられるように）
- **手ごたえ**: 着地の音・粒・つぶれ、ことばができた光と音、崩れたときのスロー・揺れ。音は Web Audio でその場で作る（素材なし）
- **目標**: 自分のさいこうの高さに点線。こえたら知らせる。台ごとに字数と高さを記録
- **テンポ**: 次を落とせるまでの待ちを短く（最短20コマ、遅くても3秒）
- 台えらびは遊ぶ前の画面へ（遊んでいる最中に押し間違えない）

## どうぶつタワーに寄せない（2026-10-03 の経緯）

一度「どうぶつタワーを真似して」で、写真の動物・青空・太陽・雲・緑のギザギザの台まで寄せたが、
ユーザーが「さすがに似すぎてて著作権」と止めた。**動物はやめて、ひらがなにした。**
遊びの仕組み（積む・回す・落ちたら終わり）は独占されないが、**見た目の組み合わせまで似せると、
App Store の審査 4.1（Copycats）と評判で危ない。** 次のものは戻さない:
写真の動物、青空＋太陽＋白い雲、緑のギザギザの台。
いまの見た目は、生成りの紙の背景・木の板・石の支点・色分けしたひらがな。
動物版の道具（写真の切り抜き・輪郭取り）は git の履歴にある（コミット「Gemini の写真5匹…」）。

## 試作（prototype/）

- `core.js` 物理（matter.js + poly-decomp）。ブラウザと node で共用
- `index.html` 画面
- `glyphs.js` ひらがな46字の当たり判定の輪郭。**`tool/glyphs.js` が生成**（手で直さない）。
  字形は `fonts/` の M PLUS Rounded 1c Black（SIL OFL 1.1、`fonts/OFL.txt`。アプリに入れて販売してよい）。
  フォントは字ごとに分割ファイルなので、**全部の字を読み込んでから**描く・輪郭を取る
  （「む」だけ別ファイルで、読み込み前に描くと見た目と当たり判定がずれた）
- `node tool/sim.js [回数] [center|rand|smart]` 自動で積ませ、何字で崩れるかと物理の破綻を見る
  （先に projects/tenbin で `npm install`）
- 輪郭を取り直す: `PLAYWRIGHT=<playwright の場所> CHROMIUM=<chromium> node tool/glyphs.js`
- 失敗: 字が床に着く／画面外へ落ちる、または板の端が床に着く
- **matter.js は部品をまとめた体の慣性に、重心からの距離の分を足さない。** `build()` で平行軸の分を足して
  `setInertia` している。外すと字が回りやすすぎて、動かない台に当たった瞬間に回って飛ぶ（2026-10-03 に踏んだ）
- 自動試験は台ごとに `PLAT=flat node tool/sim.js 20 smart` のように回す
- 重さは面積に比例（画の多い字ほど重い）。ばねの強さ `K_SPRING`、ころがりにくさ `ADAMP` が難しさの主なつまみ
