# 絵の依頼文（Gemini 用、2026-10-05）

ユーザーが Gemini で作り、チャットに貼る。受け取ったら Claude が切り抜き・ぼかし・字の重ね合わせをしてゲームに入れる。

## 共通の約束（どの絵にも）

- **動物・人・文字・ロゴを入れない**。青空＋白い雲＋太陽の組み合わせ、緑のギザギザの地面は入れない（どうぶつタワーに寄せない、CLAUDE.md）
- 絵の真ん中は空けて、ものは左右の端に寄せる（真ん中に字を積むので、字が埋もれないように）
- 色は淡く、くすませる（字のほうが目立つように）
- Gemini は右下に小さな星の印を入れることがある。右下は何も描かれていなくてよい（こちらで切る）

## 1. 台ごとの背景（6枚・横長 4:3・1600×1200 くらい）

ゲームでは、絵の**下の端が地面の高さ**、**上の4分の1はこちらで空にとけさせる**。上のほうは下の「空の色」でべたっと塗ってもらえばよい。
空は積むほど夕焼け→夜に変わるが、それはゲームが描く。絵はいちばん下（昼）だけ。

依頼文の型（［］を台ごとに入れ替える）:

```
横長（4:3）の背景イラストを1枚。日本の［場所］の、地面のすぐそばの景色。
やわらかい水彩風の和のイラストで、色は淡くくすませる。
絵の上のほう4分の1は、空の色 ［色］ の一色でべったり塗る（雲・太陽・グラデーションなし）。
絵の下の端は地面の高さで、そこから下は描かない。
［置くもの］ は画面の左右の端に寄せ、真ん中の幅半分は低い草や地面だけにして空けておく。
動物・人・文字・ロゴは入れない。
```

## 2. アイコンの絵（1枚・正方形・1024×1024）

字（もじ／つみ）と木の板はこちらで重ねる。絵は背景だけ。

```
正方形（1:1）のアプリアイコン用の背景イラストを1枚。文字は入れない。
日本の夕焼けの空。上はやわらかい朱色、下に向かってあたたかい生成りの色。
いちばん下に、遠くの低い山並みが淡い藤色で少しだけ。
真ん中の大きな部分は何も置かず、なめらかな空だけにする（あとで大きな文字を重ねる）。
やわらかい水彩風。動物・人・太陽・雲・文字・ロゴは入れない。
```

2〜3枚作ってもらえれば、字を重ねて並べ、読みやすいものを選ぶ。
