# 歴史の地層（日本史・世界史を聞き流し）

YouTube チャンネル「歴史の地層｜日本史・世界史を聞き流し」（@rekishi-no-chiso、運営：つるはし社）の
動画を作る。目的は収益化（2027-02 からの新基準＝長尺 8,000 時間を前提に、長尺で視聴時間を積む）。

## 2人のキャラと会話の流れ（2026-10-04 にユーザーと決めた。変えるときは聞く）

|  | 剣崎雌雄（語り） | 春日部つむぎ（聞き） |
|---|---|---|
| 役 | 掘る案内人。事実と記録を出す | 視聴者と同じ側。予想し、今に置き換え、言い直す |
| 口調 | 落ち着いた丁寧語 | **中間**：ふだん軽い話し言葉（でしょ？／じゃん／の？）、驚くと素が出る |
| 一人称 | 僕（ほとんど言わない） | あーし（**節に1回くらい**） |
| 呼び方 | つむぎさん | 剣崎さん（公式のあだ名「めすおちゃん」「べっつー」は使わない） |
| 素性 | **語らない**（付喪神・3600歳は出さない） | 公式の「埼玉のギャル」を口調ににじませる程度 |

- **進行役はいつも剣崎**（10-04 に「題材ごと」から固定に変更）。最初の行と締めの「今日の地層は、ここまでです」は剣崎
- **締め**：剣崎「今日の地層は、ここまでです」→ つむぎが次回の題材を一言で振る（「次回は〇〇。〜した人なんだって」）
  → コメントへの誘い → **二人**「また一緒に、掘りましょう！」（`- 二人: …`。2人の声を重ねて読む）
- **つむぎを受け身にしない**（10-04 の分析：101行の約半分が驚き・おうむ返し・「……」の感想だった）。
  驚くだけの短い返しは1節2回まで、「……」で終わる感想は2回続けない。代わりに**予想して外す・
  今に置き換える・節の終わりで自分の言葉で言い直す**。check が数えて知らせる
- **1節の流れ**：年と出来事 → つむぎの予想か疑い → 意外な答え → 反応は1回 → 次の問い → 層を分ける（記録／言い伝え）→ 事実で引く
- **まとめ**（10/11 までは「見立て」）：要点を番号で出し、要点ごとにつむぎが置き換えるか言いかける。最後につむぎが自分の言葉でその人（出来事）を言い直す

## 画面・サムネイル・次回予告（2026-10-04 に固めた）

- **画面**：背景の絵画／右上に肖像（額は二重の金、名前は「名前（太字）＋誰の絵か（小さく）」の2段）／
  左に「掘り出したメモ」（その節の札が新しい順に3枚まで。いまの札だけ明るい）／節の進み具合の点／
  地層の年表（先の地層は暗く、印の上に「1785年」）／2人のあいだの下に字幕（2行・高さ固定、
  話し手の名前をその人の側に、《》の語は朱色）。話す側は明るく足もとに光、聞く側は暗く色を落とす
- **強調語の飛び出しは使わない**（10-04「不要」。字幕の朱色だけ残す）
- **動き**：**背景の絵は動かさない**（10-06 ユーザー「背景を微妙に動かさないで」。config の video.bg_motion: false）／話し始めに跳ねる／絵が替わると溶け合う／年表の印が動く／新しいメモが左から滑り込む／
  冒頭2行は題名の問いを大きく／節の頭の間に「第N節 題名」を大きく
- **BGM は入れない**（ユーザー決定）
- **次回予告**：台本の `next: {title, teaser}` があれば、最後に12秒の画面を足す。右側は YouTube の終了画面のために空ける
- **サムネイル**（`thumb`、台本の `thumbnail:`）：絵を全面・上にいちばんの見どころの一言（hook、任意）＋赤い判子（数字など、任意）・下に赤い名前札＋その人を一言で（lead 白＋main 特大の黄。例「天下を支えた（白）弟（黄）」）。10/11 までは「本当に（白）悪女？（黄）」の通説型・
  右下に剣崎雌雄（後ろ）と驚き顔のつむぎ（手前）。シリーズ名・チャンネル名の札は入れない。目印は下端の細い地層。
  `out/*_thumbnail_preview.png` で一覧の大きさでも読めるか見る

## 質を上げる決まり（10-07。分析の前に自分でできることとして）

- **画面の替わり方**：信長の回で、同じ絵が2分前後動かない区間が6か所あった（scene 検出）。
  **同じ背景は40秒まで**（場面ごとに絵を替える。1本30〜40枚）・**20秒に1回は新しいもの**（絵・札・図・挿絵・肖像）。check の pacing が知らせる
- **絵が少ない回の道具（10-07）**（見本：`dev/output/rekishi-chiso/research/tools_look/`）:
  - **絵の一部を大きく**（`detail: {box, label}`、その行だけ）：同じ絵1枚から何度も「新しいもの」を作る。真ん中の額に止まった絵で出し（動かさない）、
    左上に全体の中のどこかを小さく、下に札。肖像・図・年表はその行だけ隠れる。pacing では新しいものと数える
  - **赤ペン**（`mark: [{type, at, text}]`）：circle／arrow／underline／strike／note。大きく見せた絵・図・真ん中の額・肖像の上に、行の頭で1つずつ描き進める。
    図は「何番目の項目」で指す（座標を書かない）。同じ絵・図の上なら行ごとに足せて、替わると消える。透明は落とさない（断面図の annotate の不具合は直して移した）
  - **紙の質感**（台本の一番上に `texture: true`、config でも可。既定は切）：図の板・メモの札・額の台紙にうっすら紙の目。紙の目は1回だけ作って控える。
    既定で入れると前の5本の見た目が変わるので、新しい回から台本に書く（ひな形には書いてある）
  - **ここまでの地層**（`recap: true`）：節の頭の「第N節」の下に、前の節のメモの札を最初・真ん中・最後の3枚まで小さく並べる（自動）。最初の節とまとめの節の頭、札が2枚未満の節は出さない
  - **出来上がった動画の点検**（`qc`）：20秒ごとの一覧（節ごとの段）を out/x_qc.png、scene 検出で画面が大きく変わらない区間（中央値・長い5つ）・
    字幕の終わりと長さの差・音の大きさ・長い無音を out/x_qc.md に。信長の回で40秒超えが9か所・音が -16 LUFS（基準 -14）と出た
- **掛け合いの配分**：5本とも剣崎の字数が72〜79%で講義に近かった。**70%まで**。つむぎにも知っている事実・予想を言わせる
- **伸びている歴史の長尺18本を調べた結果**（research/benchmark_long.md）：
  - 冒頭15秒でいちばん重い事実を1文、60秒以内に最初の掘った事実まで届かせる
  - 各節に小さな具体的な逸話を1つ（誰が何を食べた・言った）。いいねが付くのはこの細部
  - 最後の節に人柄の場面（家族・手紙・最期の言葉）を1つ。締めは余韻の一文＋次回の人物名（「いかがでしたか」は使わない）
  - 分からない所は「分かっていない」と言い、出典を1回は読み上げる
  - 節は25〜40分なら7〜8節・1節3〜5分。概要欄の章の題に年・人名・場面を入れる
  - 嫌われるもの：AIらしい不自然な日本語、元気すぎる声、期待した人物が出ないこと

## 図（地図・グラフ・相関図）— 10-04 に仕組みにした

- 台本の行に `figure:` を書くと、画面の真ん中に図の板が出る（節が変わるか `figure: null` まで）。出るときは描き進める
- 種類：`map`（線がのびる。地名は `places.yaml`、bounds は省けば自動）／`pie`／`bars`／`people`（相関図、cross で「関わっていない」）
- 図のあいだはメモ・肖像・年表を隠す。地図は Natural Earth（パブリックドメイン、クレジット不要）
- **1本に3つ以上**（`check` が知らせる）。書き方は `scripts/_template.yaml`
- `compare`：人物を並べて比べる（肖像を横に並べる）
- **10-07 に別チャンネル「世の中の断面図」から移した4つ**（調べ：`dev/output/rekishi-chiso/research/danmen_tools.md`、見本：`research/port_look/`）:
  - **1項目ずつ増える**：同じ図を行ごとに `upto: 1` → `2` → `3` と書く（upto のほかは前の行と同じ）。script.parse が前の行の upto を
    `grow_from` に入れ、新しく増えた項目だけが描き進む（前の項目は動かず、効果音も最初の1回だけ）。配置は全部の数で決まるので跳ねない。
    bars・people・compare・map の route・stats・calc・numberline・line で使える。図の数（3つ以上）は1つと数え、pacing では「新しいもの」と数える
  - **数字の図**：`stats`（数字を最大3つ）／`calc`（計算の式。項が順に出る）／`numberline`（享年・年号の数直線）／`line`（折れ線）。
    数字は太く大きく、単位は半分の大きさ（`figures.put_number`）。注目の1つだけ朱
  - **つむぎの寄り**（`reaction: {number, lead, say}`、その行だけ）：背景を落として集中線、左に大きな数字、右につむぎを腰から上で大きく
    （「驚き」の顔、口パクあり）。下の小さい2人・メモ・肖像・年表・図・用語の札は隠す。**1本2回まで**（check が知らせる）。ショートでは出さない
  - **左右の全画面比べ**（`figure: {type: versus, left, right, title, credit}`）：2枚の絵を左右に全面、真ん中に金の縦線、明るさは自動でそろえる。
    名前と大きな数字（right の `focus: false` で白）。背景の出典の代わりに `credit` を下に出す
  - 断面図の `texture.finish`・`annotate.apply` は RGBA を RGB に落とす（板の外が黒枠になる）。移した図はどれも透明を保つ（テストあり）
- **用語の札**（`terms.yaml`、その回だけの言葉は台本の `terms:`）：難しい言葉が**その回で初めて出た行から3行**、右上に説明を出す。
  台本に書き込む手間は無い（自動）。説明は40字まで・事実だけ。新しい題材では、出てくる言葉を terms.yaml に足してから draft
- **この時○歳**（台本の `people:` に生没）：肖像の左上に、その場面の年での満年齢。月は同じ年の札（「1774年5月」）から取り、
  無ければ7月1日とみなす。肖像の人物は caption の名前の末尾で探す（`match:` に言い換え、`who:` で直接も可）。生没は百科事典で確かめる
- **場所の小さな地図**（自動）：`places.yaml` の地名が初めて出た行から3行、右上（用語の札の下）に「ここ」の点。地図の図が出ている間は出さない。
  用語の中の地名（神聖ローマ皇帝のローマ）は数えない
- **お金の札**（`figure: {type: money, then, yen, basis}`）：当時の金額を今の円に直し、円の数字が数え上がる。
  「1リーヴル＝何円」は資料で300〜2,000円と割れるので使わない。コンセプトどおり**当時の日当を今の1万円とし**、その前提を basis に書く
  （basis が無いと台本が読めない）。語りでも「数え方で大きく変わるので目安」と言う。
  10-04 に一度「年収300万円」で作ってコンセプトとずれていたので直した（首飾り＝約3500年分＝約130億円）
- **節の終わりの引き**（`hook: true`）：導入と見立て以外の節は、終わり2行のどこかを次が気になる一言にする。無いと check が止める。
  答えを先に言わず、事実で引く（「事件から4年後、パリで革命が始まります」）
- **効果音**（`config.yaml` の `sfx`）：BGM は無し。節の切り替え・図が出る・お金の札・聞き手の驚き（20秒に1回まで）の4つだけ、
  声よりずっと小さく。音は chiso/sfx.py で合成していて素材の出典は要らない
- **人物の言葉**（`- 人物: 「…」` と `who: マリー`）：記録に残る本人の言葉だけを、`config.yaml` の `roles` の声で読む。
  字幕の札は深い赤で人物名。2人は口を動かさず聞き役に。前置き（「こう言ったと伝えられています」）は語りで言う。
  10-04「マリーアントワネットのセリフとかの声はどうなっている？」で、本人の言葉も剣崎が地の文の声で読んでいたので足した。
  声は剣崎（21）・つむぎ（8）と別の声。クレジットは使った回だけ自動で出る
- **吹き出し**（`bubble:`、その行だけ）：肖像の人物に一言しゃべらせる。肖像が出ているときだけ
- **挿絵**（`icon:`、その行だけ）：1文の中身を表すシルエット（Phosphor Icons、MIT）を真ん中の丸い板に。
  10-04 に人気の歴史動画と比べ、画面の替わる間隔が中央値18秒（他は5〜10秒）だったので足した

## 作り方の手順

ユーザーレベルのスキル `rekishi-video`（`~/.claude/skills/rekishi-video/SKILL.md`、バックアップは workspace/claude-skills）。
`check` は1本ぶんの決まり（見立ての節・次回予告・サムネイル・図の数・地名）を見て、足りなければ止める。

## 抑揚（ユーザーが一番気にしている）

掛け合いを「読み上げ」ではなく「会話」に聞かせる。台本でこう書く（`chiso/voice.py`）:

- `tone:` 行ごとの調子。普通／驚き／疑問／強調／しみじみ／明るい／笑い／重い／ひそひそ／納得
- **2人とも抑えめ**（10-04「女の子の声がおかしい」「かなり抑えて」「男性側は、抑揚はかなり控えめ」）：
  つむぎは素の抑揚1.0・調子の効き4割・上限1.3／1.08倍、剣崎雌雄は素の抑揚1.0・効き3割・上限1.15。
  「強めて」と言われても、上限（抑揚2.0・速さ1.2倍）に張りつかせない。`check` が知らせる
- **《》の強調も話者ごとに効きを変える**（`config.yaml` の `emphasis`）。剣崎は0.3（10-05、1.0 だと色文字の語だけ
  半音6つ分ほど上がって裏返ったように聞こえた）。つむぎは1.0のまま
- VOICEVOX は「〜んですか」を「イッテナイ／ンデスカ」と切って「ン」を最高音にする。「ン」で始まる区切りは自動でつなげる
- `《語》` その語だけ高く・ゆっくり・大きく
- 間は自動（問いへの答えは短く、驚きはほぼ間なし、重い話のあとは長め、節の切れ目は1.2秒）。
  `pause:` で上書き
- 読み違いは `readings.yaml` に足す。**音を出す前に読みをカタカナで書き出して確かめる**
  （VOICEVOX は「いちばん上」を「イチバンジョウ」と読んだ）

## 関門（チャンネル共通の決まり）

- **台本のユーザー確認は不要**（10-05「今後台本確認は不要です」）。代わりに Claude が自分で何回も確かめてから approve する：
  事実（前半・後半を資料で）・流れとキャラ（初めて聞く人の耳で）・読み（kana を1行ずつ）を並べて確認 → 直す →
  直した所の確認 → 最後の通し確認で「公開してよい水準」と出るまで回す（マリーの回は3回）。`check` の × も0に。
  `build` / `shorts` が `approve` の控え（台本のハッシュ）を要るのは変わらない（確かめた台本と作る台本を一致させるため）
- 確認用は `draft` / `shorts --draft`（右上に「確認用」と出る）
- **投稿の前に本番の動画を見せる**。`upload` は承認（台本）と `screen`（動画のハッシュ）の両方が無いと動かない
- 投稿：Google Cloud は**サッカーと別のプロジェクト「rekishi-chiso」**（API の枠を分ける。10-04 ユーザー決定）。鍵と許可は `dev/output/rekishi-chiso/secrets/`（リポジトリの外）。`whoami` でチャンネルを確かめ、違えば止まる。控えは `posted.json`
- **投稿は1日1本、19時**（10-04）。**ショートは本編の翌日の11・12・13・14・16・17・18・19・20・21時に10本**（10-06 ユーザー。15時は空ける）
- 台本はコンセプトの細部が決まってから書く（2026-10-03 指示）

## 素材

`config.yaml` の `assets_dir`（既定 `../../../output/rekishi-chiso/assets`）に置く。**リポジトリに入れない**
（立ち絵は再配布禁止、workspace は public）。立ち絵は `prepare-characters` でヘルメットをかぶせて作る。

| 素材 | 出どころ | 条件 |
|---|---|---|
| 春日部つむぎ | BOOTH 公式立ち絵 v2.0 | 加筆・加工可。商用は動画とサムネのみ。クレジット VOICEVOX:春日部つむぎ |
| 剣崎雌雄 | VOICEVOX 掲載の公式イラスト | 二次創作に制限なし。公式イラストの二次配布・商品販売は禁止。クレジット VOICEVOX:剣崎雌雄 |
| 波音リツ（クイーン） | 声だけ（マリー・アントワネットの言葉、style 65） | 商用・非商用可。クレジット VOICEVOX:波音リツ（規約 canon-voice.com/kiyaku.html）。立ち絵は使わない |
| 絵画 | Wikimedia Commons（パブリックドメイン） | 作者と年を画面と概要欄に出す |

両キャラとも禁止：誹謗中傷・第三者に不快感・特定の思想や団体に関係するもの。残虐な場面の細部や、
宗教・政治の色が強い題材は避ける。

## コマンド

```
python -m chiso.cli voice    scripts/x.yaml     # 音声だけ（抑揚の確認）
python -m chiso.cli draft    scripts/x.yaml [--lines 40]   # 確認用の動画（--lines で冒頭だけ）
python -m chiso.cli shorts   scripts/x.yaml --draft
python -m chiso.cli approve  scripts/x.yaml     # ユーザーの OK のあとだけ
python -m chiso.cli build    scripts/x.yaml
python -m chiso.cli describe scripts/x.yaml     # 概要欄（章・クレジット・絵の出典・次回）
python -m chiso.cli kana     scripts/x.yaml     # 全行の読みをカタカナで（読み違いの点検）
python -m chiso.cli check    scripts/x.yaml     # 素材の有無・長すぎ・抑揚の張りつき
python -m chiso.cli qc       scripts/x.yaml [--video out/x.mp4]   # 出来上がった動画の点検（一覧・画面の替わり方・音・無音）
python -m chiso.cli thumb    scripts/x.yaml     # サムネイルと一覧の大きさの確認用
python -m chiso.cli screen   scripts/x.yaml     # 本番の動画を見てもらった控え（OK のあとだけ）
python -m chiso.cli upload   scripts/x.yaml --at "2026-10-05 19:00"   # 予約投稿
python -m chiso.cli whoami                       # 許可したチャンネルの名前
python -m chiso.cli prepare-characters --tsumugi <png> --kenzaki <png> --tsumugi-psd <psd>
```

VOICEVOX エンジン（127.0.0.1:50021）を起動しておく。テストは CI（rekishi-chiso-tests.yml）。
