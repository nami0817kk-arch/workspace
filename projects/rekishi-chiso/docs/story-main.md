10-24〜10-25 にユーザーと決めたこと・他チャンネルの調べから入れたことのまとめ。見本はお市の方（台本 `scripts/oichi-story.yaml`、見た目 `scripts/story/oichi_main_look.yaml`）。
作るのは `chiso/storymain.py`（CLI は `story-main`）。旧型の本編（掛け合い・`chiso/render.py`）とは別の仕組みで、旧型には触らない。
縦の物語型ショートは `docs/story-shorts.md`。

## 00. 伸びる型（11-04 ユーザー「伸びる型を整理してパターン化」「型は5つは欲しい」）

調べ：`growth_patterns_1104.md`（まとめ）と型ごとの `pattern_{sonogo,kakeizu,nazo,saigo,kurashi,moshimo}_1104.md`。
他チャンネルの7月以降の長尺を、同じチャンネルの中で伸びた回と伸びなかった回に分けて約70本比べた。**自分のチャンネルの再生数からは決めない**（11-04「私の再生数から計算はダメ」）。
**型（題名の部品・サムネの作り）を写しても伸びない**（同じチャンネル・同じ型・同じ声で30万回と3,000回が並ぶ）。差を分けたのは下の5つ。

**共通の決まり（題材を選ぶ前に全部 ○ にする）**

1. **題名で答えを明かさない**。答えの席を1つ残す（謎＝名詞を伏せる／最期＝死に方・年齢を言い切らない／暮らし＝裏返る像だけ予告）。「22歳で自害した〇〇」「3つの原因」「7つの謎」「解き明かした」は負けた形
2. **主語は1人か1つの役目。その人が最後まで主役**。有名人を入口にして別の人の話をしない
3. **誰でも持っている像・知っている一点を入口にし、それを裏返すか、今に届かせる**。「明治まで」「残った線」で止めない
4. **先に出す**。他チャンネルに当たりがあれば同じ題材は2週間以内に別の切り口で。題名・サムネは写さない。自分のチャンネルで同じ人の2本目は伸びない
5. **数字は「大きいもの×短い時間」か中身そのもの**（3万の軍が半日／斬首まで14日間／嫁いで3年8か月）。年齢・項目の数を主役にしない

- 答えの席は題名かサムネのどちらかで空ける。冒頭は「誰でも知っている一点 → 問い」で、告知・挨拶の前置きは入れない
- 大河に出る人は、その人の回の放送の前日に出す
- AI を名乗らない（他チャンネルの「AIに推理させたら」は、こちらでは「当時の記録だけで採点したら」）

**5つの型**（12時の if の回は「もしも」の型。pattern_moshimo_1104.md）

| 型 | 題名の形 | サムネ | 題材の条件 |
|---|---|---|---|
| A その後 | `{続柄}・{名}のその後。{中身の数字}で迎えた{最期}と『{引き}』【豊臣兄弟！】` | 全面の人物画／上に白で具体的な事実1行／下に赤特大「{名}のその後」 | 本人の記録が死後・晩年まで残る人。その人の1本目 |
| B 家系図 | `【家系図で見る】{集団か今も当主がいる家}はその後どうなった？{並べ方}と{N年後の意外な今}` | 丸い肖像4つを点線で横一列、右端は赤丸に今の数（4500人・14代 現当主？？？） | 集団（源氏・13人・藤原四家）か現当主のいる家。絶えて終わる家は弱い |
| C 謎の推理 | `【{N}年の謎】{誰／どこ}？当時の記録だけで採点したら、意外な{人物・場所}が浮かび上がった` | 知る顔＋赤枠の空き箱「黒幕？」／下帯「記録で採点 → 意外な1位」 | 誰でも聞いたことがあり答えが出ていない（本能寺の黒幕・明智の生存）。説4〜6、採点の決まりは20%で表、1つの名前は90%前後 |
| D 最期 | `{名}｜{答えの出ていない一点の問い}？！{肩書}の残酷すぎる最期`／`{名}の最期！{起点}から{終点}まで…壮絶すぎる{短い期間}` | チャンネル内で差なし。決め手は題名 | 誰でも知る人で、死に方か理由に謎がある。いちばん奇妙な一点を題名に |
| E 暮らし | `{誰でも知る1人・役目}は{像}ではなかった？{日常の一場面}が想像以上に{逆の像}だった` | 上に白で今との違い／下に赤「どうしてた？」 | 教科書の言葉がある（将軍・宿場・伊能図）・主語が1人・記録で裏返せる像が1つ。問いは「何をしていた／どうしてた」、「なぜ」は字に出さない |

**もしも型（12時の if の回。pattern_moshimo_1104.md、7チャンネル41本）**

- 題名：`もしも{誰でも知る大事件の分岐}が{逆}だったら、{日本・世界／史実で滅んだ有名な家}はどうなった？`
  - 「どうなった？」の対象が決め手：当たりは「日本・世界（今の日本まで届く）」か「史実で滅んだ有名な家」（武田家・毛利家・豊臣家）。小さい・ぼやけた対象（信長の上洛・織田家の争い）は外れた
  - 分岐は誰でも知る大事件の逆（当たり9本中8本）。ただし同じ分岐でも外れが多いので、知名度だけでは足りない
- サムネ：分岐の前提を1行（「滅亡直前」のような時の迫りも）＋大きな問い。前提の無い問いだけのサムネは外れた
- 中身：**一点だけ変える・史実の条件の範囲内・推論と明記**（台詞なしで当たった形。こちらの「もしもと言ってから事実と混ぜない」と合う）。前半を記録と通説の答え合わせ、予想の席を研究者の説に
- 時代：当たりは戦国と太平洋戦争だけ。**幕末・古代・中世は当たり0**（龍馬 1,915・戊辰 1,030）
- 組み合わせ：もしも×その後（「〇〇家はどうなった？」）が多い。分岐の無い「もしあなたが江戸に」（もしも×暮らし）も同じ強さ
- シリーズの2本目から落ちる（7.7万→2.5万→1.7万）。同じ分岐の続き物にしない
- 上限は約28万回（謎・暮らしより下、その後と同じくらい）。当たり9本中7本は登録191〜1,740人のチャンネル

- **下の 0. の「避けるのは暮らしが主題」は E の条件を満たすものには当てはめない**（10-25 の調べは主語が広い暮らしの回だった）
- 今まで使ってきた「〇〇｜なぜ〜したのか」の題名は、答えが出ていない謎のとき（D の利休型）だけにする

## 0. 題材と「知らない事実」（10-25 ユーザー「みんな知っている内容だと興味が惹かれない」）

調べ：`unknown_facts_benchmark_1025.md`（7チャンネルの上位70本と中央70本）・`topic_candidates_unknown_1025.md`（候補15案）。

- **主役は誰でも知る人物か集団**。無名の人なら、題に有名な集団・事件の名を付ける（伸びた無名主役5本は全部この形）
- **軸は「その後・子孫」（上位11：中央1）と「有名人物の知られていない面」（9：6）**。避けるのは値段・制度・暮らしが主題（2：14）、小さな伝説の否定（4：11）、合戦や一生の通史（10：23）
- **知らない事実＝教科書・大河・Wikipedia の冒頭に出ないこと**。1分に2個以上（10〜30秒に1つ）、冒頭3分で7個以上、最初の1個は10秒以内
- 知られた流れ（結婚・合戦・本能寺など）は、知らない事実の前置きとして短く。知られた筋を順に語るだけの章を作らない（お市は第1〜3章の約11分がこれだった）
- **出どころは「誰が・いつ・何に書いたか」を1分に1回以上**。「と伝わります」は1本10回まで。名前の無い「研究では」は使わない
- **記録どうしの食い違いを1本に1〜3回並べる**（同じ場面を別の記録が違って書く・本人の手記と晩年の聞き書きのずれ・数の記録が数倍違う）
- 題名に知らない事実を1つ入れる。数字なら主役の運命を言う数字
- 新しい研究（2015年以降の新説・発掘・新史料）を優先して探し、ページを開いて確かめる。確かめられないものは台本に入れない
- **調べは `python -m chiso.cli research <名前>` から**（10-25）：NDL・NDL デジタルの全文・J-STAGE・ジャパンサーチ・Wikisource を直接叩き、出どころの段・2015年以降を上に・Wikipedia の冒頭に出るか（知らない度）・食い違いの欄を1枚の md に出す。SHIPS・全国遺跡報告総覧・CiNii は md の「手で開く入口」から。手順はスキル `rekishi-research`
- **事実カード**（10-26）：`research ... --slug <名> --cards --yt [--plan --chain --cards-in <Agent の YAML>]` で `research/<題>_facts_YYYYMMDD.yaml`（事実ごとに出どころの段・引用と頁・URL・本文を開いたか・独立した出どころの数・知らない度・他チャンネルの既出）。出どころが1つだけの事実は `single_source: true`
- **台本とつなぐ**：台本の一番上に `facts: <YAML の名前>`、事実を言う行のコメントに `# fact: masamune-03`（カードがまだ無ければ `# fact: ?`）。`check`（と `fact-check`）が「事実：」で、カードにつながらない行・本文も出どころ2つも無いのに「と伝わる」と言っていない行・冒頭3分の知らない事実（7個以上・1分に2個以上）を数える。カードの無い台本は見ない

## 1. 台本と見た目の分け方

- **台本（`scripts/<名前>.yaml`）は語りと事実だけ**。物語型の本編の書き方は `scripts/_template_story.yaml` と CLAUDE.md「2026-10-22 の見直し」（`story: true`・想像の台詞・締め）
- **画面の作りは look（`scripts/story/<名前>_main_look.yaml`）に書く**。台本に手を入れずに、絵の割り当て・動き・図の出し方・部品を決める

## 2. 画面

- **全幅の見出し帯は出さない**（参考 0/15）。**左上に小さな札「年月｜第N章 章題」**（字の高さ 約2.8%・半透明の黒地）
  - 年月は look の `chapters:` に章ごとの `now`（章の頭の「いま」）と `dates`（語りが年・月日を言った行 → その行から替わる）を**明示**する。台本の card の見出しは拾わない
  - 物語の時間が動かない章（検証）は `now: null` で章題だけ。最後の余韻（`no_tag_from` の行から）と終了画面は札なし
- **右上の札は数・要点だけ**（「37歳」「2度目の落城」）。幅 約20%。年・月日の見出しは出さない（左上にあるので）
- **語りの文字**：下中央・1行24字まで・2行まで、白の太字に黒の縁と影。下の絵が明るい所だけ半透明の座布団。**文（ブロック）ごとに一瞬で替える**（フェードしない。冒頭も0秒からはっきり）
  - 話し手の名前は出さない。**想像の台詞だけ**左上に灰紫の小さな「想像」札。**記録の言葉**（台本の人物の行で imagined でないもの）は明朝で、読んでいる所まで赤ペンの下線が伸びる
- **「AI生成画像」**は右上に小さく、**出典**は左下に小さく
- **章の頭**：声の前に4秒の章題カード（暗くした絵に「第N章」小＋章題を大きな明朝）。前後の間は0.3秒。序章は場面から始めるので出さない
- **最後**：声のあとに20秒の終了画面の空き（絵だけ。右半分が空いた絵 `end`）

## 3. 絵と動き（10-25 歴史横丁・キンブラの調べ）

- 主役は AI 絵（16:9、`main_art_dir`、1本 25枚まで）。実在の絵（パブリックドメインの古画・絵図）は**額のカード**（`frame:`）か**屏風・絵巻の一部**（`part:`）として使い、全面の主役にしない
- **全カットで一定の速さで動かす。主はパン（平行移動）**（ユーザー「寄せるではなく、上から下に、右から左に動くでは？」）
  - 絵を 1.08〜1.2倍に置き、その余白の中を端から端へ、**カットの最初から最後まで同じ速さ**で流す（画面の幅の毎秒 約1.6%。参考は 1.4〜2.5%。長いカットは余白の上限で遅くなる）
  - 縦の構図（全身・天守）は上下（look の ai の `pan: v`）、横の構図（城下・戦場・行列・廊下）は左右（`pan: h`、既定）。**隣のカットとは向きを替える**
  - **寄り（拡大）は顔の感情の場面だけ**（`pan: zoom`）。あごが字幕にかかる絵は寄らない
  - **向きと止まる所は話で決める**：その行で語る物・人・場所を look の `focus:` に書くと（`語|言い方: [倍率, 中心x, 中心y]`）、カットの終わりにそれが画面の主役になる所で止まるよう、反対側から流してくる
  - **2人目の名前を言う行は明かしのパン**：1枚の絵に `focus` が2つあり、そのカットで両方が語られると、1人目から2人目へ横に流す（額の古画でも同じ。歌麿の勝家→小谷の方）
  - 語った瞬間に寄る動きはしない（参考2チャンネルとも無い）。話に関係のない寄りはしない
- **切り替え**：次の文の頭の **0.2秒前**（参考 0.1〜0.3秒前）。**基本はハードカット**、同じ絵の別の構図（切り出し・図の有無）だけ0.5秒の溶け合い
- 同じ絵が続けて20秒を超えない・額が続いて30秒を超えない（全面の絵を挟む）。1カットの平均 約10秒
- **図の間は絵を暗くして止める**（キンブラ：図の場面は寄らない・揺らさない）。図が45秒を超えたら1ブロックだけ図を外す
- **絵の一部だけを動かす効果**（look の `fx:`）：炎のゆらぎ＋火の粉（`fire`・`sparks`）・灯のにじみのちらつき（`lamp`）・煙や霧の横流れ（`smoke`・`mist`）・水面の月の揺れ（`water`）。
  話に合う場面の絵だけ・控えめに。全面に重ねる粒子・ちらつきは参考に無いので入れない。顔・人物にはかけない（`region` で範囲をしぼる）

## 4. 図（語りに合わせて内容が増える）

- 台本の `figure:`（地図・系図・数の表・数直線…）を、**語りがその名前・記録・地点を言う0.25秒前から1つずつ書き込む**（サッカーの表の行が1本ずつ出る見せ方の流用）
- **関係図・系図はキンブラ型**：赤い点線が0.2秒で伸びる → 人物の札が0.25秒で溶け出す → 線の上の関係の小札。**系図・関係図の間は背景を止めたままでよい（1分近く続いても可。10-25 ユーザー「系図なら止まっても良い」）**
- 図を前後の行に広げて、語る行まで出しておくには look の `figure_extend: [{line, from, to, items}]`（`items` で書き込む順を語る順に）
- 地図は道のりが地点を言うたびに伸びる。数直線・数の表も語る順に
- **台本に無い図は look の `figures: [{from, to, spec}]` で足す**（10-26 数正：関係図・地図。台本を変えると承認が外れるため）。`spec: null` はその行の台本の図を外す（史料の札を主役にする行など）。
  地図に `reveal: true` を書くと、道のりの線を引かずに `places` を語る順に赤い点で打つ（地震の被害の範囲など）

## 5. 部品（look の `parts:`、from〜to の行のあいだ。出ている間は絵を暗くする）

| 部品 | type | 書き方 | 使い所 |
|---|---|---|---|
| ① 史料・要点の引用札（紺の板＋金の細枠＋小見出し＋太字＋書名） | `quote` | `{type: quote, from, to, label: 史料\|要点, text, source}` | 記録の言葉を引く行・章の要点 |
| ② 数のくい違い（箱を矢印でつなぎ、最後を赤。左から1つずつ） | `versus3` | `{type: versus3, from, to, items: [[見出し, 数], ...], every: 秒}` | 年・年齢・人数の説が割れる行 |
| ③ 覚えてほしい名前（肖像＋名前の札を3枚、1枚ずつ） | `names` | `{type: names, from, to, title, items: [[名前, 一言, 絵], ...], every}`（絵が無ければ「？」） | 序章の終わり |
| ④ 地図の矢印・印 | （図の map） | 台本の `figure: {type: map, route: [...]}`。語りが地点を言うと伸びる | 合戦・移動 |
| （補）覚えてほしい名前に AI 絵 | `names` | items の絵に `ai:K14`（肖像の古画が無い人物） | 10-26 |
| ⑤ 史料の頁＋該当の行を赤枠＋右上に出典 | `doc` | `{type: doc, from, to, image, box: [左,上,右,下], source, note}` | 記録を頁から見せる行（パブリックドメインの頁の画像があるとき） |

## 6. 音

- 声は chiso の音声合成（剣崎＝語り、人物は config の roles）。行の間は本編の決まり（gap_before）の0.75倍
- **BGM は `chiso/storyaudio.py` の合成を、声より LUFS で 30.5LU 下**（比べの物差し＝50ms の音の中央値と声の切れ目の中央値の差で 約23dB。参考の中央値 23dB）。効果音なし
- 全体を同じ倍率で -16 LUFS へ（loudnorm は使わない：声の間で BGM を持ち上げて差が縮んだ）

## 7. 作り方とコマンド

```
python -m chiso.cli story-main scripts/story/x_main_look.yaml [--ver v6]     # look の stills: の静止画と一覧、全カットの表（out/<名前>_shotlist.md）
python -m chiso.cli story-main scripts/story/x_main_look.yaml --build [--limit 60]   # 本編を書き出す（声・BGM 込み。--limit で頭の何秒だけ試し）
python -m chiso.cli story-main scripts/story/x_main_look.yaml --frames L0+2,L19+6,C2,end [--sheet out/x.jpg]   # 書き出しと同じ描き方（パン・fx・部品・図の書き込み）で、その時点のコマだけ
```

- 部品（parts）の出ている行は、台本の右上の札（card）を出さない（同じ言葉を2つ並べない。10-26）
- 台本に出てこない実在の絵の出典は look の `credits: {paintings/x.jpg: 作品名}`（左下の字・概要欄）

- 書き出しは、カットごとに補正済みの絵を1枚作り、動きは cv2 の小数の位置の補間、文字・札・図は透明な画像を範囲だけ重ね、8本に分けて4本ずつ並行で描いて ffmpeg でつなぐ（25分の本編で約30分）
- 仮ファイルに書いて長さを測ってから置き換える。ディスクの空きが30GB未満なら止まる。書き出しを2本同時に走らせない
- 書き出したら：全編のデコード検査（`ffmpeg -v error -i x.mp4 -f null -` で壊れ0）・2分ごとのコマ一覧・確認用の軽い版（480p・crf32 で 約20MB）
- 測り直しは調べの物差し（mainana の `changes.py`・`analyze.py`・`audio.py`）で、冒頭・中盤・終盤の180秒ずつ
- 台本の確認の関門（reading-ok・approve）は本編と同じ。投稿の前に本番の動画を見せる
