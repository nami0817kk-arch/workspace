# 物語型の本編（横 1920x1080）の決まり

10-24〜10-25 にユーザーと決めたこと・他チャンネルの調べから入れたことのまとめ。見本はお市の方（台本 `scripts/oichi-story.yaml`、見た目 `scripts/story/oichi_main_look.yaml`）。
作るのは `chiso/storymain.py`（CLI は `story-main`）。旧型の本編（掛け合い・`chiso/render.py`）とは別の仕組みで、旧型には触らない。
縦の物語型ショートは `docs/story-shorts.md`。

調べ：`dev/output/rekishi-chiso/research/` の `main_screen_benchmark_1024.md`（15本）・`oichi_story_vs_benchmark_1025.md`（うちとの比べ）・`screen_parts_1025.md`（動かし方と部品）。

## 1. 台本と見た目の分け方

- **台本（`scripts/<名前>.yaml`）は語りと事実だけ**。物語型の本編の書き方は `scripts/_template_story.yaml` と CLAUDE.md「2026-10-22 の見直し」（`story: true`・想像の台詞・締め）
- **画面の作りは look（`scripts/story/<名前>_main_look.yaml`）に書く**。台本に手を入れずに、絵の割り当て・動き・図の出し方・部品を決める

## 2. 画面

- **全幅の見出し帯は出さない**（参考 0/15）。**左上に小さな札「年月｜第N章 章題」**（字の高さ 約2.8%・半透明の黒地）
  - 年月は look の `chapters:` に章ごとの `now`（章の頭の「いま」）と `dates`（語りが年・月日を言った行 → その行から替わる）を**明示**する。台本の card の見出しは拾わない
  - 物語の時間が動かない章（検証）は `now: null` で章題だけ。最後の余韻（`no_tag_from` の行から）と終了画面は札なし
- **右上の札は数・要点だけ**（「37歳」「2度目の落城」）。幅 約20%。年・月日の見出しは出さない（左上にあるので）
- **語りの文字**：下中央・1行24字まで・2行まで、白の太字に黒の縁と影。下の絵が明るい所だけ半透明の座布団。**文（ブロック）ごとに一瞬で替える**（フェードしない。冒頭も0秒からはっきり）
  - 話し手の名前は出さない。**想像の台詞だけ**左上に灰紫の小さな「想像」札。**記録の言葉**（台本の人物の行で imagined でないもの）は明朝で、読んでいる所まで赤ペンの下線が伸びる
- **「AI生成画像」**は右上に小さく、**出典**は左下に小さく
- **章の頭**：声の前に4秒の章題カード（暗くした絵に「第N章」小＋章題を大きな明朝）。前後の間は0.3秒。序章は場面から始めるので出さない
- **最後**：声のあとに20秒の終了画面の空き（絵だけ。右半分が空いた絵 `end`）

## 3. 絵と動き（10-25 歴史横丁・キンブラの調べ）

- 主役は AI 絵（16:9、`main_art_dir`、1本 25枚まで）。実在の絵（パブリックドメインの古画・絵図）は**額のカード**（`frame:`）か**屏風・絵巻の一部**（`part:`）として使い、全面の主役にしない
- **全カットで一定の速さで動かす。主はパン（平行移動）**（ユーザー「寄せるではなく、上から下に、右から左に動くでは？」）
  - 絵を 1.08〜1.2倍に置き、その余白の中を端から端へ、**カットの最初から最後まで同じ速さ**で流す（画面の幅の毎秒 約1.6%。参考は 1.4〜2.5%。長いカットは余白の上限で遅くなる）
  - 縦の構図（全身・天守）は上下（look の ai の `pan: v`）、横の構図（城下・戦場・行列・廊下）は左右（`pan: h`、既定）。**隣のカットとは向きを替える**
  - **寄り（拡大）は顔の感情の場面だけ**（`pan: zoom`）。あごが字幕にかかる絵は寄らない
  - **向きと止まる所は話で決める**：その行で語る物・人・場所を look の `focus:` に書くと（`語|言い方: [倍率, 中心x, 中心y]`）、カットの終わりにそれが画面の主役になる所で止まるよう、反対側から流してくる
  - **2人目の名前を言う行は明かしのパン**：1枚の絵に `focus` が2つあり、そのカットで両方が語られると、1人目から2人目へ横に流す（額の古画でも同じ。歌麿の勝家→小谷の方）
  - 語った瞬間に寄る動きはしない（参考2チャンネルとも無い）。話に関係のない寄りはしない
- **切り替え**：次の文の頭の **0.2秒前**（参考 0.1〜0.3秒前）。**基本はハードカット**、同じ絵の別の構図（切り出し・図の有無）だけ0.5秒の溶け合い
- 同じ絵が続けて20秒を超えない・額が続いて30秒を超えない（全面の絵を挟む）。1カットの平均 約10秒
- **図の間は絵を暗くして止める**（キンブラ：図の場面は寄らない・揺らさない）。図が45秒を超えたら1ブロックだけ図を外す
- **絵の一部だけを動かす効果**（look の `fx:`）：炎のゆらぎ＋火の粉（`fire`・`sparks`）・灯のにじみのちらつき（`lamp`）・煙や霧の横流れ（`smoke`・`mist`）・水面の月の揺れ（`water`）。
  話に合う場面の絵だけ・控えめに。全面に重ねる粒子・ちらつきは参考に無いので入れない。顔・人物にはかけない（`region` で範囲をしぼる）

## 4. 図（語りに合わせて内容が増える）

- 台本の `figure:`（地図・系図・数の表・数直線…）を、**語りがその名前・記録・地点を言う0.25秒前から1つずつ書き込む**（サッカーの表の行が1本ずつ出る見せ方の流用）
- **関係図・系図はキンブラ型**：赤い点線が0.2秒で伸びる → 人物の札が0.25秒で溶け出す → 線の上の関係の小札。**系図・関係図の間は背景を止めたままでよい（1分近く続いても可。10-25 ユーザー「系図なら止まっても良い」）**
- 図を前後の行に広げて、語る行まで出しておくには look の `figure_extend: [{line, from, to, items}]`（`items` で書き込む順を語る順に）
- 地図は道のりが地点を言うたびに伸びる。数直線・数の表も語る順に

## 5. 部品（look の `parts:`、from〜to の行のあいだ。出ている間は絵を暗くする）

| 部品 | type | 書き方 | 使い所 |
|---|---|---|---|
| ① 史料・要点の引用札（紺の板＋金の細枠＋小見出し＋太字＋書名） | `quote` | `{type: quote, from, to, label: 史料\|要点, text, source}` | 記録の言葉を引く行・章の要点 |
| ② 数のくい違い（箱を矢印でつなぎ、最後を赤。左から1つずつ） | `versus3` | `{type: versus3, from, to, items: [[見出し, 数], ...], every: 秒}` | 年・年齢・人数の説が割れる行 |
| ③ 覚えてほしい名前（肖像＋名前の札を3枚、1枚ずつ） | `names` | `{type: names, from, to, title, items: [[名前, 一言, 絵], ...], every}`（絵が無ければ「？」） | 序章の終わり |
| ④ 地図の矢印・印 | （図の map） | 台本の `figure: {type: map, route: [...]}`。語りが地点を言うと伸びる | 合戦・移動 |
| ⑤ 史料の頁＋該当の行を赤枠＋右上に出典 | `doc` | `{type: doc, from, to, image, box: [左,上,右,下], source, note}` | 記録を頁から見せる行（パブリックドメインの頁の画像があるとき） |

## 6. 音

- 声は chiso の音声合成（剣崎＝語り、人物は config の roles）。行の間は本編の決まり（gap_before）の0.75倍
- **BGM は `chiso/storyaudio.py` の合成を、声より LUFS で 30.5LU 下**（比べの物差し＝50ms の音の中央値と声の切れ目の中央値の差で 約23dB。参考の中央値 23dB）。効果音なし
- 全体を同じ倍率で -16 LUFS へ（loudnorm は使わない：声の間で BGM を持ち上げて差が縮んだ）

## 7. 作り方とコマンド

```
python -m chiso.cli story-main scripts/story/x_main_look.yaml [--ver v6]     # look の stills: の静止画と一覧、全カットの表（out/<名前>_shotlist.md）
python -m chiso.cli story-main scripts/story/x_main_look.yaml --build [--limit 60]   # 本編を書き出す（声・BGM 込み。--limit で頭の何秒だけ試し）
```

- 書き出しは、カットごとに補正済みの絵を1枚作り、動きは cv2 の小数の位置の補間、文字・札・図は透明な画像を範囲だけ重ね、8本に分けて4本ずつ並行で描いて ffmpeg でつなぐ（25分の本編で約30分）
- 仮ファイルに書いて長さを測ってから置き換える。ディスクの空きが30GB未満なら止まる。書き出しを2本同時に走らせない
- 書き出したら：全編のデコード検査（`ffmpeg -v error -i x.mp4 -f null -` で壊れ0）・2分ごとのコマ一覧・確認用の軽い版（480p・crf32 で 約20MB）
- 測り直しは調べの物差し（mainana の `changes.py`・`analyze.py`・`audio.py`）で、冒頭・中盤・終盤の180秒ずつ
- 台本の確認の関門（reading-ok・approve）は本編と同じ。投稿の前に本番の動画を見せる
