# 物語型ショート（物語完結型）の決まり

10-22〜10-24 にユーザーと決めたことのまとめ。見本はお市の方（`scripts/story/oichi_s10.yaml`。第1版〜第10版の経緯は各台本の頭のコメント）。
本編へ誘うショートとは別の、**1本で話が完結する縦型の短い物語**。作るのは `chiso/storyshort.py`（CLI は `story-short`）。

## 1. 話：物語完結型

- **冒頭は「誰が・何を」＋感情の結末予告**。1行目で人物（誰の何か）と、いちばん重い結末を言う（例「信長の妹、お市の方は、二度目の落城で、逃げなかった。」）
- **1文に1つの出来事**。**主語・年・場所を言葉で言う**（代名詞だけで済ませない。「勝家の北ノ庄城」「1583年」）
- 筋に要らない挿話は外す（第9版で「別れの夜、歌が聞こえた」などを外した。10-22「これだとなんの話をしているかわからない」）
- **理解テスト4問**：初めて見る人が、見終わって語りの字だけで答えられること。台本を書いたら表を作る（見本 `out/oichi_story_s9_qa.md`）
  ①誰の話か ②いつ・どこで何が起きたか ③その人は何を選んだか、なぜか ④どうなったか
- 最後の行は、①〜④を知った人に返す問い（例「あなたなら、娘を送り出して、逃げずにいられますか。」）
- 事実は台本に書いた資料の範囲だけ。伝承は「と伝わる」と言う

## 2. 画面の文字

- **画面の文字は語りそのまま**（一字一句同じ。「、」「。」だけ除く）
- **ブロックで一度に出す**。文節ごとに増えていく方式はやらない（10-22「文字が増えてくのはやらんでいい」）
- **1行10字まで・2行まで**。白に黒の太い縁取り、強調語（《》）は黄色。最初のブロックだけ少し大きく
- 短すぎるブロック（`min_block` 秒未満）は隣と結ぶ
- 絵の中の字（落款・題字）と重なるカットは、shot に `text_box: true`（文字の下に半透明の箱）。カードや CTA と重なる所は shot・カードの `text_y` で逃がす

## 3. 上の常時表示：案B（10-24 に3案から決定）

- **黒い太帯**（上から約310px、ほぼ不透明）に、**赤い札**（例「お市の方（織田信長の妹）」）と**大きな題を2行**（《》の語は赤）。題は画面の幅の8割まで、超えたら「、」で2行に
- 帯の下の1段に、**「いま」の札**（いまの年・場所。語りがその年・場所を言った瞬間に切り替わる）と**年表のバー**（年だけ・いまの点が黄色）
- 0秒からずっと出す（`hook_clear: 0`）。「AI生成画像」の札は帯の右上に小さく
- 台本：`header:`（tag・title）・`now:`（at・text・point）・`timeline:`（label）。`header_style` を書かなければ B。`A`（今の配置で1.5倍）・`C`（帯なし）・`v9`（第9版の小さい形）も残してある
- 比べた3案の静止画：`out/oichi_story_s10_layouts.jpg`

## 4. 図解カード

語りの時刻（`from`・`until` に語りの中の字）で出入りする。上の帯の分だけ自動で下げる。

| type | 使い方 |
|---|---|
| `table` | 年表（2〜3行が語りに合わせて1行ずつ出る）。例「1573年 小谷城（夫・浅井長政）落城」 |
| `versus` | 対比（例「送り出した娘 3人 対 残ったお市 1人」） |
| `year` | 年号を特大で＋赤い下線＋呼び名（例「1615年 大坂の陣」） |
| `map` | 地図（Natural Earth）に印 |

## 5. 絵

- **表情のあるAI人物絵**：Gemini を Chrome で操作して作る。**同じ会話の中で作って人物の顔・髪・着物をそろえる**。**実在の俳優・人物に似た顔は使わない**（第7版で似て見えた P5・P5b・P3・P3b は外した）。実在人物の顔写真・肖像の加工はしない
  - 補いに FLUX（`tools/gen_story_art.py`・`tools/gen_story_faces.py`。Cloudflare の無料枠。正方形しか出ないので中央を縦に切る）
- **実在の絵**（パブリックドメインの絵画・絵図・屏風）：出典を画面の左下に小さく
- **語りと絵は1対1**（その行で話していることが映っている）。**1本に7〜14カット**
- 全部の絵に同じ色調の補正（彩度を抑え・周辺を暗く・粒子）、ゆっくり寄る／流れる動き、替わり目は溶け合わせる

## 6. 声

- **剣崎雌雄**（語り1人）。**速さは約1.3倍（毎分約380〜400字）**、**1.4倍を超えない**（10-22「ゆっくりすぎる」「もう少し早口で」）
- 調子ごとの速さは台本の `tone_speed`、声の設定は `voice:`。毎分の字数は `out/<名前>_audio.md` に出る
- 読み違いは `readings.yaml` に足し、`--kana` で全行の読みを先に見る

## 7. 音

- **効果音なし**（10-22「変な効果音はいらない」。`sfx: false` が既定）
- **BGM は numpy で合成**（`chiso/storyaudio.py`：弦＋ピアノ、BPM 76、立ち上がり2.5秒）。**声より11LU小さく**（`bgm: true`・`bgm_diff_lu: 11`）

## 8. 長さ

- **47〜60秒**（書き出しの最後に、59秒（`MAX_SECONDS`）を超えると知らせが出る）

## 9. AI の申告

- 画面の隅に「AI生成画像」（AI の絵のカットだけ）
- 概要欄に画像についての文面（見本 `out/oichi_story_s7_ai_disclosure.txt`）
- 投稿で `containsSyntheticMedia` を付ける（`chiso/upload.py` の `synthetic_media=True`）

## 10. 確認の順番

1. **静止画で先に見せる**（イメージ合わせ）：`--frames` のコマ一覧、見せ方の案があれば `--layouts` で並べる
2. OK が出てから**動画**（`--draft` → 本番）
3. 投稿はしない（ユーザーが決める）

## 作り方とコマンド

```
python -m chiso.cli story-short scripts/story/x.yaml --kana                    # 全行の読み（音を出す前に）
python -m chiso.cli story-short scripts/story/x.yaml --stills                  # 声を作らず、ブロックごとの1コマの一覧（目安の時刻・仮の絵でも可）
python -m chiso.cli story-short scripts/story/x.yaml --frames 0,4,18,28,50,58  # 本番の声の時刻で、その秒のコマを PNG と一覧に（動画は書かない）
python -m chiso.cli story-short scripts/story/x.yaml --frames 0,18,50 --layouts A,B,C   # 上の常時表示の案を並べる（行＝案、列＝秒）
python -m chiso.cli story-short scripts/story/x.yaml --draft                   # 確認用の動画（届いていない絵は仮の絵）
python -m chiso.cli story-short scripts/story/x.yaml                           # 本番の mp4（＋_preview・_sheet・_sync・_audio）
python tools/gen_story_art.py scripts/story/x.yaml [--only A,D] [--redo]      # kind: ai の絵を FLUX で
python tools/gen_story_faces.py P1 P2 --n 4                                    # 人物の表情の絵の候補を FLUX で
```

- 出力は `out/<out:の名前>*`（`--frames` の単体は `out/<名前>_frames/`）。声の控えは `work/<台本>_story/voice`
- テストは `tests/test_storyshort.py`
