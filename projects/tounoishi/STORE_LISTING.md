# 塔の意志：App Store の掲載文の案

2026-11-23 に作った初回提出用の案。ゲームの中身は `assets/game/index.html` の遊び方（`id="spane-help"`）から書いた。
貼るときは欄ごとにコードブロックの中身だけを写す。

- 使わない文字（「このフィールドには1つ以上の無効な文字」で弾かれた実績）：星の記号・四角の記号・長いダッシュ・中黒の丸・markdown のアスタリスク。見出しは【】、箇条書きは「・」と「-」、区切りは「：」
- 実在のゲーム名・会社名は書かない
- 文字数はコードブロックの中身で数えた（サブタイトルは30文字まで、キーワードは100バイトまで。日本語は1文字3バイト）
- 名前とサブタイトルに入っている語（塔・掘る・ダンジョン・防衛・魔物）は検索に効くので、キーワードには重ねて入れない
- ゲームの画面は今は日本語だけ。英語の掲載は、ゲームが英語に対応してから足す（今は日本語だけで出すのを勧める）。英語の案は下に置いておく

### 概要（説明。4000文字まで）
```
あなたは、姿の見えない「塔の意志」。
魔物に命令することはできません。できるのは、土を掘ることだけ。

掘った土の養分から魔物が生まれ、魔物は弱い魔物を食べて増えていきます。
どこを掘り、どこを残すか。その一手で、塔の中の生き物たちの暮らしが変わります。
攻めてくる冒険者に、最上階のコアを入口まで運ばれたら負け。第6波まで守り切れば、塔が1階伸びます。

【掘って、生ませる】
・掘ってある道の隣の土だけ掘れる。指でなぞって、離せばまとめて掘れる
・養分（金）からはスライム・ワーム・リザード・ドラゴンなど、魔分（紫）からはウィスプ・インプ・ハーピー・デーモンなどが生まれる
・苔・水・岩の土の色で、同じ種でも姿と強さが変わる
・掘る力には限りがある。冒険者を倒すと戻り、塔が伸びると大きく戻る

【食べ合い、増える】
・魔物は1つ下の段を食べて育つ。増え方は種ごとに違う（分裂・胞子・さなぎ・卵・巣・群れ）
・同じ種が倒され続けると、次の1匹が突然変異する（強化種・異常種・巨大種）
・スライムは養分を運び、弱るとツボミになって花を咲かせる。ドラゴンは傷つくと卵に戻り、生まれ変わる
・周りを掘り抜いて魔法陣を作れば、デーモンやリッチを呼べる

【主役と宿敵】
・よく食べた魔物、冒険者を何人も倒した魔物は、まれに名前と技を持つ「主役」に昇格する
・第6波には宿敵の勇者が来る。逃げ帰った勇者は技を覚えて、強くなって戻ってくる
・塔が落ちても、主役たちは殿堂に名を残す

【冒険者を迷わせる】
・冒険者は、入った時に掘ってあった道だけを探す。コアは近くまで来て初めて見つける
・枝道や行き止まりを掘って迷わせ、魔物の待つ所へ誘い込もう
・塔が高くなると、氷の層・溶岩の層や、新しい職業の冒険者が現れる

【遊び方いろいろ】
・難しさは「ゆったり」「ふつう」「きびしい」の3つ
・決まった条件で挑む短い面「チャレンジ」
・見つけた魔物と特殊タイプを集める図鑑
・時間は止めてから準備できる。途中で閉じても、続きから再開できる

【広告について】
塔が落ちて結果を出す前と、塔が1階伸びる前に、全画面広告が出ることがあります。
アプリ内課金「広告を消す」（買い切り）で、全画面広告が出なくなります。

ゲームの記録は端末の中にだけ保存し、アカウント登録はありません。
```

- Short Challenge stages with fixed rules

## 掲載画像

- 生成器：`python tool/screenshots/capture.py`（projects/tounoishi で。手元の Edge を画面なしで動かす。要るのは Python の websockets と Pillow）
- 出力：`~/Downloads/塔の意志_掲載画像/1_iPhone_日本語/`（iPhone 中型 1206×2622、5枚）
  1. `01_dig` 掘っているところ（最上階・準備の時間）
  2. `02_battle` 冒険者と戦っているところ（1階）
  3. `03_hero` 主役と勇者
  4. `04_list` 一覧のシート（主役・宿敵の勇者・塔の軍）
  5. `05_title` タイトル
- 検索結果には先頭3枚しか出ないので、何ができるゲームかが伝わる3枚を前に置いた（タイトルは最後）
- 課金アイテムの審査用スクリーンショット（値段のボタンが写った1枚）は、アプリの中でしか値段が出ないので、TestFlight の実機で未購入のタイトル画面を撮る
- iPhone のみ（iPad では動かさない）なので、iPad の掲載画像は要らない
