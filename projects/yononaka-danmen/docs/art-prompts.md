# 絵の依頼文（Gemini 用、2026-10-06）

ユーザーが Gemini で作り、チャットに貼る。受け取ったら Claude が切り抜き・表情差分・口パクを作って動画に入れる。

## 共通の約束（どの絵にも）

- **背景は真っ白**。影も落とさない（こちらで切り抜くため）
- **1人だけ**。正面を向いて、まっすぐ立つ。全身
- **見た目で惹きつけることを狙う**。2人とも整った顔立ちにする
- **口は閉じ、目は開ける**。表情は落ち着いたまま（驚き顔・口パクはこちらで作る）
- **手には何も持たせない**。腕は体の横に自然に下ろす（表情差分を作りやすくするため）
- **文字・ロゴ・透かし・記号を入れない**
- 絵柄は**今の日本のアニメ・ライトノベルの挿絵**のような、**かわいらしい2次元の絵**。
  線は細くやわらかく、目は大きめ、頬にうっすら赤み。**6〜7頭身**に少しデフォルメする。
  色は淡いパステル寄りで、影は平らに塗る。写実にしない
- 服は**現代の日本**のもの。奇抜にしない
- Gemini が右下に小さな印を入れることがある。右下は何も描かれていなくてよい（こちらで切る）

## 2人の見た目の決まり

このチャンネルの目印は**紺色**。2人とも紺を身につける（「歴史の地層」の黄色いヘルメットに当たるもの）。

## 1. 語り役（設計士）

```
縦長の全身イラストを1枚。かわいらしい2次元のアニメ絵で、今のライトノベルの挿絵のような絵柄。
日本人の男性、35歳くらい。見た目で惹きつける、整った顔立ちの美男子。
さらりとした黒髪を横に流し、切れ長の涼しげな目、すっきりした輪郭、細いフレームの眼鏡。
穏やかで知的な、少しだけ微笑んだ表情。
白い長袖シャツの袖を軽くまくり、紺色のベストを着ている。濃いグレーのズボン。
背が高く姿勢がよい。7〜8頭身。線は細くやわらかく、色は淡いパステル寄りで影は平らに塗る。
正面を向いてまっすぐ立ち、腕は体の横に自然に下ろす。口は閉じ、目は開ける。
背景は真っ白、影も落とさない。文字・ロゴ・記号は入れない。
```

## 2. 聞き役（生活者）

```
縦長の全身イラストを1枚。かわいらしい2次元のアニメ絵で、今のライトノベルの挿絵のような絵柄。
日本人の女性、20代なかば。素直で明るい、親しみやすい顔立ち。
肩までのふんわりした黒髪に、ゆるい内巻き。大きめのまるい目、小さな口、頬にうっすら赤み。
紺色のゆったりしたカーディガンの下に白いシャツ、ベージュのズボン。
6〜7頭身に少しデフォルメし、線は細くやわらかい。
色は淡いパステル寄りで、影は平らに塗る。写実にしない。
正面を向いてまっすぐ立ち、腕は体の横に自然に下ろす。口は閉じ、目は開ける。
背景は真っ白、影も落とさない。文字・ロゴ・記号は入れない。
```

## 受け取ったあとにこちらですること

1. 白背景を抜いて透過PNGにする
2. 口の開き（3段）を描き足す（「歴史の地層」の `chiso/jaw.py` と同じやり方）
3. 表情差分（ふつう／おどろき／納得）を作る
4. 画面の左右に置く（語り役＝左、聞き役＝右）

**同じ人物の表情違いを Gemini に作らせない**。同じ顔が出てこないため。1枚だけ作ってもらい、差分はこちらで描き足す。

## 作り直しを頼むときの言い方

- 「もっと若く／年配に」
- 「眼鏡をなくして」
- 「もっとかわいく、もっとデフォルメして」「頭身を下げて」
- 「線をもっと細く、色をもっと淡く」
- 「写実的すぎるので、アニメ寄りに」
- 「背景に色がついてしまっているので、真っ白にして」
