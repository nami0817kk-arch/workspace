## 1. プロジェクトを作る

https://console.cloud.google.com/projectcreate

- **プロジェクト名**に `yononaka-danmen` と入れる
  （既定で `My Project 4625` のような名前が入っているので、消して打ち直す）
- プロジェクト ID は自動で付く（`console-verse-...` のような文字列）。変えなくてよい
- 組織（親リソース）は「組織なし」のまま
- **［作成］** をクリック

画面の上に「割り当て内の残りのプロジェクト数は N projects です」と出るが、気にしなくてよい。

作り終わったら、**画面の上のプロジェクト名が `yononaka-danmen` になっているか見る。**
以降の作業は、このプロジェクトを選んだ状態で行う。

## 2. YouTube Data API v3 を有効にする

https://console.cloud.google.com/apis/library/youtube.googleapis.com

- 画面の上のプロジェクトが `yononaka-danmen` になっているか確かめる
- **［有効にする］** をクリック

## 3. OAuth を設定する（Google Auth Platform）

https://console.cloud.google.com/auth/overview

**「Google Auth Platform」**に変わっている。

「Google Auth Platform はまだ構成されていません」と出るので **［開始］** をクリック。
（Google の公式ドキュメントには「スタートガイド」と書かれているが、画面のボタンは「開始」）

順に聞かれるので、こう答える。

| 聞かれること | 答え |
|---|---|

### テストユーザーを足す（外部を選んだので必須）

→ **「日本のなぜ」を持っている Google アカウントのメールアドレス**を入れて ［保存］。

**審査には出さない。テストのまま使う。**
自分のチャンネルに自分で投稿するだけなので、公開（本番）にする必要がない。

### スコープ

左メニューの **［データアクセス］** → **［スコープの追加または削除］** で足せるが、
**ここで足さなくてもよい**。`post.py reauth` が許可を求めるときに、
必要なスコープ（`youtube.upload` と `youtube.force-ssl`）を一緒に出す。

```bash

python scripts/post.py reauth
```

ブラウザが開くので、

1. **「日本のなぜ」を持っている Google アカウント**を選ぶ
2. 「このアプリは Google で確認されていません」と出たら、**［詳細］→［（アプリ名）に移動］**

3. **チャンネルを選ぶ画面が出たら「日本のなぜ」を選ぶ**
4. 項目を**すべて**許可する

## 投稿する

```bash
python scripts/post.py describe 台本.yaml                   # 概要欄の文面を見る
python scripts/post.py screen 台本.yaml                     # 動画を見せて OK をもらってから
python scripts/post.py upload 台本.yaml --at "2026-10-09 19:00"
```

- `screen` を打っていないと `upload` は動かない（**動画を見せる関門**）
- 動画を作り直すと sha256 が変わるので、確認もやり直し
- 公開時刻は**日本時間・9時〜24時**。15分以上先
- 同じ題名が3時間以内に上がっていると止まる（二重投稿の防止）
- 投稿の控えは `posted.json`

## つまずき所

- **許可が切れる。** テストのまま使うので、しばらく使わないと失効することがある。
  `post.py` は失効を見つけると `reauth` の手順を出して止まる。取り直せばよい
- **別のチャンネルに投稿してしまう。** `reauth` は毎回アカウント選択を出す
  （`select_account consent`）。`upload` は投稿の前にチャンネル名を確かめ、
  「日本のなぜ」でなければ止まる
- **サムネイルで落ちても動画は上がっている。** 掛け直すと同じ動画が2本になる
  （2026-09-08 に実際に起きた）。だから `upload` はサムネイルの失敗を警告だけにする
- **予約公開は `private` ＋ `publishAt`。** `public` にすると即公開になる
