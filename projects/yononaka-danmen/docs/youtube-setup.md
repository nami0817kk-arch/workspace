# YouTube へ投稿できるようにする（1回だけ）

チャンネル「日本のなぜ」（`@nihonnaze`）に予約投稿するための下ごしらえ。
**ユーザーの作業**（Google のアカウント操作なので、Claude は代わりにやらない）。

## なぜチャンネルごとに分けるか

Google Cloud のプロジェクトは**チャンネルごとに分ける**（2026-10-04 ユーザー決定）。
API の1日の枠（10,000ユニット）を分け合わないため。投稿1本で約1,600ユニット使うので、
1つのプロジェクトを3チャンネルで共有すると、1日2本で頭打ちになる。

| チャンネル | Google Cloud のプロジェクト |
|---|---|
| 海外サッカーの理由 | （サッカー用） |
| 歴史の地層 | `rekishi-chiso` |
| **日本のなぜ** | **`yononaka-danmen`（これから作る）** |

**課金は発生しない。** YouTube Data API v3 の無料枠だけで足りる（1日10,000ユニット、
投稿6本ぶん）。Google Cloud のプロジェクト作成そのものも無料。

## 手順

1. [Google Cloud Console](https://console.cloud.google.com/) で**新しいプロジェクト**を作る。
   名前は `yononaka-danmen`
2. 「API とサービス」→「ライブラリ」で **YouTube Data API v3** を有効にする
3. 「OAuth 同意画面」を設定する
   - ユーザーの種類：**外部**
   - アプリ名・サポートメール・デベロッパーの連絡先を入れる
   - **テストユーザー**に、「日本のなぜ」を持っている Google アカウントを足す
     （審査に出さない。テストのままで使う）
4. 「認証情報」→「認証情報を作成」→ **OAuth クライアント ID**
   - 種類：**デスクトップアプリ**
   - 作ったら JSON をダウンロードする
5. ダウンロードした JSON を、**リポジトリの外**に置く
   ```
   C:\Users\なみ\dev\output\yononaka-danmen\secrets\client_secret.json
   ```
   workspace は public なので、鍵をリポジトリに入れない
6. 許可を取る（ブラウザが開く）
   ```bash
   python scripts/post.py reauth
   ```
   **「日本のなぜ」のチャンネルを選ぶ。** 別のチャンネルを選ぶと、そちらに投稿してしまう
7. 繋がったか確かめる
   ```bash
   python scripts/post.py whoami
   ```
   「チャンネル：日本のなぜ ニュースを数字で切る」と出れば終わり

## 投稿する

```bash
python scripts/post.py screen 台本.yaml                     # 動画を見せて OK をもらってから
python scripts/post.py upload 台本.yaml --at "2026-10-09 19:00"
```

- `screen` を打っていないと `upload` は動かない（**動画を見せる関門**）
- 動画を作り直すと sha256 が変わるので、確認もやり直し
- 公開時刻は**日本時間・9時〜24時**。15分以上先
- 同じ題名が3時間以内に上がっていると止まる（二重投稿の防止）
- 投稿の控えは `posted.json`

## つまずき所（歴史の地層で踏んだもの）

- **別のチャンネルに投稿してしまう。** `reauth` は `select_account consent` でアカウント選択を
  毎回出す。`upload` は投稿の前にチャンネル名を確かめ、「日本のなぜ」でなければ止まる
- **サムネイルで落ちても動画は上がっている。** 掛け直すと同じ動画が2本になる（2026-09-08 に発生）。
  だから `upload` はサムネイルの失敗を警告だけにして videoId を返す
- **予約公開は `private` ＋ `publishAt`。** `public` にすると即公開になる
