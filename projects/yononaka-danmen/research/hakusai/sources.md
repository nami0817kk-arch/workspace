# 白菜が高い。野菜の値段は誰がどう決めるのか — 材料（2026-10-11 に原典を当たった）

## 守る線
- 特定の産地・業者を悪者にしない。農家・市場の是非を言わない。**価格の見通しを言わない**（農水省の「価格見通し」は使わない。観測された事実だけ）
- 内訳の「卸売・仲卸・小売」は**経費と利潤を含む試算値**。「中間業者の取り分」と言い切らない
- 小売の最新は 9月11日（全国平均）。10月の小売は未確認
- 平年比は「日別価格と過去5か年の旬別価格の平均値との比」（農水省の注記）

## 1. 今の値段（東京都中央卸売市場、はくさい、円/kg と平年比）
- 農水省「東京都中央卸売市場における指定野菜の価格及び平年比」（令和8年9月30日の報道発表に添付、出典「青果物卸売市場調査」）：9/1 66円(66%)、9/8 88円(88%)、9/12 114円(98%)、9/17 141円(122%)、9/19 146円(126%)、9/23 182円(172%)、9/24 172円(162%)
- 農畜産業振興機構（ALIC）「やさいレポート はくさい（令和8年10月号）」（令和8年10月9日発行）：**10/6 192円/kg、平年比181%**
- 9/1 の 66円 → 10/6 の 192円：約5週間で約2.9倍（こちらで割った）
- 9/24 の他の野菜（円/kg・平年比）：キャベツ 120円・120%、だいこん 133円・95%、にんじん 134円・91%、レタス 487円・232%、はくさい 172円・162%
- **小売**：ALIC 引用の農水省データ「260円/kg（9月11日全国平均）、前月比76%、平年比95%、東京177円（1/4玉）、大阪169円（1/4玉）」。9/11 は卸売 108円（平年比93%）で小売は平年を下回っていた

## 2. なぜ高いか（公的な説明）
- 農水省「野菜の生育状況及び価格見通し（令和8年10月）」（9月30日）：主産地は長野(87%)・茨城(7%)（令和7年10月の入荷シェア）。「長野県産は9月の長雨と日照不足により生育不良や歩留まりの低下がみられ」（見通しの部分は使わない）
- ALIC：「長雨、低温で生育遅延による小玉傾向や雨による収穫遅れに加えて、気温の低下から需要も高まり、月平均で、入荷量は平年を約２割下回り、価格も約２割上回った」（9月）。長野県南佐久（9/18）は作付面積が減少、作況は「平年並み〜やや不良」、生育進度は「遅い」
- 東京都中央卸売市場「東京のはくさいはどこから来る？」（2023年度）：年度計 112,464,386kg。茨城 58.3%・長野 32.5%・群馬 6.0%。9月は長野 97.6%、10月は長野 84.2%・茨城 9.5%（月別はこちらで読み取り）

## 3. 値段の決まり方（農水省「卸売市場データ集（令和6年度版）」）
- 市場経由率（令和4年度）：青果 50.5%、**野菜 59.2%**、国産青果 72.4%。野菜は平成6年度の 82.4% から下がった
- せり・入札の割合（中央卸売市場・金額ベース・令和5年度）：青果 7.1%、**野菜 5.8%**（平成17年度は青果 24.9%・野菜 24.1%）。委託集荷の割合：野菜 63.6%。残りの大半は相対取引（相対の割合・価格の決まり方は原典で未確認）
- 生産者の出荷先（食品流通段階別価格形成調査 平成29年度、青果全体）：集出荷団体（農協等）71.0%、卸売市場 11.8%、消費者に直接 7.8%、小売業 4.3%

## 4. 値段の内訳（食品流通段階別価格形成調査、はくさい、小売価格に占める割合・試算値）
- 平成29年度（平成31年4月9日公表）：生産者受取 40.6%、集出荷団体 19.9%、卸売 5.3%、仲卸 11.7%、小売 22.5%（卸売・仲卸・小売は利潤等を含む）
- 令和4年度は正誤表の図から 39.2 / 18.8 / 5.3 / 13.3 / 23.4 と読めたが、品目の列を順序から判断したので**使わない**（e-Stat で未確認）

## 5. 値段の振れ（東京都中央卸売市場の卸売、円/kg）
- 2013年5月中旬 35円（ALIC 2013年6月3日付：直近10年で平成23年に次ぐ低い水準。主産地の天候が良く入荷量が平年を上回ったことと、前年の浅漬け食中毒事件による漬物需要の落ち込み）
- 2025年5月7日 61円（平年比60%）
- 2026年9月1日 66円 → 10月6日 192円
- 別々の年の点（長期統計は未取得）
