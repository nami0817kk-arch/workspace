## 2. 長期金利とは
- 日銀「長期国債の買入れ計画について」（2026年6月16日）：「長期金利は金融市場において形成されることが基本」。買入れ 2026年10〜12月 月2.3兆円程度、2027年4月以降 月2兆円程度。急上昇時は増額・指値オペを機動的に
- 政策金利は 2024年3月19日以降「無担保コールレート（オーバーナイト物）」
- **2026年9月18日「金融市場調節方針の変更について」p.1：「１．２５％程度で推移するよう促す」**。賛成7・反対2。適用は9月24日から。従来は1.0%程度
- 2024年以降：2024/3/19 マイナス金利・YCC終了（0〜0.1%）→ 2024/7/31 0.25% → 2025/1/24 0.5% → 2025/12/19 0.75% → 2026/6/16 1.0% → 2026/9/18 1.25%
- 基準貸付利率は 2026年9月24日から 1.5%。これより高かったのは 1995年4月13日まで の 1.75%

## 4. 暮らし
### フラット35（住宅金融支援機構、2026年10月、新機構団信付き・融資率9割以下）
- フラット35（21〜35年）年3.830%〜5.840%、最も多い **年3.830%**。フラット20 年3.510%、フラット50 年4.100%
- 推移（最低金利、グラフからの読み取り）：2019年9〜10月 約1.11%（最も低い付近）→ 2023/4 約1.76% → 2025/10 約1.89% → 2026/1 約2.08% → 2026/4 約2.49% → 2026/6 約3.21% → 2026/10 3.83%
### 変動金利
- 三菱ＵＦＪ FAQ（2026年7月10日）：「変動金利の基準金利は、当行所定の『短期プライムレート』をもとに決定」。短期プライムレート 年2.375%（2026年8月3日から）
### 大手銀行
- 三菱ＵＦＪ（2026年10月1日、新規）：変動 適用1.195%・店頭3.375%／固定10年 適用3.75%・店頭6.53%／全期間固定31〜35年 4.35%
- 三井住友（2026年10月1日、WEB専用）：変動3.375%・超長期固定20年超35年以内5.560%・フラット35 5.840%（優遇前）
### 住宅金融支援機構「住宅ローン利用者の実態調査」2026年1月調査 概要p.1
- 変動型 75.0%・固定期間選択型 14.9%・全期間固定型 10.1%
- 金利上昇時の返済額の増え方を「理解しているか少し不安・よく理解していない・全く理解していない」合計 52.0%
### 預金（税引前）
- 三菱ＵＦＪ（10/9）・三井住友（10/10）：普通 0.40%、スーパー定期1年 0.50%・5年 1.00%・10年 1.25%
### 国の利払い費（財務省）
- 「令和８年度予算のポイント」p.15：利払費 **13.0兆円**（R5当初8.5→R6 9.7→R7 10.5→R8 13.0）。積算金利 2.0% → **3.0%**（「直近１か月の長期金利の平均（1.9％）を参考に、過去の金利急上昇の事例等を勘案して設定」）→ **今の10年は想定の3.0%を上回っている**
- 「我が国の財政事情」p.2（億円）：国債費 312,758、うち利払費 130,371（R7当初 105,230）。普通国債残高 R8年度末 1,145兆円（GDP比166%）見込み
- 「後年度歳出・歳入への影響試算」（令和8年2月）：成長3.0%ケースの金利 R8 3.0 → R11 3.6%。利払費 R8 13.0 → R11 21.6兆円。**金利1%上昇で国債費 R9 +0.8・R10 +2.1・R11 +3.8兆円**。2%上昇なら R11 +7.6兆円

- A 同じ3%でも30年前と今は別物（2年金利 1.024% と 1.951%、基準貸付利率 0.5% と 1.5%、残高1,145兆円）
