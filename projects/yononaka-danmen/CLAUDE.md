# 世の中の断面図

YouTube チャンネル（名前は未決）の動画を作る。**「歴史の地層」の対**として、
過去を縦に掘るのではなく、**いまの世の中を横に切る**。

## コンセプト（2026-10-06 にユーザーと決めた）

- **切る**：毎回ニュースを1つ選び、**表面**（報じられたこと）→ **切る** → **断面**（制度・歴史・数字）
  → **見立て**（なぜそうなったか）の順で見せる
- **画面の主役は自作の断面図**。他人の写真も発言も使わない。権利の心配を構造的に持たない
  （サッカーのチャンネルが抱えている審査の危うさを、こちらは最初から持たない設計にする）
- **題材は固定しない**。その日いちばん多くの人が気にしていることから選ぶ。
  「住宅のチャンネル」「都市のチャンネル」のように題材で縛ると、幅が狭く題材も尽きる

## 「なぜが立つ」の3条件（題材を選ぶ物差し）

1. **結果は報じられたが、理由が説明されていない**（「ガソリンがまた上がった」→ なぜ？）
2. **多くの人が誤解している**（「金利が上がる」→ どの金利？）
3. **日本だけ、あるいは1国だけが異質**（中古住宅が築20〜25年で価値ゼロになるのは日本だけ）

どれにも当たらないものは、どれだけ大きいニュースでも扱わない。

## 扱わないもの

- **政治的な是非**（どちらが正しいか）。数字が何と言っているかまでに留める
- **医療・健康の助言**。審査が厳しく、誤りの責任が重い
- **事件・事故の被害者、死亡記事、芸能の私生活**
- **投資助言**。事実の提示まで

## 素材

| | |
|---|---|
| 図・グラフ・断面図 | **自作**（このチャンネルの主役） |
| 地図 | Natural Earth（パブリックドメイン）／OpenStreetMap（出典表示） |
| 写真・映像 | Pexels・Pixabay（無料・商用可）／Wikimedia Commons |
| 衛星写真 | NASA（パブリックドメイン） |

**Google マップは使わない**。動画で使うには画面に出典を出し続ける必要があり、
ストリートビューは事前申請が要る。毎日出すチャンネルで守り続けるのは事故のもと。

## 数字と出典

- 画面の下に**出典を出し続ける**（「国土交通省『○○』p.12」まで）。これが他の解説チャンネルとの差
- **価格や料金には「2026年10月時点」と必ず添える**。1年後に嘘つきにならないため
- 原典に当たる手順は `primary-source-research` スキルに従う。記事の言い換えを根拠にしない

## 題材を拾う

```bash
python scripts/gather.py --out research/candidates/<日付>.json
```

ニュースと検索トレンドの RSS を読み、「なぜが立つ芽」を含む見出しだけを拾う。
扱わないもの（事件・死亡・芸能）はここで落とす。**○× はユーザーが付ける**（番号だけ振って出す）。

## まだ決まっていないこと（ユーザーと決める。勝手に決めない）

- チャンネルの正式名と運営名
- 語り手（「歴史の地層」のような掛け合いにするか、1人か。声は誰か）
- 1本の尺と1日の本数（目安は20〜30分・1日1本）
- 台本の型、画面の作り、サムネイルの型
- 台本確認・動画確認の関門の入れ方（他の2チャンネルと同じく**必ず入れる**）

## チャンネル名（2026-10-06 に決めた）

**世の中の断面図｜ニュースを数字で切る**（運営：のこぎり社）

「歴史の地層（つるはし社）」が**掘る**のに対し、こちらは**切る**。道具の名前で運営名を揃える。

## 台本の型（1本 **30分**・9つの節）

| 節 | 名前 | 長さの目安 | 中身 | 図 |
|---|---|---|---|---|
| 00 | **表面** | 2分 | 報じられたことをそのまま出す。聞き役が素朴に反応する | 見出しの板 |
| 01 | **問い** | 30秒 | 「なぜ？」を立てる。**これが題名になる** | なし |
| 02 | **一の断面** | 4分 | いちばん分かりやすい切り口。数字を出す | 積み上げ |
| 03 | **二の断面** | 5分 | いつ、誰が、なぜそう決めたか | 年表 |
| 04 | **三の断面** | 5分 | 誰が払い、誰が受け取っているか | 流れ図 |
| 05 | **四の断面** | 4分 | **世界と比べる**。日本だけなのか | 比べる図 |
| 06 | **よくある誤解** | 4分 | 広まっている説を1つだけ潰す。人ではなく説を扱う | 比較の図 |
| 07 | **見立て** | 4分 | なぜそうなったかを**番号で**出す | まとめの板 |
| 08 | **締め** | 1分30秒 | 次回の問いを聞き役が一言で振る | なし |

2026-10-06 にユーザーが「1作30分」と決めた（18〜22分から変更）。
伸ばすために話を薄めるのではなく、**「世界と比べる」節を足して中身を増やす**。
収益化の新基準（2027-02 から長尺 8,000 時間）でも長尺のほうが効く。

### 決まり

- **節ごとに図を1つ**（05 と 07 を除く）。図が作れない節は、その節を作らない
- **出典は画面の下に出し続ける**。数字を言う行では、必ず出典を画面に出す
- **価格・料金には「2026年10月時点」を添える**
- **聞き役を受け身にしない**。驚くだけの返しは1節に2回まで。
  代わりに**予想して外す・誤解の側から疑う・自分の暮らしに置き換える・節の終わりで言い直す**
- **締めは必ず聞き役**が次回の問いを振る（「〜って、なんでなんでしょうね？」）
- **1本に1つの問いだけ**。2つ立てたくなったら、2本に割る

### 台本の書き方

`scripts/_template.yaml` を写して使う。節番号のキーは `id`（`no` は YAML で「偽」になるので使わない）。行の話者に括弧で強さを付けられる（`語り(強)`）。

## 題材の決め方（2026-10-06 に固めた）

勘で選ばない。**測れるもので点を付けて並べる**。

### 手順

```bash
python scripts/gather.py --out research/candidates/<日付>.json   # 集める・選り分ける
python scripts/pick.py research/candidates/<日付>.json            # 点を付けて並べる
python scripts/demand.py <言葉> --deep                            # 気になったものを深く見る
```

### 点の付け方（23点満点）

| 物差し | 満点 | 測り方 | なぜ見るか |
|---|---|---|---|
| **検索の広さ** | 5 | YouTube の補完が何件出るか | 関心が広いほど、届く人が多い |
| **問いの濃さ** | 5 | 補完のうち「なぜ・いつ・とは・どうなる」が占める割合 | 知りたがられている＝説明する価値がある |
| **原典の堅さ** | 5 | 当たるべき原典が公的機関（省庁・法令・統計）か | 出典を出せない題材は作らない |
| **30分もつか** | 5 | 断面が4つ立つか（見出しを出させて数える） | 1つしか立たないなら尺がもたない |
| **新しさ** | 3 | 今日のニュース・はてブ由来なら加点 | 今日見る理由になる |

### 見ないもの

- **他人の動画の再生数**（2026-10-06 ユーザー指摘）。
  再生数を基準にすると**既にある動画の後追い**になる。再生数が多い＝すでに誰かが答えている。
  見るのは「人が何を知りたがっているか」だけ

### 検索語の決め方

judge が候補ごとに**短い検索語を3つ**出す（1〜2語、長くても8文字）。
それぞれで補完を引き、**いちばん反応があったもの**を採る。
人は長く打たないので、語が長いと補完が出ず、関心が無いように見えてしまう。

### 最後はユーザーが決める

点は**並べ替えのため**であって、決めるのはユーザー。番号を振って出し、○× を付けてもらう。
