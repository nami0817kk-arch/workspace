# 世の中の断面図

YouTube チャンネル（名前は未決）の動画を作る。**「歴史の地層」の対**として、
過去を縦に掘るのではなく、**いまの世の中を横に切る**。

## コンセプト（2026-10-06 にユーザーと決めた）

- **切る**：毎回ニュースを1つ選び、**表面**（報じられたこと）→ **切る** → **断面**（制度・歴史・数字）
  → **見立て**（なぜそうなったか）の順で見せる
- **画面の主役は自作の断面図**。他人の写真も発言も使わない。権利の心配を構造的に持たない
  （サッカーのチャンネルが抱えている審査の危うさを、こちらは最初から持たない設計にする）
- **題材は固定しない**。その日いちばん多くの人が気にしていることから選ぶ。
  「住宅のチャンネル」「都市のチャンネル」のように題材で縛ると、幅が狭く題材も尽きる

## 「なぜが立つ」の3条件（題材を選ぶ物差し）

1. **結果は報じられたが、理由が説明されていない**（「ガソリンがまた上がった」→ なぜ？）
2. **多くの人が誤解している**（「金利が上がる」→ どの金利？）
3. **日本だけ、あるいは1国だけが異質**（中古住宅が築20〜25年で価値ゼロになるのは日本だけ）

どれにも当たらないものは、どれだけ大きいニュースでも扱わない。

## 扱わないもの

- **政治的な是非**（どちらが正しいか）。数字が何と言っているかまでに留める
- **医療・健康の助言**。審査が厳しく、誤りの責任が重い
- **事件・事故の被害者、死亡記事、芸能の私生活**
- **投資助言**。事実の提示まで

## 素材

| | |
|---|---|
| 図・グラフ・断面図 | **自作**（このチャンネルの主役） |
| 地図 | Natural Earth（パブリックドメイン）／OpenStreetMap（出典表示） |
| 写真・映像 | Pexels・Pixabay（無料・商用可）／Wikimedia Commons |
| 衛星写真 | NASA（パブリックドメイン） |

**Google マップは使わない**。動画で使うには画面に出典を出し続ける必要があり、
ストリートビューは事前申請が要る。毎日出すチャンネルで守り続けるのは事故のもと。

## 数字と出典

- 画面の下に**出典を出し続ける**（「国土交通省『○○』p.12」まで）。これが他の解説チャンネルとの差
- **価格や料金には「2026年10月時点」と必ず添える**。1年後に嘘つきにならないため
- 原典に当たる手順は `primary-source-research` スキルに従う。記事の言い換えを根拠にしない

## 題材を拾う

```bash
python scripts/gather.py --out research/candidates/<日付>.json
```

ニュースと検索トレンドの RSS を読み、「なぜが立つ芽」を含む見出しだけを拾う。
扱わないもの（事件・死亡・芸能）はここで落とす。**○× はユーザーが付ける**（番号だけ振って出す）。

## まだ決まっていないこと（ユーザーと決める。勝手に決めない）

- チャンネルの正式名と運営名
- 語り手（「歴史の地層」のような掛け合いにするか、1人か。声は誰か）
- 1本の尺と1日の本数（目安は20〜30分・1日1本）
- 台本の型、画面の作り、サムネイルの型
- 台本確認・動画確認の関門の入れ方（他の2チャンネルと同じく**必ず入れる**）
