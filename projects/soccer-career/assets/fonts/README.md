# 同梱フォントについて

Noto Sans JP — SIL Open Font License 1.1（`OFL-NotoSansJP.txt` 参照）
https://fonts.google.com/noto/specimen/Noto+Sans+JP

## なぜ同梱しているか

同梱していなかった頃、Web版（CanvasKit）は足りない字形を
`fonts.gstatic.com` から取りに行っていた。取りきれなかった字はそのまま
豆腐（□）になり、公開中の画面に

    監□の期待 / 得□関□ / 契約更□の年□に□く / 気持ち □くない

が出ていた（2026-09-08 に確認）。欠けていたのは 督・点・与・改・俸・効・悪 で、
どれも日常的に使う漢字。ほとんどの字は出るので、テストでも気付けない。

同梱すれば外部への通信が要らず、どの環境でも同じ字が出る。
`soccer-manager` が先に同じ問題に当たっていて、同じ対応を取っている。

## サブセットについて

`soccer-manager` が用意したものをそのまま使っている（1ファイル 2.3MB /
7,167 コードポイント）。範囲は cp932（Windows 日本語）でエンコードできる文字で、
JIS X 0208 と NEC/IBM 拡張を含む。**選手名は自由入力**なので、
ソースに出てくる文字だけに絞る形にはしない（入力した名前が豆腐になる）。

範囲外の文字は端末の標準フォントにフォールバックする。
