## 説明（4000字以内）

```
無名の選手を1人つくって、引退までを生きるゲームです。

■ 2部の下位から始まる
最初のクラブは、どの国の2部でも下のほうにいるクラブです。あなたは18歳の
育成年代上がりで、ベンチにも座れないところから始まります。上に行けるかは、
毎週の90分の中で何を選んだかだけで決まります。

■ 中核は、試合中の選択
1シーズン38試合をすべて戦います。ただし濃さは試合で変わります。大一番は
6つの局面が立ち、ふつうの試合は2つ。局面ごとに3つの手が出て、それぞれに
通る見込みが%で出ます。安全に回して評価点を刻むか、通れば大きい手に
賭けるか——通れば重く、外しても軽い手もあれば、その逆もあります。
局面はポジションごとに18〜19、全部で74。追いかける展開・守り切る展開では
出る手が変わります。

■ 伸ばす方向を自分で決める
狙う技を選ぶと、そこだけが伸びます。22の個人技は、覚えてはじめて試合の
切り札として構えられるようになります。週の練習、休み方、コンディション。
40を切った週に無理をすれば、怪我の目が上がります。

■ 11の国と、リーグのピラミッド
国ごとにリーグの格が違い、外国人枠と労働許可のルールも違います。
上の国の1部に行くほど、要求される水準が上がります。代表に呼ばれる線、
カップ戦、大陸カップ。「いま自分は世界の何番目にいるか」が常に見えます。

■ 移籍は、話が来るかどうか
シーズンが終わると、成績に応じて話が来ます。年俸を取るか、出場機会を取るか、
格を取るか。契約を延ばすこともできます。代理人は自分で選び、売り込ませる
こともできます。

■ 75の特性と、48の出来事
性格や癖が特性として付き、伸び方と出来事の出方が変わります。移籍の噂、
監督の交代、家族のこと、怪我からの復帰。選んだ答えはそのまま記録に残ります。

■ 引退したあとに残るもの
通算出場・得点・タイトル・ピーク時の総合力。引退後の道も選べます。
歴代の選手として殿堂に並び、次のキャリアのときにその記録が残っています。

■ 保存について
記録はこの端末の中にだけ置かれます。アカウント登録もログインもありません。
引き継ぎコードを出しておけば、別の端末でも続きから遊べます。

■ 広告と課金について
全画面広告はシーズンの切れ目にだけ出ます。試合中にもメニュー操作にも
割り込みません。バナー広告はありません。
「広告を消す」を買うと出なくなります。「応援する」はゲームの中では何も
起きず、回数が表示されるだけです。
**強くなるものは1つも売っていません。** 伸びしろも金も出場機会も、
釣り合いを測って決めたもので、売った瞬間にその調整が意味を失うからです。

クラブ名・リーグ名・大会名はすべて架空です。国名だけ実在のものを使っています。
```

## スクリーンショット

**手で撮らない。生成器がある。**

```bash
flutter test tool/screenshots/capture_test.dart
```

`tool/` に置いてあるのは、これがテストではなく生成器で、実行するとファイルを
書き換えるため。`test/` の外なので CI では回らない。

| 出力先 | 寸法 | 用途 |
|---|---|---|
| `marketing/screenshots/` | 1290x2796 | iPhone 6.7インチ |
| `marketing/screenshots_ipad/` | 2064x2752 | iPad 13インチ |

iPad ぶんが要るのは、アプリが iPad でも動く設定（`TARGETED_DEVICE_FAMILY` =
"1,2"）になっているため。iPhone だけだと「13インチのiPadディスプレイの
スクリーンショットをアップロードする必要があります」で提出できない
（`soccer-manager` で実際に止まった）。

| ファイル | 画面 | 上の一行 |
|---|---|---|
| `01-match.png` | 試合中の3択 | 試合は、選ぶことでしか動かない |
| `02-create.png` | 選手をつくる | 自分の選手を、ひとりつくる |
| `03-week.png` | 今週（次節・今の状態） | 今週、何に時間を使うか |
| `04-player.png` | 能力 | 伸びたところが、数字で残る |
| `05-develop.png` | 育成 | 狙った技だけが、身につく |
| `06-world.png` | この国と、世界 | 上には、まだ何部もある |
| `07-season.png` | シーズン終了 | 1年ぶんの答えが出る |
| `08-hall.png` | これまでの選手 | 終わったあとに、記録が残る |

撮り直しが必要になるのは、画面の見た目や文言を変えたとき。

### 撮るときに踏んだ穴（同じ穴を二度掘らないために）

- **1季目を撮ると、総括が「20クラブ中19位・0ゴール・監督の期待には届かな
  かった」になる。** 嘘ではないが、ストアの1枚として出すものではない。
  いまは種を固定して4季目を撮っている（`captureSeed` / `captureSeason`。
  選び方は `tool/screenshots/probe_test.dart` で8通り回して決めた）。
- **テストの既定では影が「ぼかさない真っ黒」で描かれる**
  （`debugDisableShadows`）。右下のボタンが黒い輪で囲まれたように写る。
  焦点の輪だと思って焦点のほうをいじっていたが、原因は影だった。
- **アイコンフォントを読まないと、アイコンが全部豆腐（□）になる。**
  生成器は読み込み、見つからなければ止まる。
- 帯の高さと文字は端末の幅に比例させる。固定値だと iPhone で2行に折り返して
  帯からはみ出し、iPad では豆粒になった。

### 分かっている弱み

iPad の絵は、**中身が真ん中の細い1列に収まり、左右が大きく空く**。画面は
スマホの縦長を前提に組んであり、`ReadableWidth`（最大520px）で1行が伸び
きらないようにしているため。崩れてはいないが、13インチの絵としては間が
持たない。iPhone 専用（`TARGETED_DEVICE_FAMILY` = "1"）にすれば iPad の絵は
そもそも要らなくなる——**初回提出前に決めること**。

## App プライバシー（データ収集の申告）

**「データを収集しない」を選んではいけない。** AdMob を組み込んでいるため、
広告識別子（IDFA）・おおよその位置（IPアドレス由来）・端末情報が Google に
取得される。

- 「識別子 > デバイスID」を **「サードパーティ広告」** の目的で申告する。
- 提供者自身（つるはし社）は何も収集していない。アカウントもログインも無い。
- **ATT（App Tracking Transparency）の許可は求めない**（2026-09-26 決定）。
  求めないので、`NSUserTrackingUsageDescription` も入れていない。
  パーソナライズ広告は使えないが、同意ダイアログも出ない。
- 詳細は AdMob の公式ガイダンスに従う。
