# soccer-career

1人の選手を作って、キャリアを進めるゲーム。2部の下位クラブから始まり、
試合ごとの判断で評価点を積み上げ、成長し、移籍して上を目指す。

- ポジションは8つ（GK / CB / SB / DM / CM / OMF / WG / ST）
- 選手にはポテンシャル（隠し上限）と特性2つがランダムで付く
- 1シーズン38試合すべてをプレイする
- 毎週の練習を選ぶ。練習は疲れる代わりに伸び、休養は戻す
- 試合は選択肢で介入する。先発なら3局面、途中出場なら2局面
- 評価点が落ちると先発から外れ、さらに落ちるとベンチ外になる
- 成功した手の能力が伸びやすい。選び方が選手を作る
- 2部上位2で昇格、1部下位3で降格。33歳から引退を選べる
- 代理人を選んでキャリアを始める。シーズン終了時に契約更改・移籍オファーに上乗せを要求できる
- クラブ名・リーグ名はすべて架空

## 動かす

```
flutter pub get
flutter run
```

Web で確認するときは `flutter run -d web-server --web-port=8090`。

## テスト

```
flutter test
```

合否の判断は CI（`soccer-career-ci.yml`）に置いている。
