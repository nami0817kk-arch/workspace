# soccer-career

1人の選手を作って、キャリアを進めるゲーム。2部の下位クラブから始まり、
試合ごとの判断で評価点を積み上げ、成長し、移籍して上を目指す。

- ポジションは8つ（GK / CB / SB / DM / CM / OMF / WG / ST）
- 能力値は22項目（加速・決定力・視野・タックル…）。局面の判定はこの単位
- 選手にはポテンシャル（隠し上限）と特性（22種から長所2つ、3割で欠点1つ）がランダムで付く
- 試合は自分で選んでも、安全/バランス/勝負のスタイルで自動で進めてもよい
- 1シーズン38試合すべてをプレイする
- 毎週の練習を選ぶ。練習は疲れる代わりに伸び、休養は戻す
- 試合は選択肢で介入する。先発なら3局面、途中出場なら2局面
- 評価点が落ちると先発から外れ、さらに落ちるとベンチ外になる
- 成功した手の能力が伸びやすい。選び方が選手を作る
- 2部上位2で昇格、1部下位3で降格。33歳から引退を選べる
- 代理人を選んでキャリアを始める。シーズン終了時に契約更改・移籍オファーに上乗せを要求できる
- 負傷する。疲れているほど、歳を取るほど起きやすい。重傷は体に残る
- 監督から今季の目標が示され、達成度が契約に響く
- 実力と出来がそろえば代表に招集される。キャップと代表ゴールが積み上がる
- 契約は2〜4年。残り1年になるまで移籍の話は来ない
- 11の国 × 3連盟の世界。国ごとにクラブ数・暦・格・外国人ルールが違う
- 国籍と外国人枠、労働許可がある。若手はいきなり最上位リーグへは行けない
- 大陸カップ、昇格プレーオフ、夏と冬の移籍市場、25人の登録メンバー枠
- クラブ名・リーグ名・国名はすべて架空

## 動かす

```
flutter pub get
flutter run
```

Web で確認するときは `flutter run -d web-server --web-port=8090`。

## テスト

```
flutter test
```

合否の判断は CI（`soccer-career-ci.yml`）に置いている。
