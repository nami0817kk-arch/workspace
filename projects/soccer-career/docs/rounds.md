## 進め方

1. 測る道具を書く（`test/*_sim.dart`、手動実行）か、静的に洗う
2. 実測を取る（master と比べる。比べる相手が無いと「動いていない」と言えない）
3. 直す → 測り直す → 効かなければ戻す
4. 見張りを常設テストにする

## なぜ打ち切ったか

1〜10回目は7件が「作ってあるのに効いていない」で、遊びの手触りが変わるものが
あった。11回目以降で出てきたのは**構造の粗さ**が中心で、
`balance_sim` は1も動かない——**改善ではなく点検**になっていた。
点検を数で回しても得るものが薄いので、14回で止めた。

残っている見張り（`dormant_test` / `choice_balance_test` /
`scenario_balance_test` / `event_balance_test`）が同じ腐り方を自動で拾うので、
**次に何かを足したときに気付ける**状態にはなっている。

手触りを変えたいときに、ここから入れる場所:

- **落ちても必ず1季で戻る**（6回目の実測）。構想外も降格も無出場も、
  翌季には戻っている。本当に戻らないのは重傷だけ。
- **局面の答えが動かない**（3回目）。構造的に死んではいないが、
  尖らせても最善手が入れ替わらない。能力差が難易度差に勝てていない。
- **年齢で遊びが変わらない**。22歳以降にできることは、ほぼ同じ。
