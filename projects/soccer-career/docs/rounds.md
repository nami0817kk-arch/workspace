# ゲーム性の見直し — 進行表

「更なるゲーム性の向上を100回」（2026-09-24 開始）の記録。
**毎回、先に測ってから手を入れる。** 測って何も無かった回と、見つけたのに
直せなかった回も、そのまま残す。

設計上の結論は `CLAUDE.md` に書く。ここは**どこまで進んだか**だけ。

## 進み方

1. 測る道具を書く（`test/*_sim.dart`、手動実行）か、静的に洗う
2. 実測を取る（master と比べる。比べる相手が無いと「動いていない」と言えない）
3. 直す → 測り直す → 効かなければ戻す
4. 見張りを常設テストにする
5. 10回ごとに PR にしてマージ

## これから見るもの（候補）

測る前の当て推量なので、**外れたらそう書く**。

- 戻れない領域を増やすか（落ちても必ず1季で戻る、が 6回目で分かっている）
- 年齢ごとの遊びの変化（ベテラン期に決めることが残っているか）
- 個人技・コツ・役割の選択が結果を変えているか
- 相手クラブの戦い方（`ClubStyle`）が手の順位を変えるか
- 順位表・カップの抽選が毎年同じ顔にならないか
- 代表の日程・W杯の周期が噛み合っているか
- 収支（スタッフ・生活水準）が終盤に効いているか
- 画面: 1週間に決めることの数、タブごとの情報量
