# アニメの戦闘シーン6本のリズム(2026-10-19 実測、数字のみ)

測り方: `analyze_anime.py`(workspace 外)。320x180 に縮めて、コマ間の差で「カット」「同じ絵の連続」「閃光」「画面の平行移動(揺れ)」を数えた。
元動画・切り出した画像は残さない。**カット数は多めに出る**(動きが激しいと差が閾値を超える。上限の目安)。

| 指標 | 6本の範囲 | 読み取り |
|---|---|---|
| カットの中央値 | 0.13〜0.17秒(4〜5コマ) | 戦闘の山は、4〜5コマごとに絵が大きく変わる |
| 0.5秒未満のカットの割合 | 76〜90% | 長回しはほぼ無い。短い絵の連打 |
| カット数/分 | 116〜258 | 当方の周3は 1分あたり約20(ほぼ長回し) |
| 同じ絵を続けるコマの割合 | 17〜33% | 動いている区間でも 2コマ撮りが4分の1前後 |
| 同じ絵の連続の中央値 | 2コマ | 3コマ以上は少ない |
| 閃光(明るさの跳ね)/分 | 17〜41 | 2秒に1回前後。1コマだけ |
| 画面が揺れているコマの割合 | 3〜17% | 揺れの大きさ(90%値)は 12〜36px(320幅換算)=画面幅の4〜11% |

## 取り込む方針
- 山場(命中の前後)は **0.1〜0.2秒のカットを連打**。当方の impact_cuts は固定の3角度 → 命中前後に短い寄り・引きを足す
- 2コマ撮りは全体の 2〜3割に留める(当方は全区間で適用していた)。命中の前後は1コマ
- 閃光(1コマだけ明るさを跳ねさせる)を、命中以外にも踏み込み・構えに散らす
- 画面の揺れ: 命中後に画面幅の4〜10%を数コマ

- 閃光/分 133 → 連打・受け止めの閃光を外して 35.5(範囲内)
