# 参考の走りの角度(目で読み取った値)

出典: Alan Becker「Cave Spider Roller Coaster」(YouTube、24fps)の83秒付近、緑の人物の連続19コマ。
拡大して30°刻みの分度器を重ね、角度を読んだ。**誤差は約 ±10°**。2026-10-18。
(骨組みの自動当てはめも試したが、脚や腕が重なると不安定で、角度が信用できなかったため目視に切り替えた)

真下を0°、前(進行方向)をプラスとする。

| 部位 | 値 | `stickfig/pose.py` の `RUN` |
|---|---|---|
| 胴の前傾 | 約30° | 走りのキーで `lean: 0.6` 前後(傾き+振動) |
| 後ろ足の太もも | 約-40°(膝はほぼ伸びたまま) | `leg_bias 0.25 - leg_amp 0.95` = -0.70 rad |
| 前足の太もも | 約+70°、膝は約100°曲げる | `leg_bias + leg_amp` = +1.20 rad、`knee_gain 1.6` |
| 前の腕 | 上腕 約+100°、肘 約90° | `arm_bias -0.20 + arm_amp 1.95` = +1.75 rad |
| 後ろの腕 | 上腕 約-120〜-150°(後ろ上へ高く振る)、肘 約100° | `arm_bias - arm_amp` = -2.15 rad |
| 浮く瞬間 | 両足が地面から離れる | `bounce 0.11`(脚が前後に最大に開く所で腰が上がる) |

形の縦横比(走り): 参考 0.62〜1.54 / 自作(2026-10-18 時点)0.69〜1.02。極端さは、まだ参考に届かない。

## 使い方
新しい動き(剣を振る・殴る・跳ぶ)を足すときも、同じ手順で読み取って、この表に追記する:
1. 参考の連続コマを抜く(`ffmpeg -ss <秒> -frames:v 20`)
2. 人物の周りを拡大し、腰を中心に30°刻みの線を重ねる
3. 上腕・前腕・太もも・すねの角度を、コマごとに読む
4. `pose.py` の周期、または台本のキーに写す
