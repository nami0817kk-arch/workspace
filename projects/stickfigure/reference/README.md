# reference/ — 参考動画から取った「数字だけ」

**参考動画のファイルや、そこから切り出した画像は、このリポジトリに入れない**(workspace は public。他人の作品)。
置いてよいのは、測った数字と、読み取った角度の表だけ。

- `profile_cave_spider.json` … Alan Becker「Cave Spider」を全編走査した、動きの癖の数字(色で人物を切り出して測る方式。
  カメラの動きや、色の近い背景で多少ずれる目安)
- `run_reading.md` … 走りの角度を、拡大コマから目で読み取った表

主な値(身長/コマ。速度は人物の重心の動き):
- 速度 p50 0.028 / p90 0.196 / p99 0.71
- 静止から全速力まで: 中央値9コマ、速い4分の1は3コマ以内
- 速い動きの直後の止まり: 中央値1コマ(329回中301回が1〜3コマ)
