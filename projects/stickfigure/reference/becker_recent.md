# Alan Becker 最近作を、コマで見た記録(2026-10-19、数字と観察のみ)

見たもの: The Machine(AvA 13)、Creeper Clan(AvM 40)、The Aether(AvM 39)、Cave Spider(AvM、以前)。動画・画像は残さない。

## 画づくり(当方との差)
- **人物が画面を占める**: 頭の輪が画面の高さの 1/3〜1/2 になる寄りが主役。当方は全身が画面の 1/3 以下の引きが中心
- **線が太く、先が細る**: 腕・脚は根元が太く、先へ細くなる帯(リボン)。手足の先は色が黒へ変わる(赤の人物の腕の先が黒)。当方は一定の細い線
- **頭は輪(中空)の回がある**: The Machine は中空の輪の頭。Minecraft の回は塗りつぶし。どちらも輪郭の太さは腕と同じ
- **光る縁取り**: 武器・特殊能力の人物は、水色の発光する縁取り(グロー)。剣は黒い刃+水色の縁+鍔
- **背景は実写に近い3D**: 工場・研究室の奥行きと、人物の手前/奥の重なり。人物は平面の線で、背景は立体(2Dと3Dの混在)
- **効果は手描き**: 爆発は、橙の閃光→茶色の煙のかたまり(輪郭のある塊)→灰色に薄れ、内側に細い線の渦。1つの効果が 20コマ以上かけて変化する
- **衝撃の演出は控えめ**: 放射線・SFX文字は使わない。代わりに、画面の傾き(ダッチ)、寄り、残る煙、粒子

## リズム
- 12fps で並べると、ほとんどの区間が連続2コマ以上同じ絵(静かな場面は 1/3 秒近く動かない)
- 動くときは一気に: 振り上げ→振り下ろしの間が 2〜4コマ。命中の前の溜めは、絵が止まって細かく揺れる
- 同じ画面に長くいる(1カット 2〜6秒)。当方の 0.13秒カットはアニメ(別作品)の値で、Becker とは違う

## 取り込み候補(優先順)
1. 線の太さの変化(根元太→先細り)と、手足の先の色
2. 武器の発光する縁取り
3. 煙のかたまり(輪郭のある塊)で、衝撃を放射線から置き換える選択肢
4. 寄り(頭が画面の 1/3)のカットを増やし、引きを減らす
