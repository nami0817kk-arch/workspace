## 使い方

```
pip install -r requirements.txt
python src/build_book.py books/vol1.json    # 本文 -> output/vol1-interior.pdf
python src/build_cover.py books/vol1.json   # 表紙 -> output/vol1-cover.pdf
```

`output/` は `.gitignore` 済み（同じ設計書からは毎回同じPDFができる）。

### 題名の商標確認（J-PlatPat、2026-09-26）

「商標(検索用)」で部分一致検索し、第16類（印刷物）を含むものを見た。

| 検索語 | 第16類で近いもの | 判断 |
|---|---|---|
| `?迷路? ?めいろ? ?メイロ?`（54件） | おはなしめいろ・面積迷路・カード迷路・つながるめいろ・ＱＲ迷路・めいろぬりえ・メイロマ・タッチｄｅ．めいろ | 「大きな迷路」「ゆったり迷路」「なぞって迷路」と重なるものは無い |
| `?ゆったり? ?ユッタリ?` | ゆっくり ゆったり 北海道 | 称呼が違う。重ならない |
| `?なぞって? ?なぞる?` | なぞる英語・なぞるだけのやさしい英語 | 称呼が違う。重ならない |

「大きな迷路」は商標上は空いているが、**同じ題名の KDP 本（2026-08-18 発売）が既に amazon.co.jp にある**ので避けた。

## 入稿の手順

KDP の登録・本人確認・税務情報・口座はユーザーの担当。入力する値は次のとおり。

1. 本の言語: 日本語／読む方向: **左から右（横書き）**
2. ISBN: **KDP の無料 ISBN**（出版社の表示は「個人出版」になる）
3. 印刷オプション: 黒インクと白い紙／判型 **21.0 x 29.7 cm (A4)**／裁ち落とし **なし**／表紙の仕上げは任意
4. 原稿: `output/vol1-interior.pdf`、表紙: `output/vol1-cover.pdf`（「表紙を自分でアップロード」）
5. AI 生成コンテンツ: **いいえ**（問題も表紙の絵もアルゴリズムで描いたもの）
6. 価格: 税抜で入力する（消費税は Amazon が足す）。999 円以下は印税率 50% で赤字になるので **1,000 円以上**
7. 出版できるのは**1週間に2タイトルまで**（本のフォーマットごと）

アップロード後、KDP のプレビューアで余白の警告が出ないことを確かめる。
