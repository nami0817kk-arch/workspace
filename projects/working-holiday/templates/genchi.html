現地に着いたら：手続き・病院・仕事探し

着いてすぐの数週間でやることを、どの国にも共通する順番で並べました。国ごとの手続きの名前・病院の一覧・最低賃金は、各国のページに載せています。

{{ icon("plane", 24) }}着いてからの流れ

  1. {{ icon("pin") }}

    在留届を出す（3か月以上いるなら義務）

    外国に3か月以上滞在する場合は、住む場所を管轄する日本大使館・総領事館に在留届を出す義務があります（旅券法第16条）。災害や事件のときに、大使館から安否の確認や連絡を受けられます。

    ORRネット（外務省）でオンライン提出

  2. {{ icon("home") }}

    住む場所を決め、必要なら住民登録・滞在の手続きをする

    住所を役所に届け出る国（ドイツなど）や、入国後に滞在許可の手続きが要る国（フランスなど）があります。期限がある手続きもあるので、着いたらまず確かめます。

  3. {{ icon("id") }}

    働くための番号を取る

    多くの国で、働いて給料を受け取るには税や社会保障の番号が要ります（オーストラリアの TFN、カナダの SIN、英国の National Insurance number など）。番号が無いと、税が高く差し引かれることがあります。

  4. {{ icon("bank") }}

    銀行口座を開く

    給料の振り込みに使います。口座を開くときに住所の証明を求められる国もあります。

  5. {{ icon("briefcase") }}

    仕事を探す

    政府の求人サイトや公的な職業紹介の窓口があります。最低賃金より安い時給の仕事は違法です。同じ雇用主の下で働ける期間に制限がある国もあります。
