## 長い説明文（ストア掲載用）

```
弱小クラブのオーナー兼監督として、下部リーグからの成り上がりを目指す
本格サッカークラブ経営シミュレーション。

■ クラブを育てる
選手のトレーニング方針・強度を個別に設定し、メンター制度やピンポイント特訓で
若手を一流選手へと育て上げよう。トップに絡めない選手はリザーブの試合や
育成型レンタルで実戦を積ませる。ポジションごとの衰え方や、出場機会が育成に
与える影響までシミュレートされたリアルな成長システム。

■ ユースから育てる
自前のアカデミーには年間リーグがあり、有望株は毎週の試合で実戦を積む。
一軍のベテランをメンターに付ければ、その選手の得意技を受け継いでいく。
ただし19歳を過ぎた有望株は出場機会を求め、放っておけば他クラブに
引き抜かれる。いつプロ契約を結んで一軍へ上げるか、その判断がクラブの
背骨をつくる。

■ 戦術を組み立てる
14種類の細分化されたポジション、選手ごとのプレースタイル・デューティ設定と
個別指示、セットプレーの狙い、ハーフタイムの采配まで。布陣は練習を重ねて
はじめて手に馴染む。相手のスカウティングレポートを読み解き、弱いサイドを
突くか司令塔を潰すか、その試合の対策を立てて臨もう。

■ 移籍市場を制す
資金の範囲内で選手を獲得し、不要な選手はローンや移籍リストで放出。
競合オファーやカウンターオファーが飛び交うリアルな交渉を駆け引きしよう。

■ クラブを経営する
スタジアム拡張、スポンサー契約、銀行融資。コーチ・スカウト・フィジオは
能力を見て一人ずつ雇い、週俸と成果を天秤にかける。理事会が求める路線と
順位目標をやりくりしながら、長期的な視点でクラブを強化していく。

■ シーズンを戦い抜く
昇降格のあるリーグ戦、国内カップ、大陸カップ、スーパーカップ。
得点王・年間MVP・ベストイレブンなどの個人タイトルや、殿堂入りする
レジェンド選手たちがあなたの物語を彩る。

進行状況は端末内に保存されます。オンラインのアカウント登録は不要です。

資金を受け取れる動画広告は「見たい人だけ」が対象で、一度も見なくてもゲームは
最後まで遊べます。全画面広告はシーズンの切り替わりで1回だけ表示され、試合中や
メニュー操作には割り込みません。バナー広告はありません。
サポーター（買い切り）を購入すると全画面広告は表示されなくなります。
アプリ内でクラブ資金を購入することもできます（任意・回数制限なし）。
購入しなくても最後まで遊べますが、購入するとクラブを早く強くできます。
```

## サブタイトル（App Store、30字以内）

名前のすぐ下に出て、検索にも効く欄。**空欄のままだと無料の枠を1つ捨てることになる。**

```
弱小クラブを勝たせる監督シミュレーション
```

## キーワード（App Store キーワードフィールド、100字以内目安）

**アプリ名・サブタイトルに入っている語をここで繰り返さない。** 検索の突き合わせは
名前・サブタイトル・キーワードをまとめて見るので、重ねたぶんは枠を削るだけになる。
以前ここに `サッカー,マネージャー,経営` と書いていたが、3つともアプリ名
「サッカー経営マネージャー」に入っていた。`シミュレーション` `クラブ` `監督` は
サブタイトルに移した。

区切りは読点ではなくカンマで、スペースは入れない（入れると1文字ぶん損をする）。

```
ゲーム,育成,移籍,戦術,采配,選手,ユース,リーグ,フットボール,スポーツ,無料,成り上がり,サカマネ,スカウト,昇格,オフライン,無課金,オーナー
```

## スクリーンショットとフィーチャーグラフィック

**手で撮らない。生成器がある。**

```bash
flutter test tool/screenshots/capture_test.dart --update-goldens
flutter test tool/screenshots/feature_graphic_test.dart --update-goldens
```

`tool/` に置いてあるのは、これらがテストではなく生成器で、実行すると
ファイルを書き換えるため。`test/` の外なので CI では回らない。

出力は端末ごとに9枚ずつ。

| 出力先 | 寸法 | 用途 |
|---|---|---|
| `marketing/screenshots/` | 1290x2796 | iPhone 6.7インチ。Google Play もこのまま通る |
| `marketing/screenshots_ipad/` | 2064x2752 | iPad 13インチ |

iPad ぶんが要るのは、アプリが iPad でも動く設定になっているため。iPhone
だけだと「13インチのiPadディスプレイのスクリーンショットをアップロード
する必要があります」で提出できない。

**番号は撮る順ではなく、ストアに並べる順。** 検索結果には**先頭3枚しか出ない**ので、
そこに何を置くかで見られ方が変わる。起動画面を先頭にしていた頃は、いちばん目立つ枠が
「何のゲームか伝わらない絵」で埋まっていた。

| ファイル | 画面 | この順にした理由 |
|---|---|---|
| `00_lineup.png` | スタメン編成・戦術 | **縮小しても一目でサッカーの采配ものと分かる**。ピッチに11人が並ぶ絵 |
| `01_live_match.png` | 試合（ライブ経過・ゴール演出） | 「GOAL!」が小さくても読める。試合が実際に動くことが伝わる |
| `02_home.png` | ホーム（クラブ状況ダッシュボード） | 経営の数字。ここまでの3枚が検索結果に出る |
| `03_transfer.png` | 移籍市場 | |
| `04_standings.png` | 日程・順位表 | |
| `05_squad.png` | スカッド（選手一覧） | |
| `06_halftime.png` | ハーフタイム（檄・交代・戦術変更） | |
| `07_scorers.png` | 得点・アシストランキング | |
| `08_start.png` | タイトル・セーブ選択 | **最後**。情報量が無いので、先頭に置くと枠を捨てることになる |

フィーチャーグラフィック（Google Play 必須、1024x500）は
`marketing/feature/feature_graphic.png`。背景の
`marketing/feature/stadium_bg.jpg` は生成した画像で、実在のスタジアム・
クラブ・選手は写っていない。文字はアプリ同梱のフォントで載せているので、
ストアの絵とアプリの中で書体が揃う。

> 移籍市場は、移籍ウィンドウが開いている時期に撮る。閉じている時期だと
> 「クローズ中」の帯が出て「獲得する」が全部灰色になり、何もできない画面が
> ストアに載る（1.1.0 の撮り直しで気づいた）。生成器が自分で開く時期まで
> 進めるので、手で合わせる必要はない。
>
> 撮り直しが必要になるのは、画面の見た目や文言を変えたとき。
> 以前ここに置かれていた画像は、アイコンフォントを読まないまま撮ったため
> 天気アイコンが豆腐（□）で写っていた。生成器はアイコンフォントを
> 読み込み、見つからなければ失敗する。

## 審査時の留意事項

- **データ収集の申告は「収集なし」ではなくなった。** AdMob を組み込んだため、
  広告識別子(Android広告ID / IDFA)・おおよその位置(IPアドレス由来)・端末情報が
  Google に取得される。Play のデータセーフティでは「広告 ID」「デバイスまたは
  その他の ID」を*収集する*と申告し、目的は「広告またはマーケティング」を選ぶ。
  App Store の App プライバシーでは「識別子 > デバイス ID」を
  「サードパーティ広告」の目的で申告する。詳細は AdMob の公式ガイダンスに従うこと。
- アカウント登録・ログイン機能は引き続き無い。提供者自身は何も収集していない。
- 「融資」「スポンサー契約」は実際の金銭のやり取りを伴わないゲーム内経済である旨を
  Reviewer向けメモ（App Store Connect の「レビュー用メモ」欄等）に明記すると良い。
- Web版（Cloudflare Pages、`.github/workflows/soccer-pages.yml`）は無料の試遊版として
  引き続き公開する想定。ストア版と機能差分が出た場合はこのドキュメントを更新する。
