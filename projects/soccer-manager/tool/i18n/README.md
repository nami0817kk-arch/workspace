# 未翻訳文言の検出

`lib` 配下から、まだ `Tr.pick` を通っていない日本語のリテラルを洗い出す。

```
python3 tool/i18n/scan_jp.py lib
```

0件でなければ、その文言は英語表示のときに日本語のまま出る。

## なぜ正規表現ではなくスキャナなのか

このコードの文言は `'${x ? 'a' : 'b'}'` のように、補間の中に引用符を含む。
正規表現でリテラルを取ろうとすると補間の途中で切れてしまい、翻訳済みの
ものを未翻訳と誤検知したり、置換で壊したりする。`dartstr.py` は Dart の
文字列を実際に読んで、生文字列・三重引用符・入れ子の補間を正しく扱う。

## 意図した日本語データの除外

名前プールのように、UIの文言ではなく日本語のデータそのものであるものは、
宣言の直前に `i18n-ignore` を含むコメントを置くと検出から外れる。
ファイル単位ではなく宣言単位なので、同じファイルの他の文言は検出され続ける。

## wrap_tr.py

一括置換に使ったスクリプト。JA→ENの対応表(Pythonの辞書 `M`)を渡すと、
該当するリテラルを `Tr.pick(ja, en)` で包む。既に包まれているものは
飛ばすので再実行しても安全。今後まとまった量の文言を足すときに使える。

```
python3 tool/i18n/wrap_tr.py <map-module> ../l10n/tr.dart <file...>
```
