# basketball-career

バスケットボールの選手育成シミュレーション。Flutter のスマホアプリ（広告・課金・ストア公開前提）。
baseball-manager の骨格（年齢で局面が変わる一代記・季節ごとの選択・特性・保存互換）を踏襲する。
**2026-10-19 にユーザーが「チーム経営」ではなく「選手育成」を選んだ。**

## 前提

- 国名は実在のもの、**リーグ名・チーム名・選手名・大会名は架空**（Bリーグ・NBA・ウィンターカップ等は呼ばない。
  「国内プロ」「海外プロ」「全国大会」のように言い換える）。
- 広告・課金を入れる前に `docs/app-pitfalls.md` を読む。
- 試合計算は `lib/game/` の純Dart（Flutter非依存）に置き `test/` で固定。保存データは `fromJson` に既定値。
- テストは CI（`.github/workflows/basketball-ci.yml`）で回す。手元は analyze まで。
  analyze は非 ASCII パスでクラッシュするので `subst` したドライブから回す（memory: flutter-sdk-ascii-path）。
- 出す先は iOS のみ（Android には出さない）。

## ゲームの形

1人の選手を幼少期から育て、引退まで。

段階: ミニバス(6-12) → 中学(13-15) → 高校(16-18) → **進路(19歳)** → 大学(4年)/実業団(3年)/プロ → 引退。

- 能力10個（`Ability`）: 3Pシュート / ミドル / ゴール下 / ドリブル / パス / ディフェンス / リバウンド / スピード / フィジカル / スタミナ。
- **身長**がバスケ固有の軸。`heightGrowthPerYear` で成長期(10〜17歳)に伸び、20歳でほぼ止まる。生まれつきの素質 `heightGenes`。
  身長は能力の**実効値**に効く（`Player.effective`: ゴール下・リバウンドは高いほど、ドリブル・スピードは低いほど有利）。
  **ポジション(PG〜C)は身長と能力から自動で決まる**（選べない）。総合評価 `overall` はポジションごとの重みで出す。
- 1年を春・夏・秋・冬の4ターンに分け、ターンごとに過ごし方を選ぶ（`life.dart`）:
  練習 / 特訓 / 休養 / 研究 / 交流 / 練習試合。体調(`Condition`: 疲労・気持ち・怪我)は年をまたぐ。
- **夏(slot 1)に大会**（`season.dart`）。試合は4クォーター(`match.dart`)。
  最終クォーター後に点差が3点以内なら**勝負どころ**: ドライブ / 3P / パス / ディフェンスから選ぶ。
  選ばなければ成功率の高いプレーを自動で選ぶ。勝ち抜きは負けたら終わり、プロは全試合を戦う。
- 進路（`path.dart`）: プロ契約の評価は **能力7割・実績3割 ＋ 身長（185cm超の15%）＋ 華がある**。
  **一番上(70点以上)は確実、一番下(35点未満)は絶対に無理**、間は運(±10)。
  落ちたら大学4年 / 実業団3年から選び、卒業時にもう一度だけ挑戦。それも外れたら引退。
- プロ: 21歳以上で総合70以上なら**海外挑戦**（`proAbroad`、相手が強い）。自分で引退でき、
  総合35未満が2年続くと戦力外、40歳超で強制引退。
- 特性（`traits.dart`、最大4）: 大器晩成・早熟・努力家・天才肌・頑丈・ガラスの肉体・鉄人・前向き・勝負強い・ノミの心臓・華がある・長持ち。
  効き方は `traits.dart` の関数に集める。他のファイルは特性の名前を直接見ない。

### ゲーム本体（`lib/game/game.dart`）

`Game` が全部をつなぐ。画面は `phase`（`season` / `path` / `retired`）を見て対応する操作だけを呼ぶ:
`choose(action, focus, chooseClutch:)` → `chooseRoute` / `giveUp`、プロなら `goAbroad` / `retire`。
段階に合わない操作は `StateError`。保存は `toJson` / `fromJson`（欠けた項目は既定値）。

## 現状（2026-10-19）

- **エンジン**（`lib/game/`）と**画面**（`lib/ui/`）が揃い、通しで遊べる。テスト34件が通る。
  - `ui/controller.dart` — `GameController`。操作のたびに保存（書き込みは順番に行う）。勝負どころの方針（おまかせ/ドライブ/3P/パス/ディフェンス）と「おすすめで1年進める」。
  - `ui/home_screen.dart`（はじめ）/ `ui/game_screen.dart`（育成・進路・エンディングを局面で切り替え）。大会の結果は育成画面の「いまの結果」に出る。
  - Flutter の `Action` / `Route` と名前が衝突するので、画面側は `hide Action, Route` する。
- `tool/balance.dart` でバランスの目安が出る（練習中心の素朴な遊び方で、プロ入り約48%・海外挑戦約5%）。数字は仮置き。
