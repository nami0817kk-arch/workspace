# basketball-career

バスケットボールの選手育成シミュレーション。Flutter のスマホアプリ（広告・課金・ストア公開前提）。
baseball-manager の骨格（年齢で局面が変わる一代記・季節ごとの選択・特性・保存互換）を踏襲する。
**2026-10-19 にユーザーが「チーム経営」ではなく「選手育成」を選んだ。**

## 前提

- 国名は実在のもの、**リーグ名・チーム名・選手名・大会名は架空**（Bリーグ・NBA・ウィンターカップ等は呼ばない。
  「国内プロ」「海外プロ」「全国大会」のように言い換える）。
- 広告・課金を入れる前に `docs/app-pitfalls.md` を読む。
- 試合計算は `lib/game/` の純Dart（Flutter非依存）に置き `test/` で固定。保存データは `fromJson` に既定値。
- テストは CI（`.github/workflows/basketball-ci.yml`）で回す。手元は analyze まで。
  analyze は非 ASCII パスでクラッシュするので `subst` したドライブから回す（memory: flutter-sdk-ascii-path）。
- 出す先は iOS のみ（Android には出さない）。

## ゲームの形

1人の選手を幼少期から育て、引退まで。

段階: ミニバス(6-12) → 中学(13-15) → 高校(16-18) → **進路(19歳)** → 大学(4年)/実業団(3年)/プロ → 引退。

- 能力10個（`Ability`）: 3Pシュート / ミドル / ゴール下 / ドリブル / パス / ディフェンス / リバウンド / スピード / フィジカル / スタミナ。
- **身長**がバスケ固有の軸。`heightGrowthPerYear` で成長期(10〜17歳)に伸び、20歳でほぼ止まる。生まれつきの素質 `heightGenes`。
  身長は能力の**実効値**に効く（`Player.effective`: ゴール下・リバウンドは高いほど、ドリブル・スピードは低いほど有利）。
  **ポジション(PG〜C)は身長と能力から自動で決まる**（選べない）。総合評価 `overall` はポジションごとの重みで出す。
- 1年を春・夏・秋・冬の4ターンに分け、ターンごとに過ごし方を選ぶ（`life.dart`）:
  練習 / 特訓 / 休養 / 研究 / 交流 / 練習試合。体調(`Condition`: 疲労・気持ち・怪我)は年をまたぐ。
- **夏(slot 1)に大会**（`season.dart`）。試合は4クォーター(`match.dart`)。
  最終クォーター後に点差が3点以内なら**勝負どころ**: ドライブ / 3P / パス / ディフェンスから選ぶ。
  選ばなければ成功率の高いプレーを自動で選ぶ。勝ち抜きは負けたら終わり、プロは全試合を戦う。
- 進路（`path.dart`）: プロ契約の評価は **能力7割・実績3割 ＋ 身長（185cm超の15%）＋ 華がある**。
  **一番上(70点以上)は確実、一番下(35点未満)は絶対に無理**、間は運(±10)。
  落ちたら大学4年 / 実業団3年から選び、卒業時にもう一度だけ挑戦。それも外れたら引退。
- プロ: 21歳以上で総合70以上なら**海外挑戦**（`proAbroad`、相手が強い）。自分で引退でき、
  総合35未満が2年続くと戦力外、40歳超で強制引退。
- 特性（`traits.dart`、最大4）: 大器晩成・早熟・努力家・天才肌・頑丈・ガラスの肉体・鉄人・前向き・勝負強い・ノミの心臓・華がある・長持ち。
  効き方は `traits.dart` の関数に集める。他のファイルは特性の名前を直接見ない。

### ゲーム本体（`lib/game/game.dart`）

`Game` が全部をつなぐ。画面は `phase`（`season` / `path` / `retired`）を見て対応する操作だけを呼ぶ:
`choose(action, focus, chooseClutch:)` → `chooseRoute` / `giveUp`、プロなら `goAbroad` / `retire`。
段階に合わない操作は `StateError`。保存は `toJson` / `fromJson`（欠けた項目は既定値）。

## ゲーム性の改善（2026-10-19〜、ユーザー指示「ゲーム性の向上を繰り返し」）

- **勝負どころをその場で選ぶ**（既定）: 試合を1つずつ進め（`TournamentRun`）、点差が3点以内なら止まって
  `Phase.clutch`。4つのプレーの成功率を見て選ぶ（`Game.clutchInfo` / `resolveClutch`）。おまかせ・固定も残す。
  大会の途中でも保存・復元できる（`run` を保存）。`MatchState` が4クォーター終了時点、`finishMatch` が決着。
- **ライバル**（`rival.dart`）: 9歳から現れる同い年の選手。準決勝のあたりで毎年ぶつかり、通算成績が残る。
  強さは「その回戦の普通の相手」＋素質で±4。殿堂・エンディング・実績（宿敵に勝ち越し）に出る。対戦チーム名は架空（`opponentTeamName`）。
- **年の目標**（`goals.dart`）: 年のはじめに2つ（確実／挑戦）。年末に判定し、達成でごほうび。`rollGoals` / `adoptGoal` / `_evaluateGoal`。
- **難易度**（`difficulty.dart`）: やさしい／ふつう／むずかしい。伸びの倍率と相手の強さが変わる。始めるときに選ぶ。
- **おすすめの重点**（`recommendedFocus`）と、能力に◎○△（ポジションでの効き）。「おすすめで1年進める」はこれを使う。
- **チームワーク**（`Game.teamwork` 0〜100）: 交流 +12・練習試合 +6、毎ターン −2 で薄れ、進学・移籍で40に戻る。
  大会の味方の強さに ±4 ほど効く（パスが高いほど効く）。**練習一辺倒より、交流を挟む選び方に意味がある。**
- **過ごし方の役割を整理**: 以前は練習試合・研究が練習より伸びる上位互換だった。今は 練習＝重点を伸ばす／特訓＝大きく伸びるが疲れる／
  研究＝広く少し／練習試合＝全体＋チームワーク／交流＝回復＋チームワーク／休養＝回復。`test/game_test.dart` が上位互換になっていないことを検査。
- 試合の流れを一言で（`matchStory`: 逆転・接戦・圧勝など）、段階が変わったときの知らせ。
- 通しのログを読んで直したもの: ミニバスの相手は年齢が低いほど弱い（序盤に勝てないままにしない）／同じ出来事が続かない（`recentEventIds`）／
  重点はおすすめに自動で追従（自分で選ぶと止まる。`focusAuto`）。
- **出来事は32個**（`weight` が小さいまれな出来事: 突然のひらめき・伝説の選手との出会い。四分の一の起きやすさ）（プロ限定: 契約更改・ファン感謝祭・若手の台頭・衰えとの向き合い（30歳〜）、海外限定: 言葉の壁・世界の舞台。`EventDef.abroadOnly`）（ライバルとの会話は文中に `{rival}`、コーチ・キャプテン・後輩・体づくり・海外キャンプ・スポンサー・ベテランなど）。
  **コーチとの信頼**（`Game.coachBond`、練習・特訓で増え、高いと伸び最大+20%。進学・移籍で20に戻る）。
- **エンディング**（`epilogue.dart`）: 称号（世界を制した司令塔 など）と、生い立ち・全盛期・ライバル・結末・ひとことの文章。殿堂にも称号が残る。
- **成長の軌跡**（`Game.growthLog`、年末ごとの総合と身長。`art/growth_chart.dart` のグラフ）を育成画面とエンディングに。
- **大会結果をカード表示**（試合ごとに勝/負・得点・個人成績・流れの一言。優勝は色が付く）。実績は20個（王者・全制覇・司令塔など）。
- UI テストの注意: 画面は起動時に保存を読み込む。探索用のコントローラには保存しない店（`_NullStore`）を使う。
- `test/ui/phone_layout_test.dart` は文字を1.3/1.6/2.0倍にした場合（端末の文字サイズ設定）も検査（倍率が実際に効いていることを確認済み）。幅 360/390/430 で全画面を描いてはみ出し・例外を検査。画面の絵を目で見るには、テストの中で `RepaintBoundary.toImage` で PNG を書き出す
  （テストでは日本語フォントが読まれず字は□になるが、配置は確かめられる。ブラウザのプレビューは描画が不安定だった）。
- **プロ契約の見込み**（`Outlook`: ほぼ確実／有望／五分／厳しい／難しい）を育成画面（15歳〜）と進路画面に。評価点が見える。
- **ランクアップ**の知らせ（能力のランクが上がったら「ランクアップ! 3Pシュート D→C」）、触覚フィードバック（勝負どころ・優勝）。
- **進学先の選択**（中学・高校に上がるとき必ず出る。`events.dart` の `schoolEvents`、出来事が有効なときだけ）: 強豪校／地元の学校／私立・クラブ。
  大会の味方の強さ（強豪 +4〜5／地元 −2〜−3）・コーチとの信頼・チームワーク・気持ちが変わる。三択の強さは近く（`balance.dart --local --club`）、持ち味の違い。
- **個人賞**（`TournamentResult.award`: 優勝＋個人評価72以上で最優秀選手／個人評価80以上でベスト5。1生で平均約1回）。大会カード・年ごとの成績・実績に出る。
- **殿堂からの引き継ぎ**（`legacyBonusFor`: 実績5個ごとに次の選手の全能力の初期値 +1、最大 +5）。周回の動機。はじめの画面に出る。
- **方針の探索**（`tool/strategy_search.dart`、過ごし方の確率と重点の選び方をランダムに40通り試す）: 海外挑戦率は 1%〜36%。
  上位は全て「重点＝おすすめ」で、過ごし方の配分は多様（特訓・休養・研究・交流を混ぜる）＝**単一の必勝法は無い**。
  差を生むのは**重点の選び方**で、画面の★がそれを教える。足したら再実行して、上位が1つの配分に偏っていないか見る。
- **プロの入団先・移籍**（`proEvents`: 入団時と23・27・31歳に必ず出る。強豪／育成型／地元・新天地）。進学先と同じ仕組み（`schoolBonus`）。
- **ポジションの持ち味**（`Position.perk`）: PG=チームワーク×1.4／SG=勝負どころの3P+8%／SF=動きの良さ+0.03／PF=ドライブ+7%／C=ディフェンス+8%・リバウンド×1.2。
  ポジションは身長と得意（内側/外側）で決まる（203cm〜C、195〜202は内側が得意なら199cmからC・未満はPF、外が得意なら199cmからPF・未満はSF）。画面に持ち味を出す。
- **遊び方**（`howto_screen.dart`、7項目）: はじめて始めるときだけ自動で出し（`howtoSeen`）、はじめの画面と設定からいつでも開ける。
- **保存の完全性を守るテスト**（`test/save_guard_test.dart`）: 1手ごとに保存→読み戻しても一生の結果が変わらない（保存の取りこぼしを検出。欠落を作って検出できることを確認済み）／
  初期の形の古いセーブが読める／未知・壊れた項目で落ちない。**保存する項目を足したら、`toJson`・`fromJson`・`fingerprint`（このテスト）の3か所に足す**。
- **節目のダイアログ**（`milestone_dialog.dart` / `GameController.pending`）: 優勝・個人賞・目標達成・進学・プロ契約・海外挑戦を大きく見せる（「つぎへ」で次の節目）。
- **怪我の種類**（`Injury`: 捻挫1〜2ターン60%／肉離れ2〜3ターン32%／骨折4〜6ターン8%）。骨折は後遺症でスピード・フィジカル −3。`Condition.injuryName`（保存あり）。
- 触覚は `_buzz` 経由（`HapticFeedback` の失敗は**非同期**に出るので try/catch では捕まらない。`catchError` で握りつぶす）。`test/haptics_test.dart` が回帰テスト（修正前で失敗することを確認済み）。
- ライバル戦の勝負どころでは、コートの絵に**向かい合う2人とVS**を描く（`CourtHeader(versus: true)`）。
- **ライバルのその後**（`Rival.fate`: 素質で4通り）をエンディングで語る（対戦があったときだけ）。
- **おすすめの過ごし方**（`lib/game/advice.dart`、純Dart）: 怪我・疲れ→休養／気持ち低→交流／チームワーク低→練習試合／疲れが軽ければ特訓（大会の前の季節は避ける）／それ以外は練習。
  `balance.dart --auto` は画面の「おすすめで1年進める」と同じ方針で、約62%・42%（特化の遊び方と同等）＝**既定で強い**。
- はじめの画面に絵（`art/title_art.dart`: 夕焼けの空・街のシルエット・ゴールに向かうボール）。
- エンディングに**通算の得点・リバウンド・アシスト・個人賞**と、**結果をコピー**（`shareText`、`Clipboard`。共有用の短い文章。サーバーには何も送らない）。
- **マンネリ**（`Game.isRut`）: 練習・特訓・研究・練習試合を同じもので3回続けると伸び×0.85（休養・交流は対象外）。ボタンに「マンネリ気味」を出す。
  同じ練習の繰り返しを避け、過ごし方を混ぜる動機に。基礎の伸びを 5.0→5.2 に上げて均した（素朴 約37%/9%、おすすめ 約61%/42%）。
- おすすめの過ごし方は**マンネリを避ける**（同じ練習が続くなら 研究→練習試合 に替える）。`--auto` は約67%/48%。
- 成長の見える化: ターンごとに「成長: 3Pシュート +2 / …」を出す。
- バランス（`tool/balance.dart`、`--spec` でポジション特化の遊び方）: 素朴な遊び方でプロ入り約44%・海外約8%、
  特化すると約63%・約41%（交流を挟むと約63%・約35%）。**選び方で結果が変わる**ことを確かめた（以前は選び方が結果に効かなかった）。

## 広告と課金（2026-10-19 実装・ユーザー決定: 無料＋広告＋広告を消す370円。護送ボートと同じ形）

`lib/monetization/`（`ad_service.dart` / `purchase_service.dart` は goso-boat から。`monetization.dart` がこのアプリの決まり）。

- **全画面広告**: 大会を3回終えた**次の操作の前**に1回（大会の直後には出さない）。出せなければ進行を止めず次に回す。広告を消した人には出ない。
- **動画広告**: 見ると**回復**（疲れ -40・気持ち +10・怪我が1ターン早く治る）。1ターンに1回。読み込めなければ**タダでは回復させない**。
- **広告を消す**: 買い切り・非消費型、**370円**。商品ID `basketball_career_remove_ads`。設定画面に「購入を復元」（審査要件）・プライバシー・問い合わせ/広告の報告・ライセンス。
- 広告ユニットIDは `--dart-define=ADMOB_REWARDED_IOS` / `ADMOB_INTERSTITIAL_IOS`。**既定は Google のテスト用ID**。アプリIDは Info.plist の `GADApplicationIdentifier`（今はテスト用）。
- 報酬の受け取りは `GameController.recover`（画面の `mounted` に依存しない）。広告の読み込みは `await` で待たず `Completer`（`docs/app-pitfalls.md` #1〜#3 を `test/monetization_test.dart` が検査）。
- Web・テストでは NoOp（広告も課金も出ない）。
- `legal/` に**プライバシーポリシー・サポート・利用規約の原稿**（日英）。置き場所は `Links`（既定 `https://basketball-career.pages.dev`、`--dart-define=LEGAL_BASE_URL` で差し替え）。
