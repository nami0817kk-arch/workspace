# basketball-career(アプリ名「ブザービーター」予定)

バスケットボールの**カードで戦う勝ち抜き**ゲーム。Flutter の iOS アプリ(広告・課金・ストア公開前提)。

**2026-11-06 に作り変えた。** もとは「6歳から引退までの選手育成」(野球育成と同じ雛形)だったが、
ユーザーの指摘「似てるアプリはダメになりやすい(審査 4.3)。野球と似てるから大幅にテコ入れ」を受け、
ユーザーが「B: プレーのカードで戦う」を選んだ。育成の仕組み(`lib/game/`)と画面は消した(git の履歴にある)。
**野球育成・サカマネ・選手キャリアと似た形(年齢で進む一代記・季節ごとの過ごし方・勝負どころの選択肢)に戻さない。**

## 前提

- **リーグ名・チーム名・選手名・大会名は架空**(実在の名称を画面・掲載文・絵に入れない)。
- 広告・課金を触る前に `docs/app-pitfalls.md` を読む。
- 仕組みは `lib/deck/` の純Dart(Flutter 非依存)に置き `test/deck/` で固定。保存データは `fromJson` に既定値、壊れていたら読まない。
- テストは CI(`.github/workflows/basketball-ci.yml`)。**CI の `flutter analyze` は info でも落ちる。** 手元は `W:` から `dart analyze lib test tool` まで。
- 出す先は iOS のみ。画面は日本語のみ(配信は日本だけ。2026-11-06 ユーザー決定)。

## 遊び方(`lib/deck/`)

- **1シーズン = 1回の挑戦**(`run.dart` の `RunState`)。地区予選 → 県大会 → 全国大会。全国大会の決勝に勝てば日本一。
- 各大会は**8つの行き先**を上から順に選ぶ(`NodeType`: 試合・強豪・練習・部室・出来事・決勝)。1階目は試合だけ、7階目は練習か部室、8階目が決勝。
  強豪は3階目から。どの階にも試合か強豪がある。先の階まで全部見えるので、道筋を考えて選べる。
- **気持ち(ハート)3つ**。普通の試合・強豪に負けると1減り、0で終わり。**決勝に負けたらその場で敗退**(動画で1回だけやり直せる)。
  練習で休む・次の大会へ進むと1戻る。難しさ3からは2で始まる。
- **試合**(`battle.dart`): 4クォーター×2ラウンド=8ラウンド、同点なら延長(2回まで、それでも同点なら負け)。
  毎ラウンド手札5枚・スタミナ3。相手の**予告**(`Threat`: 種類と点数)が先に見える。シュートで点、守りの「守備」で相手の点を前から削る。
  「ラウンド終了」で相手が予告どおり攻める。堅い守りの予告は、こちらのシュートを1本ごとに減らす(最低1点)。
- **カード**(`cards.dart`、35種=基本4・ふつう13・いい11・すごい6・状態1): シュート(橙)・組み立て(青)・守り(緑)・流れ(紫、試合ずっと効く)・疲労(出せない、試合が終わると消える)。
  文はカードの数字(`CardStats`)から作る(文と効き目を食い違わせない)。「＋」は練習で強くしたもの。
  パスのあとに強くなる(アリウープ・ユーロステップ)、最後のラウンドで大きい(ブザービーター)、ドライブを止める(チャージング)などの組み合わせがある。
- **仲間**(`mates.dart`、13人・5人まで): 試合ずっと効く得意(3Pのシュート+1、毎ラウンド守備2 など)。強豪に勝つ・部室・出来事で加わる。
- 勝つと部費とカード3枚の候補(取らなくてもよい)。部室でカードと仲間を買い、カードを外せる(外す値段は使うたびに+25)。出来事は6つ。
- **実績と解放**(`profile.dart`): 実績10個。最初は出ないカード5枚・仲間3人を実績で解放する。全国優勝でひとつ上の難しさ(最大10)。
  記録(シーズン数・日本一・最高到達・最多得点)と図鑑は端末に残る。
- **乱数は種から**(`rng.dart`)。試合は始めた時点の種を保存し、試合の途中で閉じたら同じ試合を始めから(`RunState.fromJson`)。
- **釣り合いは自動で遊ぶ人で測る**(`bot.dart`、`dart run tool/deck_balance.dart [回数] [難しさ]`)。
  2026-11-06: 難しさ0で優勝17%・試合の勝率85%(地区予選90%・決勝は5〜7割)、難しさ5で5%、10で1%。カードを取らないと優勝はほぼ無い(`test/deck/run_test.dart` が検査)。
  人は bot より上手いので、実際はもっと勝てる。相手の強さは `Opponent.base`。

## 画面(`lib/ui/`)

- `deck_controller.dart`: 画面とシーズンをつなぐ。保存(`deckRun`・`deckProfile`)、実績の知らせ、広告の番、動画の受け取り(画面に依らない)。
  `load()` は最初の1回だけ読み、読む前に手元で始めた局面は上書きしない(テスト・掲載画像の生成器のため)。起動ははじめの画面から(「続きから」)。
- `deck/`: `home_screen`(はじめ・実績・図鑑)、`run_screens`(行き先・報酬・仲間・練習・部室・出来事・結果)、`battle_screen`(点数板・会場の絵・予告・手札)、`card_view`(カードの見た目・デッキの一覧)、`style`(夜の体育館の色。暗い紺に橙)。
- iPad は `TabletScale`(`app.dart`)で、幅620の画面をそのまま拡大する(余白だらけにしない)。
- 絵: 会場4枚(`scene_high/university/national/final.jpg`)・タイトル・カードの絵15個(`assets/art/icons/`)・選手(4つの姿勢×12色)。自分の学校は朝日高校(橙)、相手の色は名前から。
- 掲載画像は `tool/screenshots/capture_test.dart`(iPhone 1206x2622・iPad 2064x2752、8枚)。点検用は `--plain-name "画面の点検用"` で `build/review/`。撮ったら必ず目で見る。

## 広告と課金(2026-10-19 ユーザー決定: 無料＋広告＋広告を消す370円)

`lib/monetization/`(`ad_service.dart` / `purchase_service.dart` は goso-boat から。`monetization.dart` がこのアプリの決まり)。

- **全画面広告**: 試合を3回終えた**次の行き先を選ぶ前**に1回(試合の直後には出さない)。出せなければ進行を止めず次に回す。動画を見た2分以内は重ねない。
- **動画広告**(押したときだけ): 勝ったあとのカードの候補を引き直す(1回の報酬につき1回)・決勝に負けたらやり直す(1シーズンに1回)。読み込めなければ何もしない(タダでは渡さない)。
- **広告を消す**: 買い切り・非消費型、**370円**。商品ID `basketball_career_remove_ads`。全画面広告が出なくなり、引き直し・やり直しも動画なし(回数は同じ)。
  全画面広告の2回目と、その後4回ごとに「広告なしで遊ぶ」の案内を1度だけ出す。設定画面に購入・復元・プライバシー・問い合わせ/広告の報告・ライセンス。
- 広告ユニットIDは `--dart-define`、既定は Google のテスト用ID(本番は CI が Secrets から入れる)。
- テスト: `monetization_test`(決まりとコントローラ)、`store_purchase_test`(偽の App Store)、`ad_present_test`(知らせが後から届く偽の広告。app-pitfalls #9)。
