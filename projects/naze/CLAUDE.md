# naze — 解説チャンネル「理の書」（@kotowari_no_sho）

世界の「なぜ」を、データと計算で確かめる。2026-10-25 開始、2026-10-26 に旧 棒人間ストーリーのチャンネルを作り替えた。
他チャンネルの題材の並び・題名の型・見た目をまねない。数学の題材と創作の物語は扱わない。

## 作り方

`python -m naze <手順> episodes/<題材>`（題材のフォルダに `ep.py` の `EP` を置く。出力は `out/<題材>/`）

- 地形の回（kind: terrain）: `kana` → `voice` → `prep` → `stills 1,60,…`（目で見る）→ `render` → `compose`（`all` で一気に）
  - 標高は国土地理院の標高タイル（`cache/dem` に保存）。地形は Blender（`NAZE_BLENDER` か既定のパス）で描く
  - 座標の原点は範囲の真ん中（km、x が東・y が北）。カメラの yaw は 0 で南から北を見る
  - 地形の色は 2 通り。`tex_opts=dict(photo=True, photo_sat=1.35, photo_gain=1.12)` で国土地理院の空中写真を貼る(まち・森が見える。実在の場所の回はこちら)。
    無ければ標高の色分け(低地＝緑・山＝黄土。高さそのものが主役の回はこちら)。写真のときは隅の出典に「空中写真」が付く
  - 行に `profile=dict(a="地点", b="地点", at=0.05, names=["西の山", "東の山"])` を付けると、地形を切った断面図(標高のグラフ)と切り線が出る。
    谷・台地・崖を見せる行に 1 つ入れる(立体日本列島の「地形を切る」に当たる見せ方)
  - 行に `compare=dict(value="入り口 7つ", unit="切通", n=7, note="…", at=0.1)` で、数字を身近なものに換える図(箱を n 個並べる。計算の回でも使える)。
    図が出ている間、その箱にかかる札は自動で消える
  - EP に `pins=[dict(point=…, text=…)]` で、地形の上に小さな地名を常に出す(本編の道しるべ。ショートは 2 つまで)
  - 行に `section=True` を付けると、その前にひと呼吸(0.65 秒)入る。問いのあと・結び・お願いの前は自動で入る
  - `render` は途中から再開できる（できたコマは飛ばす）。`prep` で設定が変わると古いコマは捨てる
- 計算の回（kind: sim）: `kana` → `voice` → `stills` → `compose`。画面は `ep.py` の `draw(img, dr, t, ctx)` が描く
- 世界の地図の回（2026-11-04、チリの回から）: `naze/worldmap.py`。下地は1本のあいだ立体の地図1つ（寄り引き・手前に傾ける）、その上に層を足す（国の塗り・縁・2国の境・線・矢印・輪切り・札・点・日本の形を本当の大きさで重ねる・断面のパネル・上の章の帯）。
  陸の色は NASA Blue Marble（GIBS、鍵不要・利用の制限なし）、標高は Terrain Tiles（AWS の公開データ。アカウント不要で課金なし。海底も入る）、国境・州・都市は Natural Earth 10m。どれも `cache/` に自動で取る。
  概要欄に「地図: NASA Blue Marble（GIBS）、標高 Terrain Tiles（USGS SRTM・GMTED2010、NOAA ETOPO1）、国境 Natural Earth」。書き方は worldmap.py の冒頭
  映像の質（2026-11-04）: 傾けると山が立ち上がる（手前が奥を隠す）・塗った国は影で浮いて縁が光る・札は弾んで出る・周りを少し暗く・細かい粒。1コマ 傾けて約0.9秒、真上から約0.35秒
  **画面の種類**（2026-11-04「動画が一辺倒なのが良くない」）: `naze/shots.py`。行の scene に shot＝map（view_to で飛ぶ）・globe（地球儀）・block（地形の箱の断面、沈む板）・split（左右に2つ）・illust（場面の絵、隅に「イメージ」）・card（大きな数字）・timeline（年表）。**2〜3行ごとに種類を変える**。場面の絵は FLUX の無料枠（`episodes/chile/make_illust.py` が見本）。声の前の行ごとのコマは `episodes/chile/sim/sheet.py`
  **編集の技**（同日「動画編集のスキルはたくさんあるよね」）: 層・札に `on="言葉"` で**その言葉を言い始めた瞬間に出す**（`naze voice` が時間割に marks を書く）・数字の数え上げ（card は既定、label は count=True）・切り替え tr＝zoom/whip/flash・粒 fx＝snow/dust/embers・色 grade＝old/cold/warm・地図の inset（左下の小さな地球儀）・道筋 route・広がる塗り wipe・塗りに光が走る。効果音は切り替えの種類で変わり、数字の札は「ドン」と数え上げの音（naze/sfx.py の impact・tick・swish）
  **映像の点検** `python -m naze vqc episodes/<題材>/<章>`（naze/vqc.py。声の前でも使える。qc の中でも走る）: 何も足されない間（10秒で△・15秒で✖）・寄りすぎのぼけ・カメラの速さ・字の数・1分に足す数・同じ見せ方が続く長さ（30秒で△・45秒で✖）。場面を書いたら先にこれを通す
- 3D の物理演算は MuJoCo（`pip install mujoco`、2026-10-31 導入。落下の試運転は理論値と一致）。pybullet はこの PC にコンパイラが無く入らない。2D は pymunk。計算の回の `draw()` から時間を進めて軌道を描く
- 声は VOICEVOX の剣崎雌雄（id 21、2026-10-26 ユーザーが選んだ）。読みは `kana` で全行を見て、違えば `say` で直す。概要欄に「VOICEVOX:剣崎雌雄」
- 投稿: `python -m naze.upload 動画 --title … --desc-file … --publish-at 2026-10-27T19:00:00+09:00 [--thumb サムネ.jpg]`（カテゴリ教育）。本編は 19 時、翌日にショート 5 本を 11・12・13・14・16 時

## 3D の回（three/、2026-11-03 試作）

顔のない人形＋物理計算で技を見せる場面（青空・白っぽい床・衝撃の輪・光の筋）。場面の設定は `three/scenes/<場面>.py` の `SCENE`（見本は `punch`）。
- 素材は git の外 `C:\Users\なみ\dev\assets3d`（出どころ・ライセンスは同じ場所の `SOURCES.md`。どれも CC0）。パスは `three/config.py` の一か所。
  人形と動きは Quaternius の Universal Animation Library 無料版（殴る・走る・跳ぶなど 43 本）。**蹴る・投げるは無料版に無い**（有料の Pro 版か UAL2）
- `python -m three all <場面> [--grey]`（probe → sim → plan → render → check → compose → sheet）。出力は `out/three/<場面>[_grey]/`
- 先に `--grey`（色・効果なし・半分の大きさ・0.5 秒/コマ）で動き・当たり・カメラを確かめてから本番（1920×1080・EEVEE・約 1 秒/コマ＋合成 1 秒/コマ）。
  一部だけ描き直すのは `render --only 1,2,3`、点検の数字だけ取り直すのは `render --check-only`
- 球の打ち出しは拳と球の衝突を MuJoCo で解く（`physics.punch_launch`。式 v=(1+e)MV/(M+m) と一致）。カウンターと答えの数字はこの値
- **点検**（`check.md`）を全部通し、`sheet.jpg` と当たる瞬間の拡大を目で見てから見せる: 向き・拳と球の隙間・めり込み（人形と球・マットのへこみ・床）・主役が画面から外れない・字と重ならない・数字が計算の値

## ショート（縦 1080×1920・3 分以内）と本編（横 1920×1080・15 分前後）

- 縦か横かは `ep.py` の `aspect="landscape"` で決まる（無ければ縦）。字幕などの位置は `config.LAYOUT`
- 本編は章ごとの回（地形と計算を混ぜてよい）を `episodes/<題材>/<章>/ep.py` に作り、`episodes/<題材>/long.py` に並べる:
  `LONG = dict(title="…", parts=[dict(title="章の題", ep="ch1"), …])` → `python -m naze long episodes/<題材>`
  2 章目から頭に 2 秒の章の札が入り、`out/<題材>/chapters.txt` に概要欄の目次（0:00 から）が出る。YouTube の章は 3 つ以上・各 10 秒以上
- 本編の台本は 15 分で約 4,500 字。答えが 1 つで終わる題材はショートにし、本編は「次のなぜ」が 3〜5 段続く題材にする
- 地形の章の書き出しは 15 分で 3〜4 時間かかる。背景で回す
- 題名とサムネの型は `docs/titles.md`（思い込みの否定＋数字＋知っている名前、本編 30〜50 字。upload が題名の△を出す）
- サムネイル: `python -m naze.thumb 下地.png out.jpg "1行目" "【強調】2行目" --focus fx,fy --zoom 1.5 --circle 922,360,120 --sub "添え書き"`（下地は字の無い stills のコマ）

## 質を保つ仕組み

- **点検** `python -m naze qc episodes/<題材>`(compose のあと): 台本(語りの速さ・字幕と語りの食い違い・字幕の長さ・3 分・つかみ)、
  画面(全コマで札と字幕の重なり・はみ出し・黒いコマ・止まった画面・1 分あたりの切り替え)、音(音量・ピーク・無音)。
  結果は `out/<題材>/qc.md`・`qc.json`、行ごとのコマは `qc_sheet.png`(見せる前に必ず目で見る)
- **関門**: `naze.upload` は qc に通っていない動画・点検のあとで変わった動画を止める
- **効果音**: カットの切り替えに「シュッ」、札が出る瞬間に「ポン」を自動で小さく入れる(合成音。BGM は入れない)。
  計算の回は ep.py に `sfx_events(L)` を書くと鳴らす場所を決められる。止めるなら EP に `sfx=False`
- **結びのお願い**: どの回も最後に「チャンネル登録と高評価、よろしくお願いします。」の行(声＋ボタンの画面)が自動で入る
  (2026-10-26 ユーザー指示。本編は最後の章だけ。止めるなら EP に `cta=False`)
- 引きの画面も止めない(計算の回はゆっくり寄ったり引いたり、地形の回はカメラが常に動く)。音量は 2 回測って -15 LUFS にそろえる

## 決まり

- 出典は `ep.py` の冒頭と概要欄に書く。数字は自分で計算したか一次資料のものだけ
- 台本はユーザーに見せてから作る。わかりやすさ優先（答えを先に・難しい語は言い換え・身近な比べ）
- 投稿の前に必ず動画をユーザーに見せる
