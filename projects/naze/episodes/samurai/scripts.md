4. 角度は4.11°のまま。網の位置で、58cm低い。ボール約9個分です。
5. 網の下に刺さります。外れ幅は58cm低い。失敗です。［メーター：58cm低い］
6. 直します。角度を、6.93°へ。外れ幅は0cm。ふれます。［メーター：0cm］
7. ただし、ふれる窓は狭い。角度で約6.60°から6.93°。幅は約0.32°、ボール1個分です。
8. 1°ずれると、網の高さで約20cmずれます。ボール3個分。
9. 超回転で当てるのは、角度の勝負です。

### ショート4「ラケットの限界」（実験6・7）

1. テニスの王子様のサムライドライブは、超回転。回転を、毎分5,000回転にしたら、どうなるか。
2. ものさしは「外れ幅」。網の上端にふれる高さから、何cm外れたかです。
3. 角度は8.82°。計算では、網の上端にふれます。外れ幅は0cmです。［メーター：0cm］
4. ただし5,000回転は、測定範囲をわずかに超える値。目安です。
5. 球に吸い付いても、こする速さは秒速29m要ります。時速約105kmです。
6. 大学の男子選手13人のフォアは、平均969回転。5,000回転は、その約5倍です。［棒グラフ］
7. デビスカップ1試合では、最大3,800〜4,300回転。5,000回転は、さらにその上です。
8. 出せると言える根拠がありません。外れ幅は0cmでも、失敗です。［「失敗」の札］
9. 測られた範囲にそろえます。3,000回転、角度6.93°、秒速30m。外れ幅は0cm。成功です。［「成功」の札］
10. ふれる角度は、見つかりました。

### ショート5「割れた2つは返せるか」（実験8・9）

1. テニスの王子様で、ボールがネットで割れて、2つとも打ち返される。それは、打てるのか。
2. 割れたことにして、計算します。ものさしは「外れ幅」。ラケットの面の端から、何cm外れたかです。0cmなら当たり。［メーター］
3. ラケットの面は、横の幅が最大29.2cm。ボールの直径を引くと、中心が22cmに入れば当たり。横に分かれる場合の見積もりです。［ラケットの面の図］
4. 割れた殻は、1つ約28g。向きしだいで、空気をつかむ強さが変わります。
5. 網から11.9m先に着くのは、0.60秒から1.0秒。丸い球は0.56秒です。
6. 分かれる速さは、それぞれ秒速0.5mと置きます。離れ幅は0.6〜1.0mです。
7. 外れ幅は、38〜79cm。1振りでは、返せません。失敗です。［「失敗」の札］
8. 直します。分かれる速さを、秒速0.1m前後以下に。外れ幅は0cm。両方返せます。［メーター：0cm］
9. ただし、割れ方を決められるかは、漫画です。

### 決めたこと・気をつけたこと
- 軸は「外れ幅メーター」。ボールの下が網の上端にちょうどふれる高さを0cmとし（窓の上限）、6.7cm低くなるまではふれる。実験ごとの値（0 → 13低い → 0 → 58低い → 0 → 0（測定範囲の外）→ 0 → 面から38〜79cm → 0）を各章の終わりで言う。基準は6章でラケットの面に替えると断る
- 窓は約6.60〜6.93°、幅約0.32°。揚力の見積もりで角度は±0.7°ほど動くと断り、結びは「ふれる角度は存在する」まで
- 実験6の失敗の根拠は「測定範囲の外（測られた最大を超える）」だけ。「人の腕では出せない」とは言わない。ラケットの速さ（29m/s＝時速約105km）だけで無理とは言わない
- 5,000回転は測定範囲をわずかに超える（S>0.53の外）ので「目安の値」と断る（4章3行目、s4）。10,000回転は出さない
- 「割れる」を言い切らない。3,000回転は2.1ジュールで、殻を裂く目安3〜7ジュール（確かさ低い）に届かない。届くのは約3,700回転以上。刃もない。結びは「回転が足りず、刃もない。割れ方を決められるかは漫画」
- 規則どおりならワイヤーは帯の下でボールにふれない。1章では作中の言い方（網の上端）のまま言い、5章で正す
- 割れた球のその後は6章の実験8・9で計算。半球の殻の空気抵抗係数（1.42と0.42）は二次資料で確かさが低い。減速比の細部は台本から削った。分かれる速さ（秒速0.5m）は仮置き。離れ幅は横に分かれる場合（面の幅29.2cm）。割れ方を決められるかは漫画と言う
- サーブを返す約0.5秒との比べは成り立たない（サーブの飛行〜返球と、殻の網→ベースラインは別物）ので台本から削った。2回に分ける案は「数字が無く言えない」の1行だけ
- 割れた殻は質量を半分の約28.5gとし、割れた時の速さは網での23.9m/sのまま、各殻は一定の向きで飛ぶとして計算（向きの変化・横の力は入れていない）。到着0.60秒・1.0秒は11.885m先まで
- 実験9の「秒速0.1m前後以下」は、両方がラケット面に入る条件（中心の離れ幅22cm以内）から逆算した値（0.11〜0.18m/s）。回転のエネルギー2.1Jの数千分の1に当たる
- 初速30m/s・高さ1.0m・回転が飛行中一定、は仮定。作中の数字ではないと1章で断る
- 同じ題材の動画には触れない。再現動画のまねをしない
