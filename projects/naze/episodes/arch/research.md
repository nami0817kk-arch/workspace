## 3. 計算(式と値)

### 3.1 平らな板(実験1)
- 断面係数 Z = b·h²/6 = 1×0.25/6 = 0.04167 m³、I = b·h³/12 = 0.010417 m⁴、EI = 25e9×0.010417 = 2.604e8 N·m²
- 自重だけ: w = 11.77kN/m、M = wL²/8 = 147.1kN·m、σ = M/Z = **3.53N/mm²**(36.0kgf/cm²)= ft の **1.86倍**
- 荷物込み: w = 21.77kN/m、M = 272.1kN·m、σ = **6.53N/mm²**(66.6kgf/cm²)= ft の **3.44倍**
- 自重だけで ft に収まる厚さ: σ = 0.75γL²/h → h = 0.75×23536×100/1.9e6 = **0.93m**
- 荷物 10kN/m 込みで ft に収まる厚さ: 1.9e6·h² = 0.75·L²·(γ·h + q) を解いて **h = 1.25m**(h=1.0 で 2.52N/mm²、1.5 で 1.51、2.0 で 1.07)。板の重さ = 23.54×1.25×10 = 294kN = **30トン**(0.5m の2.5倍)
- 最大たわみ(単純支持): 自重だけ 5.88mm、荷物込み 10.88mm(橋の長さの 1/920)
- 「石はほとんど曲がらないまま割れる」: ft に達する荷重のたわみは、荷物込みの 1/3.44 で約3mm(線形のとき)

### 3.2 アーチ(実験2〜3)
- 放物線アーチ y = 4f·x(L−x)/L²、一様な荷重 w = 21.77kN/m(自重+荷物とみなす。実際のブロックの自重は中心線の長さに比例するので少しずれる)
- 横押し H = wL²/(8f): f=1.0 → 272kN、1.5 → 181kN、2.5 → **108.8kN(11.1トン)**、3.5 → 77.7kN、5.0 → **54.4kN(5.5トン)**
- 鉛直反力 V = wL/2 = 108.8kN。f=2.5 では端の傾き 4f/L = 1 で H = V(端で45°)
- てっぺんの押す力(断面に均等とした平均): エンジンの H = 99.1kN を 0.5m² で割って **0.198N/mm²(2.0kgf/cm²)**(式の H では 0.218N/mm²=2.2kgf/cm²)。fc の約1/120。板の下側 6.53N/mm² の約1/30
- 実際の接触面はブロックの間の一部に集中するので、局所はこの数倍になりうる(それでも fc=24 に対して余裕がある)
- **実重量での式(2版)**: 輪の自重は中心線の長さに比例(11.77kN/m×ds)、荷物は水平方向に q=10kN/m。荷重の釣り合いからてっぺんの曲げモーメントを出し、力の線が両端とてっぺんの中心線を通ると置いて H = M_てっぺん/f。f=5.0 → **62.1kN(6.3トン)**、2.5 → **113.3kN(11.6トン)**、1.5 → **184.2kN(18.8トン)**、1.0 → 274.0kN。輪の自重(21個ぶん)は 174.0・135.1・124.4・120.7kN、全体は 274.0・235.1・224.4・220.7kN
- エンジンと同じ範囲(動かせる19個、荷物は19個の上面だけ)で出し直しても同じ: H = 61.8・113.4・184.9・275.3kN(f=5.0・2.5・1.5・1.0)。動かせる19個の自重は 157.0・122.1・112.5・109.2kN(f=2.5 で約12.4トン→台本は「約12トン」)、荷物と合わせて 250.5・214.2・203.8・200.1kN(約22トン)
- 輪の中心線の長さ: f=2.5 で 11.48m、f=5.0 で 14.79m → 比 **1.29**

### 3.3 形の比較(実験4)
- 3つの曲線(幅10m・高さ f): 放物線 z = 4f·x(L−x)/L²、円 z = √(R²−(x−L/2)²) + (f−R)(R = (L²/4+f²)/(2f))、カテナリー z = f − a(cosh((x−L/2)/a) − 1)(a は高さ f から決める)
- f=5.0: R=5.0(半円)、a=3.094。放物線との最大の差: 円 1.25m、カテナリー 0.25m。円とカテナリーの差は 1.07m。中心線の長さ: 放物線 14.79m、円 15.71m、カテナリー 14.96m
- f=2.5: R=6.25、a=5.372。放物線との差: 円 0.156m、カテナリー 0.044m
- 理論: 水平方向に一様な荷重(橋の上の道路の重さ)の押す力の線は放物線、輪の自重(中心線の長さに一様)ならカテナリー(上下反転した吊り鎖)。円は、高い(f が大きい)ほど両者から離れる

### 3.4 端を広げる(実験5)
- 放物線アーチの中心線の長さを一定として、端が離れたときの高さ f を数値で解く
  - 広げる量 0.05m → 高さ −4.2cm、0.1m(1%)→ **−8.4cm**、0.2m(2%)→ **−17.2cm**、0.3m → −26.3cm
- 鉄の棒(つなぎ材)の断面積 A = H/σ_許: H = 108.8kN(式)、σ_許 = 140N/mm² → A = 7.77cm²、直径 31.5mm。エンジンの H = 97kN なら 6.9cm²、直径 29.7mm → 「約3cm」。降伏点 235N/mm² を使えば 4.6cm²(直径 24mm)
- 地面の摩擦だけで受けるなら、必要な摩擦係数 ≥ H/V = 99/109 = 0.91(エンジンの値)

## 4. 物理エンジンの設定(MuJoCo 3.17.0、付録にコード)

- 板(実験1): 20個の剛体の棒を回転ばね(剛性 k = EI/ℓ、ℓ=0.5m)でつないだ簡易な梁。重力は切り、1個ずつに w·ℓ を外力で与える。左は固定の支点、右はローラー(水平に動くキャリアに接続)。減衰を入れて90秒回して静止させた
- ブロック(実験2〜5): 台形の凸メッシュ(継ぎ目は中心線に垂直)、奥行き1m、密度2400、摩擦0.6、`cone=elliptic`、`multiccd` 有効、反復200、刻み0.002秒。両端のブロック(b0 と b20)は地面。荷物は外力(水平方向の幅に比例、ブロック上面の中央に作用、モーメントも付与)
- 実験5: 両端のブロックにスライド関節を付け、位置制御(毎秒1cm、左右各)で外へ動かす / 摩擦損失 20kN の関節(地面が横に止める力) / 2つのスライドを等式拘束でつなぐ(つなぎ材)

- **片側だけの荷重(動く車の目安)**: f=2.5、t=0.5、左半分だけに q を載せる。q=10・20・30kN/m は立つ(最大の動き 3.7・4.6・6.5cm)。35kN/m は崩れ、40kN/m も崩れた。→「普段の荷重(10kN/m)の3倍まで立ち、3.5倍で崩れる」。1つのモデルの値で、実在の橋の安全の目安ではない。全面に一様な荷重を増やす試験は、40kN/m で最大の動き9.3cm(立つ)、80kN/mで17.7cm、120kN/mで27.6cm(判定は0.15m超で「動きすぎ」だが、全面が崩れ落ちたわけではない。曖昧なので台本では使わない)
- **端を広げる**: 位置制御で毎秒1cm(左右各)。てっぺんの沈みは広げた量に比例して増え、総広げ量50cm(5%)で沈みが0.5mに達した時点を崩れと判定。**判定の基準(沈み0.5m)は置いたもの**。地面が横に止める力(摩擦損失)を20kNにして自由にすると、端が数十cm外へ動いて崩れた。同じ条件で2つのスライドを等式拘束でつなぐと、端の動きは左−0.3cm・右+0.2cm、てっぺんの沈み約4cm、端の反力 H=96.8kN、V=108.4kN(棒の張力は約97kN)
- **ブロックの摩擦**: 0.6 は置いた値。実際の石の摩擦は面の仕上げで変わる。

## 7. 題材についての懸念

- **石の強さの値は仮置きで、一次資料(示方書の本文)で確認できていない**。さらに、台本が比べる 1.9N/mm² は直接の引っ張り強さで、曲げで割れる強さ(曲げ強度)はこれより大きい。**曲げ強度(ACI 式 0.62√f'c = 約3.0N/mm²、原文未確認)まで広げて再計算(2版)**:
  - 厚さ0.5mの板: 自重だけの応力 3.53 → 3.0 の **1.16倍**(1.9 との比 1.86倍は大きく出ている)。荷物10トン込みは 6.53 → **2.15倍**(直接の引っ張りとの比 3.44倍)
  - 割れない厚さ(曲げ強度3.0): 自重だけ 0.75γL²/3.0e6 = **0.59m**、荷物込み 3.0e6·h² = 75·(23536h+10000) を解いて **0.87m**(直接の引っ張り 1.9 では 0.93m・1.25m)。石の量は 1.7倍、板の重さ約21トン
  - 結論: 荷物10トンを載せた0.5mの板は、強さをコンクリート並みと置く限り、曲げ強度でも割れる側(2.15倍)。**ただし自重だけでは 1.16倍とぎりぎり**。そのため台本の主役は「10トンを載せると割れる計算」にし、自重だけは「耐える値を超える」(直接の引っ張りとの比 1.9倍)と言う。「割れる」を一般論にしない
  - 強さを変えたときの境: 0.5mの板は、強さが約6.5N/mm²(荷物込み)または約3.5N/mm²(自重だけ)を超えれば割れない。天然の花崗岩(曲げ強さ11〜18N/mm²とされる、出典未確認)は、密度2.7で自重応力約3.9N/mm²、10トン込みで約7.2N/mm² → 割れない側。台本は題名・1章・s1で「強さをコンクリート並みと置く」と条件を言い、概要欄で曲げ強度・花崗岩との差を書く
  - 引っ張り強さを2.5N/mm²にしても厚さ0.5mの板は自重だけで 3.53 > 2.5 となり割れる計算(荷物込みなら必要な厚さは約1.0m)。公開前に示方書(設計編)の式と数値を原文で確認したい
- 「接着剤なしのブロック」と実在のポン・デュ・ガールを結んでいない(モルタルの有無を公式で確認できないため)。冒頭の「同じ石を山なりに積むと2000年近く立つ橋がある」は、ポン・デュ・ガールが石のアーチで、紀元50年ごろから立つことだけを根拠にしている(石を積んだ橋、という言い方で接着剤には触れていない)
- 物理エンジンで実現しにくい点: ①材料が割れる様子(書いていない。板は「引っ張る力」と耐える力の比で見せる) ②吊り鎖の形の厳密な一致(13cmずれ) ③接触が柔らかいため、てっぺんの沈みの小さな値(数cm)は信用しすぎない ④ブロックの数で最小の厚さが動く(21個/31個の幅を断り書きに入れた)
- 荷物を載せた条件での形比べ(放物線が合う)は、エンジンでは確認できず、式の話。台本は「式の上で」と言っている
- 動く荷重・風・地震・盛り土の重さ・水は計算に入れていない。片側荷重は1パターンだけ試した
- 境目付近の結果は単調でないことがある(上の表)。台本は境目の値を丸めて(約45cm・20cm・10cm)言い、強く言うのは「順番は同じ」
- 検索補完・検索量は取っていない(題名の型は docs/titles.md に従った)。「橋 アーチ なぜ 強い」の需要は未確認
- 実験5の「5%で崩れる」は、強制変位を毎秒1cmで与えた結果で、地盤の変形のしかたとは違う

### arch.py(実験2〜5のブロックのアーチ)
```python
import mujoco, numpy as np
rho=2400.0; g=9.80665; B=1.0
def centerline(shape,L,f,N):
    """return N+1 points (x,z) along centerline, equal arc length, and the shape fn"""
    xs=np.linspace(0,L,4001)
    if shape=='parabola':
        z=4*f*xs*(L-xs)/L**2
    elif shape=='circle':
        R=(L**2/4+f**2)/(2*f); zc=f-R
        z=np.sqrt(R**2-(xs-L/2)**2)+zc
    elif shape=='catenary':
        # z = f - a(cosh((x-L/2)/a)-1) inverted catenary through ends; find a so that rise=f
        from scipy.optimize import brentq
        h=lambda a: a*(np.cosh(L/2/a)-1)-f
        a=brentq(h,1e-3,1e4)
        z=f-a*(np.cosh((xs-L/2)/a)-1)
    s=np.concatenate([[0],np.cumsum(np.hypot(np.diff(xs),np.diff(z)))])
    si=np.linspace(0,s[-1],N+1)
    px=np.interp(si,s,xs); pz=np.interp(si,s,z)
    return px,pz,s[-1]
def build(shape='parabola',L=10.0,f=2.5,t=0.5,N=21,mu=0.6,q=10e3,base_slide=False,tie=False,fixed_ends=True,fric_loss=0.0):
    px,pz,slen=centerline(shape,L,f,N)
    # node normals: perpendicular to local tangent (use central difference)
    tx=np.gradient(px); tz=np.gradient(pz); nrm=np.hypot(tx,tz); tx/=nrm; tz/=nrm
    nx,nz=-tz,tx          # points up/out for left->right traversal (tz>0 on left: nx<0)
    # fix the end nodes tangent (one-sided)
    inner=np.stack([px-nx*t/2,pz-nz*t/2],1); outer=np.stack([px+nx*t/2,pz+nz*t/2],1)
    bodies=[]; loads=[]
    xml='<mujoco><compiler angle="radian"/><option timestep="0.002" integrator="implicitfast" cone="elliptic" impratio="10" solver="Newton" iterations="200" noslip_iterations="3"><flag multiccd="enable"/></option>'
    assets='<asset>'; wb='<worldbody><geom type="plane" size="30 5 0.1" pos="0 0 -3" rgba=".6 .6 .6 1"/>'
    info=[]
    for i in range(N):
        c=np.array([ (inner[i]+inner[i+1]+outer[i]+outer[i+1])/4 ]).ravel()
        verts=[]
        for yy in (-B/2,B/2):
            for p in (inner[i],inner[i+1],outer[i+1],outer[i]):
                verts.append((p[0]-c[0],yy,p[1]-c[1]))
        vs=' '.join(f'{v[0]:.6f} {v[1]:.6f} {v[2]:.6f}' for v in verts)
        assets+=f'<mesh name="m{i}" vertex="{vs}"/>'
        static = fixed_ends and (i==0 or i==N-1)
        fr=f'friction="{mu} 0.005 0.0001"'
        if static and base_slide:
            sgn=1
            wb+=f'<body name="b{i}" pos="{c[0]} 0 {c[1]}"><joint name="sl{i}" type="slide" axis="1 0 0" damping="{1e4 if fric_loss==0 else 2e4}" frictionloss="{fric_loss}"/><geom type="mesh" mesh="m{i}" density="{rho}" {fr}/></body>'
        elif static:
            wb+=f'<body name="b{i}" pos="{c[0]} 0 {c[1]}"><geom type="mesh" mesh="m{i}" density="{rho}" {fr}/></body>'
        else:
            wb+=f'<body name="b{i}" pos="{c[0]} 0 {c[1]}"><freejoint/><geom type="mesh" mesh="m{i}" density="{rho}" {fr}/></body>'
        top=(outer[i]+outer[i+1])/2
        info.append(dict(c=c,dx=abs(outer[i+1][0]-outer[i][0]) if False else abs(px[i+1]-px[i]),top=top))
    assets+='</asset>'
    act=''
    eq=''
    if base_slide and fric_loss>0:
        if tie: eq=f'<equality><joint joint1="sl0" joint2="sl{N-1}" polycoef="0 1 0 0 0"/></equality>'
    elif base_slide:
        act='<actuator>'+''.join(f'<position name="p{i}" joint="sl{i}" kp="2e7" kv="2e5"/>' for i in (0,N-1))+'</actuator>'
    xml+=assets+wb+'</worldbody>'+eq+act+'</mujoco>'
    return xml,info,dict(px=px,pz=pz,slen=slen,inner=inner,outer=outer)
def apply_load(m,d,info,q):
    for i,inf in enumerate(info):
        bid=mujoco.mj_name2id(m,mujoco.mjtObj.mjOBJ_BODY,f'b{i}')
        F=-q*inf['dx']; 
        d.xfrc_applied[bid,:]=0
        d.xfrc_applied[bid,2]=F
        # torque about y from offset between load point and COM:  r x F, r=(rx,0,rz)-> tau_y = rz*Fx - rx*Fz ; Fx=0
        rx=inf['top'][0]-d.xipos[bid][0]
        d.xfrc_applied[bid,4]=-rx*F
def run(shape='parabola',T=6.0,**kw):
    q=kw.get('q',10e3)
    xml,info,geo=build(shape,**{k:v for k,v in kw.items()})
    m=mujoco.MjModel.from_xml_string(xml); d=mujoco.MjData(m)
    mujoco.mj_forward(m,d)
    return m,d,info,geo

def reaction_on(m,d,bodyname):
    bid=mujoco.mj_name2id(m,mujoco.mjtObj.mjOBJ_BODY,bodyname)
    F=np.zeros(3); fr=np.zeros(6)
    for i in range(d.ncon):
        c=d.contact[i]
        b1=m.geom_bodyid[c.geom1]; b2=m.geom_bodyid[c.geom2]
        if bid not in (b1,b2): continue
        mujoco.mj_contactForce(m,d,i,fr)
        fw=c.frame.reshape(3,3).T@fr[:3]
        F+= fw if bid==b2 else -fw
    return F
def trial(shape='parabola',T=8.0,q=10e3,avg=1.0,**kw):
    N=kw.get('N',21)
    m,d,info,geo=run(shape,q=q,**kw)
    p0=d.xpos.copy(); hist=[]
    nsteps=int(T/m.opt.timestep); acc=np.zeros(3); na=0
    for k in range(nsteps):
        apply_load(m,d,info,q); mujoco.mj_step(m,d)
        if k>=nsteps-int(avg/m.opt.timestep):
            acc+=reaction_on(m,d,'b0'); na+=1
    dis=np.linalg.norm(d.xpos-p0,axis=1)
    mov=range(1,N-1)
    W=sum(m.body_mass[mujoco.mj_name2id(m,mujoco.mjtObj.mjOBJ_BODY,f'b{i}')] for i in mov)*9.80665
    px=geo['px']; Leff=px[N-1]-px[1]
    return dict(stand=bool(dis.max()<0.15), maxdisp=float(dis.max()), crown=float(d.xpos[N//2][2]-p0[N//2][2]), R=acc/na, Wself=W, Leff=Leff, geo=geo, m=m,d=d,info=info)
```

### 試験の呼び出し(要点)
