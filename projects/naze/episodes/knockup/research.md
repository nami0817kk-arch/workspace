## 自分で計算した数字

計算は Python（scratchpad の knock/calc.py）で回した。g = 9.80665、空気は U.S. Standard Atmosphere 1976 の式
（T = 288.15 − 0.0065h、p = 101325 × (T/288.15)^5.2559、ρ = p / (287.05 T)）。

- 実験1（空気なし）: v = √(2gh)。7000m → **370.5 m/s**＝1,334 km/h。新幹線 320km/h の **4.2倍**、音速 340.3 の **1.09倍**。
  頂上まで t = v/g = **37.8秒**。（参考: 1万m なら 443 m/s・45秒）。7000/3776 = 富士山の1.85倍
- 実験2（G）: 0 → 370.5 m/s を距離 d で一定に加速。a = v²/2d、乗っている人が感じる力 = a/g + 1
  - 30m（船の長さほど・仮定）→ **234G**（0.16秒）。体重60kg × 234 = 約14トン
  - 100m → 71G、300m → 24G、1km → **8G**（5.4秒）
  - 46.2G 以下に収める距離 = **155m**（0.8秒）、3G 以下 = **3,500m**（18.9秒）＝スカイツリー634m の5.5本分
  - 押し上げのあとは水ごと放物運動で減速 → 船の中は無重力。37.8秒 ÷ 訓練機の25秒 = **1.5倍**
- 実験3（空気あり・水の玉を1つだけ）: dv/dt = −g − ρ(h) Cd v² / (2 m/A)、球は m/A = (2/3)ρ水 D。
  到達高さが7000m になる打ち出しの速さを二分法で探した（刻み 0.002秒）
  - 直径10cm（体積0.52L＝ペットボトル1本分）: 秒速20,000m でも届かない（Cd 0.5 でも 1.0 でも）
  - 直径1m（約0.52トン）: Cd 0.5 で **1,917 m/s**（音速の5.6倍）、Cd 1.0 で 14,706 m/s → 台本は「少なくとも秒速1,900m」
  - 直径10m: **423〜488 m/s**（空気なしの1.14〜1.32倍）
  - 直径100m: **375〜380 m/s**（1.01〜1.03倍）
  - 地上で秒速370mのときの空気による減速: 10cm 64〜129G、1m 6〜13G、10m 0.6〜1.3G、100m 0.1G
- 実験4（途切れない柱）: Birkhoff 型の式で、先頭の速さ u = v / (1 + √(ρ空気/ρ水))。地上で √(1.225/1000) = 0.035 → 先頭は後ろの水の **96.6%**。
  押しのけに使われる柱の長さ = ∫√(ρ空気(h)/ρ水) dh（0〜7000m）= **206m**（7000m の2.9%）。先頭の到着 **38.5秒**（空気なし 37.8秒、差 0.7秒）
  - 水の量は流れの向きに保たれる（断面積 × 速さ = 一定）ので、遅くなるほど柱は太る。太さ（直径）は √(v₀/v) 倍:
    3500m で1.2倍、6000m で **1.6倍**、6900m で **2.9倍**、6990m で5.1倍（頂上で横に開く）
  - 打ち出しが 400 m/s なら7000m で **151 m/s** 残る（380 m/s なら 84 m/s）
  - 水は空気の 1000/1.225 = **約816倍** 重い
- 実験5（実在）: 必要な打ち出しの速さ √(2gh) と、届く高さ v²/2g
  - オールドフェイスフル 55m → 32.8 m/s（7000m はその127倍の高さ）
  - スチームボート 116m → 47.7 m/s（7000m は **約60倍**）
  - ジェドー 140m（7000m は **50倍**）。噴き出し 200km/h = 55.6 m/s → 空気なしなら157m、実際は140m で89%。必要な速さは 370.5/55.6 = **6.7倍**
  - セントヘレンズ 200〜330 m/s → 空気なしでも **2.0〜5.6km**
  - ピナトゥボ 40km × 1割 = 勢いで昇るのは4km ほど

### 仮定（台本は「仮に」「置きます」と言う）

- 船: 全長30mの木造帆船、全体の重さ200トン（積み荷込み）。実在の復元船は 全長32m で236トン、25m で110トン。30mなら200トン前後に収まる
- 船底を真上から見た面積 A = 150m²（長さ25m × 幅7m × 形の係数0.85）。水に押される力は、船全体の重さ × G（Gは重力の1Gを足した値）が船底の全体にかかるとして、平均の圧力 p = M·g·G / A
- 船底の板: オーク、厚さ8cm、骨組みの間隔40cm、両端支持の等分布荷重（σ = 0.75·p·(s/t)²）
- 梁: オーク25cm角、支点の間隔L=2m、中央に1トンの大砲の荷重（σ = 1.5·P·L/(b·h²)）。曲げ強さまで耐えるとした（安全率は見ない）
- 積み荷の山: 高さ2.5m、平均密度600kg/m³
- 帆柱: 高さ25m・直径0.5m・シトカトウヒ12%（密度約450kg/m³）

### 計算（Python。式と結果）

g = 9.80665、v = √(2g·7000) = 370.5 m/s。加速の距離 d から G = v²/(2g·d) + 1、G から距離 d = v²/(2g·(G−1))。

| 押し上げの距離 | 30m | 100m | 300m | 1km | 3.5km |
|---|---|---|---|---|---|
| G | 234 | 71 | 24 | 8.0 | 3.0 |

[A] 船底（M = 200t、A = 150m²）
- 平均の圧力 p = M·g·G/A: 3Gで0.04MPa、46Gで0.60MPa、71Gで0.92MPa、234Gで **3.06MPa**（1cm²に約31kg。1円玉1枚＝約3.14cm²に約98kg＝大人1人分）。船が水から受ける力は 200t × 234 = 約46,900トン分
- 木目に直角の圧縮（板が押しつぶされる）: 生4.6MPa → 352G、乾7.4MPa → 566G。船底の平均圧力では潰れる前に曲がる
- 船底板の曲げ（厚8cm・間隔40cm、σ = 18.75·p）: 生（曲げ強さ57MPa）→ p ≤ 3.04MPa → **G ≤ 232**（押し上げ30m以上）、乾（105MPa）→ **G ≤ 428**（16m以上）。連続梁なら約1.25倍
- 感度（ここが大きい。板の仮定しだいで桁が変わる）: 厚6cm・間隔60cm → 生58G／乾107G、厚10cm・間隔30cm → 生646G／乾1,190G

[B] 荷物（1トンの大砲が梁1本に乗る。オーク25cm角、中央荷重。σ = 1.5·m·g·G·L/(b·h²) = 曲げ強さ）
- L=1.5m: 生40G（距離178m以上）／乾74G（95m以上）
- **L=2.0m: 生30G（239m以上）／乾56G（128m以上）**
- L=3.0m: 生20G（365m以上）／乾37G（193m以上）
- 砲車の接地0.5m²が甲板板（木目に直角）を潰す: 生235G／乾377G。梁の曲げのほうが先
- 1トンの物が230Gでは、約234トン分の重さ

[C] 積み荷の山（高さ2.5m、密度600kg/m³）: 底の圧力 p = ρ·g·G·h。46Gで0.68MPa、234Gで3.44MPa。甲板板（生・直角4.6MPa）が潰れるのは **313G**。積み荷の山の自重では先に限界にならない（樽やこもそのものの強さは別）

[D] 帆柱: 圧縮の強さだけなら σ/(ρ·g·H) = **351G**で潰れる。ただし横の支え（索）が無い自由な柱として自重で曲がる限界は **19G**（支えのある実物はこれより強い）。実際の限界は索と甲板の止め方しだいで、ここでは数字にしない

[E] どちらが先に限界か
- 人: 46.2G（一瞬）→ 押し上げ **155m以上**。3G（長く）→ **3,500m以上**
- 船: 船底の板 232〜428G（16〜30m以上）。重い荷物を乗せた梁 30〜56G（128〜239m以上）。船全体で見ると、重い荷物の支え（梁・柱）が先に限界になる
- 結論: 一瞬の46Gなら、荷物の梁（約130〜240m）と人（約155m）はほぼ同じ距離で限界になる。船底の板は、仮定どおりなら30mでもぎりぎり持つが、板の仮定しだいで桁が変わる。押し上げが数km（3G）なら、船も荷物も人より先には壊れない。きついのは、長く押される人

## 言い切らないこと

- 白海7000m・白々海1万m は単行本で確かめられていない（二次資料が一致しているだけ）。「作中の設定では」を付け、ユーザーの確認を待つ
- 「空島まで届く／届かない」を一言で言わない。「届く条件はある（秒速370m以上・太く途切れない柱・1km 近い押し上げ）。ただし自然の噴き上げより速い」
- 柱がまとまって昇れるかは、実際には乱れ・ちぎれ（液滴への分裂）で大きく変わる。実験4は「途切れずに続けば」の仮定の計算と言う
- 直径1m の水の玉は、実際には秒速1,900m の前に空気でちぎれる。「少なくとも」とだけ言い、届くとは言わない
- 秒速370m は空気なし。空気ありの値は柱の太さで変わるので、結びは「秒速370m以上」
- 自然界に秒速370m の水の噴き上げは「無い」と言わない。「ここで比べた噴き上げはどれも届かない」
- 船の長さ30m・体重60kg は仮の数字。作中の船の大きさ（ファンwikiだけ）は使わない
- 作中の「約400年前にジャヤの一部が空へ飛ばされた」は話として面白いが、出どころが Wikipedia と作品wiki だけなので使わない
- 作中の仕組みは「ガス」か「蒸気」か資料で食い違うので言わない
- 戦闘機の操縦士の 9G は一次資料が見つからなかったので使わない
- 【船の強度】船の構造は一様ではない。梁の組み方・支柱・肋骨の太さ・金具で、局所の強さは大きく変わる。ここは「全長30m・200トン・オーク」と置いた大まかな目安。船が実際に壊れる加速度を言い切らない
- 木材の強さは小さな無欠点の試験片の値。節・割れ・腐れ・継ぎ目・金具の穴で実物は下がる。生木か乾いた木かでも約2倍違う。安全率は見ていない（「ここで折れる」ではなく「この値で曲げ強さに届く」）
- 船底の板の限界（約230〜430G）は、厚さ8cm・骨組み40cmという仮定の結果。厚6cm・60cmなら60〜110G、厚10cm・30cmなら650G以上。台本は「と置きます」と言い、この桁の幅を書かない代わりに、結論は荷物の梁（30〜56G）を主にする
- 水が船底に均一に当たる前提。実際は水の柱の中の流れ・泡・乱れで、押す力は一様にならない
- 帆柱は、索の無い自由な柱とすれば19Gで自重で曲がる。支えのある実物の値は出せないので台本に出さない
- 作中の船の大きさ・重さ・材質（サニー号など）は出典が弱いので使わない
- 復元船の重さ（236トン）は検索で確認した値。公式ページの原文は開けていない

### 自分で計算した数字
- 7000 ÷ 312 = 22.4 → 「約22倍の高さ」
- 時速375km = 秒速104.2m。要る秒速370m ÷ 104.2 = 3.55 → 「約3.5倍」。時速でも 1332 ÷ 375 = 3.55
- 空気が無いとして312mに届く出だしの速さ: √(2×9.8×312) = 78m/s = 時速281km。報告の375km/hは、これより速い（空気の抵抗や、ノズルから水の柱になる間の損失があるためと考えられるが、原因は未確認。台本では言わない）

### 言い切らないこと
- 「世界最大」とは言わない。「世界一高い」と言う（ギネス世界記録で312m）
- 高さを260mとする資料があること、速さが350〜375km/hと資料で違うことを、概要欄の出典に書く
- ジュネーブの大噴水（140m・時速200km）は台本から外した（世界一ではないため）
