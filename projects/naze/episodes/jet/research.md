# 旅客機は60年、速くなっていない — 下調べ（2026-11-05）

担当（下請け）が一次資料を当たった結果の要点。台本はまだ書いていない。

## 前提は本当か → 本当
- 707（1958年10月26日 パンナムが就航）は経済巡航 M0.80〜0.82、787・A350 は M0.85。差は 3〜6%
- 707 の速度の上限は M0.884（FAA TCDS 4A21。原本は要確認）。「最初のジェット旅客機」コメット1（1952年）は M0.68〜0.74 で一段遅い。**「60年前」は 707 と DC-8 を基準に言う**
- km/h は資料でばらつくので、マッハで比べ、km/h は自分の計算でそろえる: 高度11km（-56.5℃）の音の速さ 295.1m/s＝1,062km/h → M0.85＝903km/h、M0.80＝850km/h、M2.02＝2,146km/h

## 使える数字（出どころ）
- A350-900: 巡航 M0.85・航続 15,750km、ULR は 18,000km（Airbus 公式）
- ロンドン→ニューヨーク 1960年 BOAC の 707 で 7時間40分（当時のニュース映画の原稿）。今の時刻表は未確認
- スーパークリティカル翼: ウィットコム 1965年（NASA TM X-1109）で抵抗の急増が M0.67→M0.79 へ。F-8 の実証 1971〜73年、効率 最大15%（NASA Facts）
- コンコルド: 就航 1976年1月21日〜2003年、M2.02・高度18,288m・100席。燃料 毎時 25,629L（英国航空のファクトシートの抜粋）。2003年の往復運賃 £6,636（スコットランド国立博物館）。米国の陸上超音速の禁止 1973年（38 FR 8051、現 14 CFR 91.817）。2000年7月25日の事故 死者113人
- 燃料の消費: 新造機は 1968〜2014年で約45%減（ICCT 2015。**起点は1968年、新造機の平均**）
- 最長路線: シンガポール〜ニューヨーク 15,349km（二次）
- これから: Boom XB-1 が 2025年1月28日に M1.122／NASA X-59 が 2026年6月5日に初の超音速／米国の大統領令 14304（2025年6月6日）と FAA の規則案（2026年7月2日）。**禁止はまだ有効のはず。「解禁された」と言わない**

## 危ない点
- 「M0.85 が燃料あたりいちばん伸びる」は不正確。いちばん伸びるのは少し遅い速さで、M0.85 は時間との折り合い
- 707 の公称「巡航 600mph」は M0.9 相当で、並べると「昔のほうが速い」になる
- コンコルドの燃料の倍率（747 の 4〜8 倍）・作られた 20 機・787 の M0.85 は一次で固まっていない
