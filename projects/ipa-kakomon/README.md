# ipa-kakomon

情報処理技術者試験の過去問を、1問1ページで公開する静的サイト。**まだ着手段階で、サイトは存在しない。**

IPA は過去問の利用について、出版や Web 掲載を含めて「許諾や使用料は必要ありません」としている
（[試験 FAQ](https://www.ipa.go.jp/shiken/faq.html)）。条件は3つ。

- 出典の明記（年度・期・試験区分・問番号）
- 改変した場合はその旨も明記
- 試験制度の意義に反しないこと

著作権は放棄されていないので、**出典表記を欠かさない**。

## 2026-09-24 に分かったこと

**問題冊子の PDF からはテキストを機械的に抜けない。**

| 対象 | 結果 |
|---|---|
| 解答例 PDF（令和7年度秋期 AP 午前） | **成功**。80問すべて欠番なく取れる |
| 問題冊子 PDF（同上、40ページ） | **失敗**。全ページが画像1枚、文字情報 0 |
| 問題冊子 PDF（令和5年度秋期 AP、44ページ） | **失敗**。総文字数 0 |

問題冊子はスキャン画像を PDF に包んだだけで、文字層を持たない。年度を変えても同じ。

このため **「問題文と正解を公式 PDF からそのまま取る」という当初の前提は、解答側にしか成り立たない**。
問題文を載せるには OCR か人の目を通す必要があり、誤識が混ざると資格試験のサイトとして致命的になる。

判断は保留。取りうる道は企画書に整理してある。

## いま動くもの

`src/answers.py` — 解答例 PDF から午前問題の正解表を取り出す。

```python
from pathlib import Path
from src.answers import extract, missing_numbers

answers = extract(Path("2025r07a_ap_am_ans.pdf"))
print(len(answers))                          # 80
print(missing_numbers(answers, expected=80)) # []
```

同じ問番号で正解が二通り読めた場合は、黙って上書きせず例外にする。
誤った正解を載せたまま公開するほうが、止まるより害が大きいため。

## テスト

```bash
python -m pytest tests -q
```

`pdfplumber` が要る（`extract` を呼ぶときだけ）。テスト自体は外部通信もPDFも使わない。

## PDF の場所

IPA の公開ページから辿る。ファイル名は `[年度][期]_[区分]_[時間帯]_[種別].pdf` の形。

```
https://www.ipa.go.jp/shiken/mondai-kaiotu/2025r07.html
  → /shiken/mondai-kaiotu/nl10bi0000009lh8-att/2025r07a_ap_am_ans.pdf
```

`qs` が問題冊子、`ans` が解答例、`cmnt` が採点講評。`a` が秋期、`h` が春期。

筆記試験は2009年度から2025年度まで公開されている。ただし
**令和2〜4年度の情報セキュリティマネジメント（SG）と基本情報技術者（FE）は非公開**。
