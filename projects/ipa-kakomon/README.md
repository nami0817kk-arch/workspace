# ipa-kakomon

情報処理技術者試験の過去問を、1問1ページで公開する静的サイト。**まだ着手段階で、サイトは存在しない。**

IPA は過去問の利用について、出版や Web 掲載を含めて「許諾や使用料は必要ありません」としている
（[試験 FAQ](https://www.ipa.go.jp/shiken/faq.html)）。条件は3つ。

- 出典の明記（年度・期・試験区分・問番号）
- 改変した場合はその旨も明記
- 試験制度の意義に反しないこと

著作権は放棄されていないので、**出典表記を欠かさない**。

## 問題文が取れる区分・取れない区分（2026-09-25 実測）

**試験の方式で分かれる。** 前日に「問題 PDF からはテキストを抜けない」と書いたが、
見ていたのが筆記試験だけだった。

| 方式 | 区分 | PDF の中身 | テキスト |
|---|---|---|---|
| 筆記 | 応用情報・高度区分など | 紙をスキャンした画像 | **取れない** |
| **CBT** | **SG・FE・IT パスポート** | 最初から電子 | **取れる** |

令和7年度で実測した値。

| ファイル | ページ | 文字数 | 取り出せた問 |
|---|---:|---:|---:|
| 情報セキュリティマネジメント 問題 | 16 | 7,854 | 15問すべて |
| 基本情報 科目A 問題 | 12 | 4,552 | 20問すべて |

**このPJTは CBT 方式の区分だけを扱う。** 応用情報以上は解答だけを扱い、
問題文は公式 PDF へリンクする。

### 取れても、そのまま出してはいけないもの

- **図と表は線で描かれている**（画像ではない）。テキストだけを取ると中身が落ちる。
  問の範囲に線があれば `has_figure` を立てる
- **ルビは本文の上の別行として出る**。捨てないと「…どれか。ぜい」のように末尾に付く。
  捨てるのは**仮名だけでできた小さい行**に限る。`CO₂` の下付きの `2` も小さい行として
  出てくるので、「小さい行は捨てる」とだけ決めると黙って `CO` に化ける（実測）
- 仮名以外の小さい文字は残したうえで `has_small_text` を立てる

どちらかが立った問は `needs_review` になる。**機械の判断で公開しない。**
令和7年度では SG が15問中5問、FE 科目A が20問中5問。

## PDF の取り方

年度ごとのページに PDF が並んでいるが、**置き場のディレクトリ名が年度ごとに変わる**
（`tbl5kb0000005r9r-att` のような文字列）。URL を組み立てて当てにいくと 404 の
HTML が返り、拡張子だけ `.pdf` のファイルが手元に残る。年度ページを読んでリンクを拾う。

```
https://www.ipa.go.jp/shiken/mondai-kaiotu/sg_fe/koukai/index.html
  → .../koukai/2025r07.html
    → .../koukai/tbl5kb0000005r9r-att/2025r07_sg_qs.pdf
```

公開されているのは令和5年度から令和8年度まで。`qs` が問題、`ans` が解答例。

## いま動くもの

`src/answers.py` — 解答例 PDF から正解表を取り出す。

```python
from pathlib import Path
from src.answers import extract, missing_numbers

answers = extract(Path("2025r07a_ap_am_ans.pdf"))
print(len(answers))                          # 80
print(missing_numbers(answers, expected=80)) # []
```

同じ問番号で正解が二通り読めた場合は、黙って上書きせず例外にする。
誤った正解を載せたまま公開するほうが、止まるより害が大きいため。

`src/questions.py` — 問題冊子 PDF（CBT 方式）から問題文と選択肢を取り出す。

```python
from pathlib import Path
from src.questions import extract

qs = extract(Path("2025r07_sg_qs.pdf"))
print(len(qs))                                    # 15
print(qs[0].choices)                              # ('リスク対応の意義は…', …)
print([q.number for q in qs if q.needs_review])   # [9, 12, 13, 14, 15]
```

読み落としを黙って通さないため、次は例外にする。

- 問番号が1からの連番になっていない（欠番のまま公開しない）
- 選択肢がアイウエの4つ揃っていない
- 問が1つも取れない（筆記試験の PDF を渡したときに空を返さない）

## 筆記試験の PDF（解答だけ使う）

ファイル名は `[年度][期]_[区分]_[時間帯]_[種別].pdf` の形。

```
https://www.ipa.go.jp/shiken/mondai-kaiotu/2025r07.html
  → /shiken/mondai-kaiotu/nl10bi0000009lh8-att/2025r07a_ap_am_ans.pdf
```

`qs` が問題冊子、`ans` が解答例、`cmnt` が採点講評。`a` が秋期、`h` が春期。
2009年度から公開されているが、**問題冊子は画像なので `questions.py` では読めない**。

**令和2〜4年度の SG と FE は非公開**。この穴は埋められない。
