## 下請けの報告で分かった注意（2026-09-28 ヤマル）

- Commons の写真は **年ごとのサブカテゴリ**（「Lamine Yamal in 2026」）に入っていることがある。下請けには categorymembers を親と年の両方で引かせる
- File 名は「File:」無しで書いてよい（`portrait --file` がそろえる）。**File 名は一字も変えない**（「7.24.26」のような日付の書き方まで）
- Transfermarkt は WebFetch を拒否する。身長・利き足はクラブ公式と FotMob で代替し、**食い違いは「8. 数字の食い違い」に必ず書かせる**（ヤマルは 175〜180 の4通りだった。使うのはクラブ公式）
- 「史上N番目」の記録は生年月日から**自分で計算**して合わないものは使わない（超WORLDの「18歳323日・史上2位」は計算が合わなかった）
- 女性誌・note・個人ブログだけの話は「未確認」として動画に入れない（弟の年齢・犬相手のドリブル）
