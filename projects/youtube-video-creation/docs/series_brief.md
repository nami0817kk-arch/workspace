作業場所は `projects/youtube-video-creation`（worktree。ここから出ない）。**詳しくは CLAUDE.md。ここは落としやすい所だけ。**
**最初に CLAUDE.md の次の節を読む**：「シリーズの質の決まり」（10/6）／「動画の質を上げる仕組み」の ⑩⑪⑬⑭／「見せる前の決まり」の表（特に 10-10・10-11 の行）。

## 作る（1本ずつ）
1. 取材メモ `research/<日付>_<鍵>.yaml` → `python -m src.cli draft <取材メモ>` → 台本 `scripts/<日付>_<鍵>.md`
2. **見本は直近の同じシリーズの回**（`research/20261011_*.yaml`。ヴィラ＝スタジアム、ハル＝ユニフォーム、バイエルン＝財政、連勝＝記録、マンC＝移籍、マレン＝比べる、ライス＝選手紹介）。形をそろえる

## 事実
- 一次情報か報道まで辿る。**題材の一覧や記事の要約を写さず、病名・数字・固有名詞は原文で引き直す**（10/11 に「心房細動」「ビー玉」で2件誤り）
- **WebFetch が弾かれたら `requests` に普通の User-Agent を付けて試す**（BBC・marca も読めた）。**ブラウザの道具は使わない**
- 試合の分・日程は Opta／ESPN scoreboard で確かめる。**思い込みで「リーグは止まっている」と書かない**
- **クラブ紹介で読んだことを、同じクラブのスタジアム・ユニフォームの回で言い直さない**
- 代理店（Getty・AFLO・AFP・ロイター・IMAGO・AP・PA・EPA・共同）の写真は取り込まない。**Yahoo! 経由の記事は警告が出ない**ので元記事を開く。放送映像は使わない
- 女子・Jリーグは扱わない

## 作り
- **冒頭は強い一点**から。基礎DATAの読み上げは5行まで。見立てに**自分で数えた比べ**（数字2つ＋比べの言葉）
- **尺は `preview4` の見積りで4分以上**（`check` の想定尺は24%長い）。**薄めるくらいなら足さない**。足りなければ材料が無いと報告
- 新しい板を使う（timeline・stats・waterfall・line・calc・convert・scatter・verdict・versus）。
  `focus` / `highlight` は**0から数える**（字で指すのが安全）。**板を下ろす行は `card: none` を明示**。`versus` を1節に20秒以上出さない
- **板と顔は共存できない**（本編の板は左74%）。顔が左にある写真は避けるか、強い行だけ `card: none`
- 写真は縦版（`_v`）を隣に置く。ショートは高さ1200px以上。切るときは `tools/facecrop.py`、**切った絵は開いて見る**
- **サムネは決めない**。取材メモに点検用に1つ書き、**報告に案を3つ**。**1行目で何の話かを言い切り、答えだけ伏せる。1行目は14字まで。同じ伏せ字を2回出さない**。集中線は付けない
- 出典は画面に出さない

## 点検（全部通してから報告）
1. `python tools/precheck.py <台本> --no-preview` → ×は「ネットの反応が1件もありません」だけ
2. `python tools/typecheck.py --note <取材メモ>` → × 0
3. `python tools/preview4.py <台本>` → **`preview4.png` を自分で開いて見る**（`approve` / `build` / `short` / `screen` / `upload` は打たない。コミットしない）
4. `python tools/flow.py --prompt` の問いを**自分で読んで自分で答え**、`output/flow/<鍵>.md` に控え（1行目「読み手: Claude」）。**`tools/flow.py` と `tools/preshow.py` に台本を渡さない**（Gemini は課金）
