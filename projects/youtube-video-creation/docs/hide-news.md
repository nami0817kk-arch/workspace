# ニュース動画の引っ込め方（収益化の審査対策）

2026-10-07 にユーザーと決めた方針。**この作業を引き継ぐセッションは、ここを正とする。**
道具は `tools/hide_news.py`（PR #613・#617）。

## なぜやるか

収益化（YPP）の審査は、**再生の多い動画・最新の動画・視聴時間の大半を占める動画**を重く見る
（support.google.com/youtube/answer/1311392）。対象外の型として、ニュースなど
「自分で作っていない資料を読み上げただけ」「SNS のコンテンツを集めたもの」が明記されている。

10/7 の点検で、再生上位の本編10本のうち5本が 9/28 以前の「反応の読み上げ」型
（他人の声58〜77%・見立て0）、いちばん見られている本編（久保の結婚）は中身がほぼインスタ投稿の紹介だった。
**新しい動画をいくら良くしても、上位に残るこれらで落ちる。**だから引っ込める。

- ニュース動画は**宣伝（登録者を集める）のために作り続ける**。本数は減らさない（9/10 の決定のまま）
- 非公開・限定公開・削除した動画の視聴時間は、条件の4,000時間に**数えられない**（answer/72851）。
  引っ込めた分の時間は消える。登録者は減らない

## 仕分け（`content_class`）

書き出した台本 `output/<名前>/script.json` の読み上げ文字数で決める。
話者がネット民・現地サポ・海外のファンなら「反応」、キャスター・解説以外の名前なら「発言の引用」、
`viewpoint` の節の語りが「見立て」。

| 区分 | 条件 | 10/7 時点（本編） | 扱い |
|---|---|---|---|
| シリーズ | front matter に `series:`（クラブ紹介・クラブ比較など） | 61本・162時間 | **残す** |
| 危ない（ng） | 他人の声（引用＋反応）が5割超 | 90本・559時間 | **いま引っ込める（決定）** |
| 際どい（border） | 他人の声5割以下だが、見立てが無いか反応2割超 | 174本・770時間 | **未決**（下の「決まっていないこと」） |
| 大丈夫（safe） | 他人の声5割以下・見立てあり・反応2割以下 | 41本・224時間 | **残す方向（推し、未確定）** |

ショートは元の本編と同じ区分に従う。`format:` では分けない（シリーズの回も `format: news` のため）。

## いまやること：「危ない」を毎日30本ずつ非公開にする

ユーザーの指示「危ないは消していく」「まとめて消すと API の残がなくなるので、徐々に減らしたい」。

```bash
# cwd は YouTube の運用ツリー（token と quota 台帳がここにある）
cd C:/Users/なみ/dev/wt-yt-0906/projects/youtube-video-creation
python tools/hide_news.py --level ng --hours            # 並べるだけ。まず見る
python tools/hide_news.py --level ng --limit 30 --apply  # 1日1回
```

- **1日30本まで**（`--limit 30`）。`videos.update` は1本50。全部で本編90＋ショート84＝約8,700、**約6日**で終わる
- **投稿の枠を残す。**quota 台帳の残りが `--reserve`（既定3,000）を切りそうなら途中でも止まる。
  投稿・サムネ・最初のコメントが先。**その日の投稿が終わってから**回す
- **本編から先**に引っ込める（審査が見るのも、時間に数えるのも本編）
- **削除はしない。非公開にするだけ。**変える前の状態を控え（`research/hidden.json`）に残す。
  戻すときは `--restore`
- 予約中の動画は予約を外して非公開にする（予約が残ると勝手に公開される）
- **控えを失くさない。**hidden.json が無いと `--restore` で戻せない。運用ツリーで回し、区切りでコミットする
- 新しいニュースが「危ない」になっていれば、翌日以降の実行で自然に拾われる

### 毎回の確かめ

1. 実行前に `--hours` で対象の本数を見る（前日より減っているか）
2. 実行後、出力の「非公開にした: N 本」と `python -m src.cli quota` の残りを見る
3. **quotaExceeded が出たらその日は止める**（再試行しない。太平洋時間の0時＝日本時間16時まで戻らない）
4. ユーザーへは1行で報告：「危ない○本を非公開（残り○本）／枠の残り○」

## やらないこと

- **削除しない。**戻せなくなる
- **シリーズに触らない**（`series:` のある回は道具が自動で外す）
- 題名・概要欄・サムネは変えない（非公開にするだけ）
- 1日に30本を超えて回さない。**枠を投稿より先に使い切らない**
- 「際どい」「大丈夫」を、ユーザーの決定なしに引っ込めない（`--level all` は審査の直前まで使わない）

## 決まっていないこと（ユーザーが決める。勝手に決めない）

1. **「際どい」174本をどうするか。**9/28 以前の、見立ての無い事実読み上げが中心。
   推しは「審査の申請前に引っ込める」。**久保の結婚（619時間）は「際どい」に入るが、
   中身はインスタ投稿の紹介（キャスターが読む代表仲間のコメント24%が語りに数えられている）なので、
   推しは「危ない」と同じく早めに引っ込める**
2. **「大丈夫」41本を審査まで残すか。**推しは残す（残る視聴時間がシリーズと合わせて約390時間になる。
   全部消すと約160時間）。残すなら、申請の直前は `--level all` ではなく
   「シリーズと safe 以外」を引っ込める形にする（道具に `--level border` 相当を足す必要がある）
3. **審査の申請の時期。**登録1,000人・本編4,000時間（引っ込めたあとの数え方で）に届いてから
