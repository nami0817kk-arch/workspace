# ショートに本編を紐づけると、本編は見られるようになるか（2026-09-12 開始）

**関連動画（Related Video）の紐付けは API に無い。**`videos` リソースの
書き込みできる項目に `relatedVideoId` にあたるものは存在しないため、
**Studio で1本ずつ手作業**になる。1日13本ぶんを毎日やるかどうかは、
効き目を測ってから決める。

## 何を確かめるか

**ショートから本編へ人が流れるか。**いまの本編は中央値5回で、
36時間たった66本のうち46本が10回未満。関連動画からの流入は
直近14日で**9回（0.1%）**しかない。

## やり方（Studio。上級機能が要る＝2026-09-08 に承認済み）

1. YouTube Studio にログイン
2. 左のメニューから「コンテンツ」
3. 紐づけたいショートを選ぶ
4. 「関連動画」で、同じ題材の本編を選ぶ
5. 保存

見る人には、**チャンネル名の下にリンクとして出る**。
選べる本編は公開か限定公開であること。

## いつ、何を見るか

**2026-09-19 に `tools/metrics/road.py` で測り直す。**
比べるのは**本編の再生数**。両方とも0〜6回から始まっている。

- 紐づけた側だけ伸びていれば、全部に広げる価値がある
- 差が出なければ、**毎日13本の手作業は割に合わない**ので広げない

**1週間では結論が出ないかもしれない。**ショートの再生は遅れて伸びる
（中村敬斗の回は5 → 425 → 710 と伸びた）。差が小さければ2週目まで見る。
