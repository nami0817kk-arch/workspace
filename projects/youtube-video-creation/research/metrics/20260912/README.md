# 2026-09-12 の実測（比べるための基準）

稼働8日目（9/5〜9/12）。**次に測ったとき、ここと比べる。**

## 何が入っているか

| ファイル | 中身 | 取り方 |
|---|---|---|
| `videos.json` | 公開中174本の1本ずつ（再生・高評価・維持率・平均視聴秒・登録・公開時刻・尺） | `videos.list` ＋ Analytics |
| `raw_videos.json` | 上の元になった `videos.list` の返り（加工前） | Data API 12ユニット |
| `daily.json` | 日ごとの再生・視聴分・登録の増減（9/5〜9/9） | Analytics（枠は別） |

再生数は **`videos.list` で1本ずつ**取る。`channels.list` の合計は本数が多いと遅れるので使わない。
Analytics は**集計が2〜3日遅れる**ので、視聴時間は9/9まで。

## 測り直すとき

```bash
python tools/metrics/road.py     research/metrics/<日付>/raw_videos.json   # 1本ずつの再生（12ユニット）
python tools/metrics/daily.py    research/metrics/<日付>/daily.json        # 日ごと（Analytics）
python tools/metrics/pervideo.py research/metrics/<日付>/pervideo.json     # 動画ごとの維持率（Analytics）
python tools/metrics/split.py                                             # ショートと本編を分ける
```

Data API の枠を食うのは `road.py` だけ（**12ユニット / 1日10,000**）。他は Analytics の別勘定。
