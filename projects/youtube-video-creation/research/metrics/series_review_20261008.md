**測れなかったもの（正直に）**

1. **Analytics の `dimensions=video` は、絞り込み無しでは200本で打ち切られる。**`startIndex=201` は 400「The query is not supported」で返る。
   既存の `tools/metrics/pervideo.py`・`watchtime.py` はこの打ち切りに当たっていて、今回も **192本**しか返らなかった（`python -m src.cli insights --hold --days 40` の「維持率が読めた192本 / 動画627本」も同じ理由。**「再生が少なすぎる」からではない**）。

2. それでも**本編293本のうち23本は測れない**（10/7〜10/8 公開でデータが来ていない、または再生0）。
   そのため **若手の数字・数字で見るランキング・記録 の3シリーズ（各1本）は数字が1つも無い**。
3. **1本しか公開していないシリーズが10個**ある。中央値も合計も、その1本の当たり外れそのもの。**言い切れない。**
4. 表示回数・クリック率は Analytics では取れない（10/5 の点検のとおり）。ここには入っていない。

## 6. 整理の案（○×を付けてください）

**こちらの推しは 1 → 3 → 2 の順。1 だけでも効きます。**

### 案A（**いちばんの推し**）── 道具のあるシリーズを先に埋め、題材探しが要るシリーズを畳む

数字の根拠：いちばん軽い3シリーズ（週報67行・順位表316行・次の相手174行）が**投稿0**で、いちばん重い型（道具なし、500〜900行）を毎日作っている。月・火・水の枠が空いたのはそのため。

| | 中身 | ○× |
|---|---|---|
| A-1 | **ラ・リーガ ⑩〜⑳の11本を、1日1本で 10/19 までに出し切る**（台本は全部出来ている。遅れ1本を取り戻す） | |
| A-2 | **週報（月）・順位表（火）を今週から必ず出す。**台本は 09-28／09-29 に出来ている。道具（`japan_abroad.py week`・`standings_week.py`）も通っている | |
| A-3 | **日本人の次の相手（10/09）・欧州カップの相手紹介（10/12）を予定どおり出す。**`next_opponent.py` で雛形まで出る | |
| A-4 | **「記録」を「記録の解説」に統合する**（名前の揺れ。再生リストが2つに割れている） | |
| A-5 | **道具が無く題材も毎回探す4つを、10月は休む**：スタジアム紹介・若手の数字・序列の理由・同じ年齢での比較（どれも1本ずつ、1本では実績が言えない） | |
