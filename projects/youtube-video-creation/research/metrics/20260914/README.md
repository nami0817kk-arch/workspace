## 測り直すとき

```bash
python tools/metrics/road.py      research/metrics/<日付>/raw_videos.json  # 1本ずつの再生（12ユニット）
python tools/metrics/daily.py     research/metrics/<日付>/daily.json       # 日ごと（Analytics）
python tools/metrics/watchtime.py research/metrics/<日付>/watch.json       # 総再生時間（Analytics）
python tools/metrics/pervideo.py  research/metrics/<日付>/pervideo.json    # 動画ごとの維持率（Analytics）
```

`watchtime.py` は**本編とショートに割って出す**。合計だけでは意味が無い
（ショートの視聴時間は4,000時間に数えられない）。割り方は尺（60秒以下がショート）で、
`raw_videos.json` の印を借りる。
