調査日: 2026-10-11。使ったのは **WebFetch / WebSearch と python の requests だけ**（ブラウザの道具は不使用）。
本編とショートの2本。**病気の話なので、病名と経過はクラブの発表文の言葉をそのまま使う。**煽らない。

## 0. 病名は「心房細動」ではない（題材の一覧の書き方と食い違う）

題材の一覧には「**良性の心房細動**」と書いたが、**一次情報にその語は無い。**

| どこ | 原文 | 訳 |
|---|---|---|
| ナポリ公式（伊、2026-09-01） | 「In seguito all'insorgenza di una **lieve aritmia benigna**」 | 軽度の良性の**不整脈**が起きたことを受け |
| 同じ発表の英語の形（theScore が引用） | 「Due to the onset of a **mild benign arrhythmia**」 | 同上 |
| football-italia（2026-10-10） | 「a **benign cardiac arrhythmia**」「a mild, benign arrhythmia」 | 良性の心臓の不整脈 |

- **心房細動（fibrillazione atriale / atrial fibrillation）という語は、ナポリの発表にも報道にも出てこない。**
  不整脈は心房細動を含む広い言い方なので、**狭い病名に置き換えると一次情報より強いことを言うことになる。**
- → 台本では「**軽度の良性の不整脈**」で通す。**「心房細動」とは言わない。**
- 処置の名前は「**アブレーション（PFA）**」。英語の形では「PFA（pulsed field ablation）」。
  ナポリは「intervento di correzione mediante ablazione」＝**アブレーションによる矯正の処置**と書いている。
  英語版の発表は「the operation was a complete success」なので、「手術」と訳せる場面もある。

## 5. 自分で数えた数字（台本の見立てで使う）

| 数えたもの | 値 | 計算 |
|---|---|---|
| 処置から出場まで | **32日** | 9月8日 → 10月10日（9月の残り22日＋10月10日） |
| 最後の出場から | **41日** | 8月30日 → 10月10日 |
| クラブが書いた休養 | **約2週間＝14日** | 9月8日の発表文 |
| 休養のあとに使った日数 | **18日** | 32 − 14。個別調整と検査にあてた期間 |
| 出場してからシュートまで | **13分** | 61分 → 74分 |
| 出場した時間 | 61分から試合終了（90分＋5分）まで | 約34分 |

- **「2週間の完全休養」は32日のうちの半分に満たない。**残りの18日のほうが長い。
  これが「段階的に戻した」ということの中身で、**この回の見立ての軸にする**

## 7. 使わないと決めたもの

- **「心房細動」**（一次情報に無い。0 を見よ）
- **煽る言い方**（「衝撃」「まさか」「奇跡」「異例の早さ」）。**早いかどうかを比べる材料を持っていない**ので、
  「4週間での復帰は異例」とは書かない。日付と週数だけを並べる
- **セリエAの順位・勝ち点**（今日のシリーズでマレン＝ローマとラウタロ＝インテルを出すため、深入りしない）
- **デ・ブライネの2得点の中身**（題に答えない）。表の1行には残すが、語りでは掘らない
- 9月2日の「気分はいい」（直接の引用が取れていない）
- 前日（10月9日）の会見の「McTominay will be in the squad」（題の出来事より前の発言）
- ホイルンドのハートの絵文字（本人の言葉ではない）
- **ネットの反応は集めていない**（この題材は反応なしで出す）
