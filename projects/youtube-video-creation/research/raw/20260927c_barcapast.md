## 2. 数え直しのやり方

- 名簿：PJ の `research/ll_data/<key>_raw.json` の `squad`（2026-09-27 01:5x に英語版 Wikipedia の各クラブ記事の「現在の選手」表から取ったもの。今そのクラブにレンタルで来ている選手を含み、よそに出している選手は含まない）。バルサを除く19クラブ・478人。**raw.json は読んだだけで書き換えていない。**
- 各選手の英語版 Wikipedia 記事（2026-09-27 に API で取得）の infobox の `youthclubs1..` / `clubs1..` に FC Barcelona / FC Barcelona (youth) / FC Barcelona B / FC Barcelona Atlètic（バルサC を含む）へのリンクがあるものを「バルサにいた」とした。バルセロナSC（エクアドル）・エスパニョール等は除外。本文に「La Masia」「joined FC Barcelona」などがあって infobox に無い選手も探したが、0人だった。
- 記事が無くて見られなかった選手：**イセイ・エルナンデス（アラベス, Izei Hernández Cañas）**、**マウロ・エチェゴイェン（オサスナ, Mauro Echegoyen Berrozpe）**。英語版に記事が無い（どちらも所属クラブの下部組織出身とみられるが、確かめていない）。
- 追加で、各クラブ記事の「Reserve team」「Out on loan」「Returning from loan」欄の選手（152人）も同じ方法で調べた（下の 3-3）。
- スクリプト：`research/raw/20260927c_barcapast_scripts/`（fetch.py → parse.py、extra.py）。
