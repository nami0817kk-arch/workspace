# ai-side-business

AI で成果物を自動生成して納品する副業の、実行エンジン＋経営管理ツール。
設計の全体像は `docs/design.md` にある（長いが、式や判断の理由はすべてそこ）。

## 前提

- Python 3.12。依存は `requirements.txt` に `==` で固定。
- **anthropic は任意依存**。キーやライブラリが無くても LLM 機能以外は動く。
  この判定は `src/llm.py` の `available()` がやる。壊さない。
- データは `data/` の JSON（`src/store.py` 経由）。壊れた JSON は退避して初期値に戻し、
  ツール自体は落とさない設計。
- ダッシュボードは手元で開くだけの静的 HTML（`src/screen.py`）。サーバは立てない。

## よく使うコマンド

```bash
pytest              # テスト（ネットワーク不要、226本）
python main.py      # メニュー
python main.py auto # 未処理案件をまとめて生成・検品・納品ファイル出力
```

Windows タスクスケジューラに `run-auto.ps1` を登録すると auto が定期実行される。

## 手を入れるときに気をつけること

- 原価計算は定額制と従量課金で分岐する（2026-08-29 の修正）。単価まわりを触るときは
  `tests/test_core.py` の両ケースを先に見る。
- 収益ゼロ期のダッシュボード表示は意図的（phase = "investment"）。ゼロ埋めで消さない。
- テストで日付を扱うときは固定の年月を書かない。**月が変わると落ちる**
  （2026-09-01 に test_screen.py で実際に起きた）。実行日から計算する。
