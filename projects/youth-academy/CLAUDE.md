構想・決定1〜80は記憶 `youth-academy-game`（C:\Users\なみ\.claude\projects\...\memory\）とまとめのページが正。
**入っているのは、試合（ビルド1〜2）・育成（ビルド3）・クラブ運営まわり（ビルド4: リーグと大会・信頼度と予算とスタッフ・目標と評価・契約と解任・スカウトとセレクション・卒業生の追跡・キャプテン・ポジション変更・関係・代表とトップ・合宿・規律・分析と映像）**。広告と課金だけ未着手（ユーザー指示: 課金と広告以外は全部作る）。

## 決まり

- **ポジションは15個**（決定81）：GK・CB・左右SB・左右WB・DM・CM・左右MF・AM・左右WG・SS・ST。布陣ボードに置いた場所から名前が決まる（`YA.pos15OfPoint`）。選手は15個すべての適性（1〜20）と登録ポジション・隠れた最適・利き足を持つ。
  試合の場面の選び方は4つの括り（GK・DF・MF・FW）のまま動き、細かい違いは役割（`YA.ROLE_DEF`：tags/boost/deny）と適性・逆足のペナルティ（`YA.slotPenalty`）で効かせる。
- **役割＋任務**（FM型。決定81の追記）：役割44個（`YA.ROLE_DEF` の表。1行足して `YA.ROLES15` に名前を足せば増える：効く能力の重み・合う特性・場面の主役のタグ・出やすい場面・相手の場面を減らす効き）に、任務5つ（`YA.DUTY`：守備・サポート・攻撃・ストッパー・カバー。上がる深さ・場面の出やすさ・戻り・疲れ方の倍率）。スロットは `role` と `duty` を持ち、`YA.fixSlotRole` が使えるものに直す。

- 試合の中身は見せ方と切り離す（決定3・79）。座標は m、攻める側が +y。`scene.frames` が絵の素。
- 試合は「見どころだけ動く」（決定79）。10〜15の場面だけ動かし、残りは実況1行。型は engine.js の `_through` など10種。
- 特性や性格が場面に効いたら `scene.fx` に記録し、画面の札に出す（守る側は守備が成功したときだけ）。
- 創作の物語を避ける決まり（no-creative-story-content）は動画の決まりで、ゲームの台詞・出来事には当てはめない（ユーザー指示）。
- 広告・課金は試作に入れていない。入れるときは docs/app-pitfalls.md を先に読む。
- 画面を直したら、ブラウザで絵にして目で確かめる（`node web/tool/build.js web/dist/index.html` → `python -m http.server` → 844×390）。
- リリース: `youth-academy-ios-release.yml`（workflow_dispatch、`upload_to_testflight=true`）。Secret は `YOUTH_ACADEMY_IOS_PROVISIONING_PROFILE_BASE64` のみ新規。
  Bundle ID `com.namiki.youthacademy`、App Store Connect の Apple ID 6828073461。ビルド番号は `app/pubspec.yaml` の `+N`。

## 遊びの流れの足場（テスト用の道具）

- 点検用シミュレーション：設定の「点検用」で、シード・年数（1/3/10）・クラブの部を選んで新しい世界を回す（いまの遊びには影響しない）。結果は年ごとの表（順位・評価・信頼度・予算・成長・怪我・退団・プロ入り・お知らせの段別・選ぶ回数・想定分/週）。`YA.runTest({seed,years,tier})`。
- 画面の点検（tool/views.js）の txt() は画面（#app）の文字だけを見る。ページに埋め込んだスクリプトの文字を拾うと何でも通ってしまう。
- 1年をおまかせで進める：ホームの「おまかせ進行」→「1年」。`node` からは `YA.simulate(w, { until: 'year', stopOnImportant: false })`。報告（`YA.simReport`）が返る。
- 新しく始める（保存がないとき）：指導者の名前・経歴・クラブ・解任の有無を選ぶ。`YA.newWorld(seed, YA.makeStart({...}))`。
- 段2（ビルド9）：伸び盛り・壁（`p.state`）・能力の低下・進路の相談（`career` 出来事。`more.js`）・練習試合の練習メニュー・退団の4理由（怪我・能力・家庭・不満）・お知らせの3段（`YA.noticeKind`、設定で項目ごとに段を変える。「必ず止める」はおまかせ進行でも止まる）・実績と引退（`YA.achievements/retire/careerSummary`）・文字の大きさ3段・選手の名前の書き換え。Bの先発GKが抜けて控えにもいないときは `autoTeamsKeep` がGKを新しく入団させる。
- 段3（ビルド10）：60クラブ（`YA.CLUB60`：各部20の固定の相手。名前・作風・監督・強さの癖は固定、毎年11を選ぶ）・クラブ名と相手名の書き換え（`YA.renameClub/renameTeam`、相手は `w.rename` に残る）・練習メニューの型3つ（`YA.saveMenuSlot/loadMenuSlot`）。
- 段4・5（ビルド11）：Bチームの指揮（`YA.setBCtl`：布陣・戦い方・起用方針。Aの並びは触らない。結果は `w.resultsB`）・中3の練習参加（25週=11月に内部昇格の候補が出て、26週に申し送り）・U-21代表（`a.u21`）・ライバル監督（`YA.rivalOf/rivalFight/rivalWeek`：取り合い・直接対決の予告・卒業生の再会）・出来事「保護者の相談」「同じ位置のライバル意識」。
- 保存の形は v3。セーブ枠は `world`（枠1）・`world1`（枠2）、年度はじめの控えは `<枠>_bak`。
- 入団の暦（ビルド18）：初年度の始めに選ぶことはしない。内部昇格は11月（25〜27週・候補12人から8人まで）、スカウトは4〜11月に月3回まで行き先を選んで出る（`YA.scoutOut`・`YA.DESTS`。栄冠ナインのスカウトに似せた。声かけ3人まで、返事は12月=28週）、セレクションは1月（31〜34週・3人まで）で合否が決まる。合わせて12人まで、足りない分は一般入団。期間の判定は `YA.scoutWindow`、月の残り回数は `YA.scoutActsLeft`。おまかせ進行は `YA.autoScout` が暦どおりに決める。
