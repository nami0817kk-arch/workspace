# つるはし採掘（tsuruhashi・仮題）

つるはしで地面を掘り進める放置ゲーム。本番は **iOS アプリ**（無料＋報酬型動画広告＋「広告を消す」買い切り）。
2026-09-28 に別セッションで企画・試作（v1）し、2026-10-03 にユーザーが改善案と構成案に同意して作り始めた。

**作り**: hikari7 と同じく、アプリの外側（広告・課金・保存・通知）は Flutter、ゲーム本体は `prototype/game.html` を
WebView で動かす予定（外側はまだ作っていない）。**ゲームの直しは game.html だけ**。

## 置き場所

| 場所 | 中身 |
|---|---|
| `prototype/game.html` | ゲーム本体（v2）。`/*ENGINE-START*/`〜`/*ENGINE-END*/` が画面を持たないエンジンで、tool/ もここだけを読む |
| `prototype/v1.html` | 2026-09-28 の試作そのまま（6層・図鑑20種・周回なし）。比べるために残す |
| `tool/sim.js` | 自動で遊ばせて進み方を測る。`--quick` は CI 用。`PLAY=heavy`・`PLAY=noads`・`CREED=aaaaaa`・`DAYS=60`・`SEED=3`・`LOG=1` |
| `tool/check.js` | エンジンの決まりごとの検査（留守の上限・代替わりで残す物・鑑定で必ずそろう・★★の出る場所など）。CI で毎回回る |

## 中身（v2、2026-10-03）

- **層**: 10層×40m（表土〜星の核）。層の境の岩盤は つるはし Lv 18/38/58/78/98/120/142/164/186。400m より下は星の核が続く
- **数値**: 固さ 30×1.078^深さ（岩盤は12倍）、鉱石 1.5×1.072^深さ（岩盤は5倍）、強化 12×1.15^(Lv-1)、雇用 ×1.15ずつ、
  つるはしの力 Lv×2^(Lv÷10の切り捨て)、会心8%で5倍、物が出る確率12%。つるはしの色は10Lvごと（20段）
- **仲間**: 7種（見習い坑夫〜掘進シールド）。一つ前を雇うまで次は伏せる
- **図鑑**: 50種（1層に普通2・★2・★★1）。1種ごとに鉱石+5%。代替わりしても残る
  - 同じ物は、その層の**かけら**になる。かけらは「売る（鉱石）」か「鑑定（10個で未発見を1つ。残りが★★だけなら25個）」——どちらに使うかが選択
  - **宝の部屋**: 各層の真ん中（20m目）。初めて開けたときは未発見の物（★★以外）、2回目からはかけら3つ
  - **★★は層の終わり8m でだけ出る**。その層の★を2つそろえると、手がかりとして場所が出る
  - **層の組**: 1層の5種がそろうと、層ごとの効果（`SETS`）
- **代替わり**（周回）: 240m（6層の底）から。名声 = 5×1.03^(この代の最深−240)。力は ×(1+0.1×名声)（タップと仲間だけ。鉱石には掛けない——掛けると雪だるまになった）
- **社訓**: 代替わりのたびに1組ずつ増える（全6組）。組ごとに2つから1つ。どれも良い点と代償を持つ（`CREEDS`）。選び直しは次の代替わりのとき
- **鉱脈**: 開いている間だけ、90〜150秒おきに8秒光る。たたくと今の採掘45秒ぶん
- **留守**: 最大8時間（社訓・層の組で増減）。起動時と裏から戻ったときに計算する。時計が戻っていたら0
- **実績** 30個・**社史**（代ごとの記録）

## 進み方の目安（tool/sim.js、1日5回×5分、広告を見る人）

| 時期 | 目安 |
|---|---|
| 1日目 | 4層の底（160m）を越える |
| 2日目 | 6層の底で1回目の代替わり |
| 1週目 | 8層（320m） |
| 3週目 | 10層の底（400m）に近づく |
| 4週目 | 図鑑50種がそろう、13代目前後 |

広告を見ない人は1.3倍ほど遅い（10層の底は28日目）。社訓の選び方で10層の底は19〜34日目まで開く。
数字を動かしたら `node tool/sim.js` と `PLAY=noads`・`CREED=aaaaaa` も回して、この表から外れていないか見る。
v1 は同じ遊び方で1日目に6層を越え、3日目で止まっていた（中身がほぼ1日分）。

## 広告と課金（決まっていること）

- 報酬型動画だけ: 「採掘2倍を5分」（重ねて最大30分）と「留守の分を2倍で受け取る」。**全画面広告・バナーは入れない**（2026-10-03）
- 「広告を消す」（買い切り・非消費型）を買った人は、**動画を見ずに2倍の効果を受け取れる**（2026-10-03、護送ボートのヒントと同じ考え）
- 受け取りは画面の状態を見ない（`tsuruAdResult`。docs/app-pitfalls.md 2番）。留守の2倍は、動画の間に画面が変わっても失わない
- アプリとのつなぎは hikari7 と同じ形: `window.__TSURU_APP`（store・adFree・price・credits）、`TsuruApp.postMessage`
  （store・reward・buy・restore・haptic・theme）、アプリから呼ぶ `tsuruAdResult`・`tsuruSetApp`・`tsuruPause`・`tsuruResume`
- 保存は `TStore`（アプリでは WebView の localStorage を使わずアプリ側へ）。12回に1回、予備（`tsuruhashi_v2_bak`）にも書く
- 通知（「8時間たまりました」）は外側を作るときに入れる。許可は初めて留守から戻ったときに聞く

公開前に3か月分を作っておき、月1回出す。v1.1 は11〜12層・図鑑+10・仲間+1、v1.2 は「つるはし社への依頼書」、

## 決まっていること（ユーザー決定）

- iOS のみ。無料＋広告（報酬型動画中心）＋「広告を消す」買い切り。月額・ガチャなし
- 公開名義は「つるはし社」。本名・nami・0817 は公開文面に出さない（tool/check.js が game.html を見ている）
- 挑戦や遊ぶ回数を減らすものは入れない（護送ボートでのユーザー指示）
- 選択には代償か裏目の可能性を持たせる（社訓・かけらの使い道）
- 絵が要るときはユーザーが Gemini アプリ（無料）で作って渡す。既存作品名をプロンプトに入れない。課金の可能性があるものは必ずユーザーに聞く
- 名前は仮題「つるはし採掘」のまま進める（2026-10-03）
