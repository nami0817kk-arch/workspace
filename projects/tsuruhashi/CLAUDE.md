# つるはし採掘（tsuruhashi・仮題）

つるはしで地面を掘り進める放置ゲーム。本番は **iOS アプリ**（無料＋報酬型動画広告＋課金アイテム）。
2026-09-28 に別セッションで企画・試作（v1）し、2026-10-03 にユーザーが改善案と構成案に同意して作り始めた。

**作り**: hikari7 と同じく、アプリの外側（広告・課金・保存・通知）は Flutter（`app/`）、ゲーム本体は `prototype/game.html` を
WebView で動かす。**ゲームの直しは game.html だけ**（`python tool/build_app_web.py` でアプリ用に組み立てる）。

## 中身（v2、2026-10-03）

- **層**: 10層×40m（表土〜星の核）。層の境の岩盤は つるはし Lv 18/38/58/78/98/120/142/164/186。400m より下は星の核が続く
- **プレイヤーはたたかない**（2026-10-03 ユーザー指示「クリックは不要」）。掘るのは仲間だけで、最初から見習い坑夫が2人いる（代替わりの後も）。
  プレイヤーがするのは強化・雇用・図鑑・代替わり・社訓の判断と、開いている間の鉱脈。社長は見た目として振るだけ（岩盤では「カキン！」）
- **数値**: 固さ 10×1.094^深さ、鉱石 1.5×1.072^深さ（岩盤は5倍）、強化 12×1.15^(Lv-1)、雇用 ×1.15ずつ。
  仲間の力 = 各仲間の力の合計×2×つるはしの倍率。**つるはしの倍率** = (1+0.02×(Lv−1))×1.15^(Lv÷10の切り捨て)。
  掛け算なので強くしすぎると雪だるまになる（1Lv+10%・10Lvごと2倍にしたら1日目に1400m 掘れた）
- **岩盤は Lv が届けばすぐ割れる**（2026-10-03 ユーザー指摘「掘れなくなる時がある」）: もとは固さ12倍で、Lv が届いた後も
  200m では21分削り続けて止まって見えた。今は固さが普通のブロックと同じで、待ちは Lv の関門だけ（企画の山場「カキン！の後に一気に割れる」）。
  Lv 待ちの間は目標の帯に「あと n Lv・約何分／今すぐ強くできる」を出す。社訓「突貫」は「岩盤に必要な Lv −15%」（`reqMul`）。
  毎コマの処理は try で包み、どこかでエラーが出ても採掘と描画は止めない（`frame` → `frame0`）
- **大当たり**: ブロックを割ったとき8%で鉱石5倍（もとはタップの会心）。物が出る確率12%。つるはしの色は10Lvごと（20段）
- **仲間**: 7種（見習い坑夫〜掘進シールド）。0〜2 が人の坑夫、3 から先が機械（社訓「人を育てる」「機械化」で効く）。一つ前を雇うまで次は伏せる
  - **雇った人数だけ描く**（2026-10-03 ユーザー指示「×でやるのではなく人をちゃんと増やす」）。「×N」の札は使わない。
    社長を真ん中に左右へ交互に並ぶ。**人が増えたら竪坑の横幅を広げ**、広げたぶん画面を引く（2026-10-03 ユーザー指示「人が増えたら横幅を広げる」）。
    引くのは 0.6倍まで（`ZMIN`。0.4 だと28人で人が豆粒になった）で、床1列に約30人。それを超えたら広げた竪坑に足場を段々に組んで上の段へ
    （最大6段、機械は下の2段だけ）。一度に描くのは100人まで（`CREW_CAP`）で、超えたら雇っている種類を1人ずつ残して人数の割合で配る。
    絵は `Z` を掛けて描き、見出し・地図・2倍の枠は縮めない。鉱脈のボタンは画面の座標なので `Z` を掛けて置く。263人でも 60fps を確認
- **図鑑**: 50種（1層に普通2・★2・★★1）。1種ごとに鉱石+5%。代替わりしても残る
  - 同じ物は、その層の**かけら**になる。かけらは「売る（鉱石）」か「鑑定（10個で未発見を1つ。残りが★★だけなら25個）」——どちらに使うかが選択
  - **宝の部屋**: 各層の真ん中（20m目）。初めて開けたときは未発見の物（★★以外）、2回目からはかけら3つ
  - **★★は層の終わり8m でだけ出る**。その層の★を2つそろえると、手がかりとして場所が出る
  - **層の組**: 1層の5種がそろうと、層ごとの効果（`SETS`）
- **代替わり**（周回）: 240m（6層の底）から。名声 = 5×1.03^(この代の最深−240)。仲間の力は ×(1+0.1×名声)（鉱石には掛けない——掛けると雪だるまになった）
- **家宝**（2026-10-04 ユーザー指示「代替わりの仕組みをもっと掘り下げて」「先代からの引継ぎものもあるでしょ」）:
  代替わりのとき、先代が家宝を1つ残す（`HEIRS`・`heirCands`・`takeHeir`）。候補は**先代の掘り方で変わる**3つ（つるはしを鍛えた・大勢雇った・深く掘った・
  図鑑を増やした・大当たりが多かった代ほど、その家宝が出やすい。同じ代なら何度開いても同じ）＋「受け取らない」。
  棚は3つまで、同じ物をもう一度受け取ると Lv が上がる（最大3）。いっぱいなら1つ手放す。**どれも代償を持つ**:
  | 家宝 | 良い点（Lv1/2/3） | 代償 |
  |---|---|---|
  | 先代のつるはし | つるはしが先代の Lv の 10/15/20% から始まる | 強化が 8% 高い |
  | 先代の名簿 | 先代がいちばん多く雇った仲間を 2/4/6人 連れて始まる | 仲間の値段 +5% |
  | 先代の地図 | 先代の最深の半分までは掘る速さ ×2/3/4（`mapMul`、留守の計算でも深さまで） | 名声の受け取り −10% |
  | 先代の日誌 | 物が出る確率 +1/2/3% | 鉱石 −5% |
  | 先代の金庫 | 手持ちの鉱石の 5/10/15% を持ち越す | 留守の上限 −1時間 |
  | 先代のお守り | 大当たりの出やすさ +2/3/4% | 仲間の力 −5% |
  sim では家宝ありでも3週目 402m・5週目 422m（なし 428m）で、代償と釣り合って進みは速くならない（代の序盤が速くなるだけ）。`HEIR=off` で比べる
- **隠居した先代**（2代目から）: 竪坑の左の端で杖をついて見守り、45〜75秒おきに昔話（「わしの頃は ○m が精一杯じゃった」「先代の地図、大事にな」）。
  **先代越え**（すぐ前の代の最深を越えた瞬間）は、お知らせ・みんなで喜ぶ・先代が「わしを越えたか！」（`S.passTold`）。社史に「残した家宝」の列
- **社訓**: 代替わりのたびに1組ずつ増える（全6組）。組ごとに2つから1つ。どれも良い点と代償を持つ（`CREEDS`）。選び直しは次の代替わりのとき
- **鉱脈**: 開いている間だけ、90〜150秒おきに8秒光る。たたくと今の採掘45秒ぶん
- **留守**: 最大8時間（社訓・層の組で増減）。起動時と裏から戻ったときに計算する。時計が戻っていたら0
- **実績** 30個・**社史**（代ごとの記録）

## さらに品質（2026-10-04 指示「さらに品質を上げたい」）

- **BGM**: 場面で鳴らし分け（`bgmKey`）、切り替えは1.5秒でなめらかに。設定「BGM なし／小／中／大」（`S.bgm`）。
  ブラウザは `audio/*.mp3` を WebAudio に通して鳴らす（iOS でも音量が効く）。アプリは `{"type":"bgm","k","vol"}` でアプリ側が鳴らす（hikari7 と同じ）。
  試作ページに出すときは `audio/*.mp3` も一緒に出す
- **序盤**: 最初から鉱石20（`START_ORE`、開いてすぐ1人雇える）。ずっと開いて遊ぶと、買い物の間は 0〜5分で中央16秒・5〜60分で中央23〜30秒（9割が45秒以内）
- 仲間の欄のアイコンは採掘の絵と同じ描き方で作った画像（`crewImg`）。2代目から最深記録を越えたら知らせる（`S.recTold`）。
  浮かぶ文字は近くのものを上へずらす。案内の吹き出しは9秒出して15秒休む

  層の景色10枚（新しい層に着いたときの見出しにカードで出す／図鑑の層の見出しの背景）。読めなかった絵は今まで通り図形で描く（`ART_OK`）
- アプリでは `tool/build_app_web.py` が絵を index.html に data URI で埋め込む（`window.__TSURU_ART`、61枚・約2.6MB）。ブラウザの試作は `art/` から読む。
  試作ページに出すときは `art/` も一緒に出す
- 起動直後の「仲間が自動で掘ります」は、層の見出しのカードが消えてから出す（重なっていた）

## 見どころ（2026-10-04 指示「もっと、見ている人が楽しめるように」）

開いて眺めている間だけ起きる、**見るだけの出来事**（得も損もしない。たたく所を増やさない・遊ぶ回数を減らさない）。`drawSights`・`drawLift`
- **層ごとの出来事**（`SIGHTS`、30〜50秒に1回）: 表土＝モグラが顔を出す、岩石層＝落石が跳ねて砕ける、鉄鉱脈＝壁の赤い筋に光が走る、水晶洞＝コウモリの群れ、
  溶岩層＝割れ目から溶岩と火の粉、古代層＝壁の絵（つるはしを掲げる3人と下への矢印）が金色に浮かぶ、地底湖＝目のない魚が跳ねる、
  菌糸の森＝胞子がいっせいに舞う、巨人の骨＝頭骨の目が光ってまばたき、星の核＝流れ星。14% で**迷い猫**が床を横切る（どの層でも）。近くの仲間がひと言で反応する
- **仲間どうしの掛け合い**（`TALKS`、35〜60秒に1回、問い→1.7秒後に答え。深さで中身が変わる）
- **鉱石の桶**: 竪坑の右のロープを、層の鉱石を載せて上り、空で降りてくる（10秒で1往復）
- **みんなで喜ぶ**（`cheer`）: 岩盤を割った・100個目ごとのブロック（「n個目！」）・珍しい物の初発見・代替わりのとき、仲間が少しずつずれて2回跳ねる（機械は小さく揺れる）

## 絵（2026-10-04 指示「二つともやろう！」）

ユーザーが Gemini アプリ（無料）で描き、Google ドライブの `つるはし採掘_絵` フォルダに入れる。こちらが取りに行って切り分け・はめ込みをする。
注文書（写すボタン付きのページ）で頼む順は ①アイコン（正方形）・タイトル画面（縦 9:16、上の3分の1は題名用に空ける）
②図鑑10枚（1層1枚・5種、同じチャットで画風をそろえる）③層の景色10枚（横 16:9、到着の演出と図鑑の見出し用、なくても出せる）。
どの頼み文にも同じ画風の一文（手描きの絵本風・太いこげ茶の輪郭・文字なし）を入れる。既存作品名は入れない。

## 広告と課金（決まっていること）

- 報酬型動画だけ: 「採掘の倍率」と「留守の分を2倍で受け取る」。**全画面広告・バナーは入れない**（2026-10-03）
- **採掘の倍率は見るたびに上がり、上限はない**（2026-10-03 ユーザー指示「広告はさらに×」「広告のかけるは上限なし」）: 1本目 ×2、5分のうちに続けて見ると ×3→×4→…。
  見るたびに残りは5分に戻り、切れたら ×1 から。留守の間も残りの分は効く。
  ブラウザの試作は動画なしで押せるので、連打で一瞬に何百倍にならないよう、次に押せるまで30秒あける（`BOOST_GAP`）
- **「広告を消す」は売らない。課金アイテムにする**（2026-10-04 ユーザー指示「広告を消すではなく、課金アイテムにする」。
  種類は「買い切りの永続アイテム」と「使い切りのアイテム」、動画広告は今のまま残す——ユーザーが選んだ）。下の品ぞろえはユーザー了承（「品揃えはいい感じ」）。
  アプリでは**誰でも動画を見て**特典を受け取る（動画なしで受け取れる買い物はない）。売店は「社」のタブ（`shopHtml`）
  | 商品ID | 名前 | 種類 | 効果 |
  |---|---|---|---|
  | `tsuruhashi_canteen` | 社員食堂 | 買い切り | 仲間の力 +25%（`CANTEEN`）。代替わりしても残る |
  | `tsuruhashi_cart` | 大きな荷車 | 買い切り | 留守の上限 +4時間（`CART_H`、8→12時間） |
  | `tsuruhashi_bento3` / `tsuruhashi_bento10` | 特製弁当 3個／10個 | 使い切り | 1個で30分、仲間の力 ×2（`BENTO_X`）。使う時は自分で選ぶ（採掘の下の「弁当」）。使っている最中に使うと30分延びる（倍率は重ならない）。動画の倍率・留守とも掛け合わさる |
  - 社員食堂の強さは sim で「1〜2日先を行く」程度（`CREW_K=2.5` で 3日目 298→323m、3週目 402→409m）。強くしすぎない
  - 値段は App Store Connect で決める（コードには書かない。ゲームはストアの表示をそのまま出す）。**値段はユーザーが決める**
  - 受け渡し: アプリは買い切りを「持っているか」（`own:<商品ID>`）、弁当を「これまでに届いた合計」（`bentoTotal`）で持つ。
    ゲームは `S.iapGot.bento` との差だけを足す（`grantBento`）ので、何度伝えても二度は渡らない。同じ取引の再送は取引番号で捨てる（`bentoTx`）。
    渡すのはストアの通知（`onDelivered`）だけで、買う操作の戻り値では渡さない（docs/app-pitfalls.md 1番）。返金された買い切りは外す、弁当は取り上げない
  - 買った物は「すべて消す」でも残す（`own`・`bento`・`bentoUntil`・`iapGot`）。弁当は使い切りなので「購入を復元」では戻らない
  - ブラウザの試作では、売店のボタンでお金をかけずにその場で付く（買い切りはもう一度押すと外れる）
- 受け取りは画面の状態を見ない（`tsuruAdResult`。docs/app-pitfalls.md 2番）。留守の2倍は、動画の間に画面が変わっても失わない
- アプリとのつなぎは hikari7 と同じ形: `window.__TSURU_APP`（store・owned・got・prices・canBuy・credits）、`TsuruApp.postMessage`
  （store・reward・buy {id}・restore・haptic・theme）、アプリから呼ぶ `tsuruAdResult`・`tsuruSetApp`・`tsuruPause`・`tsuruResume`
- 保存は `TStore`（アプリでは WebView の localStorage を使わずアプリ側へ）。12回に1回、予備（`tsuruhashi_v2_bak`）にも書く
- **通知**（`app/lib/game/notifier.dart`、flutter_local_notifications）: 許可は初めて留守から戻ったときにゲームが頼む（`{"type":"notifAsk"}`、`S.notifAsked`）。
  裏に回るたびに、留守の上限（ゲームが `{"type":"notifCap","h"}` で伝える）の時刻に「留守の採掘がいっぱいになりました」を1件だけ予約し、戻ったら取り消す
- アプリが裏から戻ったら `tsuruResume` を呼んで留守の計算をさせる（WebView の visibilitychange が来ない端末のため）
- 設定の「プライバシー」は `https://tsuruhashi.dailyquarry.com/privacy.html` を開く（ページは `legal/privacy.html`。課金アイテム・通知・広告の中身を変えたら、ここと support・terms も直す）
