# つるはし採掘（tsuruhashi・仮題）

つるはしで地面を掘り進める放置ゲーム。本番は **iOS アプリ**（無料＋報酬型動画広告＋「広告を消す」買い切り）。
2026-09-28 に別セッションで企画・試作（v1）し、2026-10-03 にユーザーが改善案と構成案に同意して作り始めた。

**作り**: hikari7 と同じく、アプリの外側（広告・課金・保存・通知）は Flutter、ゲーム本体は `prototype/game.html` を
WebView で動かす予定（外側はまだ作っていない）。**ゲームの直しは game.html だけ**。

## 置き場所

| 場所 | 中身 |
|---|---|
| `prototype/game.html` | ゲーム本体（v2）。`/*ENGINE-START*/`〜`/*ENGINE-END*/` が画面を持たないエンジンで、tool/ もここだけを読む |
| `prototype/v1.html` | 2026-09-28 の試作そのまま（6層・図鑑20種・周回なし）。比べるために残す |
| `tool/sim.js` | 自動で遊ばせて進み方を測る。`--quick` は CI 用。`PLAY=heavy`・`PLAY=noads`・`CREED=aaaaaa`・`DAYS=60`・`SEED=3`・`LOG=1` |
| `tool/check.js` | エンジンの決まりごとの検査（留守の上限・代替わりで残す物・鑑定で必ずそろう・★★の出る場所・まとめ買い・壊れた保存の復帰など）。CI で毎回回る |
| `tool/make_bgm.py` | BGM 3曲を作る（`platform/ai-lab` の audiogen。生成AIではない）。`prototype/audio/` に MP3（surface＝地上と1層・mine＝2〜5層・deep＝6層より下） |
| `tool/smoke.js` | 画面の通し確認。ブラウザで5つの状態（はじめて・中盤・岩盤・代替わりの前・深層）を開き、タブ・シート・買い物を押してエラー0件か。CI で毎回回る（playwright） |

## 中身（v2、2026-10-03）

- **層**: 10層×40m（表土〜星の核）。層の境の岩盤は つるはし Lv 18/38/58/78/98/120/142/164/186。400m より下は星の核が続く
- **プレイヤーはたたかない**（2026-10-03 ユーザー指示「クリックは不要」）。掘るのは仲間だけで、最初から見習い坑夫が2人いる（代替わりの後も）。
  プレイヤーがするのは強化・雇用・図鑑・代替わり・社訓の判断と、開いている間の鉱脈。社長は見た目として振るだけ（岩盤では「カキン！」）
- **数値**: 固さ 10×1.094^深さ、鉱石 1.5×1.072^深さ（岩盤は5倍）、強化 12×1.15^(Lv-1)、雇用 ×1.15ずつ。
  仲間の力 = 各仲間の力の合計×2×つるはしの倍率。**つるはしの倍率** = (1+0.02×(Lv−1))×1.15^(Lv÷10の切り捨て)。
  掛け算なので強くしすぎると雪だるまになる（1Lv+10%・10Lvごと2倍にしたら1日目に1400m 掘れた）
- **岩盤は Lv が届けばすぐ割れる**（2026-10-03 ユーザー指摘「掘れなくなる時がある」）: もとは固さ12倍で、Lv が届いた後も
  200m では21分削り続けて止まって見えた。今は固さが普通のブロックと同じで、待ちは Lv の関門だけ（企画の山場「カキン！の後に一気に割れる」）。
  Lv 待ちの間は目標の帯に「あと n Lv・約何分／今すぐ強くできる」を出す。社訓「突貫」は「岩盤に必要な Lv −15%」（`reqMul`）。
  毎コマの処理は try で包み、どこかでエラーが出ても採掘と描画は止めない（`frame` → `frame0`）
- **大当たり**: ブロックを割ったとき8%で鉱石5倍（もとはタップの会心）。物が出る確率12%。つるはしの色は10Lvごと（20段）
- **仲間**: 7種（見習い坑夫〜掘進シールド）。0〜2 が人の坑夫、3 から先が機械（社訓「人を育てる」「機械化」で効く）。一つ前を雇うまで次は伏せる
  - **雇った人数だけ描く**（2026-10-03 ユーザー指示「×でやるのではなく人をちゃんと増やす」）。「×N」の札は使わない。
    社長を真ん中に左右へ交互に並ぶ。**人が増えたら竪坑の横幅を広げ**、広げたぶん画面を引く（2026-10-03 ユーザー指示「人が増えたら横幅を広げる」）。
    引くのは 0.6倍まで（`ZMIN`。0.4 だと28人で人が豆粒になった）で、床1列に約30人。それを超えたら広げた竪坑に足場を段々に組んで上の段へ
    （最大6段、機械は下の2段だけ）。一度に描くのは100人まで（`CREW_CAP`）で、超えたら雇っている種類を1人ずつ残して人数の割合で配る。
    絵は `Z` を掛けて描き、見出し・地図・2倍の枠は縮めない。鉱脈のボタンは画面の座標なので `Z` を掛けて置く。263人でも 60fps を確認
- **図鑑**: 50種（1層に普通2・★2・★★1）。1種ごとに鉱石+5%。代替わりしても残る
  - 同じ物は、その層の**かけら**になる。かけらは「売る（鉱石）」か「鑑定（10個で未発見を1つ。残りが★★だけなら25個）」——どちらに使うかが選択
  - **宝の部屋**: 各層の真ん中（20m目）。初めて開けたときは未発見の物（★★以外）、2回目からはかけら3つ
  - **★★は層の終わり8m でだけ出る**。その層の★を2つそろえると、手がかりとして場所が出る
  - **層の組**: 1層の5種がそろうと、層ごとの効果（`SETS`）
- **代替わり**（周回）: 240m（6層の底）から。名声 = 5×1.03^(この代の最深−240)。仲間の力は ×(1+0.1×名声)（鉱石には掛けない——掛けると雪だるまになった）
- **社訓**: 代替わりのたびに1組ずつ増える（全6組）。組ごとに2つから1つ。どれも良い点と代償を持つ（`CREEDS`）。選び直しは次の代替わりのとき
- **鉱脈**: 開いている間だけ、90〜150秒おきに8秒光る。たたくと今の採掘45秒ぶん
- **留守**: 最大8時間（社訓・層の組で増減）。起動時と裏から戻ったときに計算する。時計が戻っていたら0
- **実績** 30個・**社史**（代ごとの記録）

## 画面（2026-10-03 ユーザー指摘「全体的な品質がひくい」で組み直し）

- **1画面のアプリの作り**（ページを縦に送らない）: 上の帯（つるはし社・代・鉱石・設定の歯車／深さ・仲間の力）→ 採掘の絵（`.stage`、高さ 46dvh）
  → 広告のボタン → 操作の欄（中だけ縦に送る）→ 下のタブ（アイコン付き4つ）
- **採掘の絵の下に「次の目標」の帯**（`updateGoal`）: 次の岩盤までの m と必要 Lv、岩盤で止まっているときは赤くして「あと n Lv」
- **まとめ買い**（×1／×10／最大、`S.buyN`、エンジンの `bulk`）。足りないボタンには「あと何秒」（`oreRate` から）
- 仲間の欄は実際の力（1人 毎秒・全体の何%）を出す。図鑑の1種は押すと大きく見られる（`openItem`）。設定は歯車のシート（`buildSettings`）
- **起動画面**（`#title`、「はじめる／つづきから」）。おかえりは押した後に出す（音もここで鳴り始める）
- 絵: 竪坑の奥の岩はだ、梁のランタンの明かり、舞うほこり、人物の輪郭、雇った人は上から降りてくる、岩盤を割ると白く光って「ドーン！」、
  つるはしの強化で社長が光る（進化は大きく）。割る音は 0.14秒に1回まで
- **層ごとの壁の模様**（`DECO`、2026-10-03 指示「品質とクオリティを上げて」）: 表土＝小石と根、岩石層＝石とひび、鉄鉱脈＝赤い筋、水晶洞＝光る結晶、
  溶岩層＝脈打つ割れ目、古代層＝刻まれた石と歯車、地底湖＝水の筋としずく、菌糸の森＝光るきのこ、巨人の骨＝骨、星の核＝瞬く星。位置は hash で毎回同じ。
  層の見出しは帯が伸びて、名前と紹介文（`LAYERS[].desc`）
- 人物の服装（`OUTFIT`）: 見習い＝青いつなぎ、ベテラン＝茶のベストとひげ、発破係＝赤い上着と背中のダイナマイト、社長＝黄色いヘルメットとライト（暗い深さで淡く光る）
- 鉱石の数字は数え上がり、大きく増えると跳ねる。代替わりは「○代目社長 就任」の演出（`ceremony`、押すか2.6秒で閉じる）
- **最初の数分の案内**（`COACH`・`S.tut`）: 仲間を雇おう → つるはしを強くしよう → 岩盤（Lv で割れる）→ 図鑑 → 代替わり。済んだら二度と出さない。
  その段のタブを開いているときは出さない
- 音: 仲間のつるはしの音を小さく（0.22秒に1回まで、層で高さが変わる。岩盤では硬い音）
- 文字は12px 以上。広告の紫は明暗どちらの表示でも同じ色（暗い表示で淡い紫に白字が読めなかった）

## さらに品質（2026-10-04 指示「さらに品質を上げたい」）

- **BGM**: 場面で鳴らし分け（`bgmKey`）、切り替えは1.5秒でなめらかに。設定「BGM なし／小／中／大」（`S.bgm`）。
  ブラウザは `audio/*.mp3` を WebAudio に通して鳴らす（iOS でも音量が効く）。アプリは `{"type":"bgm","k","vol"}` でアプリ側が鳴らす（hikari7 と同じ）。
  試作ページに出すときは `audio/*.mp3` も一緒に出す
- **序盤**: 最初から鉱石20（`START_ORE`、開いてすぐ1人雇える）。ずっと開いて遊ぶと、買い物の間は 0〜5分で中央16秒・5〜60分で中央23〜30秒（9割が45秒以内）
- 仲間の欄のアイコンは採掘の絵と同じ描き方で作った画像（`crewImg`）。2代目から最深記録を越えたら知らせる（`S.recTold`）。
  浮かぶ文字は近くのものを上へずらす。案内の吹き出しは9秒出して15秒休む

| 時期 | 目安 |

## 広告と課金（決まっていること）

- 報酬型動画だけ: 「採掘の倍率」と「留守の分を2倍で受け取る」。**全画面広告・バナーは入れない**（2026-10-03）
- **採掘の倍率は見るたびに上がり、上限はない**（2026-10-03 ユーザー指示「広告はさらに×」「広告のかけるは上限なし」）: 1本目 ×2、5分のうちに続けて見ると ×3→×4→…。
  見るたびに残りは5分に戻り、切れたら ×1 から。留守の間も残りの分は効く。
  動画なしで押せる人（広告を消した人・ブラウザの試作）は、連打で一瞬に何百倍にならないよう、次に押せるまで30秒あける（`BOOST_GAP`）
- 「広告を消す」（買い切り・非消費型）を買った人は、**動画を見ずに2倍の効果を受け取れる**（2026-10-03、護送ボートのヒントと同じ考え）
- 受け取りは画面の状態を見ない（`tsuruAdResult`。docs/app-pitfalls.md 2番）。留守の2倍は、動画の間に画面が変わっても失わない
- アプリとのつなぎは hikari7 と同じ形: `window.__TSURU_APP`（store・adFree・price・credits）、`TsuruApp.postMessage`
  （store・reward・buy・restore・haptic・theme）、アプリから呼ぶ `tsuruAdResult`・`tsuruSetApp`・`tsuruPause`・`tsuruResume`
- 保存は `TStore`（アプリでは WebView の localStorage を使わずアプリ側へ）。12回に1回、予備（`tsuruhashi_v2_bak`）にも書く
- 通知（「8時間たまりました」）は外側を作るときに入れる。許可は初めて留守から戻ったときに聞く

## 公開後の更新の計画

公開前に3か月分を作っておき、月1回出す。v1.1 は11〜12層・図鑑+10・仲間+1、v1.2 は「つるはし社への依頼書」、
v1.3 は13〜14層・社訓+2組。その後も層と図鑑を足す更新を、少なくとも2か月に1回。

## 決まっていること（ユーザー決定）

- iOS のみ。無料＋広告（報酬型動画中心）＋「広告を消す」買い切り。月額・ガチャなし
- 公開名義は「つるはし社」。本名・nami・0817 は公開文面に出さない（tool/check.js が game.html を見ている）
- 挑戦や遊ぶ回数を減らすものは入れない（護送ボートでのユーザー指示）
- 選択には代償か裏目の可能性を持たせる（社訓・かけらの使い道）
- 絵が要るときはユーザーが Gemini アプリ（無料）で作って渡す。既存作品名をプロンプトに入れない。課金の可能性があるものは必ずユーザーに聞く
- 名前は仮題「つるはし採掘」のまま進める（2026-10-03）
