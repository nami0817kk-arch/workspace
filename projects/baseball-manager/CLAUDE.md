# baseball-manager

野球の監督・育成シミュレーション。Flutter のスマホアプリ（広告・課金・ストア公開前提）。
soccer-manager / soccer-career の野球版。**中核は「試合中の采配と、シーズンを通した育成」**。

## 前提

- Flutter / Dart。依存は最小（`shared_preferences` は保存を入れるとき）。
- **国名は実在のもの、リーグ名・球団名・選手名・大会名は架空**（soccer-career と同じ線）。
  公開と収益化が前提なので商標・肖像のリスクを避ける。この線は動かさない。
  「ワールド・ベースボール・クラシック」等は商標なので「世界大会」と呼ぶ。
- 広告・課金を入れるときは**着手前に `docs/app-pitfalls.md` を読む**。
- 試合の確率計算は `lib/game/` の純Dart（Flutter非依存）に置き、`test/` で挙動を固定する。
  バランスは片方だけ触ると崩れるので、変えたらテストも更新する。
- 保存データを足すときは `fromJson` に既定値を置く（既存セーブを壊さない）。

## テスト

ローカルではなく CI（`.github/workflows/baseball-ci.yml`）で回す。手元は analyze まで。

## ゲームの形（2026-10-17 にユーザーが決定）

**1人の選手を幼少期から育て、プロを引退するまでを遊ぶ。**（監督ではなく育成の一代記。soccer-career の野球版）

- 年齢で局面が変わる: 少年(6-12) → 中学(13-15) → 高校(16-18) → 進路(大学/社会人/プロ志望届・ドラフト) → プロ → 引退。
  段階の判定は `lib/game/career.dart` の `stageOf(age)` の1か所で決める。
- 1年(1シーズン)を単位に進める。年ごとに「練習の方針」を選び、能力が伸びる。
  大事な試合では打席/登板ごとの選択(`at_bat.dart` のエンジンを使う)。
- 能力は年齢で伸びやすさが違う(少年期は伸びが大きく、30代で下降)。曲線は `growthFactor(age)` に集める。
- 進路は分岐: プロ入りできなければ大学・社会人で再挑戦、それも外れたら引退(これも結末の一つ)。
- 引退時に「通算成績・称号・エンディング」を出す。周回プレイの動機はここ。
- 保存は `shared_preferences`(端末ごと)。長編なので**保存データの互換性は最初から守る**(soccer-career の `save_guard_test` 方式を踏襲)。

### 二刀流（2026-10-17 にユーザーが追加）

- **二刀流は、プロの段階ならいつでも選べる**（何年目でも可。ユーザー確認済み）（`Role.twoWay`、`switchRole`）。それまでは打者か投手のどちらか。
- 代償: 練習が分散するため**伸びが 0.6 倍**。新しく持つ能力は初期値 25（本職より低い）。
- プロの段階なら本職に戻すこともできる。段階の縛りは `switchRole` の1か所で守る。

### 進路・ドラフト・引退（2026-10-17 にユーザーが決定）

- ドラフトは **能力＋実績＋運**（`draftScore` は能力7割・実績3割、運は ±10）。
  **一番上は確実に指名、一番下は絶対に指名されない**（境目だけ運しだい）。
  「一番上と一番下」の回答を「能力＋運の抽選」と「実績も加味」の合わせ技と読んだ。違っていたら直す。
- 実績(0〜100)は `season.dart` の勝ち抜き大会から出す（`Tournament.achievement` ＝ 勝ち上がり6割・個人の評価4割）。
  個人の評価は 50 が平均。打者は塁打と四球、投手は三振−(四球＋被安打＋被本塁打)で見る。
- 外れたら **大学4年 / 社会人3年から選び**、卒業時にもう一度ドラフト。**再挑戦は1度だけ**、外れたら引退。
- プロ入り後の引退は **自分で決められる ＋ 戦力外(総合評価35未満が2年続く)・46歳で強制**。

### 1年の中の選択（2026-10-17 にユーザーが追加）

- 1年は **春・夏・秋・冬の4季節**。夏は大会の季節。選択は**季節ごと**に行う（`life.dart`）。
- 過ごし方は6つ: **練習 / 特訓 / 休養 / 研究 / 交流 / 練習試合**。
  特訓は大きく伸びるが疲れて怪我しやすい。休養・交流は疲れと気持ちを戻す。
  重点の能力を選ぶのは練習・特訓・研究。練習試合は全体が少し伸びる。
- **体調**（`Condition`: 疲労・気持ち・怪我）は年をまたいで持ち、大会の勝ちやすさに効く。怪我中は選べず伸びない。
- **出来事**: 季節の途中に4割の確率で起き、選択肢から選ぶ（コーチ / ライバル / スランプ / 友人）。出来事を足すときは `events` に並べる。
- 年次進行 `advanceYear` は残してある（年単位の簡易進行・テスト用）。本番は `playTerm` の繰り返し。

### 特性（2026-10-17 にユーザーが追加）

- 能力とは別に**特性**を持つ（`traits.dart`、最大4つ）。良いもの（大器晩成・努力家・天才肌・頑丈・鉄人・前向き・勝負強い・華がある・長持ち）と、
  代償のあるもの（早熟・ガラスの肉体・ノミの心臓）がある。矛盾する組（大器晩成/早熟、頑丈/ガラスの肉体、勝負強い/ノミの心臓）は同時に持てない。
- 生まれつき 0〜2 個（`rollInnateTraits`）。出来事でも増える（例: 特別メニューをやり抜くと努力家）。
- **効き方は `traits.dart` の関数に集めてある**（`growthMultiplier` ほか）。他のファイルは特性の名前を直接見ない。
  特性を足すときは enum と、効く関数と、テストを足す。
- 保存は名前の文字列。未知の名前は無視して読む（特性を消しても古いセーブが壊れない）。

### ゲーム本体（`lib/game/game.dart`）

- `Game` が全部をつなぐ。画面は `phase`（季節 / 出来事 / 進路 / 引退）を見て、対応する操作だけを呼ぶ:
  `choose(action, focus)` → `resolveEvent(i)` → `chooseRoute` / `giveUp`、プロなら `changeRole` / `retire`。
  段階に合わない操作は `StateError`。
- 1年 = 春夏秋冬の4回の `choose`。夏の `choose` の中で大会が行われ、実績が積まれる。
- ドラフトは **高校卒業（19歳になる時）** と、**大学22歳・社会人21歳の卒業時**。実績は直近3回の大会の平均。
- リーグの強さは段階ごとに `_league` で決める（少年→プロで強くなる）。数字は仮置き。CI が通ったら実測して調整する。
- 保存は `toJson` / `fromJson`。欠けた項目は既定値で読めること（`game_test.dart` が見張る）。

### サクセス感（2026-10-17 にユーザーが要望: パワプロのサクセスのように）

- **ターンの細かさ（決定）**: 高校とプロは**月単位**（12ターン、4月始まり、7月が大会）、幼少期・中学・大学/社会人は**季節**（4ターン）。
  段階による切り替えは `calendar.dart` の1か所。効果・疲労・怪我・出来事は `slotShare`（月単位は1/3）で小さくなる。
- **経験点制（決定）**: 練習しても能力は**直接は上がらない**。種類（打撃 / 守備走塁 / 投球）ごとに**経験点が貯まり**、
  好きなタイミングで同じ種類の能力に振り分ける（`Game.spend` / `spendAll`、おまかせは `autoSpend`）。
  上げにくさは `expCost`（高い能力ほど高い）。衰える年だけ能力が直接下がる。
- **やる気**: 気持ちから5段階（絶不調〜絶好調）。経験点の貯まる量が 0.7〜1.3 倍になる（`Motivation`）。
- **キャラクター**（`characters.dart`、名前はすべて架空）:
  - **チームメイト**: 3人。得意分野が練習の種類と合うと**友情タッグ練習**（経験点1.3倍、絆+8）。絆が高いほど起きやすい。
  - **ライバル**: 6歳から一生のライバル。夏の大会のたびに能力で勝負（勝つと気持ち+10・実績+5、負けると気持ち-8）。通算の勝敗がエンディングに出る。
  - **家族 / 恋人**: 家族は最初から、恋人は高校で現れる。「交流」や出来事で絆が上がり、絆50以上で年末に疲れが少し抜ける。
    **引退時に恋人との絆が80以上なら結婚**（エンディング）。
  - **コーチ・監督**: 段階ごとに替わる。「コーチに教わる」（`Plan.lesson`）か居残りでコツが貯まり、**4回で特性を習得**。
    教えられる特性が無ければ経験点をもらう。
  - 仲間とコーチは段階が変わるたびに入れ替わる。ライバルと家族・恋人は続く。
  - 出来事に条件（`GameEvent.when`）と、登場人物への影響（`EventChoice.onCast`）を持たせた。
- バランスは `expPerPoint`（現在 8）と `roleExpFactor`（役割ごとの補正）で決める。**`dart run tool/balance.dart` で分布を見る**
  （「平凡」= 練習と休養だけ、「上手い」= 特訓・コーチ・交流・弱い能力の底上げ）。2026-10-17 の実測（800人）:
  プロ入りは打者 平凡33% / 上手い47%、投手 平凡46% / 上手い59%。称号「レジェンド」は 平凡0.5〜3% / 上手い13〜24%。
  投手のほうが少し入りやすい（能力が3つで底上げが効きやすい）。数字を変えたら必ずこのツールで確かめる。

### 画面（`lib/ui/`）

- `controller.dart`（`GameController`）が `Game` と保存（`shared_preferences`）をつなぐ。操作のたびに保存する。
  壊れたセーブは無いものとして扱い、最初の画面から始める。
- 画面は `phase` を見て出し分ける: 季節/月の選択 → 出来事 → 進路 → エンディング。**ロジックは画面に持たせない**（`game/` に置く）。
- 日本語の表示名・能力のランク（G〜S、10ごと）は `labels.dart` に集める。
- 直前の操作の結果（貯まった経験点・大会・出来事）は `GameController.recent` で「いまの結果」カードに出す。
- **節目の演出**: ドラフト指名・優勝・進学（少年→中学→高校→進路）・コツの習得は、ダイアログで大きく見せる（`Milestone` / `MilestoneDialog`）。
  拾うのは `GameController._detect`。ログの文言（「ドラフトで指名された」「優勝」「を習得」）に依存しているので、`game.dart` のログ文言を変えたら合わせる（`app_test.dart` が見張る）。
- Flutter の `Category` とも衝突するので、`foundation.dart` を `hide Category` で読む。
- 名前の衝突: Flutter に `Action` / `Route` があるので、ゲーム側は `Plan`（季節の過ごし方）/ `Course`（進路）。
- **未対応**: 同梱フォント（CJK）。Web は OS のフォントに頼っている。ストアに出す前に `docs/app-pitfalls.md` の6番（円記号）も含めて確認する。
  広告・課金・Android/iOS のフォルダも未着手（web のみ生成済み）。
- ローカルで画面を見るには `flutter build web --base-href / --no-web-resources-cdn` して `build/web` を配信する（CDN に出られない環境用）。

### 殿堂・あそびかた・フォント・アイコン

- **殿堂**: 引退のたびに記録が1件残る（`history.dart`、最大30件、端末ごと）。`Game.archived` で二重に書かない。
- **あそびかた**: はじめの画面の「?」から開く。ルールを足したら `showHelp` の文面も直す。
- **フォント**: NotoSansJP を同梱済み（`assets/fonts/`、soccer-* と同じファイル）。選手名は自由入力なのでサブセットは絞らない。
- **アイコン**: `tool/icon_source.png`（野球ボール。実在のロゴ・意匠なし）から `python tool/make_icons.py` で全サイズを書き出す。
- **アプリ名**: 「野球育成」。ID は `com.namiki.baseball_manager`（仮。ストアに出す前にユーザーが決める。`docs/public-identity.md` 参照）。

### グラフィック（`lib/ui/art/`）

画像素材は持たず、すべて `CustomPainter` で描く（ロゴ・実在チームの意匠は使わない）。

- `avatar.dart`: 選手の絵。**段階**でユニフォームと背丈、**役割**で持ち物（バット / グラブ）、**やる気**で表情が変わる。
- `scene.dart`: 季節で変わる球場の背景（春=桜、夏=入道雲、秋=落ち葉、冬=雪）。季節は `calendar.dart` の `seasonOf`。
- `radar.dart`: 能力のレーダー。外枠は最高値の少し上（`radarScale`）で、序盤でも形が読める。値が変わるとなめらかに動く。
- `career_chart.dart`: エンディングの「総合評価の歩み」（ランクの帯・プロ入りの縦線）。`Game.overallHistory` / `proStartAge` から描く。
- `confetti.dart`: ドラフト指名・優勝のダイアログの紙吹雪。
- **`CustomPaint` の文字は Theme を引き継がない**。`TextStyle` に `fontFamily: kFont` を必ず付ける（付けないと Web で豆腐になる）。
- レーダーは役割が変わった直後に、アニメの始点が前の役割の長さで来る。長さが違えば現在値を使う（二刀流への転向で落ちた）。
- 見た目を変えたら `tool/gallery.dart` で全段階・季節・表情を並べて見る:
  `flutter build web --base-href / --no-web-resources-cdn -t tool/gallery.dart -o /tmp/gallery`
- 広い画面（Web・タブレット）では中身を最大560pxに寄せる（`contentMaxWidth`）。ダークテーマにも対応。

### 管理者機能（2026-10-17 にユーザーが追加）

- **有効にする**: ホーム画面・育成画面の右上の**歯車（設定）→「管理者モード」のスイッチ**（育成中なら続けて「管理者機能を開く」で着く。3タップ）。
  従来の隠し操作（タイトルを2秒以内に7回タップ）も残してある。端末ごとに覚える（`adminKey`）。
  有効な間、育成画面の右上に管理者ボタンが出る（`AdminScreen`）。
- **できること**: 素質(0〜100)・特性（**上限4つも矛盾する組も無視して**付け外し）・コーチのコツ(0〜4。満タンにするとその場で習得)・
  コーチが教える特性の差し替え・能力値・経験点の加減。実体は `Game.admin*`（`game.dart`）。
- 通常の遊びには影響しない。**ストアに出す前に、隠しのままでよいか決める**（誰でも7タップで開ける。ユーザー判断）。

### 成績（2026-10-17 にユーザーが要望: 成績が見られないと意味が無い）

- **1年に1件の成績**（`SeasonRecord`、`records.dart`）を残す。アマチュアは夏の大会（7月 / 季節は夏）、
  **プロは143試合のシーズン**（10月に成績が出る。`playLeagueSeason`、`season.dart`）。
- 成績の中身は `Line`: 打者=打数・安打・塁打・四球・本塁打（→ 打率・出塁率・長打率・OPS）、
  投手=対戦・アウト・三振・四球・被安打・被本塁打・**失点の推定**（→ 防御率・投球回）・先発・勝敗。
  失点は打球結果ごとの得点価値（線形加重）から推定する（走者の動きまでは再現しない）。基準値は `runBaseline`。
- プロのシーズン: 打者は全試合に出る。投手は5試合に1度先発し、5回(15アウト)以上投げれば、チームの勝敗が勝敗になる。
  順位は勝率から（`leagueRank`、6球団）。**タイトル**（首位打者 .340・本塁打王 40・最優秀防御率 1.60・最多勝 21・最多奪三振 250・MVP）は
  規定に届いたときだけ（`titlesOf`）。しきい値は `tool/balance.dart` の分布で決めた。変えたらこのツールで確かめる。
- 実測（能力60の打者）: 打率.264 / 本塁打17 / OPS.752、（能力60の投手）: 防御率3.87 / 11勝7敗。野球として自然な範囲。
- 画面: 育成画面の右上と「最近の成績」カードから**成績画面**（通算・年度別の表・タイトル・ライバル戦績・総合評価の推移）。
  エンディングと殿堂（通算成績の一行）にも出る。`RecordsView` を共用する。
- 保存: `records` を `Game.toJson` に入れてある。古いセーブ（項目なし）は空で読める。
- **使いやすさ**: 今のおすすめ（疲れ→休養・気持ち低下→交流・普段→練習）をタイルに表示（`recommendedPlan`）。
  経験点が貯まったら、能力カードに振り分けの案内を出す。

### 使いやすさ（2026-10-17）

- 育成画面の並び: 画像 → 状態 → 直前の結果 → **操作（練習など）/ 出来事 / 進路** → 能力 → プロの決断 → 最近の成績 → まわりの人 → ログ。
  毎ターン押す操作を、スクロールせずに選べるようにしてある（`app_test.dart` が見張る）。
- はじめの2ターンだけ案内（`_FirstHint`）。経験点が貯まったら、状態カードの「おまかせで振り分ける」で、能力カードまで行かずに振れる。
- 取り返しのつかない操作（引退・「プロは諦める」）は確認ダイアログを挟む。

### 選手情報・設定（2026-10-17 にユーザーが追加）

- **選手情報**（`PlayerScreen`）: 育成画面の右上の人型ボタン / 画像をタップで開く。**プロフィール**（総合評価・素質の星・特性とその説明・能力・いまの状態・まわりの人）、
  **成績**（`RecordsView`）、**経歴**（入学・進路・ドラフト・特性の習得・転向・優勝・タイトル・引退の年表）の3タブ。
- 画面は `PlayerSnapshot`（`snapshot.dart`）を表示する。育成中は `fromGame`、**殿堂の過去の選手も同じ写しを保存してあり**、タップで同じ画面が開く
  （古い殿堂の記録には写しが無い）。項目を足すときは `fromJson` に既定値を置く。
- 経歴の元は `Game.lifeLog`（`LifeEvent`、`life_log.dart`）。節目を増やすときは `Game._note(kind, text)` を呼び、`timelineOf` の並び順表と画面の色（`_CareerTab._style`）に足す。
- **設定**（`SettingsScreen`）: 管理者モードのスイッチ・管理者機能への入口・あそびかた・すべてのデータを消す（確認つき。殿堂も消える）。

### ゲーム性の改善（2026-10-17 にユーザーが「品質とゲーム性の向上を繰り返し」と依頼）

- **練習の出来**（`Outcome`、`life.dart`）: 練習・特訓・練習試合・コーチは、毎回「失敗(×0.4) / ふつう / 好調(×1.25) / 大成功(×1.8)」のどれかになる。
  特訓は振れ幅が大きい。倍率の平均は1前後で、全体のバランスは変えない。失敗は疲れが増えて怪我しやすく、大成功は気持ちが上がる。
- **作戦**（`Tactic`、`tactics.dart`）: 大会（プロはシーズン最終月の10月）の前の月と当月に、堅実 / 強気 / 研究を選ぶ。
  その大会だけ能力が変わる（堅実=ミート・制球、強気=パワー・球威、研究=チーム力+4）。大会が終わると堅実に戻る。
- **年間目標**（`Goal`、`goals.dart`）: 年の初めに決まる（アマ=大会の勝ち上がり・打率、プロ=順位・打率・本塁打・防御率・勝利数）。
  達成で経験点（全種類、各6〜10。1年ぶんの練習の1〜2割ほど）と気持ち+18。**経験点を多くすると全体のバランスが崩れる**（最初に100〜150にしたら、プロ入りが9割になった）。未達は気持ち-5だけ。目標の高さは、実測の平均成績の表から決める
  （`test/goals_test.dart` が、どの強さでも達成率が2〜85%に入ることを検査する）。
- **ランダムプレイの検査**（`test/fuzz_test.dart`）: ランダムな操作と管理者の書き換え・保存の往復で200人を最後まで遊ばせ、毎ターン不変条件を見張る。

- **出来事**は24種類。運しだいの選択肢（`EventChoice.risky`、成功・失敗は乱数）があり、同じ出来事は続けて起きない（`drawEvent` の `exclude`）。
  出来事で能力を直接足すときは `_gain`（役割に無い能力は足さない。ランダムプレイの検査が、投手に打者の能力が付く不具合を見つけた）。
- **難しさ**（`Difficulty`、`difficulty.dart`）: はじめに選ぶ（やさしい / ふつう / むずかしい）。経験点の倍率とドラフトの合格ラインが変わる。その選手の一生ずっと変わらない。
  `dart run tool/balance.dart 500 hard` で分布を見る。2026-10-17 の実測（プロ入り）: やさしい 65〜78% / ふつう 38〜50% / むずかしい 17〜24%。

## ゲーム性の向上（繰り返し。2026-10-18 にユーザーが依頼）

### 1. 大会の試合ごとの結果
- 勝ち抜き戦(`Tournament.games`)の各試合を、ログと「いまの結果」に出す: 「○ 3回戦 vs 桜丘高校 — 4打数2安打 1本塁打」。相手は架空の名前(`opponentName`、少年は○○ジュニアーズ・中学・高校・大学・社会人)。世界大会は相手が国名。準決勝・決勝の呼び名は `roundLabel`。勝ち負けの乱数の使い方は変えていない(バランス不変)。

### 2. 目標のむずかしさを選べる
- 年の最初の行動の前だけ、今年の目標を「やさしい/ふつう/むずかしい」から選べる(`Game.chooseGoalLevel`、`goal-picker`)。むずかしいほど達成のごほうび(経験点×0.5/1/2、気持ち+10/18/30)が大きく、失敗の痛手も大きい(気持ち-3/-5/-8)。達成しやすさはおよそ75%/50%/25%で、期待値は やさしい<ふつう≒むずかしい。
- 選ばなければ「ふつう」(従来どおり)なので、バランスは変わらない。保存は `Goal.level` / `baseTarget`(既定は「ふつう」)。

### 3. 海外(アメリカ)のリーグへの移籍
- プロの24歳以上・総合評価70以上・年の最初に、「アメリカのリーグへ移籍する」を選べる(`Game.canMoveOverseas` / `moveOverseas`)。海外にいる間は、日本に戻る(`returnHome`)も年の最初にいつでも。
- 海外は**相手が+8強く、自分のチームは-3**(`_leagueBase`)。その代わり**年俸が2.5倍**(`salaryOf`、記録の `overseas`)。移籍直後は気持ちが-8、帰国は+6。球団は架空(`overseasTeams`)。目標は移籍で立て直す。

### 4. 二世（周回の楽しみ）
- 殿堂に、**結婚して引退した選手**が居ると、はじめる前に「二世として始める」で親を選べる(`heir-select`、`Game.newGame(parent:)`)。
