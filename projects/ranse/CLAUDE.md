# 乱世下剋上（ranse）

戦国日本に、運だけで決まる生まれ（身分・国・性別・生まれ順・才・特性）で生を受け、
誕生から死までを遊ぶ人生シミュレーションの **iOS アプリ**（Flutter）。
参考は個人開発のブラウザゲーム「80億分の1」（国・家庭・性別が運で決まり、
健康・幸福・知識・人間関係が動く）。それを戦国に移し、出世と天下統一の道を足した。

2026-11-22 に、ブラウザ版の試作（単一HTML）から始め、ユーザーが
「想定はアプリ」と決めたので Flutter に移した。

## 決まっていること

- **出す先は iOS だけ**（`flutter create --platforms=ios`）。向きは縦のみ。
- 日本語のみ（l10n なし）。書体は iOS 標準の明朝にフォールバックさせている。
- **収益の形は未決定。** 広告・課金（`google_mobile_ads` / `in_app_purchase`）は
  **まだ入れていない**。入れるときはユーザーの決定を取り、先に
  `docs/app-pitfalls.md` を読む（払ったのに届かない／広告の期限切れ ほか）。
- 商品名・バンドルID（今は仮の `com.namiki.ranse`）・ストア掲載文・公開名義は
  **ユーザー決定待ち**。外向きの文字列は `docs/public-identity.md` が正。

## 構成

| 場所 | 役割 |
|---|---|
| `lib/engine/` | 画面に依存しない遊びの中身。**ここだけでテストできる** |
| `lib/engine/data.dart` | 身分・国・特性・勢力のマスタ（人口比は戦国日本の概算） |
| `lib/engine/birth.dart` | 生まれの抽選と「約◯分の1」の計算 |
| `lib/engine/game.dart` | 手番の進行・死亡・昇進・世の動き。`Game` が状態と選択肢（`Prompt`）を持つ |
| `lib/engine/actions.dart` `events.dart` | 行動と出来事（子ども期／大人） |
| `lib/app/` | 画面遷移（`controller.dart`）と保存（`save.dart`） |
| `lib/ui/` | 画面（タイトル／生まれ／遊ぶ／終わり） |

## 作りの約束

- 乱数は必ず `Rng`（`lib/engine/rng.dart`）を通す。種を固定して同じ人生を再現できる。
- 1手番 = 子ども期は1年、大人は半年。`Life.t` は半年の数で、`age = t ~/ 2`。
- 選択肢（`Prompt`）は関数を抱えるので**保存できない**。保存は選択肢が出ていない区切り
  （`Game.changed()` の `onCheckpoint`）でだけ行う。終わった人生は保存を消す。
- 行動が `null` を返したら「選択肢を出した。手番は選択のあとで進める」の意味
  （`ask(..., after: g.endTurn)`）。文字列を返したら見聞録に書いて手番を進める。
- 女性の道（奉公→家政→嫁ぐ→後見）は、合戦・下剋上を出さない代わりに別の昇進路を持つ。
  女武者の特性を持つ人と当主（位8）だけは戦える（`Game.canFight`）。

## テスト

- 合否は CI（`.github/workflows/ranse-ci.yml`）で見る。手元は `dart analyze lib test` まで。
- `test/engine_test.dart`: 400通りの生まれを最後まで自動で遊ばせて例外が出ないこと／
  種が同じなら同じ人生になること／乳幼児死亡率が10〜30%／保存の往復／
  女性は合戦に出られないこと／稀少度。
- `test/app_smoke_test.dart`: タイトル→籤→人生開始→子ども期の行動→タブ切り替え。

## このPCで踏んだこと

- **`flutter analyze` は、パスに日本語（ユーザー名「なみ」）が入っていると
  解析サーバが落ちる**（`FormatException: Unexpected end of input`）。
  手元では `dart analyze lib test` を使う。CI（Linux）では `flutter analyze` で問題ない。
