# 乱世下剋上（ranse）

戦国日本に、運だけで決まる生まれ（身分・国・性別・生まれ順・才・特性）で生を受け、
誕生から死までを遊ぶ人生シミュレーションの **iOS アプリ**（Flutter）。
参考は個人開発のブラウザゲーム「80億分の1」（国・家庭・性別が運で決まり、
健康・幸福・知識・人間関係が動く）。それを戦国に移し、出世と天下統一の道を足した。

2026-11-22 に、ブラウザ版の試作（単一HTML）から始め、ユーザーが
「想定はアプリ」と決めたので Flutter に移した。

## コンセプト（2026-11-23 ユーザーとの会話で決定）

**戦国の日本に、運だけで生まれる。生まれは選べない。選べるのは、人生の岐路だけ。**
参考作品で一番惹かれたのは「選択によって将来が決まる」こと（ユーザー）。

- **対象**: ライトな暇つぶしの人と、結果をSNSで共有したい人。
- **長さ**: 最長で通して約1時間（ユーザー決定）。**早く終わる人生が多く、平均は30分前後**の見込み。
  乳幼児で亡くなる人生は数十秒、村から出ず静かに暮らす人生は20分ほど、
  仕官・戦・下剋上まで進む波乱の人生が1時間近く。**長く遊べた人生ほど波乱に富んだ人生**で、
  長さが結果の一部になる。
- **章で区切り、途中でやめて再開できる**ことが必須。1時間通しで遊ぶ人は少なく、
  「1章遊んで閉じる」が普通の遊び方になる。章の終わりに「ここまでの人生」を出し、
  再開時に「前回のあらすじ」を出す。
- **遊びの形**: 年は流れ、重みのある選択の場面（**岐路**）で止まる。
  岐路のあいだに「この数年の過ごし方」を3択ほどで選ぶ軽い作業を残す
  （鍛錬・学問・稼ぐ・人脈など。選んだものが**次に出る岐路の種類**にも効く）。
  毎手番の細かい操作は廃止の方針（今のコードはまだこの前の形）。
- **選択が後で効く（伏線）**: 寺で学んだ人は後で書状や調略で道が開く、先陣で名を上げた人は
  引き立てられる反面、恨みも買う、など。能力値より「どの道を歩んだか」で結末が変わる。
- **結末は多く**（名もなき農夫・高僧・豪商・忍び・侍大将・大名・女大名…）。
  同じ生まれでも選択で別の結末になる。
- **共有する結果カード**に載せるもの: 「生まれの稀少度」「選んだ道（分かれ道を3〜4の短い一行で）」
  「結末の称号」。**選ばなかった道は載せない**（ユーザー決定）。
- **結末の決め方（2026-11-23 決定）**: 「地位 × 幸福」の2軸で称号を決める。
  地位が高くても幸福が低ければ「孤独な天下人」、地位が低くても幸福が高ければ
  「満ち足りた農夫」。共有されやすいのは成功の大きさより、この皮肉や納得の一行。
- **最期の場面を1000本（2026-11-23 決定、ユーザー「最終的な結果は1000通りはほしい」）**:
  - 「1000通り」は**最期の場面の数**で数える（称号の掛け合わせではない）。
  - **1000本すべて別の文章で書く**（部品の組み合わせにしない）。一本は**3〜5文・約150字**（全部で約15万字）。
  - どれが出るかは**歩んだ道（旗・縁のある人）と死に方（死因・年齢・身分）**で決める。
    当てはまる中で、いちばん条件の細かいものが出る。地位×幸福も条件の一つ。
  - **最期ごとに称号を一つ持つ**（例「寺の鐘を聞きながら逝った槍の名手」）。
    結果カードの「結末の称号」はこれ。前の「地位×幸福の称号表」はこれに置き換えた。
  - **出やすさに差をつけ、希少度を出す**（数百回に一度の「幻の最期」もある。生まれの稀少度と対）。
  - **図鑑で集められる**。「1000の最期のうち◯を見た」と数を出し、見たものは読み返せ、
    見ていないものは席だけ見える。
  - 5歳までに亡くなる人生にも、身分・国・年で違う最期を**数十本だけ**用意する。残りは選んだ道のある人生に回す。
  - **公開時に1000本すべて揃える**（後から足す形にしない）。
  - **1000本の分け方（2026-11-23 決定）**:
    - 道ごとの本数は**波乱の道ほど厚く**: 幼くして40／村の暮らし（農・漁・職人）70／商いの道70／
      仏門80／忍び・流れ者・野盗90／足軽・侍130／城主・家老150／大名・下剋上180／天下人70／
      女の道（奥・後見・女大名）120。
    - 各道の中を**死に方8種**で分ける: 天寿・病・戦死・切腹や処刑・暗殺・災いや事故・飢え・行方知れず。
      道に合わないものは省く（仏門に戦死は少ない、など）。道×死に方で1組あたり平均12本ほど。
    - その12本ほどは**縁のある人**（最期の場に誰がいたか: 幼なじみ・師・伴侶・子・好敵手・信長など）で書き分ける。
    - **希少度は4段階**: よくある500本・珍しい300本・稀150本・幻50本（幻は数百回に一度）。
    - **幻の50本**は、歴史を変えた人生（本能寺で信長を救った、など）25本と、
      ありえない成り上がり（賤民から天下人、女の身で天下、など）25本。
- **人生に他人を置く（2026-11-23 決定）**: 「周りの関係者」（幼なじみ・師・ライバル・伴侶・子など
  数人）と「歴史上有名な人」（信長・秀吉・家康など）の両方を登場させる。
  選択が人との関係に効き、最後に「あの人は…」と振り返れる。有名人とは一庶民として出会う。
  生まれた年・国で、出会える有名人が決まる。
- **歴史はあなたの選択で変わる（2026-11-23 決定）**: 有名人も世界も、史実どおりに固定しない。
  史実の主要な出来事（桶狭間・本能寺など）を**分岐点**として持ち、プレイヤーの選択が
  一定以上効くとその後の世界が別の流れになる。いまの乱数だけの勢力争いは、
  「史実を土台にした争い」に置き換える。台本は史実どおりの世界と変わった世界の両方で
  出る場面が要り、量が増える。
- **結果の見せ方（2026-11-23 決定）**: 事前に**匂わせるだけ**。数字（成功率）は見せない。
  例:「先陣は名を上げるが、命を落とす者も多い」。失敗しても「自分の選択のせい」と思えるように。
  いまの下剋上の成功率表示は、この方針に合わせて廃止する。
  運の要素はゼロにしない（生まれが運なので、そこと対比する）。
- **生まれの引き方（2026-11-23 決定）**: **自由に引くだけ**。「今日の籤」（全員同じ生まれ）は
  入れない。出発点を揃えて比べる仕掛けはなし。
- **台本の量**: 毎回違う人生に感じさせるには、全体で300場面以上のプールが要る
  （身分・年齢・これまでの選択で出る場面が変わる）。道ごとに厚みを変える（波乱の道ほど厚く）。
  **岐路の数・章の数は設定値**にして作り、長さは試作を遊んでから決める（5分→30分→1時間と
  考えが動いたため）。まず幼少・青年の2章だけ作って手触りを見る。
- **売り方（未決定）**: 無料＋広告＋広告を消す課金が合う見込み。goso-boat の
  「人のやる回数を減らすものは入れない」「答えは見せない」を、この作品にどう当てるかは
  課金を入れる前に決める（例: 広告で別の道の結末を覗けるようにするか）。

## 決まっていること

- **出す先は iOS だけ**（`flutter create --platforms=ios`）。向きは縦のみ。
- 日本語のみ（l10n なし）。書体は iOS 標準の明朝にフォールバックさせている。
- **収益の形は未決定。** 広告・課金（`google_mobile_ads` / `in_app_purchase`）は
  **まだ入れていない**。入れるときはユーザーの決定を取り、先に
  `docs/app-pitfalls.md` を読む（払ったのに届かない／広告の期限切れ ほか）。
- 商品名・バンドルID（今は仮の `com.namiki.ranse`）・ストア掲載文・公開名義は
  **ユーザー決定待ち**。外向きの文字列は `docs/public-identity.md` が正。

## 幼少期の作り（2026-11-23 試作）

- **1年ごとに「今年の重点」を4択から選ぶ**（ユーザー指示 2026-11-23）。5〜14歳の10年で、
  重点の選択は10回。年の途中で、その年齢で起こりうる岐路が確率で出る（一生に6つほど。
  `Game._yearScene`）。幼少期の選択は合わせて16回ほど。
- 重点の選択回数は `Life.focus` に積まれ、**次に出る岐路の重み**に効く
  （学んだ子には旅の師、友と過ごした子には幼なじみ、が出やすい）。
  質問の文は歳ごとに変え、縁のある人（幼なじみ）がいれば一言添える（`childYearText`）。
- 岐路（`SceneDef`）は一生に一度ずつ（`scene:<id>` の旗で管理）。選択肢（`Choice.h`）は
  **結果を匂わせる一言（hint）を必ず持ち、数字は出さない**（テストで確かめている）。
- 選んだ道は `Life.flags`（のちの章で効く印）・`Life.people`（幼なじみ・師・若殿など、
  縁のある人。絆つき）・`Life.path`（結果カードに載る一行ずつ）に残る。
- 歴史上の人物（尾張の吉法師、越後の寺の少年）は **史実の年代にだけ**出る
  （`SceneDef.ageOk`。テストで年を確かめている）。
- 保存は**年の始まり**で行う（岐路の最中は選択肢が関数を抱えるので保存できない）。
  再開すると、その年を最初からやり直す。

## 大人の作り（2026-11-23、ユーザー指示「一年毎に何を重点的にやるか決める」）

- **大人も1年ごとに「今年の重点」を選ぶ**。半年ごとの行動ボタン（旧 `actions.dart`）と
  旧来の出来事（旧 `events.dart`）は廃止し、すべて `adult.dart` の重点と岐路に置き換えた。
- 重点の選択肢は身分で変わる: 身分なし（仕官の口を探す・働く・鍛える・学ぶ…）／
  主家に仕える身（主君に尽くす・戦に備える・…）／一国の主（領国を富ませる・軍備・版図を広げる）／
  仏門（修行・説いて回る）。未婚なら「妻を探す／嫁ぎ先を探す」も出る。
- **重点によっては、その年に必ず岐路が起きる**（`FocusDef.forced`）:
  仕官の口を探す→仕官、戦に備える→出陣（初陣がまだなら初陣）、版図を広げる→侵攻、
  妻を探す→縁談。それ以外の年は、半分ほどの確率で岐路が一つ起きる。
- 1年の暮らし（収支・世の動き・昇進・家族・寿命・天下）は、半年ぶん（`_halfYearUpkeep`）を
  2回進める。
- **青年の章（15〜29歳）の岐路で、幼少期の選択が効く**: 幼なじみとの再会（絆の深さで
  「共に道を歩む」か「好敵手」になる）、師との再会（推挙状→仕官しやすくなる／出家して仏門へ）、
  信長・景虎との再会（幼い日に会っていれば、史実の年代で仕える道が開く）、初陣。
- 下剋上・侵攻・仕官の成否も、数字は出さず匂わせるだけ（「機は熟している」「五分の戦い」など）。
- 岐路は `repeat`（何度でも。合戦・疫病など）と一生に一度のものがある。
  `onlyForced` は重点で選んだときにしか起きない（仕官・侵攻）。
- 画面: 選択肢は**行動タブ（「岐路」）の先頭に出し、画面を覆わない**。選んでいる最中も
  人物・天下・見聞録のタブを見られる（選択待ちのときは岐路タブに印が付く）。

## 道と死に方（2026-11-23、ユーザー指示「ふやす」）

最期1000本の分け目（道×死に方）を、ゲームの中で記録する。
- **死に方**: `Game.die(cause, kind)` で8種（`kDeathKinds`: 天寿・病・戦死・切腹や処刑・暗殺・災いや事故・
  飢え・行方知れず）のどれかを `Life.deathKind` に残す（保存にも入る）。
- **道**: `lifeWay(Life)` が10の道（`kWays`）のどれかを返す。判定順は 幼くして（15歳前）→天下人→
  仏門→女の道（女で身分を得た／女城主）→大名→城主・家老→足軽・侍→商い（`way_merchant`）→
  忍び・流れ者・野盗（`way_outlaw`・`wanderer`・忍びの子）→商人の子→村の暮らし。
- **道の重点**: 商い（商いを広げる・仕入れの旅→必ず「仕入れの旅」）、野（獲物を狙う→「獲物」、
  国をまたいで流れる→「旅路」）、隠居（子や孫と過ごす・書と歌・旧知を訪ねる）。
- **足した岐路（`ways.dart`、約45）**: 道に入る（商いの誘い・野盗の頭・旅の空・晩年の出家）／商い（座・
  南蛮の品・御用の話・店が火に・茶の湯で千宗易・店の跡目）／野（山狩り・刺客の依頼・抜け忍と追手・
  旅路・足を洗う）／仏門（住持・一向一揆・比叡山1571・南蛮の教え・弟子・遊行）／村（庄屋・水争い・
  新田・職人の工房・大水）／壮年と晩年（子の門出・隠居・旧友の死・孫・老いての出陣・老いの病・辞世・
  大地震1586）／非業の死（主君の怒りで切腹・刺客・籠城・毒）／女の道（人質・留守の城＝女城主・奥の争い）／
  史実（桶狭間1560・本能寺1582）。桶狭間で義元を守る・本能寺で信長を救うと `history_*` の旗が立つ
  （「幻の最期」の種。その後の年表が変わる。下の「史実」）。
- 隠居した人（`retired`、`Game.active` が偽）には、家中の務めや合戦の岐路は出ない。

## 史実（2026-11-23、ユーザー「史実が少ないね」）

- **世の動きは史実の年表で進む**（`history.dart` の `kHistory`。1541 信玄の家督〜1600 関ヶ原の約35件）。
  毎年の暮らし（`_halfYearUpkeep`）で `applyHistory` が、その年までの出来事を起こし【世】として見聞録に書く。
  勢力が滅ぶのは**年表とプレイヤーの侵攻だけ**（斎藤1567・六角1568・今川1569・朝倉浅井1573・武田1582・
  蘆名1589・北条1590 など）。乱数の小競り合いは領地を少し削り合うだけになった。
  幼いうちの出来事は、元服のときに見聞録に書かずに進める。
- **プレイヤーが当主の家は、年表で滅びも削られもしない**（あなたが歴史を変えている）。
  桶狭間・本能寺で史実を変えると（`history_okehazama` / `history_honnoji`）、その後の年表が別の文になり、
  勢力も別の動きをする（今川が残る、信長が生きて天下を取る、など）。山崎・関ヶ原にも `history_*` の旗がある。
- **史実の岐路**（`h_` で始まる id と、桶狭間・本能寺・比叡山・大地震）は、その年に条件が合えば
  **必ず出る**（重点で決まった岐路のあとにも、順に出る。`Game._historyScenes`）。
  - 合戦（その家に仕える者）: 川中島・姉川・三方ヶ原（家康の身代わり）・小谷城（お市と三姉妹）・長篠・耳川・
    天目山・山崎（光秀につくと稀に歴史が変わる）・賤ヶ岳・小田原評定・朝鮮出兵・関ヶ原（誰でも）。
  - 人との出会い: 木下藤吉郎（尾張・美濃）→のちの秀吉に仕える、人質の竹千代（駿河・三河）→のちの家康に仕える、
    ザビエル、伊達政宗、山中鹿介、千利休の最期、太閤の死。
  - 暮らしに届く史実: 鉄砲伝来・信玄堤・敵に塩を送る・一領具足・上洛の行列・楽市楽座・安土城の普請・
    長島と越前の一向一揆・太閤検地・刀狩・身分を定める令・伴天連追放・二十六人の殉教。
- **2026-11-23 に増やした（ユーザー「まだ少ない」）**: 年表を約35→67件（河越夜戦・永禄の変・御館の乱・
  鳥取城・高松城・天正壬午の乱・北野大茶湯・江戸入り ほか）。史実の岐路を約35→約145
  （東国33・西国33・子ども17・女商人僧16・子どもの噂10）。22の国すべてに史実の岐路がある。
  **幼少期も、その年の史実の岐路は数の上限や確率に関係なく必ず出る**（`Game._yearScene`）。
  同じ出来事を別の目で描いた岐路の組（北野大茶湯・堺の矢銭・長崎・府内の病院・遣欧使節・石山・寿桂尼・恵林寺）は、
  片方が出たらもう片方は出ない（`history.dart` の `_twinPairs`、`Game._twinDone`）。
- 実測（2000人生・ランダムな選択）: 成人した人生が出会う史実の岐路は**平均3.4**（90%点7）、
  一度も出会わない人生は12%（早く亡くなる人生が多い）。子ども（5歳以上まで生きた人生）が出会う史実は**平均2.0**、
  出会わない子は12%。世の出来事の知らせは成人した人生で中央25件。出た史実の岐路は138種類。
- 担当（サブエージェント）が「史実として自信がない」と挙げた点: 信秀の死（1551/52）、墨俣一夜城、
  長浜の地子免除の年、高松城の追撃論、桶狭間で村人が今川の陣に酒を運んだ話、北野大茶湯の席の数、
  政宗の白装束の年、恵林寺の僧の数 など。本文では「〜と伝わる」「〜と語られる」に寄せてある。

## 歴史が変わった世（世界線、2026-11-23）

- `history_lines.dart` の `worldLine(g)` が今の世を返す: 史実どおり（real）／今川義元が生き延びた世（imagawa、
  桶狭間）／信長が生き延びた世（nobunaga、本能寺）／明智光秀が天下を取った世（akechi、山崎）／西軍が勝った世（west、関ヶ原）。
- 世界線ごとに、**起きない史実の出来事**（`kSkipEvents`）と**出ない史実の岐路**（`kSkipScenes`。秀吉の天下を前提にした
  岐路など）を決め、**その世だけの出来事**（`kAltHistory`、`HistEvent.only`。今川の上洛・義元の死・信長の大坂城・
  南蛮への船団・光秀の征夷大将軍・四つに割れた天下 など約23件）と**その世だけの岐路**（`h_x_`。織田の遺児をかくまう・
  信長の褒美・光秀の政・播磨の戦 など）を置いた。
- **分岐点**: 家臣として（桶狭間で義元を守る・本能寺で信長を救う・山崎で光秀につく・関ヶ原で西軍につく）に加え、
  **庶民も**（尾張・三河で桶狭間の奇襲を今川に知らせる／京で本能寺へ走る／天王山で秀吉の軍に偽りの道を教える）。
  どれも成功は稀。実測（5000人生・ランダム）で、変わった世に入る人生は約0.8%（約120人に1人）。「幻の最期」の種。
- 天下のタブに「今の世」が出る（史実どおりでないとき）。
- テスト: 表に書いた id がすべて実在する／変わった世では表の岐路が出ず、その世だけの出来事が起き、今川の世では織田が1561年に滅ぶ。

## 作りの約束

- 乱数は必ず `Rng`（`lib/engine/rng.dart`）を通す。種を固定して同じ人生を再現できる。
- 1手番 = 1年（幼少期も大人も）。`Life.t` は半年の数で、`age = t ~/ 2`。年の始まりは `t` が偶数。
- 選択肢（`Prompt`）は関数を抱えるので**保存できない**。保存は選択肢が出ていない区切り
  （`Game.changed()` の `onCheckpoint`）でだけ行う。終わった人生は保存を消す。
- 選択肢の関数が返した文字列は見聞録に書かれる。場面は `ask(..., after: next)` で、
  選んだあとに年の続き（`_endYear` / `_endAdultYear`）へ進む。
- 女性の道（奉公→家政→嫁ぐ→後見）は、合戦・下剋上を出さない代わりに別の昇進路を持つ。
  女武者の特性を持つ人と当主（位8）だけは戦える（`Game.canFight`）。

## 画面の確かめ方（Windows で iOS を動かせないため）

リポジトリの外（作業用の一時フォルダ）に `lib/` と `pubspec.*` を写し、そこで
`flutter create --platforms=web --project-name ranse .` → `flutter build web --release` → `build/web` を
`python -m http.server` で配信して、ブラウザで幅390の縦長にして見る。**リポジトリに web/ は入れない**（iOS だけのアプリ）。
Flutter の Web はキャンバス描画なので、押す位置は表示の座標どおりに。縮めて映すと押す位置がずれる。

2026-11-23 に見て直したこと: タイトルと生まれの画面の文の1語だけの折り返し／子どもの身分名が「下級武士の子の子」になる／
選んだ結果が画面に出ない（→ 選択肢カードの上に「前の選択の結果」を出す。`Game.lastResults`）／
子どものうちに年表が進まず天下のタブが古い（→ 幼少期も毎年 `applyHistory`。その年より前の出来事は書かずに進める）。

## 結末と結果カード（2026-11-23、品質改善ループ1回目）

- `lib/engine/ending.dart` の `buildEnding(g)` が結末を作る。最期1000本を書くまでの土台で、
  **称号 = 幸福の前置き（穏やかな最期だけ。満ち足りて／苦しみの果てに／孤独に）＋死に方の言い方＋道の呼び名**
  （例「戦場に散った足軽」「満ち足りて天寿をまっとうした百姓」「刃に斃れた女商人」）。
  死に方の言い方は死因の文でも変える（お産→「お産で命を落とした」、合戦でない刃→「刃に斃れた」）。
  歴史を変えた人生・賤民からの天下人などには特別な称号。
- 最期の文 = 年と歳と死因＋最期の場にいた人（連れ合いがいれば連れ合い。いなければ絆の深い順に子・幼なじみ・弟子・主君・師・好敵手）＋幸福の一行＋変わった世の名。
- 画面確認では、一時フォルダの Web 版の `main.dart` だけを `?auto=<種>&minage=<歳>` で最後まで自動で選ぶ形に差し替えて、終わりの画面を見ている（リポジトリには入れない）。
- 結果カード（終わりの画面の上）: 生まれの稀少度・国と身分と名・選んだ道3〜4行（`pickHighlights`: 初めと終わりと、
  有名人や歴史の絡む行を優先）・称号・道と死に方・最期の文。「結果を写す」でSNSに貼る文をクリップボードへ写す
  （共有シートは使っていない。`share_plus` を入れるかは未決定）。
- 1000本を書いたら、`buildEnding` がまず手書きの最期を探し、なければこの組み立てに落ちる形にする。
