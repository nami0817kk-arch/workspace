# kdp-novel

Kindle（KDP）で小説を出すプロジェクト（収益化プラン 方式5 から 2026-09-26 に派生）。
**話の筋はユーザー、文章と組版は Claude** の分担。

## 型（2026-09-26 に amazon.co.jp で確認）

- 個人の作品が Kindle の上位を取れているのは**異世界恋愛（婚約破棄・追放・ざまぁ）**。ロマンスの上位60作中56作が個人
- 上位の個人作家の出し方: **読み放題（KDP セレクト）**、値段 400〜800 円、同じ主人公のシリーズを
  自分の文庫レーベル名で、数日〜2週間おきに出す
- 印税: KDP セレクトに入れて 250〜1,650 円（税込）なら 70%。読み放題は読まれたページ数で分配（単価は非公開）
- **文章を Claude が書くので、KDP の「AI 生成コンテンツ」の申告は「はい」**。申告すれば出せる（禁止ではない）
- 同じ型の繰り返し・中身の使い回しは KDP の品質ガイドで削除されうる。**筋で差をつける**のがユーザーの持ち分

## 進め方

1. ユーザーが筋を出す（下の「筋の出し方」）
2. Claude が章立てを出し、ユーザーが直す
3. Claude が本文を書く → ユーザーが読む → 直す
4. `python src/build_epub.py books/<slug>` で縦書き EPUB を組み、Kindle Previewer で見る
5. 表紙（1600 x 2560 px の JPG）は**文字だけのデザインをプログラムで作る**（絵は使わない。2026-09-26 ユーザー決定）
6. KDP の登録・出版はユーザー

## 筋の出し方（短くてよい）

- 主人公は誰か（立場・性格）
- 何をされるか／何が起きるか（始まりの事件）
- どう逆転するか（主人公の強み）
- どう終わるか
- 入れたい場面・言わせたい台詞があれば

## やめる基準

3作出して、どれも発売から1か月で Kindle ストア 1万位に入らなければ、この路線はやめる（案。ユーザーの確認待ち）。

## 原稿の書き方

`books/<slug>/book.json`（題名・著者名・シリーズ名）と、章ごとの `NN-*.txt`。
1行目は `# 章題`、段落は空行で区切る。ルビは `|漢字《かんじ》`、場面転換は `* * *`。
