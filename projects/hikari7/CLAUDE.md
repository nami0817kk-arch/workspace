# ひかりの七席（hikari7）

オーディション番組のプロデューサーになり、練習生の中からデビューメンバーを自分で選ぶ1人用ゲーム（仮題）。
本番は **iOS アプリ**（無料＋広告＋広告を消す買い切り、護送ボートと同じ形）。

**作り（2026-10-02 ユーザー選択「試作を中に組み込む」）**: アプリの外側（広告・課金・保存・ストア対応）は Flutter、
ゲーム本体は `prototype/game.html` をそのまま WebView で動かす。Web のテスト版とアプリは同じ1つのゲーム本体を使うので、
**ゲームの直しは game.html だけ**で両方に効く。アプリとゲームのやりとりは `app/lib/game/bridge.dart`（JS 側は `HStore`・`withAd`・`appPost`）。

## 置き場所

| 場所 | 中身 |
|---|---|
| `prototype/game.html` | 試作の本体（v11）。顔の絵は入っていない（`FACEDATA` の区間は仮の値） |
| `prototype/faces/` | 顔の絵（126×162）と `pool.json`（男女・同じ顔の組 `group`）。1シーズンに同じ組は1人まで |
| `tool/build_web_test.py` | 本体と顔を1枚のページに組み立て、`build/web/` に出す |
| `tool/sim.js` | エンジンを自動で通しプレイして、つり合いを測る（遊び方3通り×男女）。`--quick` は CI 用 |
| `tool/build_app_web.py` | アプリに入れるゲーム本体を組み立てる（`app/assets/web/index.html`。顔の絵と見出し書体を埋め込み、外へ何も読みに行かない） |
| `app/` | iOS アプリの外側（Flutter）。広告・課金は護送ボートの `lib/monetization` を写したもの。商品ID `hikari7_remove_ads`、Bundle ID `com.namiki.hikari7` |
| `legal/` `site/` | プライバシーポリシー・サポート・利用規約と、公開ページの入口・app-ads.txt。`hikari7-site.yml` が https://hikari7.pages.dev/ に出す（アプリのリンクと App Store の URL 欄はここを指す） |
| `docs/RELEASE.md` | TestFlight と App Store への出し方（護送ボートの手順を写したもの）。リリースは `hikari7-ios-release.yml` |
| `tool/make_icon.py` | アプリアイコンを描く（7つの椅子・真ん中が金色） |
| `fonts/` | 見出し書体 Dela Gothic One（OFL）。使う字だけに絞って埋め込む |
| `web-test/` | テスト用Web版に添える `_headers`・`robots.txt` |

試作の経緯（v3〜v8 の各版・設計ページ）は、公開リポジトリの外の `C:\Users\なみ\dev\game-assets\hikari7\README.md` にある。

## テスト用Web版（2026-10-01 ユーザー選択）

護送ボートの goso-boat-test と同じ形。master に入ると `.github/workflows/hikari7-web-test.yml` が
Cloudflare Pages の `hikari7-test` に出す。**検索に出さない**（meta robots・`_headers`・`robots.txt`）、
画面に「テスト版」の札、どこからもリンクしない。Web版を宣伝・収益化の入口にしない。

## つり合いの目安（2026-10-02 v11、tool/sim.js・ふつう・男女各200シーズン）

| 遊び方 | 平均 | 評価 |
|---|---|---|
| 何も考えない（naive） | 63点 | ほぼ B |
| でたらめ（random） | 69点 | A が5〜6割、B が4割 |
| よく考える（good） | 79点 | A が5割強、S が4割強 |

`DIFF=easy` / `DIFF=hard` で難易度ごとにも回せる（きびしいで good 74点・S 2割）。
数字を動かしたら回し直し、この差が縮んでいないかを見る。

## 決まっていること（ユーザー決定）

- iOS のみ。無料＋広告（報酬型動画中心）＋「広告を消す」買い切り。月額・ガチャなし
- 男性グループ・女性グループをシーズンの始めに選べる。仕組みは男女共通
- 合格者はプレイヤーが一人ずつ決める。視聴者投票で順位・脱落が決まる方式は却下済み
- レッスンは全員が1つずつ受け、特訓（2つめ）だけ人数を絞る（2026-10-02 指摘「練習枠が全員選択できない・一人二つと矛盾」）
- チーム課題は、チームごとに曲（コンセプト）とセンターを決める（2026-10-02 ユーザー指示）
- 文字と背景のコントラストは4.5以上を保つ（2026-10-02 指摘「読めないところがある」）
- **選択肢には必ず代償か、裏目に出る可能性を持たせる**（2026-09-30 指摘「選択に上昇しかないのが気になる」）
- 実在の番組名・呼び名・人物・事務所・グループ名は使わない（App Store 5.2.1）。見た目で順位を決める描き方はしない。未成年もいるので恋愛・重い不幸は扱わない
- 公開名義は「つるはし社」。本名・nami・0817 は公開する文面に出さない
- 顔の絵はユーザーが Gemini アプリ（無料）で作る。実在の人物名・既存キャラ名をプロンプトに入れない
